# HARDENING LOG — statwise (그룹 비교 통계 자동 선택기)

이 파일은 배포 전, 도구를 무인(無人)으로 **깊이 개선하고 하드닝**한 기록입니다.
먼저 임상·제약 연구자가 실제로 필요로 하는 기능을 새로 구현(모두 표준 라이브러리)하고,
그 다음 Agent 도구로 **독립적인 적대적 검토자 패널을 병렬로** 여러 라운드 소환해 각자
우선순위가 매겨진 구체적·재현가능한 결함 목록(파일:줄, 깨뜨리는 입력)을 받았습니다.
매 라운드마다 제작자(메인 루프)가 모든 material 결함을 고치고 `python3 -m pytest`를
초록으로 되돌린 뒤 다음 라운드를 시작했습니다.

검증 기준선: 모든 p값·통계량을 SciPy 1.17 / statsmodels / (Welch-ANOVA는 pingouin·R
`oneway.test`)와 대조 — 정확 순열분포·근사분포 모두 ≤1e-9 수준 일치.

### 2부. 하드닝 — 독립 패널 5개 병렬 (라운드 1)

정확성 재계산 / 엣지케이스 / 임상 타당성 / 문서 정직성 / 테스트품질·보안 패널을
동시에 소환했습니다. 아래는 **고친 것만** 적었습니다.

**치명적 수치 결함 3건 (전부 SciPy 대조로 확인·수정).**
- `special.gammainc_upper` 가 `1 − gammainc_lower` 로 계산돼 **꼬리를 통째로 소거**
  했습니다. `_gcf` 가 이미 Q(a,x)를 정확히 계산해 두고 `1−(1−Q)` 로 버린 것 —
  카이제곱 p=4.2e-29 가 **정확히 0.0** 으로 출력됐습니다. 직접 반환하도록 수정.
- 같은 이유로 `equivalence` 의 상단 꼬리 `1 − t_cdf(t, df)` 가 붕괴. TOST에서
  구속력 있는 `p_low` 가 0으로 죽고 **비구속 `p_high` 가 보고**되어, 참값 3.05e-21 인
  p가 **1.03e-88 로 3e+67배 틀리게** 나왔습니다. 새 `special.t_sf` 로 교체.

  SciPy 대비 최대 상대오차 5.3e-11, 속도는 2배 이상 개선.

**다중 엔드포인트가 자기 결론과 모순되던 문제.** `_adjust_across` 가 `pvalue_adj` 만
설정하고 `significant` 는 **원래 p값 기준으로 남겨 둬서**, 요약표는 "유의하지 않음"
인데 같은 실행의 상세 리포트·JSON·CSV는 `"significant": true` 를 주장했습니다
(Holm 보정 후 p=0.19 인 엔드포인트가 CSV 한 줄에서 `pvalue_adj=0.19, significant=yes`).
보정 후 p로 유의성을 다시 판정하고, 판정이 뒤집힌 엔드포인트에는 경고를 답니다.

**부호가 조용히 뒤집히던 경로.**
- `--paired --wide` 에서 `--columns` 없이 `--baseline` 을 주면 **무시**되어 부호가
  요청과 반대로 나왔습니다(`+7.000` vs `−7.000`). 열 목록을 파일 헤더에서 얻는
  경우까지 포함하도록 `load_paired_wide` 안으로 옮겨 해결.
- **비대칭 등가 마진**(`low,high`)은 CSV 행 순서만 바뀌어도 "등가 성립 ↔ 미입증"이
  뒤집혔습니다. 이제 `--reference`/`--baseline` 없이는 **거부**합니다.
- `--reference` 를 `--paired` 에, `--baseline` 을 독립 비교에 주면 조용히 무시됐습니다
  → 명시적 오류. `--event-value`/`--events-col`/`--n-col`/`--event-is` 를 `--binary`
  없이, `--brief` 를 `--values` 없이 준 경우도 마찬가지.

**임상 해석을 뒤집는 라벨.**
- **NNT가 NNH일 때도 NNT로 출력**됐습니다. 이상반응 엔드포인트에서 "NNT = 2.5"는
  정반대의 뜻입니다. 사건의 성격은 도구가 알 수 없으므로 `--event-is benefit|harm`
  을 추가하고, 미지정이면 `NNT/NNH (1/|위험차|)` 라는 중립 라벨을 씁니다.
- 비열등성 마진이 `--ni-direction` 에 따라 **음수로 인쇄**됐습니다("margin of -3.00").
  양의 크기 + 방향으로 바꾸고, 기각 기준선을 따로 표시합니다.
- 순위검정 RR/OR에서 `∞` 점추정값 옆에 유한한 신뢰구간이 찍히는 등, 자기 구간 밖의
  점추정값·NaN 주위의 구간을 정리했습니다.

**이진 결과의 0인 칸 판정 오류.** `risk_ratio` 가 **사건 칸만** 검사해서, 100% 반응
군(비사건 칸=0)은 Haldane 보정도 경고도 없이 **분산 0을 정상처럼** 취급한 구간을
받았습니다 — 바로 옆 오즈비는 경고를 띄우고 있었는데도. 네 칸 모두 검사하도록 수정.

**개인정보(PII) 노출 3건.** 이 도구는 환자 데이터 CSV를 읽습니다.
- `--value` 를 식별자 열에 잘못 지정하면(한 글자 실수) 오류 메시지가 **파일의 모든
  고유값을 그대로 출력**했습니다 — 그것도 한 메시지에 두 번. 새 `summarize_values`
  로 **최대 5개·30자 절단 + 나머지는 개수만** 표시하도록 전면 교체.
- 그 문자열이 `EndpointRun.error` 를 통해 **`--output` 으로 저장한 리포트 파일 안까지**
  들어갔습니다(동료에게 건네는 산출물). 길이 상한을 걸었습니다.
- `--output` 이 기존 파일을 **경고 없이 덮어썼고**(원본 CSV를 지목하면 원본 소실),
  심볼릭 링크를 따라갔으며, 0644로 생성됐습니다 → `O_EXCL`(+`--overwrite`),
  `O_NOFOLLOW`, `0600`.
- 부수적으로 `map_binary_levels` 가 리스트 멤버십으로 O(n²)라 16k 고유값에서 1.5초
  걸리던 것도 집합으로 교체.

**통계적 타당성 — 사전검정 조건부 선택의 대가를 공개.** 시뮬레이션 결과 n=(6,18),
SD=(3,1)에서 자동 선택의 1종 오류가 **0.106**(항상 Welch면 0.052)이었습니다. Levene의
검정력이 낮아 이분산을 놓치고 Student t를 고르기 때문입니다. 이제 (1) 자동 선택 시
**"자료에서 골랐습니다(사전 지정이 아님)"** 경고를 항상 출력하고, (2) `--test
student|welch|mannwhitney` 로 **SAP에 사전 지정한 검정을 그대로 실행**할 수 있습니다.
README에 이 트레이드오프를 수치와 함께 문서화했습니다.

**순위검정에서 p값과 신뢰구간이 갈리는 경우.** Hodges-Lehmann 구간은 정확 순위분포를
역산하는데 p값은 동점이 있으면 정규근사를 씁니다. 그래서 "유의함" 옆에 0을 포함하는
구간이 찍힐 수 있었고, README는 둘이 **항상** 일치한다고 단언했습니다. 이제 판정이
갈리면 **경고를 출력**하고, README의 주장은 "정확검정을 쓴 경우"로 정정했습니다.

**논문에 그대로 실릴 문장들.** `"survived Holm-corrected correction"`(중복),
`"median difference"`(실제로는 Hodges-Lehmann 유사중앙값 — 인용된 두 중앙값의 차와
달라 보여 계산 오류처럼 읽힘), `"showed a non-significant effect"`(효과의 존재를
단정), 2×2 이진 문장에 χ² 통계량 누락, 모든 구간의 신뢰수준이 `--alpha` 를 따르지
않고 95%로 고정(같은 화면에 99% CI와 95% CI가 공존) — 전부 수정.

**CSV 결과표 구조.** k군 omnibus에서 3번째 이후 군의 n이 **조용히 사라졌고**,
TOST 행은 omnibus 행과 **다른 신뢰수준**의 값을 같은 열에 넣으면서 `significant` 의
의미까지 달랐습니다(= "등가 성립"). `n_all`·`ci_conf`·`verdict` 열을 추가해 해소.

**테스트 품질 — 뮤테이션 51건 중 23건이 살아남았습니다.** 가장 심각한 것들:
`--event-value` 의 사건/비사건 집합을 **뒤바꿔도 297개 테스트가 전부 통과**(80% vs
30% 반응률이 20% vs 70%로 뒤집히는데도), 이진 사후검정의 다중비교 보정을 **통째로
삭제해도 통과**, 모든 신뢰구간의 **폭**이 검증되지 않음(alpha/2→alpha 뮤테이션 4건
생존), 리포트는 섹션 제목 존재만 확인해 `_pct` 의 ×100을 빼거나 부호를 버려도 통과.
새 `tests/test_mutation_guards.py` 로 이 계열을 값 수준에서 고정하고, CLI 미커버
표면(`--correction`, `--binary --wide`, `--values --binary`, 이진/다중 CSV,
`--paired --wide --columns`, 상세 모드, `-o` 재사용)을 채웠습니다.

**문서 정직성.** README의 인용 출력 블록들이 옛 실행에서 복사돼 있었습니다 — 특히
**대응표본 예제의 부호가 전부 반대**(부호 주의 안내 박스 바로 아래에서), 사후검정
예제가 실제로는 Student t인데 Welch t라고 표기, min/max가 실제 파일에 없는 값,
Fisher 자동 선택 규칙을 2×2 한정이라는 조건 없이 단언. 전부 실제 출력과 대조해
정정하고, 문서화되지 않았던 동작(`62.5%` → 62.5, 인코딩 폴백, NA 어휘, 이진 라벨
어휘, 종료 코드 2, Python API, JSON 전용 필드)을 README에 명시했습니다.
`실행.command` 는 EOF에서 종료코드 1을 내던 것을 고치고 새 예제 3개를 추가했습니다.

**검증 기준선.** 새 통계는 전부 외부 참조와 대조했습니다 — Fisher 정확검정
(무작위 3000표 + 전수 6561표, 최대 1.5e-12), Pearson/Yates 카이제곱(4.3e-16),
Wilson(전수, 4.4e-16), Newcombe 위험차(3000표, 4.4e-16), Katz 위험비·Woolf 오즈비
(2.8e-15), Holm/BH(20000 패밀리, 정확 일치), TOST(statsmodels `ttost_ind`/
`ttost_paired`), `norm_ppf`(9.6e-16). 테스트는 참조값을 하드코딩해 **SciPy 없이도**
동작합니다.

### 3부. 하드닝 라운드 2 — 4개 패널 병렬

라운드 1의 수정을 **검증하는 것부터** 시킨 패널입니다. 라운드 1에서 내가 새로 넣은
줄 하나가 그 자체로 틀렸다는 것이 첫 번째 발견이었습니다.

**라운드 1이 심어 놓은 결함.** 비열등성 섹션에 추가한 "기각 기준선: 평균차 > −5" 는
**틀린 기준**입니다. 비열등성은 점추정값이 아니라 **단측 신뢰한계**로 판정하므로,
평균차 −1.25(> −5)인데 결론은 "미입증"이 되어 리포트가 6줄 안에서 자기모순을
일으켰습니다. 신뢰한계 기준으로 정정.

**치명적 성능 결함 2건 (실사용 파일이 멈춘 것처럼 보임).**
- `levene` 이 `_median(g)` 을, `one_way_anova` 가 `mean(g)` 을 **원소마다 다시**
  계산해 O(n²)이었습니다. 20만 행에서 **약 50분**(50k에서 194초). 기본 분석 경로라
  모든 연속형 실행이 영향을 받았습니다. 루프 밖으로 끌어내 **0.04초**.
- 정확 Mann-Whitney 분포표를 **쌍마다 새로 만들어** 500군 사후검정이 24분. `lru_cache`
  + 불변 튜플 반환으로 **0.07초**.

**조용히 틀린 숫자 2건.**
- `text.splitlines()` 로 잘라 `csv.reader` 에 넘겨서, **따옴표 안의 줄바꿈이 사라지고**
  `"1\n2"` 가 숫자 **12** 가 됐습니다. `parse_float` 의 엄격한 문법이 막으려던 바로 그
  실패를 상류에서 우회한 것. `io.StringIO` 로 교체.
- `--columns a,a` 가 **같은 열을 두 군으로** 분석해 df와 p를 모두 틀리게 만들고
  "pre vs pre" 논문 문장까지 출력했습니다(헤더 중복은 이미 거부하고 있었는데도). 거부.

**극단적 크기에서 traceback / NaN 리포트.** |값| ≳ 1e155에서 `OverflowError`,
≲ 1e-162에서 `ZeroDivisionError` 가 **CLI 밖으로 그대로 튀어나왔습니다**(rc=1).
1.5e308에서는 더 나빠서, `W=NaN → "정규분포로 볼 수 있음"` → `p=nan` → **"유의하지
않음"** 이라는 완전히 NaN 위에 세워진 리포트를 자신 있게 출력했습니다. `variance`·
`shapiro_wilk`·`one_way_anova` 를 전부 **스케일 불변**으로 재작성(SciPy 대비 1.7e-13
유지)하고, 그래도 NaN이면 **해석 불가 경고**를 답니다.

**1e6 이상에서 기술통계 표가 붕괴.** `f"{x:.3f}"` 를 고정폭 9/10칸에 넣어서, 값이
100만만 넘어도 n·mean·median·Q1·Q3·min·max가 **한 덩어리 숫자열로 융합**됐습니다.
원화 금액·리드 카운트·CFU/mL 모두 여기 해당합니다. 열 너비를 내용에 맞춰 계산하고,
16자를 넘으면 표 전체를 지수표기로 전환.

**다중 엔드포인트가 자기 결론과 계속 모순.** 라운드 1에서 `significant` 는 고쳤지만
**옆에 인쇄되는 p값은 여전히 보정 전 값**이라 `유의하지 않음 (p<0.05)` 라는 문장이
나왔고, 논문 문장도 `not statistically significant (p = 0.020)` 이었습니다. 이제
보정 전/후 p를 모두 표기하고, 문장에도 보정 사실을 명시하며, 강등된 엔드포인트의
사후검정 표에는 **탐색적 결과라는 경고**를 답니다. 요약표에도 철회 목록을 추가.

**`--values` 가 `--test`/`--event-is` 를 조용히 버림.** SAP에 Welch를 사전 지정하고
`--values` 로 돌리면 **전 엔드포인트가 Student t** 로 계산되는데 아무 표시가 없었고,
`--event-is harm` 도 무시돼 안전성 표에서 NNH가 NNT로 남았습니다. 둘 다 전달하도록 수정.

**단위가 다른 엔드포인트에 마진 하나.** `--values` + `--equivalence-margin 2` 는 ISI
2점과 RMSSD 2ms에 **같은 마진**을 적용해 등가 판정을 4개 찍어냈습니다. 조합 자체를 거부.

**`--ni-direction` 기본값 제거.** 기본 `higher_is_better` 상태에서 ISI(낮을수록 좋음)에
`--ni-margin` 만 주면 **반대쪽 꼬리를 검정**한 완성된 리포트가 나왔습니다. 이제 필수.

**등가 "미입증"이 두 가지 다른 상황을 뭉갬.** 신뢰구간이 마진 **밖에 완전히 있는**
적극적 비동등과, 경계를 걸친 **결론 불가**를 같은 문장으로 보고했습니다. 3분기 판정으로 분리.

**추가 수치 결함 (SciPy 대조).** `t_ppf` 가 p < 5.6e-17에서 `1-p` 반올림으로
**ValueError**, df=1의 1e-7 분위수에서 브래킷 상한 1e6에 **조용히 포화**(평균 CI가
6.4배 좁아짐), `_gser` 의 1000회 상한이 df=1e6에서 **16% 틀린 꼬리**. 전부 수정 —
`t_ppf` 는 실사용 신뢰수준 격자(α ≥ 0.001, df 1~1000)에서 최대 상대오차
**6.2e-13**, 중앙값 바로 옆(p≈0.49)이나 df=1e8 같은 극단 격자에서는 **9.1e-7**
— 정확도 보장은 앞의 범위에 대해서만 하는 것입니다. `chi2_sf(1e6,1e6)` 은 SciPy와 일치.

**이진 결과 잔여 결함.** `risk_ratio` 는 `NaN` 점추정값 옆에 **유한한 신뢰구간**을
출력했고(오즈비는 이미 고쳐져 있었는데), 위험차가 정확히 0일 때 `--event-is benefit`
이 **NNH** 라는 이름을 붙였습니다. 둘 다 수정.

**개인정보·안전.** `-o` 가 `--overwrite` 와 함께면 **입력 CSV 자체를 파괴**할 수
있었습니다(복구 불가). `samefile` 검사로 차단. 빈 문자열 플래그(`--equivalence-margin ""`)
가 요청한 분석을 **조용히 없애던** 것, `--ni-margin inf` 가 "유한해야 한다"는 검사를
통과하던 것, 여러 글자 `--delimiter` 가 `TypeError` 로 터지던 것, 128KB 넘는 셀이
`csv.Error` 로 터지던 것도 전부 정리.

**임상 보고 품질.** 사후검정 표에 **차이값과 신뢰구간이 아예 없었습니다**(p값과 표준화
효과크기만). 이제 평균차/Hodges-Lehmann 이동과 CI, 각 군 n을 함께 싣고, 논문 문장에도
n·평균차·CI·군별 요약을 넣었습니다. `등분산 가정 충족` → `등분산 위배 근거 없음`,
`정규분포로 볼 수 있음` → `정규성 위배 근거 없음 (n=..., 검정력 낮음)` 으로 **부재의
증거를 주장하지 않도록** 정정. 순위검정 문장의 `median difference` 는 두 중앙값의 차와

**자료 무결성 점검이 절반만 배선돼 있었습니다.** 라운드 2에서 만든 sentinel/이상치/

세 경로 모두에 배선하고 차이값까지 점검합니다.

**논문용 문장이 어떤 경고에도 막히지 않았습니다.** 기술통계에 `mean -13.986,
sd 168.910` 이 찍혀 명백히 오염된 자료에서도, 사용자가 실제로 복사하는 그 한 줄은

무엇을 고쳐야 하는지 나열합니다(초안이 필요하면 JSON에 남아 있습니다).

**논문 문장 결함.** 다중 엔드포인트 문장이 `not statistically significant (…, p = 0.020, …)`
라고 쓰고 마침표 없이 끝났습니다 — 이제 인라인 p를 `unadjusted p` 로 명시하고 보정
방법·패밀리 크기를 문장 안에 넣습니다. 이진 k군 문장은 **효과 추정값이 아예 없어**
쌍별 유의성만 나열했고(연속형은 라운드 2에서 이미 고친 부분), 이진 사후검정 표에는
위험차 신뢰구간이 없었습니다 — Newcombe 구간을 추가했습니다. `Hodges-Lehmann median
difference` 는 인용된 두 중앙값의 차(−4.95)와 실제값(−3.70)이 달라 계산 오류처럼
읽혀 `location shift (median of all paired between-group differences, ...)` 로
정정. Welch-ANOVA의 η² 주의는 한국어 경고에만 있고 **영어 문장에는 없었습니다**.
비동등이 입증된 경우의 문장이 근거로 `p = 0.985` 를 인용하던 것도 구간 기반으로 수정.
사후검정 표·CSV에 **부호 규약**(첫 그룹 − 둘째 그룹)을 명시.

**성능 회귀 (라운드 2가 만든 것).** 사후검정에 차이값 CI를 추가하면서 쌍마다 `t_ppf`

**라운드 3 정확성 패널 — 내가 라운드 2에 심은 회귀 2건.**

- `one_way_anova` 의 주석은 "F와 η²는 비율이므로 **스케일된** 제곱합에서 계산한다"고
  적어 놓고, 실제로는 **먼저 원래 단위로 복원한 뒤** 나눴습니다. 1e-158~1e-162 구간에서
  복원값이 비정규수(subnormal)가 되어 가수를 잃고, `F = inf, p = 0.0`(화면에는
  `p<0.001`)이 나왔습니다 — 참값은 `F = 14.38, p = 1.9e-07`. 수정 전 코드는
  `OverflowError` 를 던졌으니 **"조용히 확신에 찬 틀린 값"으로 바뀐 회귀**였습니다.
  이제 F와 p는 스케일된 값에서 만들고, 복원은 **정규수로 표현될 때만** 합니다.
- 같은 이유로 `ss_total = ss_between + ss_within` 이 각 항은 유한한데 합이 넘칠 수
  있어, `η² = x/inf = 0.000 "negligible"` 이 참값 `0.57 "large"` 자리에 인쇄됐습니다
  ("매우 유의하지만 효과크기는 무시할 만함"이 한 문단에). `effects.eta_squared` 에
  유한성 가드를 넣고, 복원 판정에 합까지 포함했습니다.

**사후검정의 신뢰구간과 별표가 서로 다른 기준.** 구간은 비교 1건 기준(α),
별표는 다중비교 보정 후 판정이라 **21,935행 중 11.7%가 서로 다른 결론**을 냈습니다 —
0을 배제하는 구간 옆에 별표가 없는 식으로. 논문 문장은 더 나빠서 비보정 구간과 보정
p를 한 절에 붙여 놨습니다(`"-2.09 (95% CI ...), adjusted p < 0.001"`). 열 이름을
`95% CI(비보정)` 으로 바꾸고, 동시신뢰구간이 아님을 범례에 명시하고, 두 판정이
어긋나는 비교는 **경고로 나열**합니다(2군 경로의 CI/p 불일치 경고와 같은 방식).

**뮤테이션 54건 중 24건 생존 — 그중 9건이 사후검정 차이값/구간 한 기능에 몰려
있었습니다.** 부호를 뒤집어도(치료가 해로워 보이게), 68% 구간을 "95% CI"로 인쇄해도,
Welch 표준오차의 n을 맞바꿔도(불균형 설계에서만 틀림), 순위검정에서 중앙값 차이를
Hodges-Lehmann이라고 이름 붙여도 517개 테스트가 전부 통과했습니다. 새

**비결정적 테스트 제거.** `test_many_groups_posthoc_completes` 의 20초 벽시계 단언이

### 무엇을 추가했나

무작위배정 임상시험에서 연속형 1차 평가변수의 **사전 지정된 1차 분석은 t-검정이 아니라

- `statwise/linalg.py` — Householder QR 최소제곱(순수 표준 라이브러리). 정규방정식이
  아닙니다: `X'X` 는 조건수를 제곱하고, ANCOVA 설계행렬은 1e2 규모의 기저값 열 옆에

  가정하는 대상에 대한 점검: **기울기 동질성**(그룹×공변량 상호작용 F), **잔차** 정규성,
  **잔차** 등분산. 2군이면 **보정된 평균차**에 TOST/비열등성도 붙습니다.
- `dataio.load_ancova_long` (완전자료 + 제외 행수 보고), `report.render_ancova_text/
  ancova_to_dict/render_ancova_json` + CSV(`ancova`/`adjusted-mean`/`adjusted-contrast`/

대비·기울기 동질성까지 **1e-13 수준**으로 일치합니다(참조값은 테스트에 고정).
