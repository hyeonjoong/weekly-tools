# 사용법 (빠른 시작)

## 가장 쉬운 방법
- 이 폴더의 **`실행.command` 더블클릭** → 예제 데이터(수면 디바이스 HRV 2그룹,
  용량별 ISI 변화 3그룹)로 결과가 바로 나옵니다.

## 내 데이터로 돌리기 (터미널)

먼저 한 번만 설치(선택):
```bash
cd ~/Downloads/02_프로젝트/깃헙/statwise-그룹비교통계
python3 -m pip install -e .
```

### 1) 값 열 + 그룹 열 형식 (long)
CSV가 이런 모양일 때:
```
rmssd_ms,arm
31.2,sham
44.5,device
...
```
```bash
statwise 내데이터.csv --value rmssd_ms --group arm
# 설치 안 했으면:
python3 -m statwise.cli 내데이터.csv --value rmssd_ms --group arm
```

### 2) 각 열이 그룹인 형식 (wide)
CSV가 이런 모양일 때 (열 하나 = 그룹 하나):
```
low,mid,high
3,6,9
5,8,11
...
```
```bash
statwise 내데이터.csv --wide
# 특정 열만: statwise 내데이터.csv --wide --columns low,high
```

## 결과 읽는 법
- **[2] 가정 점검**: Shapiro-Wilk(정규성), Levene(등분산). p가 크면 가정 충족.
- **[3] 선택된 검정**: 위 가정에 따라 자동으로 고른 검정 + 그 **근거**.
  - 2그룹: 정규+등분산 → Student t / 정규+이분산 → Welch t / 비정규 → Mann-Whitney
  - 3그룹↑: 정규+등분산 → ANOVA / 아니면 → Kruskal-Wallis (+ 사후검정)
- **[4] 효과크기**: Hedges' g / rank-biserial / η² / η²[H] (크기 판정 라벨 포함).
- **[논문용 문장]**: APA 스타일로 바로 복사해서 원고에 붙이세요.

## 자주 쓰는 옵션
- `--alpha 0.01` : 유의수준 바꾸기 (기본 0.05)
- `--no-posthoc` : 3그룹 이상에서 사후검정 생략
- `--columns a,b` : wide에서 비교할 열만 선택
