# 사용법 (빠른 시작)

## 가장 쉬운 방법
- 이 폴더의 **`실행.command` 더블클릭** → 예제 9가지가 순서대로 실행됩니다:
  HRV 2그룹(long), 용량별 ISI 3그룹(wide+사후검정), ISI 전/후 대응표본,
  반응자 비율(이진: RD·RR·OR·NNT), **반응자 전/후 대응 이진(McNemar)**,
  **신속검사 vs PCR 일치도(kappa)**, 등가성 검정(TOST), 엔드포인트 4개 동시 분석,
  기저값 보정 3군 비교(ANCOVA).

### 1) 값 열 + 그룹 열 형식 (long)
CSV가 이런 모양일 때:
```
rmssd_ms,arm
31.2,sham
44.5,device
...
```
```bash
statwise 내데이터.csv --value rmssd_ms --group arm
# 설치 안 했으면:
python3 -m statwise.cli 내데이터.csv --value rmssd_ms --group arm
```

### 2) 각 열이 그룹인 형식 (wide)
CSV가 이런 모양일 때 (열 하나 = 그룹 하나):
```
low,mid,high
3,6,9
5,8,11
...
```
```bash
statwise 내데이터.csv --wide
# 특정 열만: statwise 내데이터.csv --wide --columns low,high
```

### 3) 같은 대상의 전/후 비교 (대응표본 paired)
같은 환자를 치료 전(pre)·후(post)로 잰 경우처럼 **짝지어진** 데이터:
```
subject,time,isi
S01,pre,18
S01,post,12
...
```
```bash
statwise 내데이터.csv --paired --value isi --group time --id subject --baseline pre
# wide(두 열이 pre/post)라면: statwise 내데이터.csv --paired --wide --columns post,pre
```
→ 차이값의 정규성에 따라 **대응 t-검정** 또는 **Wilcoxon 부호순위검정**을 자동 선택.
→ 차이는 `(조건A − 조건B)` 이며 출력에 방향을 명시합니다. 부호를 고정하려면
   `--baseline 기준조건`(그 조건이 빼지는 기준)을 쓰세요. Wilcoxon이면 위치차의
   **Hodges-Lehmann 신뢰구간**도 함께 나옵니다.

### 4) 반응자/이상반응 같은 예-아니오 결과 (이진)
CSV가 이런 모양일 때:
```
subject,arm,responder
S001,sham,no
S002,device,yes
...
```
```bash
statwise 내데이터.csv --binary --value responder --group arm --reference sham
```
→ **반응률(Wilson 95% CI)**, 카이제곱 또는 **Fisher 정확검정**(두 군이고 기대빈도가
   5 미만이면 자동. 3군 이상은 Fisher를 못 쓰므로 k×2 카이제곱 + 경고),
   **위험차(RD)·위험비(RR)·오즈비(OR)·NNT** 를 신뢰구간과 함께 출력합니다.
   `--reference` 로 기준(대조)군을 정하면 RD/RR/OR 방향이 고정됩니다.
   `1/0`, `Y/N`, `yes/no`, `유/무` 는 자동 인식하며, **어떤 값을 '사건'으로 봤는지
   항상 출력**합니다. 자동 인식이 안 되면 `--event-value 반응` 처럼 직접 지정하세요.
   이미 세어 둔 표(`arm,responders,total`)라면
   `--events-col responders --n-col total --group arm`.

### 4-1) 같은 대상의 예-아니오 결과 (대응 이진 · McNemar)
같은 환자를 치료 전/후로 "반응자/비반응자"로 나눴거나, 같은 검체를
**두 가지 검사(또는 두 판독자)** 로 각각 양성/음성 판정한 경우입니다.
이때 `--binary` 만 쓰면 같은 사람을 서로 다른 두 사람처럼 세게 되어
**표본 수가 두 배가 되고 p값이 실제보다 작아집니다.** `--paired` 를 붙이세요.
```
subject,time,responder
S01,pre,N
S01,post,Y
...
```
```bash
statwise 내데이터.csv --binary --paired --value responder --group time \
    --id subject --baseline pre --event-is benefit
# wide(두 열이 검사A/검사B)라면:
statwise 내데이터.csv --binary --paired --wide --columns rapid_test,pcr
```
→ **짝지어진 2×2 표**(둘 다 사건 / 한쪽만 / 둘 다 비사건)를 먼저 보여 주고,
   **불일치(discordant) 쌍만** 쓰는 McNemar 검정을 실행합니다.
   불일치 쌍이 25개 미만이면 **정확 이항검정**, 그 이상이면 **McNemar 카이제곱**을
   자동 선택하며 근거를 출력합니다(`--binary-test exact|mcnemar|mcnemar-cc` 로 고정 가능).
→ 함께 나오는 값:
   - **대응 위험차(RD)** = p(A) − p(B), **Tango 점수 신뢰구간**(0/100% 근처에서도 안전)
   - **조건부 오즈비** = 불일치 쌍의 비, **정확(Clopper-Pearson) 신뢰구간**
     — 두 사건률의 주변부 오즈비와 **다른 값**이니 그렇게 인용하지 마세요.
   - **NNT/NNH**(`--event-is benefit|harm` 지정 시 올바른 이름으로)
   - **Cohen's kappa**(일치도) — 두 검사/판독자 비교일 때 핵심 지표입니다.
     McNemar는 "한쪽이 더 자주 양성인가", kappa는 "같은 검체에서 일치하는가"로
     서로 다른 질문이라 둘 다 봐야 합니다.
→ 한쪽 값이 비어 있거나 해석 불가면 **그 쌍 전체가 빠지며** 몇 개가 빠졌는지 표시합니다.
→ 불일치 쌍이 0개면 p=1.000이지만 이는 "차이 없음의 증거"가 아니라 **판단 불가**이며,
   경고와 함께 **논문용 문장 생성을 거부**합니다.
→ wide 형식에서는 `--columns` 의 **두 번째 열이 기준**입니다. `--baseline` 으로 명시하세요.
→ **치료 전/후 설계에서 kappa를 신뢰도로 읽지 마세요** — 거기서 일치도가 낮은 것은
   치료가 실제로 효과가 있었다는 뜻입니다(출력에도 같은 주가 붙습니다). kappa 신뢰구간은
   대표본 근사라 짝이 30개 미만이면 경고합니다.
→ McNemar p값(정확검정)과 대응 위험차 신뢰구간(Tango 근사)의 판정이 갈릴 수 있습니다.
   그럴 때는 경고와 함께 논문용 문장에도 "경계선 결과"라고 적습니다.

### 5) "같다/뒤지지 않는다"를 주장하기 (등가성·비열등성)
p > 0.05 는 **같다는 증거가 아닙니다**. 마진을 정해 놓고 검정해야 합니다.
```bash
# 평균차가 ±1.5 안에 있는가 (TOST)
statwise 내데이터.csv --value isi --group arm --equivalence-margin 1.5

# 3점 이상 나빠지지만 않으면 OK (ISI는 낮을수록 좋음)
statwise 내데이터.csv --value isi --group arm --reference 대조군 \
    --ni-margin 3 --ni-direction lower_is_better
```
→ TOST의 `p = max(두 단측 p)` 와 **90% 신뢰구간**(등가 판정과 같은 구간)을 함께 봅니다.
   **마진은 통계가 아니라 임상적 판단**이라 도구가 정해 주지 않습니다.
   비열등성·비대칭 마진은 **`--reference` 로 기준군을 고정해야** 합니다 —
   그러지 않으면 CSV 행 순서만 바뀌어도 결론이 뒤집힙니다.

## 한계 (반드시 읽어 주세요)
- 이 도구는 **검증된(validated) 통계 소프트웨어가 아닙니다.** 탐색적·내부 보고용으로
  쓰고, 규제 제출용 분석은 검증된 도구로 재현하세요.
- **검정을 자료에서 고릅니다.** 소표본·불균형 설계에서 1종 오류가 커질 수 있어
  출력에 항상 경고가 붙습니다. 사전 지정이 필요하면 `--test` 를 쓰되, 이 옵션은
  **독립 2그룹 연속형에만** 적용됩니다(대응·3그룹↑·이진 경로는 여전히 자료 의존적).
- **공변량 보정(ANCOVA)은 있지만**(아래 6번) 고정효과 선형모형 하나뿐입니다 —
  상호작용 모형·혼합모형(반복측정)·비선형 항은 없습니다.
- **대응 이진은 `--binary --paired`(McNemar)로 지원**하지만 2조건 2×2 하나뿐입니다 —
  3조건 이상(Cochran's Q), 층화(Mantel-Haenszel), 대응 비율의 등가/비열등성은 없습니다.
  **생존분석·다중대체도 없습니다.** 결측은 제외하고 개수를 셀 뿐 대체하지 않습니다.
- 사후검정은 **쌍별 검정 + Holm/BH 보정**입니다 — Tukey HSD도, Dunn도,
  Games-Howell도 아닙니다.
- 자세한 한계는 README의 "Notes / limitations"를 보세요.

### 6) 기저값으로 보정해서 비교하기 (ANCOVA) — RCT의 표준 1차 분석

무작위배정 시험에서 연속형 1차 변수의 표준 분석은 t-검정이 아니라 **기저값 보정
(ANCOVA)** 입니다. 기저값이 결과를 잘 설명할수록 잡음이 줄어 **검정력이 올라가고**,
기저 불균형이 있어도 변화량(post − pre) 분석과 달리 편향되지 않습니다.

```bash
# 기저 ISI로 보정, 기준군 = placebo
statwise 내데이터.csv --value isi_8주 --group arm --covariate isi_기저 --reference placebo

# 기관(site)처럼 층화인자까지 함께 보정, 공변량 2개
statwise 내데이터.csv --value isi_8주 --group arm \
    --covariate isi_기저,나이 --adjust-factor site --reference placebo
```
→ 군별 **보정평균(adjusted mean)** 과 신뢰구간, **보정된 군간 차이**, 공변량 기울기,
   그리고 ANCOVA에 필요한 가정 점검(**기울기 동질성**, 잔차 정규성·등분산)까지
   한 번에 나옵니다.

**부호(방향)** — 차이는 항상 `(다른 군 − 기준군)` 입니다. `--reference placebo` 로
기준군을 고정하세요. 생략하면 CSV에서 **마지막으로 처음 등장한 군**이 기준이 되므로,
행 순서가 바뀌면 부호가 뒤집힙니다 (paired의 `--baseline` 과 같은 이유입니다).

**3군 이상이면** 기준군을 포함하지 않는 쌍까지 **모든 쌍**의 보정된 차이가 나오고,
다중비교 보정(Holm 기본, `--correction bh`)은 그 전체에 적용됩니다. `--reference` 는
부호만 고정할 뿐 비교 대상을 줄이지 않습니다.

`--equivalence-margin` / `--ni-margin` 을 같이 주면 **보정된 평균차**에 대해 등가·
비열등성 검정도 합니다 — 단 **2군일 때만**이고, 3군 이상이면 경고와 함께 건너뜁니다.

함께 쓸 수 없는 옵션: `--wide`, `--paired`, `--binary`, `--columns`, 그리고
**`--values`(여러 엔드포인트)**. 보정이 필요한 엔드포인트는 하나씩 따로 돌리세요.
`--no-posthoc` 와 `--test` 도 이 경로에는 적용되지 않고 오류로 거부됩니다.

**꼭 지킬 것:** 공변량은 **무작위배정 전에 측정된 값**이어야 합니다. 치료 시작 후에
측정한 값(중간 방문 수치, 순응도, 부작용 여부)을 넣으면 치료효과가 편향되고 **그
편향은 자료로는 확인할 수 없습니다.** 결측이 있는 행은 제외(complete-case)하고 몇 행을
뺐는지 함께 표시합니다.

### 7) 결과가 여러 개일 때 (엔드포인트 8개면 위양성 34%)
```bash
statwise 내데이터.csv --values isi,psqi,hrv,ess --group arm --brief
```
→ 엔드포인트마다 알맞은 검정을 돌리고, **엔드포인트 간 다중비교까지 보정한 요약표**를
   출력합니다(`--endpoint-correction holm|bh|none`). `--brief` 를 빼면 엔드포인트별
   상세 리포트도 이어서 나옵니다. `--binary` 와 같이 쓰면 이상반응 표도 한 번에.

## 결과 읽는 법
- **[2] 가정 점검**: Shapiro-Wilk(정규성), Levene(등분산).
  **p가 크다고 가정이 충족된 것은 아닙니다** — 위배의 *근거가 없을* 뿐이고,
  표본이 작으면 검정력이 낮아 실제 위배를 놓칩니다. (paired면 **차이값**의 정규성만 봅니다.)
- **[3] 선택된 검정**: 위 가정에 따라 자동으로 고른 검정 + 그 **근거**.
  - 2그룹(독립): 정규+등분산 → Student t / 정규+이분산 → Welch t / 비정규 → Mann-Whitney
  - 2조건(대응): 차이 정규 → 대응 t / 아니면 → Wilcoxon 부호순위
  - 3그룹↑: 정규+등분산 → ANOVA / 정규+이분산 → Welch-ANOVA / 아니면 → Kruskal-Wallis (+ 사후검정)
- **[4] 효과크기**: Hedges' g / Cohen's d_z / rank-biserial / η² / η²[H] (크기 판정 라벨 포함).
  비모수 검정이면 **위치차 Hodges-Lehmann 추정값 + 신뢰구간**도 표시됩니다.
  이진 결과면 [3] 자리에 **RD / RR / OR / NNT** 가 나옵니다.
- **[3b] 등가성·비열등성**: 마진 옵션을 줬을 때만 나오는 섹션.
- **miss 열**: 원본 파일에 있었지만 결측·비수치라 빠진 관측치 수(CONSORT식 보고용).
- **[논문용 문장]**: APA 스타일 **초안**입니다. 그대로 제출하지 말고 (1) 검정이
  자료에서 선택된 것인지, (2) 다중비교 보정 후 결론인지, (3) 자료 무결성 경고가
  없는지 확인한 뒤 Methods와 함께 고쳐 쓰세요. 무결성 경고가 있으면 도구가 문장
  생성을 아예 거부합니다.

## 자주 쓰는 옵션
- `--alpha 0.01` : 유의수준 바꾸기 (기본 0.05)
- `--reference 대조군` : (독립 비교) 기준군 고정 — 차이 = (다른 군 − 기준군)
- `--binary` : 예/아니오 결과 분석 (RD·RR·OR·NNT + 카이제곱/Fisher)
- `--binary --paired` : 같은 대상의 예/아니오 결과 (McNemar + 대응 RD·조건부 OR·kappa)
- `--equivalence-margin 1.5` / `--ni-margin 3` : 등가성 / 비열등성 검정
- `--values a,b,c` : 여러 엔드포인트를 한 번에 (+ 엔드포인트 간 보정)
- `--covariate 기저열` : 기저값 등으로 보정한 비교(ANCOVA). `--adjust-factor site` 로
  기관·층화인자 같은 범주형 보정인자도 함께 (long 형식 전용)
- `--test welch` : (연속형 2그룹) 검정을 미리 정해 두기 — 자동 선택은 소표본에서
  1종 오류가 커질 수 있어, 사전 계획서(SAP)가 있으면 이렇게 고정하는 편이 안전합니다
- `--event-is harm` : (`--binary`) 이상반응처럼 나쁜 사건이면 NNT 대신 **NNH**로 표시
- `--binary-test exact|mcnemar|mcnemar-cc` : (`--binary --paired`) 대응 이진 검정을 고정
- `-o 결과.csv` : 화면 대신 파일로 저장 (기존 파일은 안 덮어씀; `--overwrite` 필요)
- `--version` : 버전 확인
- `--overwrite` : (`-o`) 기존 파일 덮어쓰기 허용 (입력 CSV는 절대 덮어쓰지 않습니다)
- 입력이 잘못되면 `입력 오류: ...` 와 함께 **종료 코드 2** 로 끝납니다.
- `--paired --id 대상열` : 같은 대상의 전/후 대응표본 분석
- `--baseline 기준조건` : (paired) 차이의 기준(빼지는) 조건을 고정해 부호를 재현 가능하게
- `--correction bh` : 사후검정을 BH(FDR)로 보정 (기본은 Holm)
- `--format json` : 결과를 JSON으로 출력
- `--no-posthoc` : 3그룹 이상에서 사후검정 생략
- `--columns a,b` : wide에서 비교할 열만 선택
- `--delimiter ';'` : 구분자 강제 지정 (보통은 자동 감지)
