# pubgap 빠른 사용법

키워드 하나로 **PubMed 동향 요약 + 덜 연구된 각도(연구공백)** 를 뽑아 주는 도구입니다.

## 가장 쉬운 실행 — 더블클릭
`실행.command` 파일을 **더블클릭**하면 번들 예시(수면·호흡·HRV·EEG·수면제 논문 28편)로
리포트가 바로 출력됩니다. (네트워크 없이 동작)

## 터미널에서

```bash
cd pubgap-논문공백탐색

# 1) 오프라인 데모 — 예시 파일로 즉시 확인
python3 -m pubgap.cli --from-file examples/sleep_pubmed.xml

# 2) 실제 PubMed 조회 — 관심 키워드로 최근 10년 스캔
python3 -m pubgap.cli "slow breathing AND sleep" --email 내이메일@lab.org

# 3) 결과를 파일로 저장
python3 -m pubgap.cli "hearing loss AND cognitive decline" --out 결과.md

# 4) 내려받은 NBIB·RIS·CSV·.gz 파일도 그대로 (형식 자동 판별)
python3 -m pubgap.cli --from-file 내보낸논문.nbib
python3 -m pubgap.cli --from-file endnote_내보내기.ris
python3 -m pubgap.cli --from-file scopus.csv
python3 -m pubgap.cli --from-file pubmed_result.xml.gz

# 5) 스프레드시트(CSV)로 공백 표만 뽑기
python3 -m pubgap.cli --from-file examples/sleep_pubmed.xml --format csv --out gaps.csv

# 6) 검색어 자체를 주제에서 빼기(기본 정렬은 이미 '부족 편수' 순)
python3 -m pubgap.cli --from-file examples/sleep_pubmed.xml --exclude-term Sleep

# 6-1) 미개척 정도(lift) 순으로 보고 싶다면
python3 -m pubgap.cli --from-file examples/sleep_pubmed.xml --gap-sort lift

# 7) 근거 공백(RCT가 비어 있는 주제) 표만 CSV로
python3 -m pubgap.cli --from-file examples/sleep_pubmed.xml \
    --format csv --csv-section topic-evidence --out 근거공백.csv

# 8) 연구 각도 공백(부주제어 축) 표만 CSV로
#    "이 주제는 논문이 많은데 '약물치료(drug therapy)' 각도로 본 논문은 없다"
python3 -m pubgap.cli --from-file examples/sleep_pubmed.xml \
    --format csv --csv-section angles --out 각도공백.csv

# 8-1) 대상집단 공백(연령·성별 축) 표만 CSV로
#      "이 주제는 논문이 많은데 고령자(65+)에서는 거의 안 봤다"
python3 -m pubgap.cli --from-file examples/sleep_pubmed.xml \
    --format csv --csv-section population --out 대상집단공백.csv

# 9) 여러 출처(PubMed XML + Scopus CSV + EndNote RIS)를 하나로 합쳐 분석
#    중복은 PMID → DOI → 제목+연도 순으로 자동 제거하고, 몇 건을 합쳤는지 리포트에 적습니다.
python3 -m pubgap.cli --from-file pubmed.xml --from-file scopus.csv --from-file endnote.ris
```

`pip install -e .` 를 한 번 해두면 `python3 -m pubgap.cli` 대신 `pubgap` 로 짧게 쓸 수 있습니다.

## 결과 읽는 법
- **연도별 발행량 / 성장**: 이 분야가 커지는지 식는지. 두 구간의 **연평균 편수**와
  로버스트 추세 기울기(**Theil–Sen**, 편/년), 그리고 **Mann–Kendall 추세 검정**이
  "통계적으로 유의한 증가/감소인지"를 알려줍니다.
  ⚠️ 검색 결과가 `--max-records` 보다 많으면 표본이 잘려(기본은 연도 층화 표집,
  `--min-year/--max-year` 를 쓰면 최신순) 추세를 낼 수 없습니다. 그 경우 리포트가 "표본이 잘렸습니다"라고 알리고 추세 절을 생략합니다 —
  `--max-records` 를 올리거나 `--min-year/--max-year` 로 기간을 좁혀 전수를 받으세요.
- **주요 주제(MeSH)**: 이 검색어에서 실제로 많이 다뤄진 개념들.
- **↗︎ 부상 / ↘︎ 쇠퇴**: 최근 비중이 오른/내린 세부 주제.
  (맨 위 **## 요약** 블록에 1순위 후보와 '달성한 최소 q' 가 먼저 나옵니다 — 바쁠 땐
  그 4~5줄만 봐도 됩니다.)
- **🧪 근거 지형**: 이 분야가 어떤 연구 설계로 채워져 있는지(RCT/관찰/종설…).
  이어지는 **"개입연구가 비어 있는 주제"** 표는 *논문은 많은데 RCT·임상시험은 유의하게
  적은 주제* — 즉 **시험을 설계할 자리**입니다. `q ≤ 0.05` 이면서 `개입비율`이
  `그 외 논문`(= 그 주제를 달지 않은 나머지)보다 낮은 줄을 보세요. (설계 정보가 없는 논문은 분모에서 빠지며,
  그 커버리지도 함께 표시됩니다.)
- **🎯 연구 각도 공백(부주제어 축)**: 주제쌍 공백이 "A와 B를 함께 본 논문이 없다"라면,
  이 절은 **"이 주제를 *치료/약물치료/이상반응* 관점에서 본 논문이 없다"** 를 말합니다.
  PubMed 색인자가 주제어에 붙인 부주제어(`Insomnia/therapy`, `Heart Rate/drug effects`)를
  세로축으로 본 것이라, 곧바로 프로토콜 아이디어로 이어지는 경우가 많습니다.
  - `이 주제의 주요 각도` 열이 "그럼 지금은 뭘 하고 있나"를 보여 줍니다.
  - `주제 표목` 은 논문 수가 아니라 **(논문, 주제어) 칸 수**입니다(부주제어가 붙은 것만).
  - ⚠️ MeSH 규칙상 **애초에 붙일 수 없는 조합**이 있습니다(해부 용어 × `/drug therapy`).
    그런 칸은 `색인 가능성` 열에 `⚠ 규칙상 불가?` 로 표시되고 순위가 뒤로 밀립니다
    (지우지는 않습니다 — 통계의 분모를 정직하게 유지하기 위해서). 표시가 없는 행도
    각 행의 PubMed 링크를 눌러 실제 문헌을 꼭 확인하세요.
    `--angle-hide-implausible` 로 표시된 칸을 아예 감출 수 있습니다.
  - RIS/CSV 내보내기에는 부주제어가 대개 없습니다. 그 경우 이 절은 "낼 수 없습니다"라고
    솔직히 말합니다 — PubMed XML/NBIB 로 받으면 자동으로 채워집니다.
- **👥 대상집단 공백(연령·성별 축)**: 같은 질문을 **"누구를 대상으로"** 로 바꾼 절입니다.
  *"이 주제의 논문은 이 분야 평균보다 고령(65+)·소아 비중이 낮다"* 를 찾아 줍니다.
  임상시험 계획서의 대상자 기준을 정당화하거나(ICH E7 고령자, 소아 개발계획),
  "왜 이 집단을 봐야 하는가"를 리뷰어에게 숫자로 답할 때 씁니다.
  - `기대` = 그 주제의 논문 수 × **그 주제를 달지 않은 나머지 논문**(= `그 외` 열)의
    해당 집단 비중, `부족` = 기대 − 관측입니다. `q ≤ 0.05` 인 줄이 가장 뚜렷합니다.
  - 이 표의 `95% CI` 는 lift 가 아니라 **바로 왼쪽 `비중`** 의 신뢰구간입니다
    (Clopper–Pearson). `0/7편 = 0%` 는 "없다"가 아니라 "상한이 41% 다"라는 뜻입니다.
  - ⚠️ **'거의 안 봤다'가 아니라 '상대적으로 낮다'입니다.** 비중 29% 여도 나머지가
    73% 면 이 표에 오릅니다. 진짜로 비어 있는 줄을 원하면 `관측` 이 0 인 행을 보거나
    `--population-sort share` 로 비중이 낮은 순으로 보세요.
  - 분모는 **축마다 따로**입니다(연령 태그가 붙은 논문 / 성별 태그가 붙은 논문).
    태그가 없는 논문은 분모에서 빠지고, 그 커버리지가 절 맨 위에 표시됩니다.
    그래서 **같은 주제인데 `논문` 열의 값이 행마다 다를 수 있습니다**(예: 연령 행 119편,
    성별 행 100편) — 오타가 아니라 축이 다른 것입니다.
  - ⚠️ 연령 구간은 NLM 정의라 **서로 겹칩니다**(40–70세 코호트 = 성인+중년+고령).
    비중의 합이 100% 가 아닌 것은 정상입니다.
  - ⚠️ 이 축이 세는 것은 **색인자가 단 체크 태그**입니다. 고령자를 포함한 연구라도
    연령이 보고되지 않으면 태그가 없고, 오래된 레코드일수록 태그가 성깁니다.
  - ⚠️ **성별 축은 참고용입니다.** `Female`/`Male` 은 '그 성별이 한 명이라도 포함됐는가'
    표시라 인체 논문의 90% 이상에 둘 다 붙습니다. 여성 등록 비율이나 성별 층화분석
    여부는 이 축으로 알 수 없습니다(모든 논문에 붙은 집단은 아예 검정하지 않습니다).
  - ⚠️ `확인` 링크는 **당신의 검색어·기간과 무관한 PubMed 전체 검색**입니다. 표의
    편수와 직접 비교하지 말고, "그 조합의 논문이 실제로 어떤 것들인지" 눈으로 볼 때
    쓰세요(MeSH 하위어 자동 확장은 꺼 두어 표와 같은 정의로 셉니다).
  - RIS/CSV 내보내기에는 체크 태그가 대개 없습니다. 그 경우 이 절은 "낼 수 없습니다"
    라고 솔직히 말합니다 — PubMed XML/NBIB 로 받으면 자동으로 채워집니다.
  - `--population-min-articles`(기본 5)·`--population-top-k`(기본 12)·
    `--population-sort {deficit,share,q,lift}`, 끄려면 `--no-population`.
- **🔍 덜 연구된 주제 조합**: 표의 맨 윗줄이 가장 유망한 공백입니다.
  - `함께(관측)` = 두 주제를 같이 다룬 논문 수, `기대` = 우연히 겹칠 만한 수,
    `lift` = 관측/기대. **lift가 0에 가까울수록** 아직 아무도 안 엮은 조합입니다.
  - `부족` = 기대−관측, 곧 **"있었어야 하는데 없는 논문 편수"**. 실제로 착수할 후보를
    고를 땐 lift 보다 이 값이 큰 쪽(문헌이 두꺼워 근거가 탄탄)이 유리합니다 →
    이것이 **기본 정렬**입니다(`--gap-sort lift` 로 바꿀 수 있습니다).
  - `추이`: `⬜ 완전공백`(두 구간 모두 0편 — **내 표본에서** 0편이라는 뜻이지 문헌에
    없다는 뜻이 아닙니다. 반드시 검증 링크/판정 열로 확인하세요) / `↗ 메워짐`(남들이
    이미 들어오는 중) / `↘ 벌어짐`(여전히 비어 있음) / `→ 유지`(비율 동일) /
    `–`(동시등장 3편 미만·연도 미상 혼입·한쪽 구간 0편 → **판단 불가**).
  - `95% CI` 는 lift 의 **정확 신뢰구간**입니다. 상한이 1 을 넘으면(예: `0.00–1.64`)
    편수가 적어 "덜 엮였다"고 단정할 수 없다는 뜻이니, 구간이 좁은 줄을 우선하세요.
  - `p` 는 초기하검정, `q(FDR)` 는 여러 쌍을 동시에 본 것을 보정한 값입니다.
    **여러 후보를 비교할 땐 q ≤ 0.05 를 기준**으로 삼으세요. 표 아래 "검정한 주제쌍
    m=N개 · 달성한 최소 q" 줄이 그 설정에서 실제로 어디까지 갔는지 알려 줍니다.
    검정 수가 많을수록 q 는 나빠지므로, 유의한 후보가 없으면 `--gap-top-k` 를 낮추거나
    (검정 수 감소) `--max-records` 를 올리세요.
    (`--gap-min-expected` 를 낮추면 검정 수가 늘어 q 는 **더 나빠집니다**.)
  - **검증 링크**를 꼭 눌러 보세요. 자유어(`제목/초록`) 검색에서 논문이 쏟아진다면,
    그 공백은 연구 공백이 아니라 **색인 방식의 차이**입니다.
    ⚠️ 링크의 결과 수는 표의 `함께(관측)` 와 **직접 비교하면 안 됩니다.** PubMed 는
    MeSH 상하위어를 자동 확장(explode)해서 세고, 이 도구는 문자 그대로 같이 달린
    경우만 셉니다. 그래서 표가 13편이라도 링크는 2만 편일 수 있습니다 — 정상입니다.
  - 네트워크 조회에서는 표에 **`PubMed 전수` / `판정`** 열이 함께 나옵니다. 도구가
    각 쌍을 PubMed 전체로 다시 세어 `✅ 진짜 공백` / `❌ 색인 artifact` 로 판정한
    것입니다. **`❌` 인 줄은 그냥 버리세요.**
  - 판정 열이 없을 때(오프라인) 직접 거르는 30초 규칙:
    (1) A 가 B 의 **하위 개념**이면 버린다(예: 불면증 × 수면장애).
    (2) 둘 다 **약리작용 표제어**면 버린다(같은 약을 다르게 부른 것).
    (3) 임상적으로 **자명한 쌍**이면 버린다(예: 류마티스관절염 × 염증).
  - 맨 아래 "> 제안" 줄이 곧바로 검토할 논문 각도이고, 이어지는 "> 가교(Swanson ABC)"
    줄은 A·B 를 잇는 제3 주제 C(기전 서사용), "> 대표 논문 ID" 줄은 바로 원문 확인용입니다(RIS/CSV 입력은 PMID 대신 DOI 가 나올 수 있습니다).
- PubMed 체크 태그(Humans/Male/Female/Adult…)와 방법론 표제어(Treatment Outcome,
  Risk Factors, Surveys and Questionnaires, `… as Topic` …)는 연구 주제가 아니므로
  **기본 제외**됩니다(포함하려면 `--include-check-tags`). 검색어 자체가 상위 주제를 다 차지하면
  `--exclude-term Sleep` 처럼 빼고 다시 보세요.
- 리포트 맨 아래 **"실행 정보(재현용)"** 접힘 블록에는 도구 버전·입력 파일 sha256·사용한
  옵션이 남습니다. 논문 Methods 에 그대로 옮겨 적으면 재현 가능한 기술이 됩니다.

## 이 리포트를 믿어도 되나 — 30초 체크리스트
> 1·5번은 **실제 PubMed 조회**에서만 나옵니다(`--from-file` 에는 해당 없음).

1. **표본이 잘렸나?** 첫머리 `PubMed 검색 결과 N편 중 M편` 을 보세요. 표본이면 추세는
   아예 나오지 않습니다. 전수를 보려면 `--count-only` 로 N 을 확인한 뒤
   `--max-records N` 으로 다시 돌리세요. (수천 편이면 NCBI 예절 대기 때문에 몇 분
   걸립니다 — `--api-key` 를 쓰면 빨라집니다.)
2. **주제어가 몇 편에나 붙어 있나?** `(MeSH 주제어 보유 N편)` 이 전체의 **70% 미만**이면
   공백 통계의 근거가 얇습니다(색인 전 최신 논문이 많다는 뜻).
3. **설계 커버리지는?** 근거 지형의 `전체 N편의 X%` 가 50% 아래면 경고가 뜹니다.
   각도 절의 **부주제어 커버리지**, 대상집단 절의 **연령·성별 태그 커버리지**도
   같은 방식으로 표시됩니다 — 50% 아래면 '공백'이 아니라 '색인 부재'일 가능성이 큽니다.
3-1. **신뢰구간이 얼마나 넓나?** `개입비율 0% (95% CI 0–46%)` 는 "시험이 없다"가 아니라
   "이 표본으로는 46% 까지도 가능하다"는 뜻입니다. 좁은 구간만 근거로 쓰세요.
4. **q 가 도달했나?** 공백표 아래 `달성한 최소 q` 를 보세요. 0.05 를 못 넘겼으면
   그 후보들은 탐색적 힌트입니다.
5. **판정 열이 `✅ 진짜 공백` 또는 `⬜ 전수 0편` 인가?** 이 둘이 확인된 공백이고,
   `❌ 색인 artifact` 는 실제 문헌에 이미 충분히 있다는 뜻입니다(`–` 는 판단 불가).
6. **`⚠상하위어?` 표시가 붙어 있지 않은가?** 붙어 있으면 부모–자식 개념일 가능성이
   커서(예: `Sleep` × `Sleep, REM`) 연구 공백이 아닙니다.

## 팁
- 실제 조회 시 `--email 내이메일` 을 붙이는 게 NCBI 예절입니다(가능하면 `--api-key`도).
- `--years N` 은 **오늘부터 N×365+1일 전까지**의 롤링 창입니다(달력 연도가 아님). 특정
  기간을 고정해 보려면 `--min-year/--max-year` 를 쓰세요 — 이 둘은 PubMed 질의 자체를
  그 창으로 제한합니다.
- **공백이 하나도 안 나올 때**: 좁은 분야에서는 흔한 일입니다. `--gap-max-lift` 를
  올려 더 느슨한 조합까지 보거나, `--gap-top-k` 를 올려 후보 주제를 늘리세요
  (단 검정 수가 늘어 q 는 나빠집니다). 표본이 작다면 `--max-records` 를 올리는 게 먼저입니다.
- 리포트가 210줄쯤 됩니다 — `--out 결과.md` 로 저장하거나 `| less` 로 보세요.
- 여러 파일을 합칠 때 같은 논문이 다른 제목 표기로 들어와 있으면 제목 대조로 합쳐집니다.
  그게 걱정되면 `--no-fuzzy-dedup` 으로 PMID·DOI 가 같을 때만 합치세요.
- 공백이 너무 많거나 적으면 `--gap-min-expected`(기본 2.0)·`--gap-max-lift`(기본 0.5)로 조절하고,
  **통계적으로 유의한 것만** 보려면 `--gap-max-q 0.05` 를 더하세요.
- 최신 논문이라 MeSH 가 아직 없다면 `--include-keywords`, 더 정밀하게 보려면
  `--major-topics-only`(별표가 붙은 실제 PubMed 색인에서만 의미가 있습니다).
- `--years`·`--save-xml` 은 네트워크 조회 전용입니다. 파일 분석에서 기간을 좁히려면
  `--min-year/--max-year` 를 쓰세요.
- 입력은 XML·NBIB·**RIS**·**CSV/TSV**·`.gz` 를 내용으로 자동 판별하고, 같은 PMID(또는 DOI)는
  자동으로 한 번만 셉니다. MeSH 가 아예 없는 파일(RIS/CSV 내보내기)이면 저자 키워드를
  주제로 자동 승격하고 그 사실을 알려 줍니다.
- 표본이 30편 미만이면 리포트가 **표본 주의** 경고를 띄웁니다 — 통계가 한두 편에 흔들립니다.
- 실제 조회는 기본이 **연도 층화 표집**이라 표본이 최근 몇 달로 쏠리지 않습니다
  (`--sample recent` 로 예전 방식). 공백쌍은 기본으로 **PubMed 전수 재조회**로
  검증해 색인 artifact 를 걸러 냅니다(`--no-verify-gaps` 로 끄기).
- ⚠️ "공백"은 착수 힌트일 뿐입니다. 상위 조합의 대표 논문은 실제로 확인하세요.
