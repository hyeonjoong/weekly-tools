## 2026-07-31 (2차) — 임상 종점 확장 + 병렬 리뷰 1라운드

### 새로 추가한 기능 (테스트 포함)

- **이분 종점(두 비율 비교)** `effect: {"type":"two_proportion","p1":…,"p2":…,"allocation":…}`.
  pooled/unpooled 정규근사(연속성 보정 없음). 30% vs 50% → 총 186명(군당 93) — Fleiss 표와 일치.
  MDES는 **대조군 비율을 고정하고 검출 가능한 시험군 비율을 역산**(위험차는 기저 비율 없이
  의미가 없기 때문), 검정력·민감도 스트립도 같은 척도.
- **시간-사건 종점(로그순위)** `effect: {"type":"survival","hr":…,"event_rate":…}`.
  Schoenfeld: HR 0.70 → **247 사건**, 사건률 60% 가정 시 412명. **필요 사건 수와 등록 인원을
  둘 다** 보고하고, 보유 N × 사건률로 예상 사건 수도 계산. MDES는 로그척도 대칭성을 살려
  `HR≥1.60 (또는 ≤0.63)` 양방향 표기.
- **임상 모달리티 추가**: `임상`(CRF/EHR/생존), `검사`(바이오마커/유전체), `영상`(MRI/CT/PET).
  예시 코호트 `examples/clinical_manifest.json` + 임상 템플릿 2종(반응률·PFS)을 함께 제공.
- **표본수 산출 근거 문장 자동 생성** — 상세 블록/CSV/JSON에 프로토콜·IRB에 그대로 옮길 수
  있는 한국어 문장. 검정 종류·가정 효과크기·α·배분비·다중비교 보정·반복측정 환산·탈락 보정·
  (생존이면) 비례위험 가정까지 실제 계산값에서 생성.
- **`--max-n N`** (모집 상한 초과 표시) / **`--feasible-only`** (`--top`보다 먼저 적용).

### 리뷰 1라운드에서 고친 것 (독립 리뷰어 4인 병렬)

**정확성**

- `analysis_unit: "observation"` 오버라이드가 **피험자 단위 종점까지 반복측정으로 나눴음**:
  생존 권장 N 412 → 134, 판정이 "표본 부족"에서 "충분 가능"으로 뒤집히면서 같은 레코드가
  여전히 "필요 사건 247건"을 출력. 엔진에서 무시하도록 막고, 팩 로드 시 오류로 거부.
- IRB 문장의 군당 N이 `총 N // 2` 라 **홀수 총계에서 1명 부족**(869 → 434+434=868, 검정력
  0.7996). 각 군을 올림해 합이 총계와 맞도록 수정.
- IRB 문장이 **배분비를 말하지 않아** 문장 안의 숫자만으로 재현되지 않았음(1:2 배분 211명인데
  적힌 조건으로 계산하면 186명). 배분비·양군 인원을 항상 명시.
- 반복측정이 적용된 경우 문장이 **환산된 피험자 수를 공식의 결과인 것처럼** 서술
  ("총 46명이 필요하다" 뒤에 "85개를 46명으로 환산했다"). 공식 결과는 관측 수로, 환산은
  별도 절로 분리.
- `scale_effect`의 생존 분기가 **`OverflowError`로 traceback**(exit 1) — HR>1 템플릿 +
  `--effect-scale`, 또는 기본 설정에서도 민감도 계수 1.5로 재현. 지수를 클램프.
  반대 방향은 0.0으로 언더플로해 "hr must be > 0"이라는 **사용자가 넣지도 않은 값**에 대한
  메시지를 냈음.
- `_checked_n`이 `_snap` 없이 올림해 사건 수 왕복이 1건씩 부풀었음(40.000000000000014 → 41).
- `--one-sided` 주의 문구가 신규 두 종점에 안 붙었음(적용은 되는데 경고는 없음).
- 사건 발생률 `5.5%`가 `6%`로 반올림돼 문장 속 숫자로 역산이 안 맞았음.

**정직성·유용성**

- **임상 기능이 동봉 파일만으로는 실행 불가능**했음: README가 존재하지 않는 `my_cohort.json`을
  가리키고, 예시 매니페스트에는 임상 모달리티가 없어 임상 템플릿이 하나도 안 나왔음
  → `examples/clinical_manifest.json` 추가 + 문서 수정.
- **매칭 안 되는 템플릿이 조용히 사라졌음** → "템플릿 N개가 … 제외됐습니다" 경고 추가.
- IRB 문장을 사용법.md는 "그대로 복사", README는 "초안"이라고 **서로 다르게** 안내했고,
  문장 자체에 **효과크기 출처와 비례위험 가정이 빠져** 있었음 → 문장 끝에
  `가정 효과크기의 근거는 [출처 기재 …]이다.`를 넣어 빈칸 없이는 제출할 수 없게 하고,
  생존 분기에 비례위험 문구 추가. 두 문서 표현도 "초안"으로 통일.
- 요약표 범례가 **어떤 행에도 없는 가짜 예시 숫자**(`Δp≥0.17`, `HR≥1.44`)를 항상 출력하며
  README와도 어긋났음 → 해당 종점이 실제로 있을 때만, 숫자 없이 표기법만 설명.
- 민감도 스트립이 `효과 0.79`로만 적어 **HR에서는 보수적/낙관적이 거꾸로 읽혔음** →
  지표 이름(`HR 0.79`) 표기.
- 생성 문장·경고의 **조사가 하드코딩**돼 있어 항상 하나 이상 틀렸음(`HR=0.70를`, `N=84을`,
  `20%을`). 끝자리 숫자의 한자음 받침(퍼센트는 예외)으로 조사를 고르는 헬퍼로 교체.
- `power.py` 독스트링이 `94 per group`이라고 적었으나 실제·표·테스트 모두 93.
- JSON 출력만 경고를 합치지 않아 5만 행 입력에서 **5.2MB JSON**(동일 경고 5만 개) 생성 →
  Markdown과 같은 방식으로 합침. 모달리티 n 충돌 경고도 30KB까지 늘어나 상한 추가.
- 엑셀 "유니코드 텍스트"(UTF-16) 저장 파일이 latin-1로 잘못 해석돼 **"modality 열이 없습니다"**
  라는 엉뚱한 진단을 냈음 → BOM 기반 UTF-16 처리 + 안내 경고.
- README에 **출력 필드(CSV 26열/JSON) 표**, 사용법.md에 `python3 -m paperforge.cli` 대체 실행
  안내와 임상 모달리티 표기 추가. `--feasible-only`가 탐색적·표본수 미상도 제외한다는 점,
  `--max-n`(앞으로 모집)과 실현가능성(지금 보유)이 다른 질문이라는 점 명시.

테스트: 335개 → **421개** (신규 `tests/test_clinical_endpoints.py`, 위 수정 전부에 회귀
테스트 포함). 전부 통과.

## 2026-07-31 — 기능 확장 + 병렬 리뷰 1라운드

### 새로 추가한 기능 (테스트 포함)

- **현재 표본의 검정력(attained power)** — 요약표에 `현재 검정력` 열 추가. "충분/부족"
  이분법 대신 실제 검정력 숫자를 보여 줌. 상관/평균차는 정규근사(양측이면 반대쪽 기각역도
  합산), 회귀·ΔR²는 비중심 F로 정확히 계산. 권장 N 공식의 정확한 역산이라 상호일치
  (권장 N에서 ≥목표, N−1에서 <목표 — 균형 2군만 군당 올림 때문에 예외, 테스트에 명시).
- **연결 표본수 `linked_n`** — 여러 모달리티를 **모두** 가진 피험자 수를 매니페스트에서
  직접 선언. 선언된 조합이 아이디어 모달리티 집합의 부분집합이면 상한으로 적용. 선언이
  없으면 종전처럼 각 n의 최소값을 쓰되 "낙관적 가정"임을 리포트에 명시. CSV에서는
  `modality` 칸에 `뇌파+워치` 로 적는 방식 지원.
- **반복측정 설계효과 `--repeats M --icc RHO`** — `DE = 1+(M−1)·ICC` 로 분석 행 수 ↔
  피험자 수 환산. 관측 단위로 사이징되는 설계(상관·회귀·ΔR²)에만 적용하고, 이미 피험자
  단위인 설계(대응·2군)에는 적용하지 않음을 리포트에 명시.
- **다중비교 `--n-tests K`** — alpha/K (Bonferroni)로 표본수·MDES·현재 검정력을 모두
  일관되게 재계산.
- **단측검정 `--one-sided`** — 상관·평균차에 적용. F 기반 ΔR²에는 단측 개념이 없어
  적용되지 않으며 그 사실을 아이디어 주석에 표시.
- **임의 alpha/power** — 역정규 CDF를 stdlib로 구현(Acklam 유리근사 + Halley 1회 보정,
  ~1e-15). 종전의 0.05/0.01/0.10 · 0.80/0.90/0.95 하드코딩 표 제한 제거. `alpha/K` 같은
  값이 필요하기 때문.
- **사용자 템플릿 팩** `--templates PATH`(복수 지정) / `--no-builtin` / `--list-templates`
  — 내장 수면/각성 템플릿 외에 자기 분야 아이디어를 JSON으로 추가. 필드·효과크기 스펙·
  모달리티 별칭을 로드 시점에 엄격 검증(오타는 조용히 매칭 실패하지 않고 즉시 실패).
  내장과 id가 같으면 그 자리에서 교체하고 경고. 예시: `examples/clinical_pack.json`.
- **지저분한 실무 CSV 대응** — `"1,234"`, `"40명"`, `"120 subjects"` 파싱, `-`/`n/a`/
  `미상`/`없음`/`TBD` 는 조용히 "미제공" 처리(진짜 해석 불가한 값만 경고), 변수명 공백
  제거·대소문자 무시 중복 제거.
- 출력 확장: CSV에 `required_rows`/`analysis_n`/`attained_power`, JSON에 `linked_n`·
  `alpha_effective`·`planned_effect`·`linked_declared` 추가. `--list-templates` 는
  매니페스트 없이 동작.

테스트: 132개 → 251개 (신규 파일 `test_attained_power.py`, `test_templates.py`,
`test_linkage_and_design.py`, `test_messy_inputs.py` + CLI 테스트 확장). 전부 통과.

### 리뷰 1라운드 — 독립 리뷰어 4명 병렬 (correctness / edge cases / docs / tests·security)

**통계 정확성 (수정 완료 + 회귀 테스트)**

- `power ≤ alpha/sided` 구간에서 **음수 MDES**가 출력되고(`--power 0.01` → `d≥-0.08`)
  권장 N이 목표 검정력이 낮아질수록 오히려 커지는 역전이 있었음. `_z_pair()`가 이 구간을
  명시적으로 거부하도록 수정.
- `subjects_to_rows`의 부동소수점 경계 오차(`11×3/1.1 = 29.999…` → 29)로 **"충분 가능"과
  검정력 0.79가 동시에** 표시될 수 있었음. 정수 근처 값 스냅으로 수정(왕복 위반 0건 확인).
- `norm_ppf` 상단 꼬리에서 Halley 보정이 상쇄로 무력화돼 실제 오차가 ~1e-9였음(광고는 1e-15).
  중앙값 위에서는 **반사(reflection)** 후 보정하도록 수정 → scipy 대비 2e-16.
- `_f_quantile`이 `hi=1e9`에서 조용히 잘려 임계값을 **과소평가**(→검정력 과대평가)했음.
  브래킷을 동적으로 확장하도록 수정.
- `mdes_regression*`이 이분법 **중점**을 반환해 목표 검정력에 0.5e-9 미달, 왕복 시 N이 1 커짐.
  목표를 실제로 달성하는 `hi`를 반환하도록 수정 → 왕복 정확 일치.
- 회귀 표본수 탐색이 N을 1씩 증가시키는 선형 스캔이라 작은 효과에서 수십 초~시간.
  기하 브래킷 + 이분법으로 교체(f²=1.5e-4: 73초 → 0.04초, G*Power 계열 55/68/77/85/92 유지).

**적대적 입력 (수정 완료 + 회귀 테스트)**

- `--effect-scale 1e-16`/`1e200`, 템플릿의 `r=1e-300`·`f2=1e300` → ZeroDivisionError /
  OverflowError 트레이스백. 효과크기 상·하한 검사로 깨끗한 exit 2.
- 깊게 중첩된 JSON → RecursionError 트레이스백(매니페스트·템플릿 팩 양쪽). 포착 후 exit 2.
- `--repeats 10**20` → OverflowError 및 비중심모수 폭주로 **무한정 지연**. 상한 + `_MAX_LAMBDA`
  조기 반환으로 수정.
- **`"40,50"` → 4050** (셀에 두 값을 적은 흔한 실수)가 조용히 100배 큰 N이 되어 판정을
  뒤집었음. 정상적인 천단위 구분 패턴만 허용하도록 수정.
- CSV `modality` 칸의 각주 표시(`EEG*`)나 후행 구분자가 연결선언으로 오인돼 **데이터셋 행이
  통째로 사라졌음**. 인식되는 모달리티가 2개 이상일 때만 연결선언으로 처리.
- `--alpha/--power`가 검증 없는 `float`라 `--power 7`이 리포트에 찍히고 `--power inf`가
  **유효하지 않은 JSON**(`Infinity`)을 출력. 전용 argparse 타입으로 수정.
- `--out`과 `--csv`가 같은 경로면 앞 파일이 조용히 덮어써지고도 성공 보고. 충돌 검사 추가.
- 들쭉날쭉한 CSV 행(헤더보다 길거나 짧음)이 무경고로 잘려나감 → 경고 추가.
- 인용부호 미종료로 파일 전체가 한 필드가 되면 경고에 **원문 줄바꿈이 그대로** 실려 리포트가
  깨졌음 → 경고 값 한 줄·길이 제한.
- `n: 1e308`이 309자리 정수로 표에 출력 → 표본수 상한(10⁹) 추가. 매니페스트 파일 크기 상한
  (32MB)도 추가(`/dev/zero` 무한 읽기 방지).
- 5만 행 인벤토리에서 동일 경고 7,148줄·170만 자 한 줄 출력 → 경고 중복 합치기 + 변수 목록 절단.

**정직성·유용성 (문서/동작 수정)**

- `linked_declared`가 "선언값이 상한일 때만" 참이라 **선언한 사용자에게 "선언 안 함"**이라고
  보고했음 → 선언 사실 자체를 보고하고, 선언값이 최소값보다 크면 모순 경고를 별도 표시.
- `--repeats/--icc`가 효과크기 타입만 보고 적용돼 **심리측정 타당화·기기 일치도**처럼 피험자당
  값이 하나인 분석의 N까지 85→46으로 줄였음. 템플릿에 `analysis_unit`(observation/subject)

## 2026-08-02 (3차) — 다군/기저값 보정 설계 + HTML 출력 + 병렬 리뷰 1라운드

### 새로 추가한 기능 (테스트 포함)

- **일원배치 ANOVA(k군)** `effect: {"type":"anova","f":0.25,"k_groups":3}`.
  비중심 F(분자 df=k−1, λ=f²N)로 **정확 계산**, 군 균형을 위해 k의 배수로 올림.
  f=0.25 → 159명(군당 53) / k=4 180 / k=5 200 — G*Power "ANOVA: Fixed effects,
  omnibus, one-way"와 일치(리뷰어가 scipy `ncf`로 독립 재계산해 12개 셀 전부 확인).
  2군 비교로 우회 사이징하면 분자 자유도를 1로 세어 **표본이 모자랍니다**.
- **기저값 보정 ANCOVA** `effect: {"type":"ancova","d":0.40,"r_covariate":0.60,
  "k_covariates":1}`. Borm 등(2007): 잔차분산이 (1−ρ²)배로 줄고 공변량 자유도
  (k_cov+1명)를 되돌려 더함. d=0.40·ρ=0.60 → 128명(보정 없으면 198명).
  ρ=0이면 2군 t검정 + 자유도 보정과 정확히 같아 검산이 쉽습니다. MDES·검정력은
  사이징의 **정확한 대수적 역함수**(왕복 오차 0). 임상시험의 사실상 표준 분석인데
  표본수만 보정 없이 계산되는 흔한 관행을 겨냥한 기능입니다.
- **`--html PATH`** — 스크립트·외부 리소스 없는 단일 파일 HTML 리포트(브라우저에서
  PDF 인쇄·공유용). 사용자 입력(연구명·템플릿 문구·변수명·경고)은 전부 이스케이프.
- **CSV 열 구분자 자동 감지** — 쉼표 외 `;`·탭·`|` 도 그대로 읽습니다. 엑셀이 지역
  설정에 따라 `;`로 내보낸 파일이 "modality 열이 필요합니다"라는 엉뚱한 오류로
  거부되던 문제. **쉼표가 modality 열을 찾으면 무조건 쉼표**(기존 동작 불변).
- 예시 팩에 `dose_ranging_omnibus`·`baseline_adjusted_endpoint`·`ni_response_rate`
  추가. README에 **비열등성 설계 절 신설**(그동안 코드에만 있고 문서에 전혀 없었음).

### 리뷰 1라운드에서 고친 것 (독립 리뷰어 4인 병렬)

**정확성**

- `analysis_unit: "observation"` 오버라이드가 **ANOVA/ANCOVA를 반복측정으로 나눴음**
  (159→64, 128→52, 판정이 "충분 가능"으로 뒤집힘). 생존·이분 종점에 이미 있던 가드에
  두 신규 계열을 추가하고 팩 로드 시 거부.
- `mdes_anova`가 `power ≤ alpha` 구간에서 하한 브래킷으로 붕괴해 **`f≥0.00`**(=어떤
  효과든 검출 가능)을 출력. F 검정의 영효과 기각률은 alpha/2가 아니라 **alpha**라
  전용 가드 추가.
- 잔차 자유도가 거의 없을 때 `f≥12.81`(η²=0.99)을 인쇄. 회귀의 `f²>9` 가드와 같은
  규칙(f>3)으로 억제.
- ANCOVA 프로토콜 문장이 **감소량이 0인데도 "표본수 감소가 정당화된다"**고 주장
  (ρ≲0.1). 실제 감소가 있을 때만 비교 문구를 넣고, 없으면 그렇게 말하도록 변경.
- `n_total_ancova`가 자신의 `power_for_ancova`가 거부하는 N(=5)을 반환 → 권장 N=5·
  충분 가능인데 검정력·MDES 칸이 빈 행. 하한을 걸어 자기일관성 회복.
- 표본수 초과 오류가 Cohen's f를 **`f2`로 잘못 지칭**.
- 최상위 자유문구 `design`에 "noninferiority"를 적으면 **조용히 우월성 기준으로**
  계산됐음(규제 대상 설계에서 최악). 이제 경고로 명시. README도 `effect` 안에
  넣어야 한다고 정정.
- 등록 코호트 규모(N=1,000,000)에서 MDES가 `f≥0.00`으로 반올림 → 0.01 미만은 유효
  숫자 표기(`f≥0.0031`).
