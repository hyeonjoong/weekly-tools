# 빠른 사용법 (paperforge)

보유 데이터 목록(JSON)을 넣으면 **멀티모달 논문 아이디어 표**를 만들어 줍니다.

## 가장 쉬운 방법
- 이 폴더의 **`실행.command` 더블클릭** → 예시 데이터로 아이디어 매트릭스가 바로 나옵니다.

## 터미널에서

```bash
# 1) 한 번만 설치
cd ~/Downloads/02_프로젝트/깃헙/paperforge-논문아이디어발굴기
python3 -m pip install -e .
# 설치가 안 되거나 'paperforge: command not found' 가 나오면, 아래 모든 예시에서
# `paperforge` 대신 `python3 -m paperforge.cli` 를 쓰면 그대로 동작합니다.

# 2) 예시로 실행 (점수순 전체)
paperforge examples/sleep_moa_manifest.json

# 3) 상위 5개만 + 파일로 저장 (JSON도 가능)
paperforge examples/sleep_moa_manifest.json --top 5 --out ideas.md --csv ideas.csv --json ideas.json

# 3-1) 브라우저에서 열어 PDF로 인쇄/공유할 HTML 리포트
paperforge examples/sleep_moa_manifest.json --html ideas.html

# 4) 스프레드시트에서 내보낸 CSV도 그대로 입력
#    (쉼표·세미콜론·탭 중 무엇으로 저장됐든 자동으로 알아봅니다)
paperforge examples/sleep_moa_manifest.csv

# 5) 중도탈락 20% 가정 시 "모집 목표 N"까지 보정
paperforge examples/sleep_moa_manifest.json --dropout 0.2

# 6) 효과가 가정보다 작다면? (효과크기 30% 축소해 보수적으로 판정)
paperforge examples/sleep_moa_manifest.json --effect-scale 0.7

# 7) 아이디어당 주요 비교가 5개 → Bonferroni(alpha/5)로 표본수 다시 계산
paperforge examples/sleep_moa_manifest.json --n-tests 5

# 8) 피험자당 3박 측정, 관측 ICC 0.3 → 필요한 "피험자 수"로 환산
paperforge examples/sleep_moa_manifest.json --repeats 3 --icc 0.3

# 9) 내 분야 아이디어 템플릿 추가 / 목록 보기
paperforge examples/sleep_moa_manifest.json --templates examples/clinical_pack.json
paperforge --list-templates

# 10) 최대 300명까지만 모을 수 있다면? 실행 가능한 아이디어만
paperforge examples/sleep_moa_manifest.json --max-n 300 --feasible-only
```

## 내 데이터로 쓰려면
`examples/sleep_moa_manifest.json`(또는 `.csv`)을 복사해 내 데이터셋으로 고치세요.
임상/제약 코호트라면 `examples/clinical_manifest.json` 쪽이 출발점으로 더 가깝습니다.
모달리티는 한글로 적어도 됩니다(`뇌파`, `워치`, `호흡밴드`, `설문`, `유저테스트`, `moa`,
그리고 임상용 `임상`(CRF/EHR/생존), `검사`(바이오마커/유전체), `영상`(MRI/CT/PET)).
`n`(표본수)을 적으면 "이 표본으로 가능한지"까지 자동으로 판정합니다.
`"1,234"`, `"40명"` 같은 표기도 읽고, 비어 있거나 `-`/`n/a`/`미상`이면 "미제공"으로 봅니다.

> **먼저 읽으세요 — 연결 표본수**: 멀티모달 아이디어의 판정을 가장 크게 바꾸는 입력입니다.
> EEG 90명·설문 40명이어도 **둘 다** 가진 사람이 32명이면 그 32가 실제 상한입니다.
> 아래 예시의 `뇌파+설문` 줄(CSV) / `linked_n`(JSON)이 그것이고, 자세한 설명은 바로 아래
> "[연결 표본수(꼭 넣으세요)](#연결-표본수꼭-넣으세요)" 절에 있습니다.

**JSON 예시**
```json
{
  "study": "내 연구",
  "datasets": [
    {"modality": "뇌파", "n": 35, "variables": ["alpha_power", "theta_power"]},
    {"modality": "설문", "n": 40, "variables": ["psqi_total", "stress_score"]}
  ]
}
```

**CSV 예시** (엑셀에서 그대로 저장 → `modality` 열만 필수, 변수는 `;`/`|` 로 구분)
```csv
study,modality,n,variables
내 연구,뇌파,35,alpha_power;theta_power
,설문,40,psqi_total;stress_score
,뇌파+설문,32,
```
> 엑셀이 CP949/EUC-KR로 저장해도 자동으로 읽습니다(가능하면 UTF-8 권장).

### 연결 표본수(꼭 넣으세요)
마지막 줄처럼 **`modality` 칸에 `뇌파+설문` 로 적고 `n`에 인원**을 넣으면 "둘 다 가진
피험자 수"로 해석합니다. 이걸 안 넣으면 도구는 각 모달리티 n의 **최소값**을 쓰는데, 이는
"작은 쪽이 큰 쪽에 완전히 포함된다"는 낙관적 가정입니다(리포트에 그렇게 명시됩니다).
JSON에서는 최상위에 `"linked_n": {"뇌파+설문": 32}` 로 적습니다.

## 결과 읽는 법
- **요약 매트릭스 표**: 위에서부터 추천 순위. **실현가능성이 1순위**(충분 가능 → 표본수 미상/탐색적 → 표본 부족 우려)이고, 같은 등급 안에서 멀티모달·변수 풍부 순입니다.
- **권장 N / 보유 N**: 보유 N이 권장 N보다 작으면 "표본 부족 우려" — 표본을 늘리거나
  더 큰 효과를 기대할 수 있는지 검토.
- **현재 검정력**: 지금 가진 N과 가정 효과크기에서 **실제로 얻는 검정력**. `0.62`면 참
  효과가 있어도 38% 확률로 놓친다는 뜻 — "충분/부족"보다 훨씬 실행에 가까운 숫자입니다.
- **탐지가능 효과**: 지금 가진 N으로 검출 가능한 **최소 효과크기**(예: `r≥0.29`).
  "표본 부족"이라도 이 값보다 큰 효과라면 검출할 수 있다는 뜻 — 표본을 늘릴지 판단에 유용.
- **표본수 민감도**(상세 블록): 효과가 가정보다 작을/클 때의 권장 N을 함께 보여 줍니다
  (`보수적 / 계획 / 낙관적`). 가정이 낙관적이면 표본이 얼마나 더 필요한지 바로 확인.
- **`탐색적(표본 판정 비적용)`**: 군집분석처럼 표본수 공식이 없는 설계 — 파일럿으로 접근.
- **`표본수 미상`**: 매니페스트에 `n`이 없어 판정 불가 — `n`을 채우면 자동으로 평가됩니다.
- **상세 블록**: 각 아이디어의 가설·변수·권장 통계분석·적합 저널·신규성 메모·가정 주의(caveat).
  "선택 모달리티 …의 표본은 N명뿐입니다" 주석이 붙으면, 보유 N보다 **그 숫자가 실제 상한**입니다.

## ⚠️ 효과크기는 도구의 가정입니다
표의 모든 **권장 N·현재 검정력·실현가능성**은 템플릿에 내장된 효과크기(상관 r=0.30,
평균차 d=0.50, f²=0.15 등)에서 나옵니다 — **내 데이터에서 추정한 값이 아닙니다.**
- 내 분야 파일럿 값이 있으면 `--templates` 로 같은 `id` 템플릿을 덮어써 바꾸세요(README 참고).
- 없으면 `--effect-scale 0.7` 로 "효과가 30% 작다면" 결과를 함께 보고 보수적으로 계획하세요.
- 상세 블록의 **표본수 민감도** 줄(보수적/계획/낙관적)이 이 가정의 폭을 바로 보여 줍니다.

## 프로토콜/IRB에 옮겨 적을 문장 — 자동 생성됩니다
상세 블록의 **`표본수 산출 근거(프로토콜·IRB 문장)`** 줄을 복사해 쓰세요. 판정에 쓰인
값에서 직접 만들어지므로 **숫자를 옮겨 적다 생기는 오류가 없습니다.** 다만 **초안**입니다 —
문장 안의 `[출처 기재 …]` 칸을 채우고, 적응증·설계 문구를 검토한 뒤 제출하세요.

> 양측 유의수준 α=0.05, 목표 검정력 80% 조건에서 Pearson 상관 r=0.30을 검출하기 위해
> Fisher z 변환 근사로 산출한 필요 표본은 총 85명이다. 중도탈락 20%를 고려한 모집 목표는
> 107명이다. 가정 효과크기의 근거는 [출처 기재 — 선행연구/자체 파일럿]이다. 본 수치는
> 계획용 근사치이므로 최종 검정력은 전용 검정력 분석 소프트웨어(예: G*Power)로 확인한다.

`--n-tests`(다중비교), `--repeats/--icc`(반복측정), `--dropout`(탈락)을 켰다면 **그 보정
사실과 숫자가 문장에 함께 들어갑니다**. 다만 효과크기 **출처는 직접 밝히세요** — 템플릿
내장 사전값인지 자체 파일럿 값인지는 도구가 알 수 없습니다.

## 임상 종점(반응률·생존)도 사이징됩니다
평균 차이가 아니라 **반응률(이분)** 이나 **생존기간(시간-사건)** 이 1차 종점이라면
`--templates examples/clinical_pack.json` 을 붙여 보세요.

| 종점 | 예시 | 나오는 숫자 |
|------|------|-------------|
| 반응률 30% → 50% | `two_proportion` | 총 186명(군당 93명), `Δp≥0.18 (30%→48%)` |
| PFS HR=0.70, 사건률 60% | `survival` | **247 사건** · 등록 412명, `HR≥1.60 (또는 ≤0.63)` |

> **생존 설계에서 검정력을 정하는 것은 사람 수가 아니라 사건 수입니다.** 240명을 등록해도
> 추적 중 사건이 144건뿐이면 부족합니다 — 리포트가 둘 다 보여 줍니다.
> 매니페스트 모달리티는 `임상`(CRF/EHR/생존), `검사`(바이오마커/유전체), `영상`(MRI/CT/PET)을
> 그대로 쓰면 됩니다.

## 3군 이상 비교(ANOVA)와 기저값 보정(ANCOVA)도 사이징됩니다
같은 `--templates examples/clinical_pack.json` 안에 들어 있습니다
(`dose_ranging_omnibus`, `baseline_adjusted_endpoint`).

| 설계 | 예시 | 나오는 숫자 |
|------|------|-------------|
| 위약·저용량·고용량 3군, 중간 효과 | `anova` (f=0.25, k=3) | 총 **159명(군당 53명)**, 보유 240명이면 `f≥0.20` |
| 기저값 보정 2군, d=0.40·ρ=0.60 | `ancova` | 총 **128명** (보정 없으면 198명), 보유 320명이면 `d≥0.25` |

- **3군 이상**은 2군 t검정으로 계산하면 안 됩니다. 군이 늘수록 옴니버스 F가 쓰는 자유도가
  늘어 필요 N도 늘어납니다(159 → 180 → 200 for k=3/4/5). 옴니버스가 유의해도 *어느 두 군이*
  다른지는 알 수 없으니, 사후 비교를 할 계획이면 `--n-tests` 로 그 횟수를 넣어 보세요.
- **기저값 보정(ANCOVA)** 은 임상시험에서 사실상 표준 분석인데 표본수는 보정 없이 계산되는
  일이 흔합니다. 기저값과 종점의 상관 ρ가 0.6이면 필요 N이 약 35% 줄어듭니다. 대신 ρ를
  실제보다 높게 잡으면 표본이 모자라니, **파일럿에서 잰 상관**을 넣으세요.
  생성되는 프로토콜 문장은 "보정 안 했을 때 몇 명"인지도 같이 적어 줍니다.

## 자주 쓰는 추가 옵션
| 상황 | 옵션 |
|------|------|
| 논문에서 주요 비교를 여러 번 한다 | `--n-tests 5` (alpha/5 Bonferroni) |
| 한 사람에게서 여러 번(여러 밤) 측정한다 | `--repeats 3 --icc 0.3` (아래 주의) |
| 방향이 정해진 가설이다 | `--one-sided` |
| 내 분야 아이디어를 넣고 싶다 | `--templates 내팩.json` (형식은 README) |
| 최대 몇 명까지 모을 수 있는지 정해져 있다 | `--max-n 300` (초과 아이디어에 "도달 불가" 표시) |
| 지금 당장 실행 가능한 것만 보고 싶다 | `--feasible-only` (`--top`보다 먼저 적용) |
| 다른 유의수준/검정력이 필요하다 | `--alpha 0.025 --power 0.85` (임의 값 가능) |
| PI/공동연구자에게 돌릴 문서가 필요하다 | `--html ideas.html` (브라우저에서 열고 PDF 인쇄) |

> **`--repeats/--icc` 주의**: ICC는 **파일럿에서 추정한 값**을 쓰세요. 낮게 잡으면 필요
> 인원이 과소평가됩니다(모르면 높게 잡는 쪽이 안전). 피험자당 값이 하나뿐인 분석
> (심리측정 타당화·기기 일치도)에는 적용되지 않도록 템플릿에 표시돼 있습니다.

> 권장 N은 계획용 근사치입니다. 최종 검정력은 G*Power 등으로 확정하세요.
> `--repeats/--icc`와 `linked_n`은 **사용자가 선언하는 가정**이며, 도구가 원본 데이터를 읽어
> 검증하지는 않습니다(paperforge는 데이터 파일을 열지 않습니다).
