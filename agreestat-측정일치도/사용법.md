# 사용법 (빠른 시작)

## 어떤 분석을 쓸까?

| 내 자료가… | 명령 | 나오는 것 |
|---|---|---|
| **숫자**(호흡수, RMSSD, 농도) | `agreestat 파일.csv -a A열 -b B열` | Bland–Altman, ICC, CCC, 반복성, 회귀 |
| **범주**(수면단계, 등급, 양성/음성) | `agreestat 파일.csv --categorical -a A열 -b B열` | kappa, 가중 kappa, Gwet AC1, 범주별 일치도 |
| **평가자·방법이 3개 이상**(판독의 3명 등) | `agreestat 파일.csv --raters "A,B,C"` | ICC(1,1)~(3,k), SEM·MDC95, 쌍별 LoA |
| **평가자 3명 이상 + 범주** | `agreestat 파일.csv --raters "A,B,C" --categorical` | Fleiss kappa, Gwet AC1, Krippendorff alpha |
| **한 행 = 한 측정(긴 형식)** | `agreestat 파일.csv --long --id-col ID --method-col 방법 --value-col 값` | 위와 동일 (자동으로 넓은 형식으로 변환) |

## 가장 쉬운 방법
- 이 폴더의 **`실행.command` 더블클릭** → 예제 데이터(비접촉 호흡수 vs 밴드,
  워치 RMSSD vs ECG, 수면단계 기기 vs PSG)로 결과가 바로 나옵니다.

먼저 한 번만 설치(선택):
```bash
cd ~/Downloads/02_프로젝트/깃헙/agreestat-측정일치도
python3 -m pip install -e .
```

### 입력 형식
같은 대상에 두 방법을 적용한 **짝지은 수치 두 열**. (선택) 피험자 ID 열.
```
subject,sensor,band
S01,14.2,14.0
S01,15.1,14.8
S02,11.9,12.3
...
```

### 기본 실행
```bash
agreestat 내데이터.csv -a sensor -b band
# 설치 안 했으면:
python3 -m agreestat.cli 내데이터.csv -a sensor -b band
```
- 수치열이 딱 두 개면 `-a/-b`를 생략해도 자동으로 찾습니다.

### 반복측정 / 백분율 / JSON
```bash
agreestat 내데이터.csv -a watch -b ecg -s subject   # 반복성 지표까지
agreestat 내데이터.csv -a watch -b ecg --percent    # 백분율 Bland–Altman
agreestat 내데이터.csv -a watch -b ecg --json       # JSON 출력
```

## 결과 읽는 법
- **[2] Bland–Altman**: `bias`(평균차)와 `95% LoA`(일치한계)가 핵심. bias가 0에
  가깝고 LoA가 좁을수록 두 방법이 잘 일치. `비례 편향 있음 ⚠`이 뜨면 차이가 측정값
  크기에 따라 변하는 것이므로 `--percent`나 회귀 기반 LoA를 고려.
- **[3] ICC**: **ICC(2,1)**(절대일치)을 우선 보세요. Koo & Li: <0.5 낮음 /
  0.5–0.75 보통 / 0.75–0.9 좋음 / >0.9 매우 좋음.
- **[4] Lin's CCC**: 정밀도×정확도를 한 수로. `Cb`가 1에 가까울수록 계통오차 작음.
- **[5] 반복측정**: 피험자당 반복이 있을 때만. within-subject CV(%)와 반복성 계수.
- **[6] 상관/차이**: 참고용. ⚠ 높은 r은 일치도가 아닙니다.
- **[7] 방법비교 회귀 (Deming·Passing–Bablok, CLSI EP09)**: 검증법(A)=절편+기울기·기준법(B).
  **기울기 CI가 1을 포함하면 비례편향 없음**, **절편 CI가 0을 포함하면 상수편향 없음**.
  Passing–Bablok은 이상치에 강건하고, Deming은 두 방법 모두의 측정오차를 반영합니다.
- **[논문용 문장]**: 그대로 복사해 원고에 붙이세요.

## 자주 쓰는 옵션
- `--alpha 0.01` : 신뢰구간을 99%로 (기본 0.05 → 95%)
- `-s subject`   : 피험자 ID 열 지정 (반복측정 지표)
- `--percent`    : 비례오차 데이터용 백분율 Bland–Altman
- `--accept 5`   : 임상 허용한계 ±5. 95% LoA가 그 안이면 "교환가능" 판정까지 출력
  (`--accept-lower/--accept-upper`로 비대칭 한계 지정 가능)
- `--target-loa-hw 0.5` : 목표 LoA CI 반너비 0.5 달성에 필요한 표본수 n을 계산
- `--deming-lambda 4` : Deming 회귀 오차분산비 λ=Var(err_기준B)/Var(err_검증A)
  (기본 1=직교회귀). 기준(B)이 훨씬 정밀하면 λ를 **작게**, 검증(A)이 정밀하면 크게
- `--at 12` : 결정수준 12(기준법 값)에서의 예측 계통편향을 계산 (`--accept`와 함께 판정)
- `--markdown` : 논문 부록용 마크다운 표로 출력 (`--markdown out.md`로 파일 저장)
- `--plot-data out.csv` / `--svg out.svg` : Bland–Altman 플롯을 CSV/SVG로 저장
- `--encoding cp949` : 엑셀(한글) CSV가 안 열릴 때 인코딩 지정 (기본은 자동 감지)
- `--raters "A,B,C"` : 평가자/방법 열을 직접 나열 (3개 이상이면 다중 평가자 분석)
- `--long --id-col ID --method-col 방법 --value-col 값` : 긴(tidy) 형식 입력

## 반복측정(개인당 여러 쌍) 데이터라면
`-s subject`로 피험자 ID 열을 주면, 각 행을 독립으로 가정한 naive LoA 대신
**반복측정 보정 LoA(Bland & Altman 2007)**를 계산해 권장 지표로 보여 줍니다
(수면 디바이스 epoch처럼 개인당 반복이 있는 데이터의 올바른 방법).

## 범주형(kappa) 분석 — `--categorical`

평가자·기기가 **숫자가 아니라 범주**를 매길 때 씁니다 (수면단계 vs PSG, 병변 등급,
양성/음성 판정). 입력은 똑같이 짝지은 두 열입니다.

```
epoch,psg_stage,device_stage
E0001,N2,N2
E0002,W,N1
```

```bash
# 명목형(순서 없는 범주)
agreestat 수면.csv --categorical -a psg_stage -b device_stage \
    --categories "W,N1,N2,N3,REM"

# 순서형(경증<중등도<중증) — 가중 kappa + 사전 기준 판정
agreestat 등급.csv --categorical --ordinal --categories "0,1,2,3" --min-kappa 0.6
```

### 결과 읽는 법
- **[2] 교차표**: 대각선이 일치. **어느 범주에서 어긋나는지**가 여기서 바로 보입니다.
- **[3] 일치도 계수**: `Cohen's kappa`(순서형이면 `가중 kappa`)가 주 지표.
  Landis & Koch: <0.21 미미 / 0.21–0.40 약함 / 0.41–0.60 보통 / 0.61–0.80 상당함 /
  \>0.80 거의 완벽. **점추정이 아니라 CI 하한으로 판단하세요.**
- **[4] kappa 역설 진단**: "관찰 일치도는 90%인데 kappa는 0.2"라면 자료가 한 범주에
  쏠린 것입니다(도구가 자동 경고). 이때는 **Gwet's AC1**과 **PABAK**을 함께 보고하세요.
- **[5] 범주별 일치도**: 전체 kappa가 숨기는 "특정 범주만 나쁨"을 드러냅니다.
  2×2에서는 FDA의 **PPA/NPA**와 같은 값입니다.
- **[6] 주변 동질성**: 유의하면 한 평가자가 특정 범주를 **체계적으로 더 많이** 쓴다는
  뜻입니다(계통 편향) — kappa 하나로는 안 보입니다.

### ⚠ 피험자당 여러 행이면 반드시 `-s`를 주세요 (수면 epoch 등)

한 사람에게서 수백 epoch가 나오는 자료에서 각 행을 독립으로 세면 **신뢰구간이 몇 배나
좁아집니다**. `-s subject`를 주면 피험자를 재표집하는 **군집 부트스트랩**으로 바로잡습니다.

```bash
agreestat 수면.csv --categorical -a psg_stage -b device_stage -s subject --min-kappa 0.70
```

```
[3b] 군집 보정 신뢰구간 — 권장
    Cohen's kappa = 0.738  군집 CI [0.680, 0.789]
       naive CI [0.713, 0.762] — 각 행을 독립으로 가정, 너무 좁음
    설계효과 = 4.87  →  유효 표본수 ≈ 370 (실제 1800행)
    피험자별 kappa: 중앙값 0.770, IQR 0.637–0.837, 범위 0.486–0.907
```

이 예에서 naive CI는 기준 0.70을 통과하지만 군집 CI는 통과하지 못합니다 —
`--min-kappa` 판정은 **군집 CI로** 하므로 거짓 통과가 생기지 않습니다.

### 범주형 옵션
- `--ordinal` : 순서형 → 가중 kappa(기본 quadratic). 인접 오분류에 부분 점수를 줍니다.
- `--weights linear|quadratic` : 가중치 방식 (쓴 방식은 반드시 논문에 밝히세요)
- `--categories "W,N1,N2,N3,REM"` : **범주 순서를 직접 지정** — 순서형이면 필수입니다.
  지정하지 않으면 숫자는 크기순, 문자는 **알파벳순**으로 가정하고 경고합니다.
- `--min-kappa 0.6` : 사전 기준. **CI 하한**이 0.6 이상이어야 "충족" 판정입니다.
- `-s subject` : 피험자 열 → 군집 보정 CI (`--bootstrap 2000`, `--seed`로 조절)
- `--na "NA,모름"` : 결측으로 처리할 라벨. **기본은 빈 칸만 결측**입니다 —
  `None`·`-`·`.`·`NA`는 실제 등급일 수 있어(예: None/Mild/Severe, +/−) 임의로 버리지
  않습니다. 결측이면 반드시 `--na`로 지정하세요.
- `--json` / `--markdown` : 연속형과 동일하게 동작합니다(경고도 함께 출력).

> 주의: 이 절(Cohen's kappa 계열)은 **평가자 2명·완전자료**를 다룹니다. 평가자가
> 3명 이상이면 아래 "평가자 3명 이상" 절(`--raters`)로 가세요. `pos`와 `Pos`는 다른
> 범주로 취급하니 원자료 표기를 먼저 통일하세요.

## 평가자·방법이 3개 이상 — `--raters`

판독의 3명이 같은 영상을 읽거나, 세 가지 assay를 같은 검체에 돌린 경우입니다.

```bash
# 연속형: 판독의 3명의 종양 크기 측정
agreestat 종양.csv --raters "reader_A,reader_B,reader_C"

# 범주형: 판독의 3명의 등급 판정 (순서형)
agreestat 등급.csv --raters "reader_A,reader_B,reader_C" --categorical --ordinal \
    --categories "mild,moderate,severe"
```

### 연속형에서 나오는 것
- **ICC 6종** — `ICC(1,1)`·`ICC(2,1)`·`ICC(3,1)`(평가자 **1명**의 신뢰도)과
  `ICC(1,k)`·`ICC(2,k)`·`ICC(3,k)`(평가자 **k명 평균**의 신뢰도).
  - CI: ICC(1,1)·ICC(3,1)은 F분포 기반 **정확 구간**, ICC(2,1)(절대일치)은
    **Satterthwaite 근사**(McGraw & Wong 1996), (·,k)는 단일측정 한계의
    Spearman–Brown 변환입니다.
  - `ICC(1,·)` 대상마다 평가자가 다를 때 / `ICC(2,·)` 같은 평가자가 전원을 볼 때(절대일치)
    / `ICC(3,·)` 이 평가자들에만 관심(일관성).
  - 실무에서는 **한 명이 읽을 거면 (·,1), 여러 명 평균을 쓸 거면 (·,k)** 를 보고합니다.
- **평가자 간 계통차이 F 검정** (`MSC/MSE`) — 유의하면 특정 평가자가 일관되게
  높거나 낮게 읽는다는 뜻이라 보정(calibration)을 검토해야 합니다.
- **SEM**(측정의 표준오차). 두 가지를 함께 보여 줍니다: **절대일치 기준 √MSW**
  (ICC(2,1)과 짝을 이루며 평가자 간 계통차이를 포함)와 **일관성 기준 √MSE**
  (계통차이 제외). **MDC95 = 1.96·√2·SEM(절대일치)** 보다 작은 변화는 측정오차와
  구분할 수 없습니다. 추적관찰을 매번 **같은 평가자**가 한다면 일관성 SEM 기반의
  더 작은 값을 써도 되지만, 평가자가 바뀔 수 있으면 절대일치 기준을 쓰세요.
- **s_w**(개체내 표준편차 = √MSW)와 **2.77·s_w**. 여기서 이 값은 같은 평가자의
  반복측정을 뜻하는 Bland–Altman '반복성(repeatability)'이 아니라 평가자 간
  **재현성(reproducibility)** 계수입니다.
- **평가자 쌍별 표** — 쌍마다 bias, sd(diff), LoA(`--alpha`가 정하는 신뢰수준, 기본
  95%), Lin's CCC. 어느 쌍이 문제인지
  한눈에 보입니다.

### 범주형에서 나오는 것
- **Fleiss' kappa** — 3명 이상의 명목 일치도 표준 지표. `kappa=0` 검정은 Fleiss(1971)
  의 H0 표준오차로, **신뢰구간은 대상 단위 부트스트랩 백분위법**으로 냅니다
  (정규근사 CI보다 정직합니다).
- **Gwet's AC1** — 한 범주에 쏠린 자료에서 kappa가 부당하게 낮아지는
  "유병률 역설"에 강건. kappa와 크게 벌어지면 도구가 경고합니다.
- **Krippendorff's alpha** (`--ordinal`이면 ordinal metric) — **결측에 강건**해서
  2명 이상이 평가한 모든 대상을 씁니다(Fleiss·AC1은 완전자료만).
- **범주별 Fleiss kappa** — "중등도만 유난히 안 맞는다"를 드러냅니다.
- **평가자 쌍별 Cohen's kappa**와 그 평균(**Light's kappa**).

### 결측 처리 (중요)
- 연속형: 한 평가자라도 값이 없으면 그 대상을 **통째로 제외**합니다(완전자료 분석).
  ICC 모형이 균형 자료를 요구하기 때문이며, 제외한 건수를 리포트에 표시합니다.
- 범주형: Fleiss·AC1·관측일치율은 **완전자료만**, Krippendorff's alpha는
  **2명 이상 평가된 모든 대상**을 씁니다(신뢰구간도 각각 같은 대상을 재표본합니다).
  리포트에 각각의 n이 따로 나옵니다.
- 모든 평가자가 **같은 범주만** 매긴 자료는 거부합니다 — 서로 다른 범주가 2종 이상
  없으면 kappa·AC1·alpha 자체가 정의되지 않습니다.
- `--ordinal` 을 줘도 headline **Fleiss kappa는 비가중**입니다(가중 kappa는 Fleiss에
  정의되지 않습니다). `--min-kappa` 판정도 비가중 기준이며 리포트가 이를 명시합니다.
  순서 정보를 반영한 지표는 Krippendorff's alpha(ordinal)와 쌍별 가중 kappa입니다.

## 긴(long/tidy) 형식 입력 — `--long`

REDCap·EDC·R 파이프라인에서 나오는 "한 행 = 한 측정" 형식을 그대로 읽습니다.

```
subject_id,reader,size_mm
P01,radiologist1,22.4
P01,radiologist2,23.0
P01,radiologist3,21.8
P02,radiologist1,15.1
...
```

```bash
agreestat 종양_long.csv --long --id-col subject_id --method-col reader --value-col size_mm
```

- 방법이 2개면 평소의 A vs B 리포트(Bland–Altman·ICC·CCC·회귀)가 나오고,
  3개 이상이면 자동으로 다중 평가자 리포트가 나옵니다.
- 분석에 넣을 방법만 고르거나 순서를 정하려면 `--raters "radiologist1,radiologist2"`.
- **같은 (ID, 방법) 조합이 두 번 나오면 오류**로 멈춥니다. 평균을 내거나 마지막 값을
  쓰면 결과가 조용히 달라지기 때문입니다 — 반복 회차가 있다면 `P01_v1`처럼 ID에
