# 사용법 (빠른 시작)

## 가장 쉬운 방법
- 이 폴더의 **`실행.command` 더블클릭** → 예제 데이터(비접촉 호흡수 vs 밴드,
  워치 RMSSD vs ECG)로 결과가 바로 나옵니다.

## 내 데이터로 돌리기 (터미널)

먼저 한 번만 설치(선택):
```bash
cd ~/Downloads/02_프로젝트/깃헙/agreestat-측정일치도
python3 -m pip install -e .
```

### 입력 형식
같은 대상에 두 방법을 적용한 **짝지은 수치 두 열**. (선택) 피험자 ID 열.
```
subject,sensor,band
S01,14.2,14.0
S01,15.1,14.8
S02,11.9,12.3
...
```

### 기본 실행
```bash
agreestat 내데이터.csv -a sensor -b band
# 설치 안 했으면:
python3 -m agreestat.cli 내데이터.csv -a sensor -b band
```
- 수치열이 딱 두 개면 `-a/-b`를 생략해도 자동으로 찾습니다.

### 반복측정 / 백분율 / JSON
```bash
agreestat 내데이터.csv -a watch -b ecg -s subject   # 반복성 지표까지
agreestat 내데이터.csv -a watch -b ecg --percent    # 백분율 Bland–Altman
agreestat 내데이터.csv -a watch -b ecg --json       # JSON 출력
```

## 결과 읽는 법
- **[2] Bland–Altman**: `bias`(평균차)와 `95% LoA`(일치한계)가 핵심. bias가 0에
  가깝고 LoA가 좁을수록 두 방법이 잘 일치. `비례 편향 있음 ⚠`이 뜨면 차이가 측정값
  크기에 따라 변하는 것이므로 `--percent`나 회귀 기반 LoA를 고려.
- **[3] ICC**: **ICC(2,1)**(절대일치)을 우선 보세요. Koo & Li: <0.5 낮음 /
  0.5–0.75 보통 / 0.75–0.9 좋음 / >0.9 매우 좋음.
- **[4] Lin's CCC**: 정밀도×정확도를 한 수로. `Cb`가 1에 가까울수록 계통오차 작음.
- **[5] 반복측정**: 피험자당 반복이 있을 때만. within-subject CV(%)와 반복성 계수.
- **[6] 상관/차이**: 참고용. ⚠ 높은 r은 일치도가 아닙니다.
- **[논문용 문장]**: 그대로 복사해 원고에 붙이세요.

## 자주 쓰는 옵션
- `--alpha 0.01` : 신뢰구간을 99%로 (기본 0.05 → 95%)
- `-s subject`   : 피험자 ID 열 지정 (반복측정 지표)
- `--percent`    : 비례오차 데이터용 백분율 Bland–Altman

## 팁
- 외부 라이브러리가 필요 없어 인터넷 없이도 동작합니다.
- 결과의 "경고(Warnings)"를 꼭 확인하고 최종 판단은 직접 하세요.
- **상관계수(r)만 높다고 두 방법이 같은 게 아닙니다** — bias·LoA·ICC·CCC로 판단.
