# 사용법 (한글 빠른 시작)

## 0. 제일 빠른 길

폴더 안의 **`실행.command` 를 더블클릭**하세요. 합성 예제로 감사 → 사본 만들기 →
안전장치(키 파일 위치 위반·병합 옵션)까지 한 번에 보여 주고, 임시 폴더에 쓴 뒤 지웁니다.

## 1. 한 번만 설치

```bash
cd ~/Downloads/02_프로젝트/깃헙/deidaudit-비식별화점검
python3 -m pip install -e .
```

이후 어느 폴더에서나 `deidaudit` 명령을 씁니다. (설치가 귀찮으면 `python3 -m deidaudit` 도 같습니다.)

## 2. 내보내기 직전 30초 — 감사만

```bash
deidaudit 수면일기_원본.csv
```

옵션 없이 파일만 던져도 됩니다. 파일은 하나도 만들지 않고 화면에만 보고합니다.
여러 개를 한 번에 던져도 됩니다 — **절대 합치지 않습니다.**

```bash
deidaudit 수면일기.csv UT로그.xlsx merged.csv
```

준식별자 조합이 몇 명까지 좁혀지는지도 보고 싶으면:

```bash
deidaudit 수면일기.csv --quasi birth,sex,visit_date
```

`--quasi` 를 안 주면 계산하지 않고 **"계산 안 함"으로 자백한 뒤 후보 열을 제안**합니다.

## 3. 안전한 사본 만들기

```bash
deidaudit 수면일기.csv UT로그.xlsx \
  --quasi birth,sex,visit_date \
  --link-id subject_id \
  --pseudonymize --shift-dates --shift-weeks \
  --drop-columns name,phone,birth \
  --out-dir 보낼폴더_2026-08-27 \
  --key-out ~/보안/키_2026-08-27.csv
```

**결과가 세 곳으로 나뉩니다. 섞이면 안 되기 때문입니다.**

```
보낼폴더_2026-08-27/내보내기/     ← 이 폴더만 보냅니다
보낼폴더_2026-08-27_점검리포트/   ← 내 컴퓨터에만 (소유자만 읽기)
~/보안/키_2026-08-27.csv         ← 절대 함께 보내지 않습니다
```

리포트를 함께 보내면 안 되는 이유: 리포트에 적힌 **행 번호가 사본의 행과 1:1 로 맞습니다.**
받은 사람이 두 파일을 나란히 놓으면 "가명 P001 = 성이 김, 1988년생, 번호 끝자리 89" 가
복원됩니다 — 증거를 아무리 마스킹해도 소용이 없습니다.

- `--link-id` : 피험자 ID 열. **파일 간 같은 사람에게 같은 가명을 주기 위해서만** 씁니다. 행을 합치지 않습니다.
- `--pseudonymize` : ID 를 `P001`, `P002` … 로 치환.
- `--shift-dates` : 피험자별로 고정된 오프셋(±180일)만큼 날짜를 이동. **방문 간격과 자정 넘김 야간 귀속은 그대로 보존**됩니다.
- `--drop-columns` : 사람이 정한 열만 뺍니다. 자동 삭제는 하지 않습니다. **열 이름이 어느 파일에도 없으면 오타로 보고 `exit 2`** 로 멈춥니다(지웠다고 생각한 열이 그대로 나가는 사고 방지).
- `--shift-weeks` : 이동량을 7의 배수로 맞춰 **요일을 보존**합니다. 수면 데이터라면 켜는 쪽을 권합니다(주중/주말은 TST·SE 의 공변량입니다).
- `--key-out` : 원본ID↔가명ID + 날짜 오프셋 매핑표. **반드시 `--out-dir` 밖에.** 안이면 실행을 거부합니다(대소문자만 다르거나 유니코드 형태만 다른 경로, 심볼릭 링크, 하드링크까지 막습니다).
- `--report-dir` : 점검 리포트 위치를 직접 지정합니다(기본값 `<out-dir>_점검리포트`).

같은 결과를 다시 만들려면 키 파일 옆에 생기는 `키_..._솔트.txt` 의 값을 `--salt` 로 주세요.

## 4. 결과 읽는 법

화면 맨 아래 한 줄이 결론입니다.

- `치명 N건 발견. 이 상태로 내보내면 안 됩니다.` → **보내지 마세요.** `문제목록.csv` 를 열어 파일·시트·행·열을 따라가 고칩니다.
- `치명 0건 · 경고 N건.` → 경고는 자동 처리하지 않습니다. 정확 날짜 열·자유텍스트 인명은 사람이 판단합니다.
- `판정불가` → 못 읽은 파일이 있습니다. **"치명 0건"이라고 말할 수 없는 상태**이니 먼저 그 파일을 해결하세요.

**[커버리지 자백] 블록을 꼭 보세요.** 몇 파일/시트/열/셀을 봤는지, 어느 열을 자유텍스트로 판정했는지,
무엇을 건너뛰었는지가 적혀 있습니다. 이 블록을 만들 수 없으면 리포트를 아예 출력하지 않습니다.

사본을 만들었다면 화면에 `[내보낸 사본 재감사]` 가 한 번 더 나옵니다. **종료코드는 사본 기준**입니다 —
"고친 결과가 정말 안전해졌는가"를 툴이 직접 확인한 값입니다.

## 5. 자주 만나는 상황

| 화면에 나온 것 | 뜻 / 할 일 |
|---|---|
| `숨김 시트 … state=hidden` | 엑셀로 열어도 안 보이는 시트에 데이터가 있습니다. 사본에는 **내보내지 않습니다**. 원본에서 삭제하세요. |
| `문서 메타데이터(작성자)` | 파일 속성에 이름이 남아 있습니다. 엑셀 → 파일 → 정보 → 문서 검사로 제거하세요. |
| `정확 날짜 열 … 날짜 이동 권고` | 방문 날짜만으로 병원 기록과 대조하면 특정됩니다. `--shift-dates` 를 쓰세요. |
| `자유텍스트 내 인명 …○○○ 간호사…` | 자유기술 칸에 사람 언급이 있습니다. **행 번호로 찾아가 사람이 판단**하세요. |
| `최소 k = 1` | 그 조합만으로 각각 한 명씩 특정됩니다. 바로 아래 "빼면 k ≥ 5" 줄을 보세요. |
| `joinaudit 을 먼저 쓰세요` | 병합 옵션을 준 것입니다. 이 툴은 파일을 합치지 않습니다. |
| `--key-out 경로가 --out-dir 안에 있습니다` | 폴더째 압축해 보내면 매핑표가 함께 나갑니다. 밖으로 옮기세요. |
| `피험자 ID 열을 찾지 못했습니다` | `--pseudonymize` 를 요청했는데 ID 열을 못 찾았습니다. 그냥 진행하면 **원본 ID 가 그대로 나갑니다.** `--link-id 열이름` 을 주세요. |
| `다음 열은 이동하지 못했습니다` | `미상`·`N/A` 가 섞여 날짜로 안 읽히는 열입니다. 그대로 두면 그 열만 원본 날짜로 나갑니다. 값을 정리하고 다시 돌리세요. |
| `헤더 행이 데이터` | 헤더 없이 저장된 CSV 입니다. 첫 행이 검사되지 않으니 헤더 행을 추가하세요. |
| `열 밖으로 밀린 값` | 자유기술 칸의 쉼표가 이스케이프되지 않았습니다. 원본을 확인하세요. |
| `숨김 열·행은 일반 열/행으로 사본에 포함됩니다` | 숨김 **시트**는 빼지만 숨김 **열/행**은 데이터라 나갑니다. 필요하면 `--drop-columns` 로 빼세요. |
| `시트 이름에 인명` | 시트 이름은 파일을 열면 바로 보이고, 시트별로 내보내면 파일 이름이 됩니다. 원본 엑셀에서 고치세요. |
| `(헤더 위 제목 행)` | 표 위의 제목 줄에 담당자 이름·연락처가 들어 있습니다. |

## 6. 하지 않는 일 (중요)

- 자유텍스트를 자동으로 지우지 않습니다 — 위치만 알려 줍니다.
- 나이를 구간으로 묶는 등의 일반화를 자동으로 하지 않습니다 — 분석이 바뀝니다.
- 파일을 합치지 않고, 통계를 계산하지 않습니다.
- PDF·DOCX·`.xls` 를 읽지 않습니다.
- **원본 파일을 절대 수정하지 않습니다.**
- 자유텍스트의 이름은 **호칭이 있을 때만** 잡습니다(`김철수 씨`·`김철수님`·`○○○ 간호사`). 호칭이 없으면(`박서연이 재측정 시행`) 놓칩니다.
- 날짜 이동은 요일과 계절을 보존하지 않습니다(`--shift-weeks` 를 쓰면 요일은 보존).
- **리포트도 원본과 같은 취급으로 다뤄 주세요.** 증거는 마스킹돼 있지만 어느 파일 어느 행에 무엇이 있었는지가 적혀 있습니다.
