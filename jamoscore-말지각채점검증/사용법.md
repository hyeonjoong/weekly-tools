# 사용법 (한글 빠른 시작)

## 0. 가장 빠른 방법

이 폴더의 **`실행.command` 를 더블클릭**하세요. 번들 예제 4종이 순서대로 돌면서
종료코드 **0 → 1 → 3 → 2** 가 어떤 상황에서 나오는지 보여 줍니다.

| 예제 | 상황 | 종료코드 |
|---|---|---|
| `정상_채점.xlsx` | 요약표가 문항과 맞고 규칙 대조도 깨끗함 | 0 |
| `문제있음_채점.xlsx` | 요약표 값 불일치 · 분모로 만들 수 없는 % · 문항수 이상 | 1 |
| `판정불가_채점.xlsx` | 점수 칸이 반쯤 비어 있어 **다 읽지 못함** | 3 |
| `요약만_있음.csv` | 문항이 없고 % 만 있음 → 판정 없이 거절 | 2 |

## 1. 내 파일로 돌리기 — **반드시 `--inspect` 부터**

이 툴은 채점 규칙도, 문항수도, 만점도 **추측하지 않습니다.** 추측하면 조용히
거짓말을 하기 때문입니다. 그래서 먼저 "내가 무엇을 무엇으로 봤는지"를 인쇄합니다.

```bash
cd ~/Downloads/02_프로젝트/깃헙/jamoscore-말지각채점검증

python3 -m jamoscore ~/Downloads/내채점파일.xlsx --inspect \
    --subtest "자음:목표=2음절초성,문항=18" \
    --subject-pattern "^s[0-9]+$"
```

> `--subject-pattern` 을 주지 않으면 정답·요약·식별정보 시트를 뺀 **모든** 시트를
> 엽니다. 이름만으로 걸러지지 않는 시트(예: `차트1`)까지 열리므로, 피험자 시트
> 이름 규칙을 아는 경우에는 처음부터 주는 편이 안전합니다.

여기서 확인할 것 세 가지:

1. **피험자 시트를 제대로 골랐는가.** 통계 시트까지 피험자로 잡혔으면
   `--subject-pattern "^s[0-9]+$"` 처럼 이름 규칙을 주세요.
2. **블록별 문항수·분모가 맞는가.** `일음절` 처럼 한 블록을 두 번(단어·음소)
   채점한 파일이면 분모가 18과 54로 갈립니다 — 그 사실이 파일에는 안 적혀 있습니다.
3. **`[레이아웃 경고]` 가 있는가.** 있으면 본 실행에서 소견으로 보고됩니다
   (문항수가 선언과 다르면 `[치명]`, 패스가 통째로 없으면 `[경고]`).

열 이름을 못 찾으면 툴은 **멈추고 사유를 한국어로 인쇄합니다**(종료코드 2).
엑셀의 헤더를 `제시자극 | 응답 | 점수` 형태로 고치거나, `--inspect` 로 실제 헤더를
확인한 뒤 검사 이름을 맞춰 주세요.

## 2. 본 실행 (실제 임상 파일 예시)

```bash
python3 -m jamoscore ~/Downloads/본실험_결과.xlsx \
    --subtest "자음:목표=2음절초성,문항=18" \
    --subtest "모음:목표=1음절중성,문항=14" \
    --subtest "일음절:단위=단어,목표=전체,문항=18" \
    --subtest "일음절:단위=음소,목표=초중종,문항=18,만점=3" \
    --subject-pattern "^s[0-9]+$" \
    --answer-key 언어검사_정답 \
    --summary total-최종 \
    --map 매핑.json \
    --out-dir ~/Desktop/채점검증_0911
```

(`--map` 은 요약표 열 이름을 툴이 해석하지 못할 때만 필요합니다. 없으면 빼세요 —
해석하지 못한 열은 자백 블록에 적힙니다.)

`pip install -e .` 를 한 번 해 두면 `python3 -m jamoscore` 대신 `jamoscore` 로
줄여 쓸 수 있습니다.

## 3. 결과 읽는 법

리포트는 **심각한 것부터** 나옵니다.

### `[치명]` — 논문 표에 넣기 전에 반드시 정리해야 하는 것

- **요약표 값 불일치 / 시트 요약값 불일치** — 표에 적힌 %가 문항에서 다시 나오지
  않습니다. 분모(`14/18`)를 같이 찍어 주니 어느 쪽이 맞는지 바로 보입니다.
- **불가능한 백분율** — 분모 18로는 어떤 정답수로도 나올 수 없는 값(`70.0%` 등).
  옮겨 적는 과정에서 생긴 값입니다.
- **레이아웃 이상** — 선언한 문항수와 시트에서 읽은 행 수가 다릅니다.
- **자극 리스트 불일치** — 정답 시트의 어느 리스트와도 맞지 않습니다(빠진·중복 자극).
- **요약표 열이 한 행 밀림** — 표의 값이 바로 아래 피험자의 값과 같습니다.
  붙여넣기 사고의 전형이고, 밀린 구간을 통째로 짚어 줍니다.
- **요약표에 행이 없는 피험자 / 집계행이 일부 피험자만으로 계산됨** — 그 표로
  논문 표를 만들면 빠지는 사람이 있고, 표 아래 평균·표준편차는 전원이 아닙니다.
- **채점 선언 의심** — 규칙 대조가 80% 넘게 어긋납니다. 자료가 아니라 `--subtest`
  선언(목표 규칙·만점)이 틀렸을 가능성이 큽니다.

### `[경고]` — 사람이 원 기록을 봐야 하는 것

- **응답이 전부 비었는데 0점** — 미실시·탈락이 0점으로 기록된 것으로 보입니다.
  그 블록은 `statwise`·`longistat` 입력 CSV 에서 **빼고** 내보냅니다.
- **사람 채점과 규칙 채점이 다름(확인 필요)** — 어느 쪽이 맞는지는
  **이 툴이 판정하지 않습니다.** `규칙대조.csv` 에 전수가 들어 있습니다.
- **동일 쌍 다른 채점** — 같은 (제시, 응답)인데 점수가 다릅니다.
  채점 규칙이 무엇이든 성립하는 소견이라 가장 확실한 확인 대상입니다.
- **같은 문항을 두 번 다르게 전사** — 한 발화를 단어 패스와 음소 패스에서
  다르게 옮겨 적었습니다. 둘 중 하나가 원 기록과 다릅니다.
- **응답 칸 위생** — 관찰 메모 혼입, 한글 외 문자, 응답은 비었는데 점수가 있음 등.

### `[정보]` — 해석에 쓰는 것

- **음소 혼동 상위** — `혼동행렬_초성.csv` 등에 전체 표가 있습니다.
  관측 3회 미만 칸은 표에서 빼고 그 개수를 자백합니다(`--min-count` 로 조절).
- **개인 내 변화와 검사 오차 범위** — `임계차.csv` 에 피험자별로
  `사전 · 사후 · 변화%p · 오차범위 정답수 · 95% 임계차 · 판정` 이 들어 있습니다.
  판정 어휘는 **`초과` / `미달` / `판정불가` 세 가지뿐**입니다.
  예: n=18 · 사전 12/18 이면 오차범위는 7~16 정답이라, 2문항(11.1%p) 변화는
  **`미달`** 입니다. 이 사실을 툴이 정직하게 말합니다.
  임계차는 `↓33.3 ↑27.8` 처럼 **방향별로** 적히고, 천장(18/18)처럼 그 방향으로
  벗어날 수 없으면 `↑—` 로 비워 둡니다.
  **주의:** 이 구간은 사전 점수 하나로만 만든 것이라 문헌의 임계차 표보다
  좁습니다. 논문에 쓸 때는 `Methods_초안.md` 의 경고 문단을 함께 읽으세요.
- **천장·바닥 도달** — 그 블록에서는 더 좋아지거나 나빠질 폭이 구조적으로 없습니다.

### `[커버리지 자백]` — **여기를 꼭 읽으세요**

무엇을 못 봤는지가 적혀 있습니다. 이 블록이 없으면 리포트 자체가 출력되지
않습니다(코드로 강제). **리포트에 안 나온 항목이 "이상 없음"이라는 뜻이 아닙니다.**

## 4. 결과를 다음 툴로 넘기기

`--out-dir` 안의 `statwise_longistat_입력/` 폴더에 검사별 CSV(`ID,시점,점수`)가
바로 쓸 수 있는 모양으로 들어 있습니다.

```bash
cd ~/Desktop/채점검증_0911/statwise_longistat_입력

# 전/후 대응 비교
python3 -m statwise.cli 자음_단어.csv --paired --value 점수 --group 시점 \
    --id ID --baseline 사전

# 시점 추이
python3 -m longistat.cli 자음_단어.csv --id ID --time 시점 --value 점수 \
    --time-order 사전,사후
```

`Methods_초안.md` 에는 채점 규칙·분모·임계차 산출 방식을 그대로 문장화한
한국어/영어 초안이 들어 있습니다. 숫자를 넣을 자리는 비워 두었습니다.

## 5. 자주 막히는 곳

**Q. `--subtest 가 없습니다` 라며 멈춥니다.**
A. 일부러 그렇습니다. 검사마다 무엇을 맞히면 정답인지가 달라서, 툴이 정하면
안 됩니다. `--inspect` 로 검사 이름을 확인한 뒤 선언해 주세요.

**Q. `만점=3 인데 목표=초중종 규칙의 만점은 3 입니다` 같은 오류가 납니다.**
A. 선언한 만점과 목표 규칙이 어긋났습니다. 툴은 만점을 추론하지 않는 대신,
선언이 규칙과 맞는지 확인합니다.

**Q. 응답·점수 열을 못 찾는다고 멈춥니다.**
A. 자극 열 **오른쪽 4칸 안에** `응답`·`점수`(또는 `반응`/`전사`/`response`,
`채점`/`score`) 헤더가 있어야 합니다. 엑셀 헤더를 고치는 쪽이 가장 빠릅니다.

**Q. 요약표 열 몇 개가 "대조하지 못한 열"로 나옵니다.**
A. 열 이름을 해석하지 못한 것입니다(예: `일음절2_차이`). 억지로 맞추면 가짜
불일치가 나오므로 조용히 넘기지 않고 자백만 합니다. 꼭 대조하려면
`--map 매핑.json` 으로 알려 주세요.

```json
{
  "요약열": {
    "일음절2_차이": { "검사": "일음절", "단위": "음소", "종류": "차이" }
  }
}
```

**Q. 자극 리스트가 사전·사후에 서로 바뀌어 있는데 오류가 안 납니다.**
A. 맞습니다. 상쇄균형(counterbalancing) 설계가 흔해서, **어느 리스트를 썼는지는
자료가 말하게** 둡니다. 대신 `[정보] 사용한 자극 리스트` 로 몇 명이 어느 리스트를
썼는지 보여 줍니다.

**Q. 개인정보 시트가 걱정됩니다.**
A. 이름이 `개인정보`·`명단`·`연락처` 류면 그 시트의 셀을 **한 번도 열지 않습니다**
(`--pii-sheet 우리회사표기` 로 이름 조각을 더할 수 있습니다). 열어 본 시트라도
열 이름이 이름·연락처·생년월일이면 읽자마자 버립니다. 전사 칸에 적혀 들어온
전화번호·주민등록번호·생년월일은 리포트와 모든 CSV에서 `010-****-****` 처럼
가립니다.
다만 사람 **이름**은 어떤 패턴으로도 못 잡습니다. 시트 이름이 곧 사람 이름인
파일이라면 `--subject-pattern` 으로 거르고, 외부로 내보내기 전에는 반드시
`deidaudit` 를 한 번 돌리세요.

**Q. 응답 칸에 `모름` 이라고 적혀 있습니다.**
A. 그건 전사가 아니라 '반응 없음' 기록이라, 규칙 대조와 혼동 행렬에서 뺍니다
(`모름` 을 자리별로 대조하면 "모든 모음이 ㅗ로 간다" 같은 없던 패턴이 생깁니다).
다른 표기를 쓰신다면 `--non-response 무반응` 처럼 추가하세요.
