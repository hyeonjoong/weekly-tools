### 문서 정정 (검토자가 README 숫자를 직접 재현해 대조)

- `"요약 셀 308개 … 전부 맞았습니다. 옮겨 적기는 정확했습니다."` → **거짓이었다.** 308은 피험자 7명이 빠진 분모였고, 대조하지 못한 `일음절2_차이` 열에는 **한 행씩 밀린 값 4개**가 있었다. 해당 문단 전면 교체.
- `"2,240문항 중 2,172건 일치(불일치 0.2%)"` → 2240−2172 = 68 로 3.0%. 실제 수치는 **2,169문항 대조 · 갈림 4건(0.2%)**. 교체.
- README 의 예시 출력을 **현재 코드로 다시 돌린 실제 출력**으로 전면 교체.
- `--response-alias` / `--score-alias` 를 오류 메시지가 안내하는데 **그 옵션이 없었다** → 실제로 구현.
- 사용법의 `--map` 예시가 `"단위": "단어"` 로 잘못돼 있어, 그대로 따르면 진짜 소견 4건이 가짜 26건에 묻혔다 → `"음소"` 로 정정하고, 한 열이 거의 전부 어긋나면 **`[치명] 요약표 열 매핑 의심`** 한 건으로 묶도록 코드도 수정.
- `"식별정보 시트는 열지 않습니다"` → 시트 부분은 사실이지만 엑셀의 **공유 문자열 테이블**은 메모리에 올라온다는 사실을 명시.
- `HARDENING.md` 링크가 404 였다(이 파일).
- `jamoscore` 콘솔 스크립트가 `PATH` 에 없을 수 있어 `python3 -m jamoscore` 를 기본 예시로.

산출물 폴더 **바깥**까지 훑고, 줄 위조는 시트 이름·응답 칸 두 경로를 모두 본다.
