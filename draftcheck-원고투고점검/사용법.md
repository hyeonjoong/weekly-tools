# 사용법 (빠른 시작)

## 1분 만에 보기

폴더 안의 **`실행.command`를 더블클릭**하세요. 결함을 일부러 심은 예제 원고와 깨끗한 대조본을
나란히 돌려서, 이 툴이 무엇을 잡아내는지(그리고 정상 원고에서는 조용한지) 바로 보여 줍니다.

## 내 원고로 쓰기

한 번만 설치하면 어디서든 `draftcheck` 명령을 쓸 수 있습니다.

```bash
cd ~/Downloads/02_프로젝트/깃헙/draftcheck-원고투고점검
python3 -m pip install -e .
```

### 예 1. 투고 직전, 일단 한 번 돌려보기

```bash
draftcheck ~/Downloads/내원고_v7_최종.docx
```

Word 원고를 그대로 주면 됩니다. 추적 변경이 남아 있어도 **삭제된 문장은 빼고** 최종본 기준으로 봅니다.
EndNote 필드로 넣은 인용도 화면에 보이는 대로 읽습니다.

### 예 2. 저널 한도까지 함께 대조하기

```bash
draftcheck 내원고.docx --limits examples/journals/sleepmed.json
```

저널 홈페이지의 Author Guidelines를 보고 JSON을 하나 만들어 두면 리비전마다 재사용할 수 있습니다.

```json
{
  "journal": "Sleep Medicine",
  "title_chars_max": 120,
  "abstract_words_max": 250,
  "body_words_max": 4000,
  "references_max": 50,
  "figures_tables_max": 6
}
```

필요 없는 항목은 빼면 됩니다(그 항목은 계수만 보여 줍니다).

### 예 3. 공저자에게 보낼 리포트로 저장하기

```bash
draftcheck 내원고.docx --limits sleepmed.json --out-dir 점검_20260806
```

`점검_20260806/` 안에 세 개가 생깁니다.

- `점검결과.md` — 줄번호가 붙은 한국어 리포트. 그대로 공저자에게 보내면 됩니다.
- `문제목록.csv` — 엑셀에서 심각도·유형으로 정렬/필터
- `references.csv` — 이어서 `citecheck references.csv` 로 DOI 실존·철회까지 확인

**원본 원고는 절대 수정되지 않습니다.** 출력은 `--out-dir` 폴더에만 만들어집니다.

## 결과 읽는 법

```
■ 치명 5건        ← 지금 고치지 않으면 리뷰어/에디터가 반드시 잡는 것
■ 경고 7건        ← 고치는 편이 좋은 것 (저널 지침·통계 보고 관행)
■ 정보 …          ← 참고 (확인됐다는 긍정 보고도 여기 나옵니다)
```

- 앞의 `L142`는 **줄 번호**입니다. `.docx`에서는 **문단 번호**(Word 화면의 줄 번호가 아닙니다).
  `--dump-text` 로 번호가 붙은 텍스트를 그대로 볼 수 있습니다.
- **`■ 이 점검이 실제로 본 것`** 을 꼭 보세요. "인용 26개를 인식했고 목록은 26개"처럼
  이 툴이 무엇을 봤는지 스스로 보고합니다. 이 숫자가 원고 실제와 크게 다르면 결과를 믿지 마세요.

### 가장 중요한 한 가지: '점검 불가'

```
┏━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━┓
┃★ 점검 불가 — 아래 항목은 '이상 없음'이 아닙니다   ┃
┗━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━┛
```

이 상자가 보이면 **통과한 게 아니라 확인을 못 한 것**입니다. 참고문헌 목록이 별도 파일이거나
"References" 제목이 없는 원고가 흔한데, 그때 조용히 "이상 없음"을 찍으면 위험하기 때문에
일부러 크게 알립니다. 그 부분은 눈으로 확인하세요.

## 자주 겪는 상황

| 상황 | 이렇게 하세요 |
|---|---|
| 인용을 하나도 못 찾았다고 나옴 | `--dump-text` 로 본문이 제대로 뽑혔는지 확인. 인용이 이미지·필드로만 있으면 인식되지 않습니다 |
| 저자-연도 스타일인데 매칭률이 낮음 | 출력의 "인용 N개 중 M개 매칭" 숫자를 보세요. 낮으면 결과를 신뢰하지 말고 눈으로 확인 |
| 표에 쓴 약어가 자꾸 걸림 | `--abbrev-ok ISI,PSQI,WASO` 로 예외 처리 |
| 그림을 별도 파일로 내는 저널 | 캡션이 원고에 없으면 그림 번호 대조는 자동으로 건너뛰고 그 사실을 알려 줍니다 |
| `.doc`(구형) / PDF 원고 | Word에서 `.docx`로 다시 저장한 뒤 실행하세요 |
| 스크립트/CI에서 쓰고 싶음 | `--strict` (문제 1 · 점검 불가 3 · 오류 2 · 정상 0) |

## 하지 않는 일

영문 교정, 과학적 타당성 판단, 문헌이 실제로 존재하는지(DOI 검증 → `citecheck`),
참고문헌 스타일 자동 변환, 저널 템플릿 서식 적용, 표절 검사. 그리고 **원고를 자동으로 고치지 않습니다.**
