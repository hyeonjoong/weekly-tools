# calmbark — 반려견 안정 사운드 N-of-1 실험

반려견이 짖으면 마이크로 감지해, 사용자의 NBR 리비전 원고 티어 프레임워크대로
**합성한 저각성 안정 사운드를 자동 재생**하고, 모든 짖음 에피소드·개입 여부를 CSV로
남겨 **"이 소리가 실제로 우리 개의 짖음을 줄이는가"를 N-of-1 실험으로 검증할 수 있게**
하는 오프라인 브라우저 앱입니다. 카탈로그 최초의 데이터 **수집** 도구입니다 —
분석은 statwise / longistat 가 받습니다.

---

## 목적 / Why this exists

**한국어.** 재택 근무 중 옆방에서 개가 택배 기사 소리에 짖기 시작하면, 우리는
유튜브에서 "dog calming music"을 틀어줍니다. 효과가 있는지는 아무도 모릅니다 —
세어본 적이 없으니까요. 그리고 그 영상이 왜 진정 효과가 있다는 건지 근거는 아무
데도 없습니다. calmbark 는 이 두 구멍을 동시에 막습니다. 첫째, 재생되는 소리는
파일이 아니라 **논문 Table 1 의 설계 규칙(안정 레벨, 완만한 어택, 30–150 Hz 변조
회피, 규칙적 패턴, 느린 템포 — 문헌 예시 60–80 BPM(구현 허용 대역 42–80 BPM),
고주파 제한, 음의 스펙트럼 기울기)을 코드로 옮긴 합성**이고, 그 준수 여부가
`node --test` 회귀 테스트 8종 + 검증 시드 16종 스위프로 고정되어 있습니다 —
논문 주장을 기계가 검사합니다. 둘째, 효과를 주장하는 대신 **측정**합니다:
에피소드 단위 50% 무작위 개입 모드가 개입/비개입 에피소드의 짖음·지속·오염 여부를
CSV로 남기고, 판단은 statwise 가 합니다.

**English.** calmbark is a fully offline browser app that detects dog barking via the
microphone and responds with a **synthesized low-arousal sound** whose design rules are
taken from Table 1 of the author's manuscript under revision at *Neuroscience &
Biobehavioral Reviews* — stable level, gradual onsets, avoidance of the 30–150 Hz
amplitude-modulation (roughness) band, predictable structure, slow modulation near
the literature's exemplar 60–80 BPM (implementation tolerance 42–80 BPM), limited
high-frequency energy, negative spectral slope. Compliance is not
a claim: each rule is pinned by an automated regression test against the rendered PCM.
And efficacy is not a claim either: a per-episode 50% randomized-intervention mode
produces a CSV so the effect can be *tested* (in `statwise`), not asserted. Every
byte stays on your machine — zero network requests, zero audio recording.

> **이 툴이 이기는 지점은 소리가 아니라 검증 가능성입니다.** "강아지 진정 음악"은
> 유튜브에도 많습니다. 유튜브가 절대 주지 않는 것은 (1) 왜 이 소리인지 논문 표
> 행 단위로 답할 수 있는 파라미터 소급성과 (2) 우리 개에게 실제로 효과가 있는지
> 검정할 수 있는 개입/비개입 로그입니다.

## 논문 ↔ 구현 대응표

그리고 어떤 회귀 테스트가 그것을 고정하는지 (`tests/paper-compliance.test.mjs` —
프리셋 3종 × 시드 3종(패널 재현 시드 8·15 포함) × 지표 8종, **검증 시드 16종
전수 ②④ 스위프**, 음성 대조 8종):

| Tier | 파라미터 | 논문 설계 규칙 | calmbark 구현 | 회귀 테스트 (프록시) |
|---|---|---|---|---|
| 1 | Event Structure | 안정 평균 레벨, 순간 Lmax 최소화 | 지속 텍스처 + 느린 AGC + 영위상 엔벨로프 정칙화, 얕은 진폭변조만 | ⑤ 125 ms RMS p95−p5 ≤ 15 dB, max−p50 ≤ 12 dB · ⑧ 크레스트/클릭 가드(1 ms 피크 ≤ 국소 RMS+14 dB, 차분 크레스트 ≤ 22 dB) |
| 1 | Onset Dynamics | 완만한 어택 (수십 ms 이상) | 모든 레벨 상승이 올림코사인 반주기(≈300 ms), 개입 페이드인 1.5 s(소스 검사로 ≥1 s 고정) | ④ 온셋(≥8 dB 돌출) 10–90% 상승 ≥ 50 ms — 검증 시드 16종에서는 ≥ 60 ms |
| 1 | Roughness | 러프니스 최소화 (Arnal et al. 2015: 편도체가 30–150 Hz AM 주율에 선택 반응) | 이산 트레몰로 없음; 영위상 정칙화로 20 Hz 초과 확률 변조 억제; 드론 부분음 간격을 2·f0=168–208 Hz 로 설계해 대역 회피 | ② 변조 스펙트럼 30–150 Hz: 이산 피크 ≤ +10 dB & 대역 융기 ≤ 1.0 — 검증 시드 16종에서는 융기 ≤ 0.90 |
| 1 | Predictability | 규칙적 패턴, 급격한 구조 변화 회피 | 엄격 주기 변조, 루프 무봉합(크로스페이드+정수 사이클+위상 적분 정수) | ⑦ 변조 주기 자기상관 r ≥ 0.7 (실측 0.94–0.99) |
| 2 | Tempo / Rhythm | 문헌 예시 60–80 BPM, 개체 안정 HR 적응 | 느린 진폭변조 1.0 / 1.1 / 1.0 Hz = 60·66·60 BPM (전부 문헌 예시 대역 안) | ③ 지배 변조 주율 0.7–1.33 Hz (42–80 BPM — 구현 허용 대역) |
| 2 | Sharpness | 고주파 에너지 제한 (1.5 acum 은 잠정값) | 저역통과 캐스케이드 — 초음파 성분 구조적 0 | ⑥ >4 kHz 에너지 ≤ 5% (실측 ≤ 0.7%) |
| 2 | Pitch | 저–중역 중심, 하강 음형 | 드론 프리셋: 84–104 Hz, 12 s 반코사인 하강 음형 | (전용 테스트 없음 — 드론 스펙트럼이 ①⑥ 에 포함) |
| 2 | Spectral Slope | 음의 기울기, 핑크~브라운 | 캐리어 목표 β≈−1(핑크)·−2(브라운) — **실측(100 Hz–8 kHz 회귀) −2.8 / −4.0 / −5.6**: 저역통과 캐스케이드가 회귀 상단(>1.2 kHz)을 추가로 깎아 핑크~브라운 서술 범위(−1~−2)보다 가파르다 | ① β ≤ −0.5 단측 — 덜 가파른(0 쪽) 위반만 각성 방향 위험이므로. 더 가파른 쪽은 샤프니스에 유리하나 논문의 "핑크~브라운" 문구보다는 어두운 소리임을 명시 |
| 2 | Complexity | 저복잡도 기악 텍스처 | 무선율 잡음/드론 텍스처 (구조적으로 저복잡도) | (전용 테스트 없음) |
| 3 | Semantic Content | 기악 기본, 가사는 통제 시에만 | 전부 합성 — 언어 성분 자동 부재 | (합성이므로 구조적 충족) |
| 3 | Harmonicity · Familiarity | 보편 처방 불가 | 처방하지 않음 (개체 선호 프로파일링은 범위 밖) | — |

**프록시 고지:** 위 테스트 지표는 정식 심리음향 단위(asper 러프니스, acum 샤프니스,

## 실험 모드와 산출물

| 모드 | 동작 | 용도 |
|---|---|---|
| 관찰 | 감지·기록만, 재생 없음 | 기저선 수집 (권장 시작점) |
| 상시 개입 | 모든 에피소드에 재생 | 적응/기기 확인용 — 효과 비교 불가 |
| **무작위 개입** | **에피소드 단위 50% 배정, seed 기록** | **N-of-1 비교 (권장)** |

CSV 두 벌을 내려받습니다 (UTF-8 BOM, 수식 인젝션 가드 적용):

- `calmbark_이벤트_YYYYMMDD_HHMM.csv` — `타임스탬프,유형,에피소드ID,상세`
  (세션시작·보정완료·에피소드시작·**배정**(seed 포함)·짖음·**짖음(재생중)**·재생시작·
  **재생연장**(새 에피소드가 기존 재생을 연장)·재생종료·에피소드종료·**에피소드재개**·
  **갭(N초)**(절전/탭 정지 공백)·**시드(미검증)**·오류(보정실패/마이크종료)·세션종료)
- `calmbark_에피소드_YYYYMMDD_HHMM.csv` —
  `에피소드ID,시작,종료,짖음횟수,지속초,개입여부,모드,seed,재생겹침초,후속180초짖음수`

에피소드 규칙: 마지막 짖음 종료 후 30초 안 재짖음은 같은 에피소드.

**결과지표와 오염 (라운드 1 C1 — 꼭 읽으세요):** 재생(기본 180초)은 에피소드 병합
간격(30초)보다 깁니다. 그래서 개입 에피소드의 재생이 아직 나오는 중에 새 에피소드가
시작되면, 그 에피소드가 "비개입"으로 배정됐어도 실제로는 소리에 노출됩니다.
calmbark 는 에피소드 규칙을 군마다 비대칭으로 바꾸는 대신(병합 편향) 오염을 열로
드러냅니다:

- **1차 비교 지표는 `후속180초짖음수`** — 에피소드 시작 후 180초 *고정* 창의 짖음
  수. 창이 두 군에 동일해서 "개입 에피소드는 재생이 짖음을 억누르는 동안 계속
  연장·연결된다"는 지속시간 계열의 편향이 없습니다.
- **`재생겹침초` > 0 인 비개입 에피소드는 오염**입니다 — per-protocol 비교에서
  제외하세요(화면 요약에도 ⚠오염 으로 표시). ITT 식으로 전부 넣은 결과와 제외한
  결과를 둘 다 보고하는 것을 권합니다.

하류 연결 (아래 명령은 실제 실행 확인됨):

```bash
# 개입/비개입 1차 비교 — 에피소드 단위
statwise calmbark_에피소드_*.csv --value 후속180초짖음수 --group 개입여부

# 일차 추이 (여러 날 수집 후): 에피소드 CSV들을 합치고 `시작` 열에서 날짜 열을
# 만든 다음 — 군(개입여부)을 대상으로, 날짜를 시점으로. 같은 날 여러 에피소드는
# --duplicates mean 이 하루 평균으로 요약한다.
longistat 병합_날짜열추가.csv --id 개입여부 --time 날짜 --value 후속180초짖음수 --duplicates mean
```

> **주의 — 에피소드는 독립 관측이 아닐 수 있습니다.** 같은 날의 연속 에피소드는
> 상관될 수 있습니다(자극원 지속, 흥분 이월). 화면 요약은 기술통계까지만 보여주며,
> 표본이 작으면 차이는 우연입니다 — 검정은 statwise 로 하고, 여러 날 수집을 권합니다.
> longistat 추이는 "대상"이 개입/비개입 2개뿐인 기술적(descriptive) 용도입니다 —
> 확증 검정은 에피소드 단위 statwise 로 하세요.

## 정직성 절 (Honesty)

- **효과는 미검증입니다.** 이 앱은 효과를 검증할 수 있게 하는 도구이지, 효과가
  검증된 도구가 아닙니다. "효과 없음"이 결과여도 도구로서는 성공입니다.
- **종간 외삽입니다.** 근거 프레임워크는 사람 대상 문헌의 종합입니다. 개의 청각
  범위·정서 반응은 다르며, 개 대상 파라미터 검증은 존재하지 않습니다. 이 앱이
  만드는 데이터가 바로 그 공백을 개인 수준에서 메우는 시도입니다.
- **감지는 휴리스틱입니다.** 250–4000 Hz 대역 에너지 문턱 — ML 분류가 아닙니다.
  문 닫는 소리·TV·박수가 짖음으로 기록될 수 있고(오탐), 낮은 낑낑거림은 놓칠 수
  있습니다(미탐). 오탐 의심 행(짖음 1회·지속 0초대)은 CSV에서 사후 식별하세요.
- **재생음 자기 감지 가능성.** 재생 중 감지는 문턱 +6 dB·소음 바닥 동결로 완화했고
  `짖음(재생중)` 유형으로 따로 기록되지만, 스피커·방 배치에 따라 자기 트리거가
  완전히 없다고 보장할 수 없습니다. 재생 중 행은 보수적으로 해석하세요.
- **무작위 모드의 대조군은 오염될 수 있습니다.** 재생이 에피소드 간격보다 길어서,
  비개입 배정 에피소드가 직전 개입 에피소드의 재생에 노출된 채 기록될 수 있습니다.
  이 노출은 숨기지 않고 `재생겹침초` 열로 드러납니다 — 지속시간 계열 지표를 그대로
  비교하면 개입 효과가 과대/과소평가될 수 있으므로, 1차 지표는 고정 창
  `후속180초짖음수` 를 쓰고 오염 행은 per-protocol 에서 제외하세요.
- **수의학적 조언이 아닙니다.** 심한 분리불안·자해 수준의 반응이 의심되면
  수의사·행동 전문가와 상담하세요. 혐오 자극(초음파 목걸이류)과 정반대 접근이지만,
  그렇다고 치료가 되는 것은 아닙니다.
- **볼륨은 디지털 게인 %일 뿐입니다.** 절대 SPL 보정이 없습니다 — 실제 음압은
  스피커·거리·방에 좌우됩니다. 개의 청각은 사람보다 민감하므로 낮게 시작해
  사람 귀 기준 "배경음 수준"을 넘기지 마세요.

## 한계 (솔직하게)

- **통계를 하지 않습니다.** 화면 비교표는 기술통계뿐입니다. 검정은 statwise,
  추이는 longistat 의 몫입니다.
- **온셋 테스트는 8 dB 미만 돌출을 보지 않습니다.** 가우스 텍스처의 제거 불가능한
  자체 요동 아래는 "이벤트"로 정의하지 않았습니다. 그 미시 영역은 ⑧ 크레스트/클릭
  가드가 별도로 지킵니다(HARDENING.md).
- **논문 준수는 44.1 kHz 기준, 시드는 검증 목록 기준입니다.** 테스트가 강제하는
  것은 정확히 이것입니다: 검증 시드 16종 × 3 프리셋에서 ②(융기 ≤0.90)·④(상승
  ≥60 ms), 그리고 시드 3종(패널 재현 시드 8·15 포함)에서 지표 8종 전부. 목록 밖
  시드는 보장하지 않으며 앱이 `시드(미검증)` 으로 기록합니다. 48 kHz 는 렌더
  스모크만 합니다.
- **백그라운드 탭에서는 감지가 거칠어집니다.** 타이머가 초당 1회 수준으로 스로틀되어
  1초 미만 버스트를 놓칠 수 있습니다. 5초 이상 프레임 공백(절전 등)은 `갭(N초)`
  이벤트로 기록되고 걸친 버스트는 폐기됩니다. 세션 중에는 탭을 전면에 두세요.
- **다일 스케줄링·모바일 패키징·고양이(타 축종) 모드는 없습니다.** 세션 단위
  도구입니다. 타 축종은 감지 대역·프리셋 검증이 전혀 없으므로 지원하지 않습니다.
- **감지 프레임 계층(app.js)은 실행 테스트 밖입니다.** 순수 로직(엔진·감지기·집계)은
  전부 오프라인 테스트로 고정했고, app.js 의 안전 상수·가드(페이드 ≥1 s, 미리듣기
  세션 차단, 단조 시계, 시드 정책 등)는 소스 계약 검사로 고정했지만, WebAudio
  접착층의 *실행*은 수동 스모크만 거쳤습니다.
- **echoCancellation 을 껐습니다.** 켜면 OS가 스피커 소리와 함께 개 소리 특성도
  왜곡할 수 있어서입니다. 대신 자기 트리거 완화는 문턱·동결·별도 로그로 처리합니다.
