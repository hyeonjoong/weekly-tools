# HARDENING LOG — surveyscan (설문 응답 CSV 분석기)

이 파일은 배포 전, 도구를 무인(無人)으로 출시하기 위해 거친 **다회차 적대적 하드닝** 및
**심층 기능 개선**의 기록입니다. 매 라운드마다 Agent 도구로 **독립적인 전문 검토자 패널을
병렬로** 소환해, 각자 우선순위가 매겨진 구체적·재현가능한 결함 목록(파일:줄, 깨뜨리는 입력)을
받았습니다. 제작자(메인 루프)가 모든 material 결함을 고치고 pytest를 재실행한 뒤 다음 라운드를
시작했습니다.

검증 기준선: 모든 통계는 scipy 1.17.1 / numpy 를 오라클로 제1원리에서 재계산하여 대조합니다
(betainc ≤4e-14, t/F 분위수 ≤~1e-11, Cronbach α·SEM·문항간 상관·왜도(G1)·첨도(G2)·
분위수는 기계정밀도 일치). **런타임은 표준 라이브러리만** 사용하며, scipy/numpy 는 테스트에서
오라클로만 씁니다.

## 2026-07-16 — v0.1 → v0.2 심층 개선 (임상 연구자 관점의 신규 역량)

기존 도구(문항 기술통계·결측·역문항·하위척도 평균·Cronbach α·문항총점 상관·문항제거시 α)에
임상/제약 연구자가 논문 Methods/Results에 바로 쓸 수 있는 역량을 대폭 추가했습니다.

**신규 통계·분석.**
- **Cronbach α의 95% 신뢰구간 (Feldt 1965, F 분포).** 순수 파이썬으로 정규화 불완전
  베타함수(연속분수 Lentz)→t·F 분포 CDF/PPF 를 직접 구현(`special.py`). scipy 대비
  betainc ≤4e-14, t/F 분위수 ≤~1e-11 일치. 문헌 예시(α=.90,n=100,k=10→[.868,.927])로 검증.
- **측정의 표준오차 SEM = SD_점수·√(1−α)** — 점수 지표(평균/총합) 단위로 보고.
- **평균/최소/최대 문항간 상관(inter-item r)** — 신뢰도 진단 보조 지표.
- **하위척도 점수 CI (t 분포 기반)** 및 **왜도(G1)·첨도(G2)·사분위(Q1/Q3)** 문항 통계
  (SPSS/Excel 편향보정 공식과 동일).
- **바닥/천장 효과(floor/ceiling)** — 척도 범위 선언 시 가능한 최소/최대 점수에 몰린 비율,
  15% 초과 시 ⚠ 플래그.

**신규 입출력·옵션.**
- **총합(sum) 점수 방식 + 비례배분(pro-rate)** — ISI·PHQ-9·GAD-7 등 총점 척도 지원.
  `score_method`(config) / `--score-method`(CLI).
- **Markdown 출력**(`--format md`) — 논문 초안·GitHub·노션 붙여넣기용 표.
- **응답자별 점수 CSV 내보내기**(`--scores-out`) — ID 유지, 원자료에 재병합. CSV 수식 인젝션 가드.
- **탭 구분자**(`--delimiter tab`), **신뢰수준 지정**(`--ci-level`), `--format text|json|md`,
  `--json` 은 하위호환 별칭으로 유지.

**테스트.** 35개 → 74개. `special.py` 는 scipy 사전계산 참조값을 하드코딩(런타임 무의존)하고,
불변식(하한≤α≤상한, 완전응답 시 sum==mean×k, CDF/PPF 왕복)과 손계산 기대값으로 검증.
