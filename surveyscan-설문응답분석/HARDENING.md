# HARDENING LOG — surveyscan (설문 응답 CSV 분석기)

이 파일은 배포 전, 도구를 무인(無人)으로 출시하기 위해 거친 **다회차 적대적 하드닝** 및
**심층 기능 개선**의 기록입니다. 매 라운드마다 Agent 도구로 **독립적인 전문 검토자 패널을
병렬로** 소환해, 각자 우선순위가 매겨진 구체적·재현가능한 결함 목록(파일:줄, 깨뜨리는 입력)을
받았습니다. 제작자(메인 루프)가 모든 material 결함을 고치고 pytest를 재실행한 뒤 다음 라운드를
시작했습니다.

검증 기준선: 모든 통계는 scipy 1.17.1 / numpy 를 오라클로 제1원리에서 재계산하여 대조합니다
(betainc ≤4e-14, t/F 분위수 ≤~1e-11, Cronbach α·SEM·문항간 상관·왜도(G1)·첨도(G2)·
분위수는 기계정밀도 일치). **런타임은 표준 라이브러리만** 사용하며, scipy/numpy 는 테스트에서
오라클로만 씁니다.

## 2026-07-31 — 기능 확장(집단 비교 · 임상 심각도 구간) + 라운드 3 (4인 병렬 패널)

**추가한 기능.**
- **집단 비교 `--group-col`** (`compare.py` 신설): 하위척도 점수를 집단별로 나눠 N·평균·SD·중앙값과
  **집단별 Cronbach α**, 2집단이면 **Welch t + 평균차 CI + Hedges' g(CI)**, 3집단 이상이면
  **Welch ANOVA**, 하위척도가 여러 개면 **Holm 보정 p**. 부호 기준(A−B)·검정 제외 집단·라벨 없는
  응답자 수를 모두 표기하고, "탐색적 분석" 캐비앗을 리포트에 고정.
- **임상 심각도 구간 `severity_bands`**: 점수를 임상 범주(ISI 0–7/8–14/15–21/22–28 등)로 나눈
  `N(%)` 분포표 + `--scores-out` CSV의 응답자별 `_심각도` 열. 겹침·오타·단위 불일치는 오류/⚠로 차단.
- 예시 자료에 `군`(치료/대조) 컬럼 추가, 예시 config를 ISI 관례대로 `sum` + 구간으로 갱신.
- 버전 0.2.0 → 0.3.0.

**패널 결론.** 정확성 패널은 Welch t/df/p·CI, Welch ANOVA(statsmodels 대조), Hedges g, Holm,
norm_ppf, 집단별 α를 재계산해 **~1e-15 일치** 확인. 엣지 패널은 5000×40 자료 정확성·행 정렬을
독립 재계산으로 검증(불일치 0). 문서 패널은 모든 문서 명령을 실행해 통과, 예시 출력이 실제와 일치함을 확인.

**고친 결함(전부 회귀 테스트 추가).**
- **[HIGH] p 값이 0.0 으로 언더플로.** `2*(1-t_cdf)` 는 |t|≳9 에서 정확히 0 → JSON에 `"p": 0.0`.
  → `special.t_sf_two_sided` / `f_sf` 로 꼬리를 직접 계산(scipy와 1e-10 일치, p=8.0e-114 재현).
- **[HIGH] 심각도 라벨 중복 시 이중집계.** 같은 라벨의 두 구간이 서로의 인원을 합산해 합계 180%.
  → 라벨이 아닌 **구간 인덱스**로 집계(`band_index`).
- **[HIGH] `--scores-out`/`-o` 가 입력 CSV를 덮어씀.** 경로 한 번 잘못 주면 임상 원자료가 소실.
  → 동일 파일 검사 후 차단(심볼릭 링크 포함), `--scores-out`==`-o` 도 차단.
- **[HIGH] 결측 표기가 '군'이 됨.** `NA`·`.`·`999` 등이 실제 치료군과 나란히 검정되는 유령 집단 생성.
  → 집단 셀에도 결측 판정 적용(라벨 없음으로 집계). 제로폭 공백/NBSP 로 같은 군이 둘로 쪼개지던
  문제도 `normalize_label` 로 해결.
- **[MED-HIGH] 단위 불일치 점검이 조용히 꺼짐.** `scale_min/max` 가 없으면 총합 구간을 평균 점수에
  적용해도 **전원 최하위 구간**으로 정상처럼 보임 → '점검 불가'를 명시(`bands_range_unknown`).
