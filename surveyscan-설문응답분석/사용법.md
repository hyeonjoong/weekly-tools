# surveyscan 빠른 사용법

설문 응답 CSV → **문항 기술통계(왜도·첨도) · 결측 · 역문항 · 하위척도 점수(평균/총합) · Cronbach α + 95% CI · SEM · 바닥/천장 효과 · 임상 심각도 구간 분포 · 집단 비교(Welch t/ANOVA + 효과크기) · 사전-사후 변화량(대응표본 t · dz · ICC · 반응자)** 리포트. 표준 라이브러리만 사용.

## 가장 쉬운 방법 (더블클릭)

`실행.command` 파일을 **더블클릭**하면 번들 예시(수면 설문 40명)로 분석 결과가 바로 뜹니다.
처음 한 번은 macOS가 막을 수 있어요 → 파일 우클릭 → "열기" → "열기".

## 내 데이터로 돌리기 (터미널)

CSV는 **행=응답자, 열=문항**, 첫 줄은 문항 이름. 빈 칸·`NA`는 결측으로 처리됩니다.

```bash
cd surveyscan-설문응답분석

# 1) 하위척도 설정과 함께 (권장) — config.json에 척도/역문항 정의
python3 -m surveyscan.cli 내설문.csv --config 내설정.json --id-col ID

# 2) 설정 없이 빠르게 — ID만 빼고 숫자 컬럼 전체를 한 척도로
python3 -m surveyscan.cli 내설문.csv --id-col ID

# 3) 결과를 파일로 저장
python3 -m surveyscan.cli 내설문.csv -c 내설정.json --id-col ID -o 결과.txt

# 4) 총합(sum) 점수 + 응답자별 점수 CSV로 저장 (ISI·PHQ-9 등 총점 척도)
python3 -m surveyscan.cli 내설문.csv -c 내설정.json --id-col ID \
    --score-method sum --scores-out 점수.csv

# 5) 논문 초안용 Markdown 표로 출력
python3 -m surveyscan.cli 내설문.csv -c 내설정.json --id-col ID --format md -o 결과.md

# 6) 집단 비교 (치료군 vs 대조군 등) — 컬럼 이름만 알려주면 됨
python3 -m surveyscan.cli 내설문.csv -c 내설정.json --id-col ID --group-col 군
```

```bash
# 7) 사전-사후(기저 vs 12주) 변화량 — 한 사람이 시점마다 한 줄인 긴 형식 CSV
python3 -m surveyscan.cli 내설문.csv -c 내설정.json --id-col ID --time-col 시점

# 8) 치료군 vs 대조군의 '변화량' 비교 + 비모수 검정까지
python3 -m surveyscan.cli 내설문.csv -c 내설정.json --id-col ID \
    --time-col 시점 --group-col 군 --nonparam

# 9) 엑셀(한글 Windows)에서 받은 CSV가 안 읽힐 때
#    먼저 그냥 돌려 보세요 — UTF-8 로 실패하면 CP949 로 자동 재시도합니다.
python3 -m surveyscan.cli 내설문.csv --id-col ID --delimiter auto
#    그래도 컬럼명이 깨져 보일 때만 인코딩을 직접 지정(UTF-8 파일에 주면 오류가 납니다)
python3 -m surveyscan.cli 내설문.csv --id-col ID --encoding cp949
```

번들 예시로 바로 보기: `python3 -m surveyscan.cli examples/sleep_prepost.csv -c examples/sleep_prepost_config.json --id-col ID --time-col 시점 --group-col 군`

설정 파일(`내설정.json`) 예시는 `examples/sleep_config.json` 을 복사해서 고치세요.
역문항(긍정문)은 `reverse_items`에 넣으면 자동으로 뒤집어 계산합니다. (이때 `scale_min`/`scale_max` 필수)
`--scores-out 점수.csv` 로 응답자별 하위척도 점수를 뽑아 원자료에 다시 붙일 수 있습니다 — 병합 기준은 첫 열 **`원본CSV행`** 이 가장 안전합니다(중간에 빈 줄이 있으면 순번이 밀립니다). 출력 경로를 입력 CSV와 같게 주면 도구가 막습니다(원자료 보호).
탭 구분(TSV) 파일은 `--delimiter tab`, 신뢰수준 변경은 `--ci-level 0.90`.

## 결과 읽는 법 (3줄 요약)

- **Cronbach α (+95% CI)**: `.7` 이상이면 신뢰도 OK. (`.9 우수 / .8 양호 / .7 수용 / <.6 낮음`) CI는 Feldt 방법.
- **`← 제거시 α↑`** 표시가 뜬 문항: 빼는 게 신뢰도에 더 좋을 수 있음 → 검토. 단, 문항 제거는 척도 **개발** 단계용입니다 — ISI·PHQ-9 등 검증된 표준척도에서는 문항을 빼지 마세요.
- **하위척도 점수 (+95% CI)**: 역문항 반영 후 문항 평균 또는 총합. 논문 표·분석에 바로 사용.
- **바닥/천장 효과 ⚠**: 15% 초과면 표시 — 척도 변별력 점검.
- **심각도 구간 분포**: config의 `severity_bands`(예: ISI 0-7/8-14/15-21/22-28)를 적으면 `N(%)` 표가 나오고, `--scores-out` CSV에 응답자별 심각도 라벨 열이 붙습니다. 구간은 **지금 쓰는 점수 방식(평균/총합) 단위**로 적으세요. ⚠ 구간 기준값은 이 도구가 검증한 것이 아니라 **사용자가 원 논문 기준(예: ISI는 Morin et al. 2011)을 직접 적는 값**입니다.
- ⚠ `--time-col` 을 쓰면 리포트 상단의 문항 통계·α·점수는 **모든 시점을 합친** 값입니다(같은 사람이 여러 번 들어감). 시점별 α는 사전-사후 절에서 보세요.
- **사전-사후**: `--time-col 시점` 을 붙이면 같은 ID를 시점 간에 짝지어 **변화량(사후−사전)·대응표본 t·Cohen dz·검사-재검사 ICC(2,1)·반응자 수**가 나옵니다. 시점 순서는 숫자면 숫자 순, 아니면 파일에 먼저 나온 시점이 사전이며 `--time-pre`/`--time-post` 로 바꿀 수 있습니다. 짝을 못 지은 사람(한 시점만 있음, 같은 (ID,시점) 중복)은 인원수로 표시됩니다. ⚠ 두 시점 점수가 모두 있는 사람만 쓰는 **완전자료 분석**이라 중도탈락이 많으면 낙관적으로 치우칩니다.
- **반응자 수**: config 에 `"mcid": {"불면증상(ISI)": 6}` 처럼 임상적 최소중요차이를 적으면 그 값을, 없으면 MDC₉₅ 를 임계값으로 **감소/변화없음/증가** 인원을 셉니다(방향 해석은 연구자 몫). ⚠ MCID 값도 원 논문에서 옮겨 적는 값입니다. `mcid` 가 없으면 이 짝 자료에서 나온 `MDC₉₅(재측정 기반)`을, 그것도 낼 수 없으면 `MDC₉₅(α 기반·전체 시점 합산)`을 씁니다 — 어느 것을 썼는지 리포트에 찍힙니다.
- **`--nonparam`** 은 `--group-col` 또는 `--time-col` 과 함께 써야 표가 나옵니다.
- **비모수 검정**: `--nonparam` 을 붙이면 Mann-Whitney U / Kruskal-Wallis / Wilcoxon 부호순위가 t·ANOVA 옆에 함께 나옵니다(민감도 분석용).
- **엑셀 CSV가 안 열릴 때**: UTF-8 이 아니면 CP949 로 자동 재시도합니다(리포트에 표시). 안 되면 `--encoding cp949`, 구분자가 이상하면 `--delimiter auto`.
- **집단 비교**: `--group-col 군` 을 붙이면 집단별 평균±SD·α와 Welch t(2집단)/Welch ANOVA(3집단 이상), Hedges g, Holm 보정 p 가 나옵니다. **탐색적 분석**이므로 사전 정의된 1차 분석을 대신하지 않습니다.
