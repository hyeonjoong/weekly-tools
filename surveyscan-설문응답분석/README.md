# surveyscan — 설문 응답 CSV 분석기

설문(설문지) 응답 CSV 한 개를 넣으면 **문항별 기술통계(왜도·첨도, 사분위는 md·json) · 결측 요약 · 역문항 자동 재코딩 · 하위척도 점수(평균/총합) · Cronbach α + 95% 신뢰구간(Feldt) · McDonald ω · 표준화 α · 측정의 표준오차(SEM) · 최소검출가능변화(MDC₉₅) · 평균 문항간 상관 · 수정된 문항-총점 상관 · 문항 제거 시 α · 바닥/천장 효과 · 임상 심각도 구간 분포 · 집단 간 비교(Welch t/ANOVA + Hedges g + Holm 보정) · **사전-사후(반복측정) 변화량 분석(대응표본 t + Cohen dz + 검사-재검사 ICC + 반응자 분석 + 집단별 변화량 비교)** · (옵션) 순위 기반 비모수 검정(Mann-Whitney/Kruskal-Wallis/Wilcoxon) · (옵션) 응답 선택지 빈도표 · (옵션) 부주의응답 선별** 을 한 번에 리포트로 만들어 줍니다. 텍스트·JSON·Markdown 출력, 응답자별 점수·심각도 CSV 내보내기까지. **표준 라이브러리만 사용 — 설치할 외부 패키지가 없습니다** (t·F 분포 분위수까지 순수 파이썬으로 구현, scipy와 ~1e-11 일치).

## 목적 / Why this exists

**(한국어)** 임상·제약 연구나 사용자 연구에서 설문 데이터를 받으면 매번 똑같은 일을 합니다 — 문항별 평균/표준편차 보기, 결측 확인, 역문항 뒤집기, 하위척도 점수 만들기, 신뢰도(Cronbach α) 계산. SPSS를 열어 클릭으로 반복하거나 R 코드를 매번 다시 짜는 대신, CSV와 (선택) 하위척도 설정만 주면 일관된 리포트가 나옵니다. ISI(불면), 청능재활 설문 등 우리 데이터에 바로 쓰도록 설계했습니다. 논문 Methods/Results에 넣을 신뢰도와 기술통계를 빠르고 재현 가능하게 뽑는 것이 목표입니다.

**(English)** Clinical/UX researchers repeat the same chores on every questionnaire dataset: per-item descriptives, missing-data checks, reverse-coding, subscale scoring, and Cronbach's alpha. Instead of clicking through SPSS or rewriting R each time, give this tool a CSV (and an optional subscale config) and get one consistent, reproducible report. Built for a researcher who writes manuscripts and needs trustworthy reliability + descriptive numbers for Methods/Results — fast and offline.

## 설치 / Install

```bash
cd surveyscan-설문응답분석
python3 -m pip install -e .
```

설치 없이도 실행할 수 있습니다: `python3 -m surveyscan.cli ...`

설치하면 `surveyscan` 명령도 생기지만, pip 스크립트 폴더가 PATH에 없으면 `command not found` 가 납니다. 그럴 때는 아래 예시처럼 `python3 -m surveyscan.cli` 를 쓰세요 (이 문서의 모든 예시는 그 형태입니다).

## 사용법 / Usage

입력 CSV는 **행=응답자, 열=문항**, 첫 행은 헤더(문항 이름)입니다. 빈 칸과 `NA`, `N/A`, `NaN`, `null`, `none`, `.`, `-`, `missing` (대소문자 무관)은 결측으로 처리합니다(숫자 결측코드는 `--na-number`). 같은 표기가 `--group-col`·`--time-col` 값에 있으면 그 응답자는 '집단 라벨 없음'·'시점 없음'으로
비교/짝짓기에서 빠집니다. config JSON 은 UTF-8 로 저장하세요(윈도우 메모장이 붙이는 BOM 은 허용).

### 1) 하위척도 설정과 함께 (권장)

`config.json` 예시:

```json
{
  "scale_min": 0,
  "scale_max": 4,
  "score_method": "sum",
  "subscales": {
    "불면증상(ISI)": ["ISI1", "ISI2", "ISI3", "ISI4", "ISI5", "ISI6", "ISI7"],
    "주간기능": ["DAY1", "DAY2", "DAY3"]
  },
  "reverse_items": ["DAY3"],
  "min_valid_ratio": 0.5,
  "severity_bands": {
    "불면증상(ISI)": [
      [0, 7, "임상적 불면증 없음"],
      [8, 14, "역치하 불면증"],
      [15, 21, "중등도 임상적 불면증"],
      [22, 28, "중증 임상적 불면증"]
    ]
  }
}
```

- `reverse_items`: 역방향(긍정문) 문항. `x' = (scale_min + scale_max) - x` 로 자동 재코딩합니다. 역문항이 있으면 `scale_min`/`scale_max`는 필수입니다.
- `min_valid_ratio`: 응답자가 해당 하위척도 문항을 이 비율 이상 응답해야 점수를 부여(기본 0.5).
- `score_method`: `"mean"`(가용문항 평균, 기본) 또는 `"sum"`(비례배분 총합). ISI·PHQ-9·GAD-7 등 임상 척도는 보통 **총합**으로 보고합니다. `--score-method` 로도 덮어쓸 수 있습니다. 총합 방식은 일부 문항이 결측이어도 `min_valid_ratio`를 넘으면 가용문항 평균×문항수로 **비례배분(pro-rate)** 합니다.
- `mcid`: 하위척도별 **임상적 최소중요차이**(예: `{"불면증상(ISI)": 6}`). 사전-사후 반응자 분석의
  임계값으로 씁니다(없으면 재측정 기반 MDC₉₅ 를 대신 사용). **점수 방식(평균/총합) 단위**로 적으세요.
  ⚠ 이 값도 도구가 아는 것이 아니라 사용자가 원 논문에서 옮겨 적는 값입니다.
- `severity_bands`: 하위척도 점수를 **임상 심각도 범주**로 나눌 구간. `[하한, 상한, "라벨"]` 이며 **양끝 포함**, 구간끼리 겹치면 오류로 막습니다. 지정하면 리포트에 `N(%)` 분포표가 나오고 `--scores-out` CSV에 응답자별 `_심각도` 열이 추가됩니다. **지금의 점수 방식 단위로 적으세요.** 단위가 어긋나면 표가 정상처럼 보이면서 틀립니다 — ISI 총점 구간(0~28)을 `score_method: "mean"`(0~4)에 적용하면 **전원이 최하위 구간으로 몰려 '100% 정상'** 처럼 보이고, 반대로 평균 단위 구간을 총합 점수에 적용하면 대부분 '미분류'가 됩니다. 두 경우 모두 ⚠ 경고가 뜨니 반드시 확인하세요(단, `scale_min`/`scale_max` 를 적어야 이 점검이 가능하며, 없으면 '점검 불가'라고 알립니다).
- 오타 방지: config에 알 수 없는 키가 있거나 `severity_bands` 이름이 `subscales` 에 없으면 **조용히 무시하지 않고 오류**를 냅니다(메모는 `_` 로 시작하는 키를 쓰세요).

```bash
python3 -m surveyscan.cli examples/sleep_survey.csv --config examples/sleep_config.json --id-col ID
```

### 2) 설정 없이 빠르게

ID 컬럼만 빼면 숫자 컬럼 전체를 하나의 척도(`전체`)로 보고 분석합니다.

```bash
python3 -m surveyscan.cli examples/sleep_survey.csv --id-col ID
```

### 3) 집단 비교 (치료군 vs 대조군 등)

CSV에 집단 컬럼(예: `군`)이 있으면 `--group-col` 로 하위척도 점수를 집단별로 비교합니다.

```bash
python3 -m surveyscan.cli examples/sleep_survey.csv --config examples/sleep_config.json \
    --id-col ID --group-col 군
```

집단별 N·평균·SD·중앙값·**집단별 α**, 2집단이면 **Welch t 검정 + 평균차 CI + Hedges' g(CI)**, 3집단 이상이면 **Welch ANOVA**, 하위척도가 여러 개면 **Holm 보정 p** 를 함께 냅니다. 집단 컬럼은 문항 분석에서 자동 제외되고, 라벨이 빈 응답자(빈 칸 또는 `NA`·`.` 같은 결측 표기)는 비교에서 빠집니다(인원수 표기). 알아둘 점:

- 서로 다른 집단이 **2~20개**일 때만 비교합니다. 20개를 넘으면(21개 이상이면) "ID 컬럼을 지정한 것 아니냐"는 안내만 내보내고 라벨은 출력하지 않습니다(식별자 유출 방지).
- 점수가 **2명 미만**인 집단은 검정에서 제외하고, 어떤 집단을 뺐는지 리포트에 이름으로 남깁니다.
- `--scores-out` CSV에는 집단 열, (`--time-col` 을 썼다면) 시점 열, (구간을 정했다면) `_심각도`
  열이 함께 저장됩니다. 점수는 유효숫자 6자리로 반올림되며, `=`·`+`·`-`·`@` 로 시작하는 ID·라벨
  값에는 스프레드시트 수식 실행을 막으려고 앞에 작은따옴표(`'`)가 붙습니다(예: ID `-001` →
  `'-001`) — 엑셀에서 ID 로 병합할 때 참고하세요. 원자료 병합은 **ID가 아니라 첫 열 `원본CSV행`** 기준이 안전합니다(중간 빈 줄 때문에 순번이 밀릴 수 있음).

### 4) 사전-사후(반복측정) 변화량 — 기저 vs 12주

한 사람이 시점마다 한 줄씩 있는 **긴 형식(long format)** CSV면 `--time-col` 로 시점 컬럼을
알려 주세요. 같은 ID를 시점 간에 짝지어 변화량을 냅니다(`--id-col` 필수).

```csv
ID,군,시점,ISI1,ISI2,...
P001,치료군,기저,2,2,...
P001,치료군,12주,1,2,...
```

```bash
python3 -m surveyscan.cli examples/sleep_prepost.csv --config examples/sleep_prepost_config.json \
    --id-col ID --time-col 시점 --group-col 군 --nonparam
```

나오는 값:

- 시점별 N·평균±SD·중앙값·**시점별 α**(측정이 두 시점에서 비슷하게 작동했는지)
- **변화량(사후−사전) 평균±SD + CI**, **대응표본 t**, **Cohen's dz**(+CI)
- **사전-사후 상관 r**, **검사-재검사 ICC(2,1) 절대일치**(+CI)와 반복측정 **SEM**
- **반응자 분석** — 임계값 이상 변한 사람의 **감소 / 변화없음 / 증가** 인원수와 비율
  (변화가 임계값과 정확히 같으면 반응자로 셉니다). 임계값은 아래 순서로 정하며, 무엇을 썼는지
  리포트에 함께 찍습니다:
  1. config 의 `mcid` — 원 논문의 임상적 최소중요차이. **가장 권장**
  2. `MDC₉₅(재측정 기반)` — 이 짝 자료의 반복측정 오차(√MSE)에서 나온 값. 짝지어진 사람만 사용
  3. `MDC₉₅(α 기반·전체 시점 합산)` — 위 둘이 불가능할 때만. ⚠ **모든 시점을 합친** 표본
     (같은 사람이 여러 번)의 α·SD 라 개입 효과로 부풀려져 있습니다
- `--group-col` 을 함께 주면 **집단별 변화량 비교**(Welch t + Hedges g, 3집단 이상은 Welch ANOVA)
  — 임상시험에서 흔한 '기저 대비 변화의 군간 차이'에 해당하는 탐색적 계산
- 하위척도가 여러 개면 **Holm 보정 p** 도 함께

시점 순서는 라벨이 전부 숫자면 **숫자 순**(`0`→`4`→`12`), 아니면 **자료에 먼저 나온 시점**을
사전으로 봅니다. 리포트에 어떤 규칙이었는지 찍히며, 파일 순서로 **추정**한 경우에는 ⚠ 경고가
함께 나옵니다 — 자료를 시점 기준으로 정렬했거나 첫 사람의 기저 행이 없으면 사전/사후가 뒤집혀
**변화량 부호가 통째로 반대**가 되기 때문입니다. `--time-pre`/`--time-post` 로 직접 지정하면
경고가 사라집니다(시점이 3개 이상이면 지정 필수).

짝짓기에서 빠진 사람은 숫자로 남깁니다 — 한 시점에만 있는 ID, 같은 `(ID, 시점)`이 두 번 나와
어느 줄이 맞는지 알 수 없어 통째로 제외한 ID, ID 가 빈 행. **짝이 하나도 없어 분석이 실패한
경우에도** 이 숫자와 원인(예: `--pair-id` 조합이 응답자를 유일하게 구분하지 못함)을 함께 냅니다. `--pair-id` 로 짝짓기에 쓸 ID
컬럼을 고를 수 있습니다(예: 접수번호는 방문마다 바뀌고 환자번호만 같을 때).

`--time-col` 을 주면 리포트 상단의 **문항 기술통계·α·하위척도 점수는 파일에 있는 모든 시점을
합친 값**이라는 경고가 함께 나옵니다(같은 사람이 시점 수만큼 들어가므로). 시점이 3개 이상인데
`--time-pre`/`--time-post` 로 두 시점만 비교하는 경우에도 **상단 통계에는 비교하지 않는 시점의
행까지 포함**됩니다(그 행 수는 짝짓기 진단줄에 '비교 대상이 아닌 시점의 행 N개'로 표시됩니다).
시점별 α는 사전-사후 절에서 보세요.

시점 라벨이 **20개를 넘으면**(날짜·ID 컬럼을 잘못 지정한 경우) 라벨을 출력하지 않고 사전-사후
절을 건너뜁니다.

### 5) 순위 기반(비모수) 검정 — `--nonparam`

리커트 합산 점수는 정규분포와 거리가 있어 "비모수로도 같은 결론인가"를 확인하는 것이 표준
절차입니다. `--nonparam` 을 붙이면 t/ANOVA **옆에** 순위 기반 검정을 함께 냅니다(대체가 아니라
민감도 분석):

- 2집단 → **Mann-Whitney U**(동순위·연속성 보정) + rank-biserial r
- 3집단 이상 → **Kruskal-Wallis H**(동순위 보정) + ε²
- 사전-사후 → **Wilcoxon 부호순위**(작은 표본·동순위 없으면 정확검정, 아니면 보정 정규근사)
  + matched-pairs rank-biserial r

`--nonparam` 은 `--group-col` 또는 `--time-col` 과 함께 써야 출력됩니다(단독으로 주면 비교 대상이
없어 아무 표도 나오지 않으며, 그 사실을 경고로 알립니다).

### 6) 엑셀에서 받은 CSV가 안 읽힐 때 — 인코딩·구분자 자동 처리

- **인코딩**: UTF-8 로 못 읽으면 **CP949(엑셀 한글 Windows)** 로 자동 재시도하고, 어떤 인코딩으로
  읽었는지 알립니다. `--encoding cp949` 로 직접 지정할 수도 있습니다(지정하면 자동 재시도 없음).
- **구분자**: `--delimiter auto` 를 주면 헤더를 보고 콤마/탭/세미콜론/파이프 중에서 고릅니다
  (유럽 지역설정 엑셀이 세미콜론으로 저장하는 경우 등). 판별 결과도 알려 줍니다.

### 주요 옵션

| 옵션 | 설명 |
|------|------|
| `--config, -c` | 하위척도/역문항/심각도구간 설정 JSON |
| `--id-col 이름` | 분석에서 제외할 ID 컬럼(여러 번 가능) |
| `--group-col 이름` | 집단 비교 기준 컬럼(치료군·성별·기관 등). 문항 분석에서는 제외 |
| `--quality` | 부주의응답 선별 지표(longstring·IRV·결측률) 추가 |
| `--longstring-min N` | `--quality` 의 longstring 플래그 기준(기본: max(3, 문항수/2)) |
| `--na-number 999` | 결측 코드로 쓰인 숫자(여러 번 가능) |

## 결과 읽는 법

- **Cronbach α + 신뢰구간** — 내적 일치도(신뢰도). 해석: `.9 우수 / .8 양호 / .7 수용가능 / .6 의심 / <.6 낮음`. 완전응답자(listwise)만으로 계산하며, 제외된 인원 수를 함께 표기합니다. **95% CI는 Feldt(1965) F 분포 방법**으로 계산합니다(신뢰수준은 `--ci-level`).
- **SEM(측정의 표준오차)** — `SD_점수 × √(1−α)`. 개인 점수의 오차폭 추정에 쓰이며, 점수 방식(평균/총합)과 같은 단위입니다. 예: 총합 방식이면 총점 단위의 SEM. **완전응답자(listwise) 총점 SD** 로 계산하므로, 화면의 점수 SD(가용문항 N)와 분모가 다를 수 있습니다.
- **MDC₉₅(최소검출가능변화)** — `1.96 × √2 × SEM`. 개인의 점수가 이 값 이상 변해야 측정오차를 넘어선 **실질적 변화**로 볼 수 있습니다(추적관찰·치료반응 판정에 유용).
- **표준화 α** — 평균 문항간 상관 기반 α(`k·r̄/(1+(k−1)·r̄)`). 문항 SD가 크게 다를 때 원 α와 함께 참고합니다.
- **평균 문항간 상관** — 문항끼리의 평균 상관. 통상 `.15~.50` 이 적절하며, 너무 높으면(>.70 ⚠) 문항 중복, 너무 낮으면(<.15 ⚠) 이질적 구성을 의심합니다.
- **응답 선택지 빈도**(`--item-freq`) — 문항별로 각 선택지를 고른 응답자 수/%. 미사용 선택지·치우친 분포·입력 오류를 드러냅니다. config에 **정수 `scale_min`/`scale_max` 가 있을 때만** 출력되며, 없으면 표가 조용히 생략됩니다.
- **하위척도 점수** — 역문항 재코딩 후 가용 문항의 **평균** 또는 **비례배분 총합**(`score_method`). 평균 CI는 t 분포 기반입니다. `min_valid_ratio` 미만으로 응답한 사람은 점수에서 제외됩니다.
- **바닥/천장 효과** — 가능한 최소/최대 점수에 몰린 응답자 비율(척도 범위 선언 시). `> 15%` 면 ⚠ 로 표시하며, 척도가 특정 집단에서 변별력이 낮을 수 있음을 시사합니다.
- **왜도·첨도** — 문항 분포의 비대칭/뾰족함(SPSS/Excel과 동일한 편향보정 G1·G2). 정규성 가정 점검용.
- **문항-총점 r** — 수정된 문항-총점 상관(해당 문항을 제외한 나머지 합과의 상관). `< .30` 이면 그 문항이 척도와 잘 안 맞을 수 있습니다. **음수(`← 음수 r`)** 면 역문항 설정 누락/오류일 가능성이 큽니다(`reverse_items` 확인).
- **임상 심각도 구간**(`severity_bands`) — 하위척도 점수를 임상 범주(예: ISI 0–7 없음 / 8–14 역치하 / 15–21 중등도 / 22–28 중증)로 나눈 `N(%)` 분포. 논문 Table 1의 '중증도 분포' 행에 옮겨 적을 수 있습니다(구간 기준은 반드시 원 논문에서 확인한 값으로). 구간 사이 빈틈(예: 결측 비례배분으로 생긴 7.5점)이나 범위 밖 점수는 **미분류**로 따로 세어 ⚠ 로 알립니다 — 조용히 아무 구간에나 넣지 않습니다.
- **집단 비교**(`--group-col`) — 하위척도 점수의 집단별 N·평균·SD·중앙값·α와, 2집단이면 **Welch t 검정**(등분산 가정 없음), 3집단 이상이면 **Welch ANOVA**. 효과크기는 **Hedges' g**(소표본 편향 보정 Cohen's d)와 그 CI로 보고합니다(관례: |0.2| 작음 / |0.5| 중간 / |0.8| 큼). 하위척도가 여러 개면 **Holm-Bonferroni 보정 p** 를 함께 표기합니다. Hedges' g 는 **2집단일 때만** 나오며 CI는 대표본 근사라 소표본에서는 실제보다 좁습니다(`--ci-level` 은 α CI와 집단비교 CI에 함께 적용). 집단별 α가 크게 다르면(예: 한쪽만 <.6) 점수 비교의 전제가 흔들린다는 신호입니다 — 다만 집단 N이 작으면 α는 매우 불안정하고 음수도 나오므로 참고용으로만 보세요(표의 N은 점수 산출 인원, α는 그 집단의 완전응답자 기준이라 분모가 다릅니다).
- **변화량 · 대응표본 t · Cohen's dz**(`--time-col`) — 변화량은 **사후 − 사전**입니다(증상척도는
  음수가 호전). dz 는 **변화량의 SD** 로 표준화한 값이라 독립표본 Hedges' g 와 스케일이 다릅니다 —
  같은 표에 놓고 크기를 비교하지 마세요(Lakens 2013). 두 시점 점수가 **모두 있는 사람만** 쓰는
  완전자료(complete-case) 분석이므로, 중도탈락이 많으면 결과가 낙관적으로 치우칩니다.
  dz 의 CI 는 `dz ± z·√(1/n + dz²/2n)` 의 **대표본(Wald) 근사**로, 비중심 t 분포를 쓰는 정확
  구간이 아니며 짝 수가 적으면 실제보다 좁습니다. 또 dz 에는 Hedges' g 와 달리 **소표본
  편향보정이 들어 있지 않습니다**.
- **검사-재검사 ICC(2,1)** — 이원 확률효과·절대일치·단일측정 급내상관(McGraw & Wong 1996 ICC(A,1)).
  두 시점 사이에 **개입이 없을 때만** 신뢰도로 읽습니다. 치료 전후에서 ICC 가 낮은 것은 측정이
  나쁜 것이 아니라 **반응의 개인차**를 뜻합니다. 함께 나오는 SEM(재측정)=√MSE 는 α 기반 SEM 과
  달리 실제 재측정 자료에서 얻은 오차입니다. 다만 이는 **두 시점의 평균 이동(체계적 변화)을
  제외한 일치(consistency)형 SEM**(Weir 2005)이라, 개입으로 점수가 통째로 이동한 자료에서는
  '절대일치' 기준 오차보다 작습니다 — 논문에 옮길 때 어느 정의인지 밝히세요. JSON 출력에는
  절대일치 값(`sem_agreement`·`mdc95_agreement`, √(MSE+(MSC−MSE)/n) 기반)도 함께 들어 있어
  두 정의를 모두 확인할 수 있습니다.
- **반응자 분석** — 임계값(`mcid` 또는 MDC₉₅) 이상 변한 인원수. 척도마다 좋은 방향이 다르므로
  '개선/악화'로 라벨하지 않고 **감소/변화없음/증가**로만 셉니다 — 방향 해석은 연구자의 몫입니다.
- **집단별 변화량 비교** — 변화량을 집단별로 Welch t(2집단)/Welch ANOVA(3집단 이상)로 비교합니다.
  **기저값 보정(ANCOVA)이 없는 탐색적 계산**이며, 같은 ID가 시점마다 다른 집단으로 적혀 있으면
  그 사람은 **집단별 비교에서만** 제외하고(전체 대응표본 t·dz·ICC 에는 그대로 포함) 인원수를
  남깁니다.
- **비모수 검정**(`--nonparam`) — Mann-Whitney U(+rank-biserial r) / Kruskal-Wallis H(+ε²) /
  Wilcoxon 부호순위(+matched-pairs r). 모두 **동순위 보정**을 적용하고, p 는 양측입니다.
  t/ANOVA 와 결론이 갈리면 분포·이상치를 먼저 보세요. Wilcoxon 은 차이가 0인 쌍을 제외합니다.
- **α(문항제거시)** — 그 문항을 빼면 척도 α가 어떻게 변하는지. 현재 α보다 **올라가면**(`← 제거시 α↑`) 문항 적합성을 재검토하세요. **단, 문항 제거는 척도 *개발* 단계용입니다 — ISI·PHQ-9 등 이미 검증된 표준척도에서는 문항을 빼지 마세요.**

## 한계 / Notes

- 신뢰도(α)·문항-총점 상관은 **완전응답자(listwise)** N 기준이고, **하위척도 점수**는 가용문항(`min_valid_ratio` 충족) N 기준입니다 — 둘의 N이 다를 수 있으니(예: α는 37명, 점수는 40명) 논문에 옮길 때 분모를 구분하세요. 리포트에 두 N을 모두 표기합니다.
- `scale_min`/`scale_max`를 지정하면 **범위를 벗어난 값**(입력 오류 가능)을 리포트 상단에 ⚠로 표시합니다. 역코딩은 이런 값을 그대로 뒤집으므로(예: 1~5 척도의 `9` → `-3`), 경고가 뜨면 원자료를 먼저 정리하세요.
- `--config` 없이 실행하면 숫자값이 없는 컬럼(전부 결측/텍스트)은 자동 제외되며, 어떤 컬럼이 빠졌는지 경고로 알립니다. 의도와 다르면 `--config`로 문항을 명시하세요.
- 파이썬 3.9 이상이 필요합니다(macOS 기본 `python3` 로 충분). `pip install` 이 시스템 정책으로 막히면 설치 없이 `python3 -m surveyscan.cli` 로 그대로 실행하세요.
- 문항별 기술통계는 **원자료(raw) 값** 기준으로 보고합니다(역코딩 전). 데이터 입력 오류·범위 이탈을 그대로 보기 위함입니다. 역코딩은 신뢰도·하위척도 점수 계산에만 반영됩니다.
- Cronbach α는 일차원성(단일 구성개념)을 가정합니다. 요인구조를 **검정**하지는 않습니다 — ω 계산을 위해 단일요인만 추출할 뿐, 다요인 해·적합도 지수(χ²·CFI·RMSEA)는 제공하지 않으므로 일차원성이 나쁜 척도에서도 숫자는 나옵니다(Heywood case만 ⚠).
- **α 신뢰구간**은 Feldt(1965) 방법으로, 문항 점수의 정규성과 본질적 타우동등성(essential tau-equivalence)을 가정합니다. 강한 위반 시 폭이 부정확할 수 있습니다. **SEM**은 고전검사이론(CTT) 기반이며, α를 신뢰도 추정치로 사용합니다.
- **바닥/천장 효과**는 척도 범위(`scale_min`/`scale_max`)가 선언된 경우에만, 점수 방식에 따른 가능한 최소/최대 점수 기준으로 계산합니다.
- **집단 비교는 탐색적(exploratory) 분석**입니다 — 자료 점검·기술 목적이며, 사전에 정의된 1차 분석(공변량 보정, 반복측정, ITT 등)을 대신하지 않습니다. 무작위배정 전 기저 특성 비교에 p 값을 쓰는 것은 권장되지 않습니다(CONSORT). 3집단 이상은 전체 차이만 검정하며 **사후 쌍별 비교는 제공하지 않습니다**. Holm 보정은 **한 번의 실행에서 나온 하위척도 검정들에 대해서만** 적용되며, 여러 번 실행한 결과를 합칠 때는 사용자가 직접 다중성을 고려해야 합니다.
- **심각도 구간(`severity_bands`)의 기준값은 도구가 아니라 사용자가 정합니다.** 내장된 표준척도 컷오프는 없으며(예시 config의 ISI 값도 참고용), 쓰는 척도의 원 논문 기준을 config에 직접 적으세요.
- **사전-사후 분석은 완전자료(complete-case) 분석**입니다. 두 시점 점수가 모두 있는 사람만 쓰며,
  결측 대치·혼합효과모형(MMRM)·ITT 분석을 대신하지 않습니다. 짝을 못 지은 인원수는 리포트에
  그대로 남기니 중도탈락이 많으면 결과를 그대로 믿지 마세요. 3개 이상 시점의 궤적 분석,
  기저값 보정(ANCOVA), 시점×집단 상호작용 검정은 제공하지 않습니다(두 시점 비교만).
- **ICC(2,1)** 은 두 시점 사이에 개입이 없을 때만 검사-재검사 신뢰도로 해석할 수 있습니다.
  CI 는 McGraw & Wong(1996) 의 F 분포 근사이며 정규성을 가정합니다.
- **비모수 검정**(`--nonparam`)의 p 는 Mann-Whitney·Kruskal-Wallis 가 **정규근사**(동순위·연속성
  보정 포함, 정확검정 아님)이고, Wilcoxon 은 쌍 25개 이하·동순위/0 차이가 없을 때만 정확검정입니다.
  순위 검정은 '중앙값 차이 검정'이 아니라 분포의 위치·형태 차이에 민감합니다.
- **인코딩 자동 판별은 UTF-8 → CP949 두 가지만** 시도합니다. CP949 는 대부분의 바이트열을 어떻게든
  읽어내므로, 다른 인코딩(EUC-JP·UTF-16 등)의 파일이 **깨진 글자로 읽힐 수 있습니다** — 리포트
  상단의 '파일 인코딩' 표시와 컬럼명을 확인하고, 필요하면 `--encoding` 으로 직접 지정하세요.
  구분자 자동 판별(`--delimiter auto`)은 헤더 한 줄만 보고 정합니다.
- 결측 다중대치, ML 추정 CFA와 적합도 지수, 측정불변성 검정, 사후 쌍별 비교는 포함하지 않습니다(의도적으로 표준 라이브러리만으로 가볍게 유지). McDonald's ω 는 주축분해로 적합한 단일요인 congeneric 모형에서 계산하며 수렴 시에만 표기합니다 — **모형 적합도는 보고하지 않습니다.** t·F 분포 분위수는 순수 파이썬으로 직접 구현했으며 scipy와 ~1e-11 수준에서 일치함을 테스트로 확인합니다(테스트에서만 scipy/statsmodels 사용).
