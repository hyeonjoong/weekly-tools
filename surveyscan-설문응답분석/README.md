# surveyscan — 설문 응답 CSV 분석기

설문(설문지) 응답 CSV 한 개를 넣으면 **문항별 기술통계(왜도·첨도, 사분위는 md·json) · 결측 요약 · 역문항 자동 재코딩 · 하위척도 점수(평균/총합) · Cronbach α + 95% 신뢰구간(Feldt) · 표준화 α · 측정의 표준오차(SEM) · 최소검출가능변화(MDC₉₅) · 평균 문항간 상관 · 수정된 문항-총점 상관 · 문항 제거 시 α · 바닥/천장 효과 · (옵션) 응답 선택지 빈도표** 를 한 번에 리포트로 만들어 줍니다. 텍스트·JSON·Markdown 출력, 응답자별 점수 CSV 내보내기까지. **표준 라이브러리만 사용 — 설치할 외부 패키지가 없습니다** (t·F 분포 분위수까지 순수 파이썬으로 구현, scipy와 ~1e-11 일치).

## 목적 / Why this exists

**(한국어)** 임상·제약 연구나 사용자 연구에서 설문 데이터를 받으면 매번 똑같은 일을 합니다 — 문항별 평균/표준편차 보기, 결측 확인, 역문항 뒤집기, 하위척도 점수 만들기, 신뢰도(Cronbach α) 계산. SPSS를 열어 클릭으로 반복하거나 R 코드를 매번 다시 짜는 대신, CSV와 (선택) 하위척도 설정만 주면 일관된 리포트가 나옵니다. ISI(불면), 청능재활 설문 등 우리 데이터에 바로 쓰도록 설계했습니다. 논문 Methods/Results에 넣을 신뢰도와 기술통계를 빠르고 재현 가능하게 뽑는 것이 목표입니다.

**(English)** Clinical/UX researchers repeat the same chores on every questionnaire dataset: per-item descriptives, missing-data checks, reverse-coding, subscale scoring, and Cronbach's alpha. Instead of clicking through SPSS or rewriting R each time, give this tool a CSV (and an optional subscale config) and get one consistent, reproducible report. Built for a researcher who writes manuscripts and needs trustworthy reliability + descriptive numbers for Methods/Results — fast and offline.

## 설치 / Install

```bash
cd surveyscan-설문응답분석
python3 -m pip install -e .
```

설치 없이도 실행할 수 있습니다: `python3 -m surveyscan.cli ...`

설치하면 `surveyscan` 명령도 생기지만, pip 스크립트 폴더가 PATH에 없으면 `command not found` 가 납니다. 그럴 때는 아래 예시처럼 `python3 -m surveyscan.cli` 를 쓰세요 (이 문서의 모든 예시는 그 형태입니다).

## 사용법 / Usage

입력 CSV는 **행=응답자, 열=문항**, 첫 행은 헤더(문항 이름)입니다. 빈 칸과 `NA/N/A/NaN/.` 등은 결측으로 처리합니다.

### 1) 하위척도 설정과 함께 (권장)

`config.json` 예시:

```json
{
  "scale_min": 0,
  "scale_max": 4,
  "subscales": {
    "불면증상(ISI)": ["ISI1", "ISI2", "ISI3", "ISI4", "ISI5", "ISI6", "ISI7"],
    "주간기능": ["DAY1", "DAY2", "DAY3"]
  },
  "reverse_items": ["DAY3"],
  "min_valid_ratio": 0.5,
  "score_method": "mean"
}
```

- `reverse_items`: 역방향(긍정문) 문항. `x' = (scale_min + scale_max) - x` 로 자동 재코딩합니다. 역문항이 있으면 `scale_min`/`scale_max`는 필수입니다.
- `min_valid_ratio`: 응답자가 해당 하위척도 문항을 이 비율 이상 응답해야 점수를 부여(기본 0.5).
- `score_method`: `"mean"`(가용문항 평균, 기본) 또는 `"sum"`(비례배분 총합). ISI·PHQ-9·GAD-7 등 임상 척도는 보통 **총합**으로 보고합니다. `--score-method` 로도 덮어쓸 수 있습니다. 총합 방식은 일부 문항이 결측이어도 `min_valid_ratio`를 넘으면 가용문항 평균×문항수로 **비례배분(pro-rate)** 합니다.

```bash
python3 -m surveyscan.cli examples/sleep_survey.csv --config examples/sleep_config.json --id-col ID
```

### 2) 설정 없이 빠르게

ID 컬럼만 빼면 숫자 컬럼 전체를 하나의 척도(`전체`)로 보고 분석합니다.

```bash
python3 -m surveyscan.cli examples/sleep_survey.csv --id-col ID
```

### 주요 옵션

| 옵션 | 설명 |
|------|------|
| `--config, -c` | 하위척도/역문항 설정 JSON |
| `--id-col 이름` | 분석에서 제외할 ID 컬럼(여러 번 가능) |
| `--na-number 999` | 결측 코드로 쓰인 숫자(여러 번 가능) |
| `--delimiter ';'` | CSV 구분자(기본 콤마). 탭은 `--delimiter tab` |
| `--score-method mean\|sum` | 하위척도 점수 방식(config보다 우선). 기본 `mean` |
| `--ci-level 0.95` | 신뢰구간 신뢰수준(0~1, 기본 0.95) |
| `--format text\|json\|md` | 출력 형식(기본 text). `md`=Markdown 표 |
| `--item-freq` | 문항별 응답 선택지 빈도표 추가(척도 범위가 정수일 때) |
| `--json` | `--format json` 과 동일(하위호환) |
| `--scores-out 파일.csv` | 응답자별 하위척도 점수를 CSV로 저장(원자료에 다시 붙여 분석용) |
| `-o, --output 파일` | 리포트를 파일로 저장 |

## 결과 읽는 법

- **Cronbach α + 신뢰구간** — 내적 일치도(신뢰도). 해석: `.9 우수 / .8 양호 / .7 수용가능 / .6 의심 / <.6 낮음`. 완전응답자(listwise)만으로 계산하며, 제외된 인원 수를 함께 표기합니다. **95% CI는 Feldt(1965) F 분포 방법**으로 계산합니다(신뢰수준은 `--ci-level`).
- **SEM(측정의 표준오차)** — `SD_점수 × √(1−α)`. 개인 점수의 오차폭 추정에 쓰이며, 점수 방식(평균/총합)과 같은 단위입니다. 예: 총합 방식이면 총점 단위의 SEM. **완전응답자(listwise) 총점 SD** 로 계산하므로, 화면의 점수 SD(가용문항 N)와 분모가 다를 수 있습니다.
- **MDC₉₅(최소검출가능변화)** — `1.96 × √2 × SEM`. 개인의 점수가 이 값 이상 변해야 측정오차를 넘어선 **실질적 변화**로 볼 수 있습니다(추적관찰·치료반응 판정에 유용).
- **표준화 α** — 평균 문항간 상관 기반 α(`k·r̄/(1+(k−1)·r̄)`). 문항 SD가 크게 다를 때 원 α와 함께 참고합니다.
- **평균 문항간 상관** — 문항끼리의 평균 상관. 통상 `.15~.50` 이 적절하며, 너무 높으면(>.70 ⚠) 문항 중복, 너무 낮으면(<.15 ⚠) 이질적 구성을 의심합니다.
- **응답 선택지 빈도**(`--item-freq`) — 문항별로 각 선택지를 고른 응답자 수/%. 미사용 선택지·치우친 분포·입력 오류를 드러냅니다(척도 범위가 정수일 때).
- **하위척도 점수** — 역문항 재코딩 후 가용 문항의 **평균** 또는 **비례배분 총합**(`score_method`). 평균 CI는 t 분포 기반입니다. `min_valid_ratio` 미만으로 응답한 사람은 점수에서 제외됩니다.
- **바닥/천장 효과** — 가능한 최소/최대 점수에 몰린 응답자 비율(척도 범위 선언 시). `> 15%` 면 ⚠ 로 표시하며, 척도가 특정 집단에서 변별력이 낮을 수 있음을 시사합니다.
- **왜도·첨도** — 문항 분포의 비대칭/뾰족함(SPSS/Excel과 동일한 편향보정 G1·G2). 정규성 가정 점검용.
- **문항-총점 r** — 수정된 문항-총점 상관(해당 문항을 제외한 나머지 합과의 상관). `< .30` 이면 그 문항이 척도와 잘 안 맞을 수 있습니다. **음수(`← 음수 r`)** 면 역문항 설정 누락/오류일 가능성이 큽니다(`reverse_items` 확인).
- **α(문항제거시)** — 그 문항을 빼면 척도 α가 어떻게 변하는지. 현재 α보다 **올라가면**(`← 제거시 α↑`) 문항 적합성을 재검토하세요. **단, 문항 제거는 척도 *개발* 단계용입니다 — ISI·PHQ-9 등 이미 검증된 표준척도에서는 문항을 빼지 마세요.**

## 한계 / Notes

- 신뢰도(α)·문항-총점 상관은 **완전응답자(listwise)** N 기준이고, **하위척도 점수**는 가용문항(`min_valid_ratio` 충족) N 기준입니다 — 둘의 N이 다를 수 있으니(예: α는 37명, 점수는 40명) 논문에 옮길 때 분모를 구분하세요. 리포트에 두 N을 모두 표기합니다.
- `scale_min`/`scale_max`를 지정하면 **범위를 벗어난 값**(입력 오류 가능)을 리포트 상단에 ⚠로 표시합니다. 역코딩은 이런 값을 그대로 뒤집으므로(예: 1~5 척도의 `9` → `-3`), 경고가 뜨면 원자료를 먼저 정리하세요.
- `--config` 없이 실행하면 숫자값이 없는 컬럼(전부 결측/텍스트)은 자동 제외되며, 어떤 컬럼이 빠졌는지 경고로 알립니다. 의도와 다르면 `--config`로 문항을 명시하세요.
- 문항별 기술통계는 **원자료(raw) 값** 기준으로 보고합니다(역코딩 전). 데이터 입력 오류·범위 이탈을 그대로 보기 위함입니다. 역코딩은 신뢰도·하위척도 점수 계산에만 반영됩니다.
- Cronbach α는 일차원성(단일 구성개념)을 가정합니다. 요인구조 검증(EFA/CFA)은 이 도구의 범위 밖입니다.
- **α 신뢰구간**은 Feldt(1965) 방법으로, 문항 점수의 정규성과 본질적 타우동등성(essential tau-equivalence)을 가정합니다. 강한 위반 시 폭이 부정확할 수 있습니다. **SEM**은 고전검사이론(CTT) 기반이며, α를 신뢰도 추정치로 사용합니다.
- **바닥/천장 효과**는 척도 범위(`scale_min`/`scale_max`)가 선언된 경우에만, 점수 방식에 따른 가능한 최소/최대 점수 기준으로 계산합니다.
- McDonald's ω, 결측 다중대치, CFA 기반 신뢰도 등은 포함하지 않습니다(의도적으로 표준 라이브러리만으로 가볍게 유지). t·F 분포 분위수는 순수 파이썬으로 직접 구현했으며 scipy와 ~1e-11 수준에서 일치함을 테스트로 확인합니다(테스트에서만 scipy 사용).
