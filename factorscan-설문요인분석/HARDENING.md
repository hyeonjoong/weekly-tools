# factorscan 하드닝 기록

여러 라운드에 걸친 독립 리뷰어(적대적 검토) 패널의 지적을 반영해 도구를 강화한 기록.
각 라운드는 (1) 통계 정확성(제1원리 재계산 대조) (2) 엣지케이스 (3) 실제 유용성/누락 기능
(4) 문서 정직성 (5) 테스트·보안/PII 다섯 축을 새 패널로 점검한다.

---

## 2026-07-16 — Round 1

베이스라인: 50 테스트 통과. 4개 독립 리뷰어 병렬 실행(정확성 / 엣지케이스 / 유용성 / 문서·테스트·보안).

### 검증된 강점 (변경 없음)
- **통계 코어는 정확**. `factor_analyzer`·`scipy` 독립 오라클과 기계정밀도로 일치 확인:
  Bartlett χ²/df/p, KMO 전체+문항별 MSA, `chi2_sf`(불완전감마, df 1~20000·x 0.001~50000
  상대오차 ≤~1e-13), 주성분 적재·공통성, Varimax(직교회전 공통성 보존), 평행분석 절차.
- PII/보안: 네트워크·임시파일·eval/exec 없음, 오류메시지에 원자료 미노출, 예시 CSV는 합성.
- README "실제 출력 예시"의 수치(χ², KMO, 고유값, 적재)가 실제 실행과 일치(조작 없음).

### 수정한 결함
1. **[HIGH] 설정 `scale_range` 언패킹 크래시** — `cfg["scale_range"]`가 try 밖에서 실행돼
   `[1,5,9]`/`5`/비-dict 설정이 raw 트레이스백을 냈다. → 설정 구조 검증(`_cfg_scale_range`,
   `_cfg_list`, 최상위 dict 확인) 추가, 깨끗한 `설정 파일 오류`+rc=2.
2. **[MED] CP949/EUC-KR 파일** — 한국어 엑셀 기본 인코딩이 utf-8 decode 실패로 암호같은
   오류만 냈다. → `--encoding` 옵션 추가, `UnicodeDecodeError`를 CP949 안내가 담긴 `DataError`로,
   알 수 없는 인코딩도 깔끔히 처리.
3. **[MED] 자릿수구분 쉼표("1,000")가 조용히 결측화** → `_to_float`에서 천단위 쉼표 인식·파싱.
   추가로 **숫자로 못 읽은 비어있지 않은 토큰 수**를 `Dataset.coercion`으로 세어 경고로 표면화.
4. **[LOW-MED] 헤더보다 긴 행이 조용히 잘림** → 넘치는 칸에 실제 값이 있으면 행번호와 함께 오류,
   빈 칸만 넘치면(엑셀 흔한 케이스) 무해하게 절단.
5. **[LOW] 인자 미검증** — `--min-loading -0.5`(모든 문항 교차적재로 오판)·`--scale-min≥max`
   허용 → 범위/순서 검증 후 rc=2.
6. **[LOW] 설정 items/reverse/id_cols 문자열이 문자단위 순회** → `_cfg_list`로 정규화.

### 정확성 다듬기
7. **평행분석 유지 규칙**: `np.sum(obs>ref)`(단순합산)을 **첫 교차에서 멈추는** 표준
   `retained_by_parallel`로 교체(비단조 상황 과대추정 방지).
8. **n≤p일 때 평행분석 생략**: 무작위 상관행렬이 특이해 기준선이 왜곡되는 문제 → 명시적 생략+경고.
9. **설명분산 분모**: 클리핑된 고유값 합 대신 대각합 p 사용(미세 음수 제거로 인한 총합 왜곡 제거).
10. **JSON 스키마 안정성**: `parallel_eigenvalues`/`parallel_k`를 생략 시에도 항상 `null`로 존재.

### 추가한 기능 (임상 연구 실사용 가치)
- **McDonald ω(요인별 합성신뢰도)** — 적재량으로부터 직접 계산, 표에 표시+JSON.
- **RMSR·비중복잔차(재현 상관행렬 적합도)** — 유지요인해의 적합도 근거.
- **요인(하위척도)별 수정된 문항-총점** — 다차원 척도에서 전체합 대신 소속 요인 내 합 사용
  (기존 전체합 값은 `item_total_overall`로 유지). 표시·플래그는 요인별 기준으로 전환.
- **문항별 MSA를 표에 표시**(기존엔 JSON에만 존재), **추출=주성분(PCA) 명시**를 보고서 헤더/도움말에.
- `실행.command`에 python3 부재 시 안내.

### 문서
- README "실제 출력 예시" 블록을 신규 포맷(MSA·ω·RMSR·PCA 표기)으로 갱신(실제 출력과 일치 유지).
- README/사용법.md에 `--encoding`, ω/RMSR, 요인별 문항-총점, PCA-기준 RMSR 주의 반영.

### 테스트
50 → **81 통과**. 신규 `tests/test_hardening.py`(31개): 인코딩(CP949/미지정/오류), 천단위 쉼표,
헤더 초과 행, 강제결측 카운트, 설정 검증 3종, 인자 검증 2종, 평행분석 n≤p 생략·첫교차·키존재,
요인별 문항-총점(수기 대조·싱글턴 NaN·k=1 동치), ω(공식 대조·클린데이터 범위), RMSR(완전적합 0·범위),
설명분산 합=1, report 신규항목 표시·특이행렬 MSA '—', 전체 파이프라인 결정성, 완전상관→비양정부호 경로.

신규 통계(ω·RMSR·요인별 문항-총점)는 모두 독립 수기 계산과 기계정밀도로 대조 확인.

## 2026-07-16 — Round 2

Round 1 산출물(신규 코드)에 새 4개 패널을 병렬 투입(정확성 / 엣지케이스 / 유용성·문서 / 테스트·보안).
핵심 지적이 여러 리뷰어에서 수렴 → 정직성·해석 위험 위주로 수정.

### 재확인된 강점
- 신규 통계 독립 재검증 통과: `retained_by_parallel`(첫 교차 규칙), `residual_stats`(비대각 RMSR),
  `corrected_item_total_by_group`, `eigen_summary`(합=1) 모두 수기/오라클과 일치.
- 보안: 천단위 정규식 ReDoS 없음(400KB 적대적 입력 <9ms), 오류메시지에 원자료 미노출,
  네트워크·eval·임시파일 없음. coercion 카운트 루프 500K행 0.5s로 선형.
- README 예시 수치(ω·RMSR·MSA 포함)가 실제 출력과 일치.

### 수정한 결함 (해석 정직성)
1. **[핵심] McDonald ω가 PCA 기반이라 낙관적인데 README 방향 설명이 반대였음** — 유용성 리뷰어가
   실측(F1 정식 congeneric ω=0.882 vs 도구 0.916)으로 상향편향 입증. 또한 정확성 리뷰어가
   "분자=자기요인 적재, 분모=전체 공통성"의 비일관성(교차적재 분산이 소실되어 과대추정)을 지적.
   → ω 공식을 **자기 요인 오차분산** `Σ(1−λ_if²)` 기준으로 일관화, docstring/보고서/README에
   **'PCA 기반 근사(낙관적), RMSR과 반대 방향'** 명시. (예시 ω 0.916/0.918 → 0.911/0.911)
2. **[핵심] ω의 <2문항 요인 미가드** — 1문항 요인이 무의미한 0.495 등을 출력. 문항-총점은 이미
   NaN 처리했는데 ω만 누락. → 요인 내 문항 2개 미만이면 `None`('—')로 정의 불가 처리.
3. **argmax 배정 불안정성 미고지** — 요인별 ω·요인총점이 |적재|최대 배정에 의존하는데 교차·저적재
   문항에서 불안정함을 알리지 않음. → 보고서/README에 참고용 경고 + 전체합 기준값(JSON
   `item_total_overall`) 병행 안내.
4. **`--rotation none` 다요인 결과 오해 유발** — 비회전 시 첫 성분에 몰려 전 문항 교차적재·F2 ω
   미정의가 아무 설명 없이 발생. → k≥2·비회전이면 안내 note 추가.

### 수정한 결함 (엣지케이스)
5. **[MED] 유럽식 소수 "1,234"(=1.234)를 자릿수구분으로 오독해 1000배 조용한 오염** —
   천단위 정규식이 단일 그룹까지 매칭. → **명확한 경우만**(소수점 동반 또는 그룹 2개 이상) 인식,
   모호한 단일 그룹은 결측+강제변환 경고로 표면화(조용한 오독 제거).
6. **[LOW] 설정 scale_range의 NaN/Infinity 통과** → `math.isfinite` 검증 추가.
7. **[LOW] `--items` 중복 지정 미거부**(파일 헤더 중복만 거부) → 중복 문항 명시적 오류.
8. **[LOW] 잘못된 --encoding으로 ID열이 조용히 분석문항으로 승격** → `--id-col` 미존재 시 경고.

### 테스트 (테스트 리뷰어 후속)
- 자기참조(tautological) ω 테스트를 **수기 리터럴**(0.7424…) 대조로 교체.
- 미보강 경로 회귀 가드 추가: config 경로 scale_min≥max·NaN·items-as-dict, CLI --json 강제변환
  경고 종단, CLI 잘못된 인코딩 rc=1, --na의 coercion 제외, ω '—' 렌더, 중복 items, 비회전 note,
  id-col 경고, **README 골든 스냅샷**(핵심 수치 표류 방지).
- 취약 임계값 테스트에 argmax 그룹핑 사전확정으로 진단성 강화.

81 → **95 통과**. 신규 통계 재검증 및 모든 Round-1/2 수정에 대응 회귀 테스트 확보.

## 2026-07-16 — Round 3

새 검증 패널(최종 정확성·회귀 / 문서·유용성·엣지) 투입. **결함 0건으로 클린 라운드** 확인:
- ω(자기요인 잔차) 재검증: 단일요인 congeneric ω와 정확히 일치, [0,1] 유계 증명·확인.
- 천단위 정규식 9개 스펙 케이스 전부 정확, config/인자 검증 정상, headline 통계(Bartlett·KMO·MSA·
  고유값·Varimax·공통성·RMSR·요인별 문항-총점·ω=0.911) 오라클과 정확 일치. README 예시 수치 일치.

세 라운드 모든 패널이 **일관되게 지목한 단 하나의 실질 개선점(사교회전)** 을 반영(필러 아님):

### 추가한 기능
1. **Promax 사교(oblique)회전 + 요인 상관행렬 Φ** — 임상·심리 하위척도는 대개 상관되어 직교(Varimax)
   가정이 부적절할 수 있음. `--rotation promax` 로 패턴적재+Φ 제공. `factor_analyzer`의 promax와
   패턴·Φ가 varimax 허용오차 수준으로 일치(Φ=−0.294 vs −0.293) 검증.
   - **요인 상관은 회전과 무관하게 항상 추정**해 보고서에 표시하고, |r|≥.32면 사교회전 검토 note 출력
     (직교가 타당한지 판단 근거 제공).
   - 사교회전 공통성은 `diag(P Φ Pᵀ)`(회전 불변), 설명분산은 구조행렬 기준+겹침 note로 정직하게 처리.
   - **ω는 구조행렬 S=PΦ(요인-문항 상관, |값|≤1) 기준으로 계산** — 사교회전에서 패턴계수가 1을
     넘어도 ω가 [0,1]에 머물도록 보장(직교회전이면 S=적재이므로 값 동일). 강상관 요인에서 검증.
   - promax 정규화를 Kaiser(공통성) 정규화 후 목표/최소제곱 → 복원 순서로 맞춰 factor_analyzer/R/SPSS
     promax와 자연 요인수에서 기계정밀도 일치.
   - **정확성 수정**: 사교회전 RMSR을 `R̂=PΦPᵀ`로 재현하도록 수정(초기엔 `PPᵀ`로 0.178 과대 →
     올바른 0.068). 독립 재계산으로 확인.
2. **상관행렬 행렬식(다중공선성 진단)** — det(R)<1e-5면 거의 중복 문항 경고(Field/SPSS 관례 임계).

### 문서
README 예시 블록에 요인상관 행렬 추가(실제 출력 일치), Promax·행렬식·직교/사교 한계 갱신, 사용법.md 옵션표.

95 → **105 통과**. Promax(Φ 유효성·회전불변 공통성·RMSR=PΦPᵀ·독립 알고리즘 대조·k=1 항등),
요인상관(직교하 추정·k=1 None), 행렬식·다중공선성 경고, CLI --rotation promax JSON/렌더 회귀 테스트 추가.

**결론**: 3라운드(리뷰 클린 + 최상위 요청 기능 반영) 후 통계 코어는 오라클 검증 완료, 엣지·문서·보안
모두 통과, 105 테스트 그린. 도구는 게재용 척도검증에 신뢰 가능한 상태로 판단하여 하드닝 종료.
