# factorscan 하드닝 기록

여러 라운드에 걸친 독립 리뷰어(적대적 검토) 패널의 지적을 반영해 도구를 강화한 기록.
각 라운드는 (1) 통계 정확성(제1원리 재계산 대조) (2) 엣지케이스 (3) 실제 유용성/누락 기능
(4) 문서 정직성 (5) 테스트·보안/PII 다섯 축을 새 패널로 점검한다.

## 2026-07-16 — Round 1

베이스라인: 50 테스트 통과. 4개 독립 리뷰어 병렬 실행(정확성 / 엣지케이스 / 유용성 / 문서·테스트·보안).

  Bartlett χ²/df/p, KMO 전체+문항별 MSA, `chi2_sf`(불완전감마, df 1~20000·x 0.001~50000

## 2026-07-16 — Round 3

새 검증 패널(최종 정확성·회귀 / 문서·유용성·엣지) 투입. **결함 0건으로 클린 라운드** 확인:
- ω(자기요인 잔차) 재검증: 단일요인 congeneric ω와 정확히 일치, [0,1] 유계 증명·확인.
- 천단위 정규식 9개 스펙 케이스 전부 정확, config/인자 검증 정상, headline 통계(Bartlett·KMO·MSA·
  고유값·Varimax·공통성·RMSR·요인별 문항-총점·ω=0.911) 오라클과 정확 일치. README 예시 수치 일치.

세 라운드 모든 패널이 **일관되게 지목한 단 하나의 실질 개선점(사교회전)** 을 반영(필러 아님):

### 추가한 기능
1. **Promax 사교(oblique)회전 + 요인 상관행렬 Φ** — 임상·심리 하위척도는 대개 상관되어 직교(Varimax)
   가정이 부적절할 수 있음. `--rotation promax` 로 패턴적재+Φ 제공. `factor_analyzer`의 promax와
   패턴·Φ가 varimax 허용오차 수준으로 일치(Φ=−0.294 vs −0.293) 검증.
   - **요인 상관은 회전과 무관하게 항상 추정**해 보고서에 표시하고, |r|≥.32면 사교회전 검토 note 출력
     (직교가 타당한지 판단 근거 제공).
   - 사교회전 공통성은 `diag(P Φ Pᵀ)`(회전 불변), 설명분산은 구조행렬 기준+겹침 note로 정직하게 처리.
   - **ω는 구조행렬 S=PΦ(요인-문항 상관, |값|≤1) 기준으로 계산** — 사교회전에서 패턴계수가 1을
     넘어도 ω가 [0,1]에 머물도록 보장(직교회전이면 S=적재이므로 값 동일). 강상관 요인에서 검증.
   - promax 정규화를 Kaiser(공통성) 정규화 후 목표/최소제곱 → 복원 순서로 맞춰 factor_analyzer/R/SPSS
     promax와 자연 요인수에서 기계정밀도 일치.
   - **정확성 수정**: 사교회전 RMSR을 `R̂=PΦPᵀ`로 재현하도록 수정(초기엔 `PPᵀ`로 0.178 과대 →
     올바른 0.068). 독립 재계산으로 확인.
2. **상관행렬 행렬식(다중공선성 진단)** — det(R)<1e-5면 거의 중복 문항 경고(Field/SPSS 관례 임계).

### 문서
README 예시 블록에 요인상관 행렬 추가(실제 출력 일치), Promax·행렬식·직교/사교 한계 갱신, 사용법.md 옵션표.

95 → **105 통과**. Promax(Φ 유효성·회전불변 공통성·RMSR=PΦPᵀ·독립 알고리즘 대조·k=1 항등),
요인상관(직교하 추정·k=1 None), 행렬식·다중공선성 경고, CLI --rotation promax JSON/렌더 회귀 테스트 추가.

**결론**: 3라운드(리뷰 클린 + 최상위 요청 기능 반영) 후 통계 코어는 오라클 검증 완료, 엣지·문서·보안
모두 통과, 105 테스트 그린. 도구는 게재용 척도검증에 신뢰 가능한 상태로 판단하여 하드닝 종료.

## 2026-07-16 — Round 4 (심층 확장 + 4패널 병렬 검토)

베이스라인 107 테스트. **먼저 실사용 가치가 큰 신규 통계·출력 기능을 추가**하고, 이어 4개 독립 리뷰어
(정확성 / 엣지케이스 / 유용성 / 문서·테스트·보안)를 병렬 투입해 하드닝.

### 추가한 기능 (임상 척도검증 실사용 깊이)
1. **주축분해(PAF) 추출** (`--extraction paf`) — README가 유일한 한계로 명시했던 '공통요인 모형' 제공.
   SMC 초기화 → 축소상관행렬 반복분해 → 공통성 수렴. Heywood(공통성>1·경계) 절단·경고. 독립 오라클과
   공통성 1e-6 일치, ω·RMSR이 PCA보다 덜 낙관적(예시 ω 0.911→0.874, RMSR 0.068→0.036).
2. **Velicer MAP(최소평균편상관) 검정** — Kaiser·평행분석과 독립적인 제3의 요인수 근거. 편상관 기반
   평균제곱 최소화(Velicer 1976). 독립 오라클과 1e-15 일치, 잡음자료에서 0개, 클린 2요인에서 2개.
3. **요인별 Cronbach's α** — 적재기반 ω와 나란히 응답분산기반 신뢰도를 제공(추출방식 무관). 수기공식 대조.
4. **적재표 CSV 내보내기**(`--csv-out`) — 문항×요인 적재+공통성·MSA·문항총점 **+ 요약행**(SS·설명분산%·
   누적%·ω·α·요인상관 Φ)까지 담아 논문 부록 표로 완결. utf-8-sig(엑셀), 수식 인젝션 방어, 4자리 반올림.
