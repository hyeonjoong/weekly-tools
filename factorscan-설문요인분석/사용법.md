# factorscan 빠른 사용법

설문 척도가 **몇 개 요인으로 이루어졌는지, 요인분석에 적합한지, 각 문항이 어느 요인에 실리는지**
한 번에 뽑아 주는 도구입니다. (신뢰도 Cronbach α는 짝 도구 `surveyscan`이 담당)

## 가장 쉬운 방법 — 더블클릭

`실행.command` 파일을 **더블클릭**하세요. 번들 예시(수면 자가진단 8문항·80명)로
KMO·Bartlett·요인 수·적재량 표가 바로 출력됩니다.

> 처음 한 번은 macOS가 막을 수 있어요 → 파일 우클릭 → **열기** → **열기**.

## 내 데이터로 돌리기 (터미널)

CSV는 **행=응답자, 열=문항** 형식이면 됩니다. **엑셀(.xlsx)·TSV 파일도 그대로** 넣을 수 있어요
(확장자를 보고 알아서 읽습니다 — CSV로 다시 저장하지 않아도 됩니다).

```bash
# 1) 설정 파일로 (역문항·척도범위 지정 가능, 권장)
python3 -m factorscan.cli 내설문.csv --config 내설정.json

# 2) 문항 열을 직접 지정, ID 열 제외
python3 -m factorscan.cli 내설문.csv --items Q1,Q2,Q3,Q4,Q5,Q6 --id-col ID

# 3) 요인 수를 2개로 고정
python3 -m factorscan.cli 내설문.csv --id-col ID --n-factors 2

# 4) 엑셀 파일을 그대로 (시트 이름 지정)
python3 -m factorscan.cli 설문결과.xlsx --sheet 응답 --id-col 환자ID

# 5) 논문 표에 넣을 적합도지수(χ²·RMSEA·CFI·TLI)까지
python3 -m factorscan.cli 내설문.csv --id-col ID --extraction ml --fit-scan

# 6) "표본을 다시 뽑아도 이 결과가 나올까?" — 부트스트랩 신뢰구간
python3 -m factorscan.cli 내설문.csv --id-col ID --bootstrap 500

# 7) 다기관/성별로 요인구조가 같은지 점검 (합쳐서 비교해도 되나?)
python3 -m factorscan.cli 내설문.csv --id-col 환자ID --group-col 사이트
```

설정 파일(`내설정.json`) 예:
```json
{ "id_cols": ["ID"], "reverse": ["Q1","Q2"], "scale_range": [1,5] }
```

**가설 구조를 미리 적어 두면** 실제 요인해와 자동으로 대조해 줍니다(`[3-4]` 섹션):
```json
{
  "id_cols": ["ID"], "reverse": ["Q1","Q2"], "scale_range": [1,5],
  "structure": {
    "수면의질": ["Q1","Q2","Q3","Q4"],
    "주간기능": ["Q5","Q6","Q7","Q8"]
  }
}
```

`pip install -e .` 를 한 번 해두면 `factorscan 내설문.csv ...` 로 더 짧게 쓸 수 있어요.

## 결과 읽는 법 (핵심만)

- **[1] 적합성**: `KMO ≥ 0.6`(≥0.8 우수) 이고 `Bartlett p < .05` 면 요인분석 OK.
- **[2] 요인 수**: 세 기준을 나란히 봅니다 — `★`(평행분석) · `고유값>1`(Kaiser) · `Velicer MAP`.
  대개 이들이 가리키는 수만큼의 요인을 잡으면 됩니다(기본은 평행분석 적용).
- **[3] 적재량**: 각 문항 행에서 별표(`*`, |0.40|↑)가 붙은 요인이 그 문항의 소속.
  두 요인에 모두 별표면 **교차적재**(애매한 문항). `MSA`·`요인총점`(소속 요인 내 문항-총점) 열도 함께 봅니다.
  표 아래 **ω·Cronbach α**(요인별 신뢰도, ≥0.70 권장)와 **RMSR**(모형 적합, 작을수록 좋음)도 참고하세요.
- **[4] 점검 문항**: 공통성 낮음·문항-총점<0.3·MSA<0.5·교차적재 문항을 모아 알려줍니다.
  여기 뜨는 문항은 제거/수정을 검토하세요. (공통성 기준은 추출 방식에 따라 다릅니다 —
  PCA는 0.3, PAF/ML은 공통분산만 모형화해 값이 체계적으로 낮으므로 0.2를 씁니다.)
- **[1-1] 문항 기술통계**: 논문 Table 1에 그대로 옮기는 표입니다. `←몰림`이 붙은 문항은
  응답이 척도 끝(바닥/천장)에 쏠려 변별력이 없다는 뜻이고, `←치우침`은 정규성 가정이
  깨졌다는 뜻이라 `--correlation polychoric` 을 검토하세요.
- **역문항 경고**: `주적재가 음수인 문항이 있습니다` 가 뜨면 거의 항상 역문항을 빠뜨린 것입니다.
  메시지가 알려주는 `--reverse ...` 명령을 그대로 붙여 다시 돌리세요. 이 상태에서는 합산점수
  저장이 **거부**됩니다(거꾸로 더해진 점수를 내보내지 않으려고 일부러 막습니다).
- **[0] 결측 구조**(결측이 있을 때만 표시): 어느 문항 때문에 응답자를 잃었는지 보여 줍니다.
  `삭제 편향 점검`에 문항이 뜨면 **버려진 응답자가 남은 응답자와 체계적으로 다르다**는 뜻이라
  결측 사유를 확인해야 합니다(무작위 결측이 아닐 수 있음). 판정은 d의 크기가 아니라 **신뢰구간이
  0을 배제하는가**로 하고 문항 수만큼 다중비교를 보정합니다 — 고정 임계값(|d|≥0.2)을 쓰면
  완전 무작위 결측에서도 거의 항상 발화해 경고가 무의미해지기 때문입니다.
- **α의 95% 신뢰구간**: α 줄 바로 아래에 나옵니다. 점추정이 .85여도 **구간 하한이 .70 밑**이면
  "신뢰도 .70 이상 확보"라고 쓸 수 없습니다(표본이 작을 때 흔합니다) — 보고서가 그럴 때 알려 줍니다.
- **[1-2] 응답 범주 분포**(리커트처럼 정수 범주일 때): 각 선택지를 몇 %가 골랐는지 보여 줍니다.
  `←2번 미선택`은 **아무도 그 선택지를 고르지 않았다**는 뜻이라 그 문항은 사실상 더 짧은 척도이고,
  `←희소`는 선택률 5% 미만입니다 — 둘 다 범주를 합치는(collapse) 근거가 됩니다.
  `--scale-min 1 --scale-max 5` 를 함께 주면 **아무도 안 고른 범주까지** 0%로 표시됩니다.
- **[3-2] 부트스트랩 안정성**(`--bootstrap 500` 일 때만): 응답자를 다시 뽑아 전 과정을 500번 반복합니다.
  적재 구간이 **넓거나(폭>0.3) 0을 포함**하면 그 문항의 적재는 표본이 바뀌면 달라집니다.
  `요인 수 안정성`이 70% 밑이면 요인 수를 확정적으로 보고하지 마세요. 500회에 보통 1초 안팎이며,
  `--correlation polychoric` 과 함께 쓰면 매우 느립니다.
- **[3-3] 집단별 요인구조 재현성**(`--group-col 사이트` 일 때만): 사이트·성별·투여군별로 요인분석을
  다시 돌려 **Tucker φ**로 비교합니다. `φ≥.95`면 같은 요인, `<.85`면 **그 집단에서는 다른 것을 재고
  있다**는 뜻이라 집단을 합친 총점 비교가 위험합니다. `집단 쌍 직접 비교` 줄도 꼭 보세요 — 두 집단이
  각각 전체 해와는 닮았는데 서로는 다른 경우를 여기서만 잡습니다.
  `판정보류*` 가 붙은 집단은 **표본이 작아서** φ가 낮게 나온 것이라 '구조가 다르다'는 근거가 되지
  못합니다(문항당 3명 미만이면 같은 모집단에서도 φ가 떨어집니다) — 그 집단은 표본을 더 모은 뒤 보세요.
- **[3-4] 가설 요인구조 대조**(설정에 `structure` 를 넣었을 때만): 미리 정한 하위척도 배정표와
  실제 결과를 대조해 **일치율**과 **어긋난 문항의 행선지**를 알려 줍니다. 논문에
  "8문항 중 6문항(75%)이 이론적으로 배정된 하위척도에 주적재되었다" 로 그대로 옮겨 쓰세요.
- **점수 파일에서 환자를 잃지 않으려면**: 기본(`listwise`)은 한 문항이라도 빠진 응답자를 점수
  파일에서 통째로 뺍니다. 하위척도 점수가 시험의 평가변수라면 `--score-missing prorate` 를 쓰세요 —
  하위척도별 결측이 20% 이하면 응답한 문항 평균으로 환산해 **모든 응답자에게 점수를 줍니다**
  (요인분석 자체는 그대로 완전응답자 기준). `대체된_문항응답수` 열로 몇 문항을 대체했는지 확인하세요.
- **[3-1] 모형 적합도**(`--extraction ml` 일 때만): 논문에 그대로 옮기는 표입니다.
  `RMSEA ≤ .08`·`CFI/TLI ≥ .90`(≥.95면 우수)이면 대체로 수용 가능. `--fit-scan` 을 붙이면
  요인 수 후보별 적합도를 한 표로 훑어 **BIC가 가장 작은 k**를 짚어 줍니다.

## 자주 쓰는 옵션

| 옵션 | 뜻 |
|---|---|
| `--n-factors K` | 요인 수 직접 지정 (기본: 자동/평행분석, 평행분석 끄면 Kaiser) |
| `--extraction paf` | 공통요인 추출(주축분해). 기본은 `pca`(주성분, SPSS 기본) |
| `--extraction ml` | 최대우도 추출 — χ²·RMSEA·CFI·TLI 적합도지수를 함께 출력 |
| `--fit-scan` | 요인 수 k별 적합도지수 표(ML 전용, 요인 수 결정 근거) |
| `--sheet 이름` | 엑셀(.xlsx) 입력에서 읽을 시트 (기본: 첫 시트) |
| `--delimiter ';'` | 구분자 직접 지정 (기본: `.tsv`→탭, 그 외→쉼표) |
| `--correlation polychoric` | 순서형(리커트) 잠재상관으로 요인분석. 기본은 `pearson` |
| `--rotation promax` | 사교(oblique)회전 — 요인 간 상관행렬 Φ 함께 출력 |
| `--rotation none` | Varimax 회전 끄기 |
| `--reverse Q1,Q2 --scale-min 1 --scale-max 5` | 역문항 재점수화 |
| `--bootstrap 500` | 적재량 95% CI · 요인 수 안정성 · α/ω 비모수 구간 (기본 0=생략) |
| `--group-col 사이트` | 집단별 요인구조 재현성 점검(Tucker φ). 이 열은 문항에서 자동 제외 |
| 설정의 `structure` | 가설 하위척도 배정표와 실제 요인해를 대조(일치율·어긋난 문항·하위척도별 α) |
| `--score-missing prorate` | 결측이 있어도(하위척도별 20% 이하) 점수를 계산 — 환자를 잃지 않음 |
| `--max-missing-prop 0.25` | 비례배분에서 허용할 하위척도별 결측 비율(기본 0.2) |
| `--parallel-iter 0` | 평행분석 생략(더 빠름) |
| `--encoding cp949` | 한국어 엑셀 등 UTF-8이 아닌 CSV 읽기 |
| `--csv-out 경로` | 문항×요인 적재표+요약행을 CSV로 저장(논문 부록·엑셀용) |
| `--scores-out 경로` | 응답자별 하위척도(요인) 점수를 CSV로 저장(후속 분석용, 역문항 반영) |
| `--score-method mean` | 하위척도 점수를 평균으로(기본은 합산 `sum`) |
| `--score-method regression` | Thurstone 회귀 요인점수(전 문항 적재 가중·표준화) |
| `--eigen-out 경로` | 고유값+평행분석 기준선 CSV(엑셀에서 스크리 도표 그리기) |
| `--json` | JSON으로 출력(다른 분석에 넘길 때) |
