# factorscan — 설문 척도 요인분석·타당도 진단기

설문 응답 파일(**CSV · TSV · 엑셀 .xlsx**)을 넣으면 **탐색적 요인분석(EFA)** 과 척도 타당도 진단을
한 번에 출력합니다: 요인분석 적합성(KMO·Bartlett), 몇 개의 요인으로 이루어졌는지(고유값·Kaiser·평행분석·MAP),
요인 적재량(Varimax/Promax 회전)·공통성, 최대우도(ML) 적합도지수(χ²·RMSEA·CFI·TLI),
결측 구조 진단, 그리고 수정된 문항-총점 상관까지.

## 목적 / Why this exists

**한국어** — 설문 척도로 논문을 쓸 때, 리뷰어는 거의 항상 *"이 척도가 요인분석에 적합한가(KMO·Bartlett), 몇 개
차원인가, 각 문항이 어느 요인에 얼마나 실리는가(적재량), 겉도는 문항은 없는가"* 를 묻습니다. SPSS로 매번
클릭해 뽑던 이 표들을 CSV 하나로 재현 가능하게(시드 고정) 뽑아 줍니다. 신뢰도(Cronbach α)를 다루는
`surveyscan`과 짝을 이루어, 이 도구는 **차원성·구성타당도** 쪽을 담당합니다. 임상·제약 연구자가
자체 개발 설문(예: BELL-001 수면 자가진단, 와우핏 청능재활 설문)을 검증하거나 게재 전 표를 준비할 때 씁니다.

**English** — When publishing with a survey scale, reviewers almost always ask whether the scale is
*factorable* (KMO, Bartlett), *how many dimensions* it has, *how each item loads* on the factors, and
*which items misbehave*. factorscan reproduces those exact tables — the ones you'd otherwise click through
in SPSS — from a single CSV, reproducibly (fixed seed). It is the *dimensionality / construct-validity*
companion to `surveyscan` (which covers *reliability*, Cronbach's α). Built for a clinical/pharma researcher
validating an in-house questionnaire or preparing a scale-validation table before submission.

**이 도구가 하는 것 / What it computes**
- **요인분석 적합성**: Bartlett 구형성 검정(χ², df, p), KMO 전체 + 문항별 MSA(표에 함께 표시)
- **요인(차원) 수**: 상관행렬 고유값·설명분산, Kaiser 기준(고유값>1), **평행분석**
  (Horn 1965; 무작위 정규자료 고유값의 **95백분위** 기준선은 Glorfeld 1995의 변형),
  **Velicer MAP(최소평균편상관)** — 세 기준을 나란히 제시(서로 독립적 근거).
  MAP는 편상관 기반이라 상관행렬이 양의 정부호가 아니거나 문항이 3개 미만이면 생략되며,
  생략되면 그 사실을 보고서에 남깁니다
- **상관·추출·회전**: 피어슨 또는 **폴리코릭(순서형 리커트 잠재상관)** 상관행렬(`--correlation`) →
  **주성분(PCA)** · **주축분해(PAF, 공통요인)** · **최대우도(ML)** 추출(`--extraction`) + Varimax 직교회전 /
  Promax 사교회전(요인 간 상관행렬 Φ 함께) / 비회전, 공통성
- **모형 적합도(ML 추출)**: χ² 적합도 검정, **RMSEA + 90% CI · PCLOSE**, **CFI · TLI**, AIC/BIC —
  게재 표에 그대로 옮길 수 있는 공식 지표. `--fit-scan` 으로 **요인 수 k=1..최대의 적합도를 훑어**
  표에서 **BIC 최소 k를 표시**하고, χ²가 비유의해지는 최소 k는 함께 실린 p값으로 바로 읽을 수 있습니다
- **결측 구조 진단**: 문항별 결측률, listwise 삭제로 잃은 표본 규모와 **유발 문항**,
  그리고 완전응답자 vs 삭제된 응답자의 응답 분포 차이(Cohen's d)로 **MCAR 위배 신호**를 점검
- **문항 기술통계(척도 논문 Table 1)**: 평균·SD·왜도·첨도·**바닥/천장 효과** — 응답이 척도
  끝에 몰려 변별력이 없는 문항을 짚고, |왜도|>2·|첨도|>7이면 폴리코릭 전환을 권고
- **응답 범주 분포**: 문항별 선택지 선택률 표와 **죽은 범주**(아무도 고르지 않은 선택지)·
  **희귀 범주**(선택률 5% 미만) 탐지. 요인분석은 이걸 절대 알려 주지 않습니다 — 5점 척도에서
  2번을 아무도 고르지 않아도 적재량은 멀쩡하게 나오고, 그 문항은 사실상 4점 척도로 작동합니다.
  규제기관(FDA PRO guidance)이 요구하는 표이자 범주 축소(collapse)의 근거입니다.
  `--scale-min/--scale-max` 를 주면 **관측되지 않은 범주까지** 0%로 세워 드러냅니다
- **역문항 미처리 탐지**: 주적재가 음수인 문항을 찾아 **실행할 명령(`--reverse ...`)** 을 제시하고,
  방향이 뒤섞인 채로는 합산점수를 만들지 않음(조용히 오염된 점수를 내보내지 않음)
- **제거 시 α(alpha-if-deleted)**: "이 문항을 빼면 신뢰도가 오르나?"에 직접 답하는 플래그
- **요인별 신뢰도·적합도**: 합성신뢰도 **ω**(적재기반 — 기본 PCA에서는 근사·낙관적이라
  'PCA 기반 ω(근사)'로 표기하고, PAF/ML에서만 **McDonald ω**로 부릅니다) + **Cronbach α**(응답분산기반),
  **α의 95% 신뢰구간(Feldt)** — APA·COSMIN 보고 지침이 요구하는 구간까지,
  RMSR·비중복잔차(재현 상관행렬 적합도), 상관행렬 행렬식(다중공선성).
  ω와 α가 0.20 이상 벌어지면 역문항 미처리·이질 척도 혼입·배정 오류 중 하나이므로 경고합니다
- **재현 가능성(부트스트랩, `--bootstrap N`)**: 응답자를 복원추출로 재표집해 전 과정을 다시 돌려
  **적재량의 95% 신뢰구간**(Procrustes 정렬), **요인 수 안정성**(평행분석이 같은 k를 지지한 재표본 비율),
  **α·ω의 비모수 신뢰구간**을 냅니다 — **적재량과 요인 수에 대해 표집 불확실성을 직접 재는
  유일한 지표**입니다(α의 Feldt 구간·RMSEA 90% CI는 각각 모수적 가정 아래의 구간입니다).
  n<200 임상 표본에서 특히 중요합니다
- **집단 간 구조 재현성(`--group-col`)**: 사이트·성별·투여군별로 요인해를 다시 적합해
  **Tucker 일치계수 φ**로 비교합니다(≥.95 동일 · .85~.94 유사 · <.85 다름). 다기관 자료에서
  "합쳐서 총점을 비교해도 되는가"를 CFA 측정동일성 검정 **전에** 거르는 표준 선별 절차입니다.
  표본이 작은 집단은 **같은 모집단에서 뽑아도** φ가 떨어지므로(모의실험에서 문항당 1~2명이면
  오경보 100%), 문항당 3명 미만이거나 KMO<.50인 집단은 값만 표시하고 **판정에서 제외**합니다
- **문항 품질**: 수정된 문항-총점 상관(소속 요인/하위척도 기준), 저(低)공통성·저MSA·교차적재·저적재 자동 플래그
- **입력 형식**: CSV · TSV · **엑셀 .xlsx**(확장자로 자동 판별, `--sheet` 로 시트 선택) — 엑셀을
  CSV로 다시 저장할 필요 없음. 날짜 서식 셀은 날짜로 인식해 문항으로 오인하지 않고, 분석에서
  빠진 열은 사유와 함께 보고. 구분자 지정(`--delimiter`), 인코딩 지정(`--encoding`, CP949 등)
- **요인 자동 명명**: 설정에 `structure`를 주면 요인 번호(F1/F2)에 **하위척도 이름**을 붙여
  보고서와 점수 CSV 전체에서 `F1(신체증상)` 처럼 읽히게 합니다(요인 번호는 고유값 크기 순일 뿐
  의미가 없습니다). 대응은 목표 일치계수로 자동 결정합니다
- **결측 처리 선택**(`--missing listwise|pairwise`): 기본은 완전응답자만 쓰는 listwise지만,
  임상 설문은 결측이 여러 문항에 흩어져 있어 **한 문항만 빠져도 응답자가 통째로 버려집니다**
  (12문항 · 문항별 결측 8%가 무작위로 흩어지면 완전응답자는 0.92¹² ≈ 37%, 300명 중 약 110명만
  남습니다). `--missing pairwise` 는 상관 r_ij를 **i·j를 모두 답한 사람**으로 추정해 유효 표본을
  되살립니다(같은 조건에서 쌍별 N은 0.92² ≈ 85%, 약 250명).
  쌍별 상관행렬은 양의 정부호가 아닐 수 있어 필요하면 고유값 보정(smoothing)을 적용하되,
  보정을 하면 **KMO·Bartlett·ML 적합도는 생략**합니다(이 값들은 |R|·R⁻¹에 의존해 보정 하한값이
  결과를 지배합니다). Bartlett·평행분석에는 **가장 작은 쌍별 N**을 보수적 유효 N으로 씁니다
- **단일 파일 HTML 보고서**(`--html-out`): **스크리 도표(SVG)** 와 색으로 크기가 읽히는 적재표,
  적합성·신뢰도 표를 담은 HTML 하나를 만듭니다. 외부 CSS/JS/이미지를 참조하지 않아 메일 첨부·
  공유 폴더로 그대로 전달됩니다(matplotlib 등 추가 의존성 없음)
- **역문항 재점수화**, JSON 출력, **논문 부록용 적재표 CSV 내보내기**(`--csv-out`),
  응답자별 **하위척도 점수 CSV**(`--scores-out`, 합산·평균·**Thurstone 회귀 요인점수**),
  **비례배분 채점**(`--score-missing prorate`) — 하위척도별 결측이 허용치 이하면 응답한 문항
  평균으로 환산해 **결측이 있는 응답자도 점수를 받습니다**(PRO 채점 매뉴얼의 표준 규칙)

> 추출은 기본이 **주성분(PCA)** 으로 SPSS 요인분석의 기본 추출과 동일합니다. 공통요인 모형이 필요하면
> `--extraction paf`(주축분해, SMC 초기·반복)를, **적합도지수(χ²·RMSEA·CFI·TLI)가 필요하면
> `--extraction ml`**(최대우도)을 쓰세요 — 둘 다 ω·RMSR이 덜 낙관적으로 나옵니다(아래 한계 참고).

## Install

```bash
cd factorscan-설문요인분석
python3 -m pip install -e .        # numpy만 설치됩니다
# 또는 설치 없이 바로:  python3 -m factorscan.cli ...
```

의존성은 `numpy` 하나입니다(카이제곱 p값 등 통계는 자체 구현, scipy 불필요).

## Usage

아래 예시는 `pip install -e .` 를 마친 상태(`factorscan` 명령이 PATH에 있음)를 가정합니다.
설치하지 않았다면 `factorscan` 을 `python3 -m factorscan.cli` 로 바꿔 그대로 쓰면 됩니다.

```bash
# 1) 설정 파일로(역문항·척도범위·문항목록 지정) — 가장 권장
factorscan examples/sleep_scale.csv --config examples/sleep_config.json

# 2) 열을 직접 지정
factorscan responses.csv --items Q1,Q2,Q3,Q4,Q5,Q6 --id-col ID

# 3) 요인 수를 직접 지정 + 회전 끄기 + JSON
factorscan responses.csv --id-col ID --n-factors 3 --rotation none --json
```

```bash
# 4) 공통요인 추출(PAF) + 적재표 CSV + 응답자별 하위척도 점수 CSV 저장
factorscan responses.csv --id-col ID --extraction paf \
    --csv-out loadings.csv --scores-out scores.csv

# 5) 엑셀 파일을 그대로 + 최대우도(ML) 적합도지수 + 요인 수 스캔
factorscan 설문결과.xlsx --sheet 응답 --id-col 환자ID --extraction ml --fit-scan

# 6) Thurstone 회귀 요인점수로 내보내기(전 문항 적재 가중·표준화)
factorscan responses.csv --id-col ID --scores-out scores.csv --score-method regression

# 7) 스크리 도표용 표(고유값 + 평행분석 기준선)를 엑셀로
factorscan responses.csv --id-col ID --eigen-out scree.csv

# 8) 부트스트랩으로 적재량 신뢰구간 + 요인 수 안정성 확인(작은 표본에서 특히 권장)
factorscan responses.csv --id-col ID --bootstrap 500

# 9) 다기관 자료: 사이트별로 요인구조가 재현되는지 Tucker φ로 점검(번들 예시로 바로 실행 가능)
factorscan examples/multisite_scale.csv --config examples/multisite_config.json \
    --group-col 사이트 --n-factors 2

# 10) 결측이 흩어져 완전응답자가 얼마 안 남을 때: 쌍별 삭제로 표본 되살리기
factorscan responses.csv --id-col ID --missing pairwise

# 11) 공동연구자에게 보낼 HTML 보고서(스크리 도표 포함) 만들기
factorscan responses.csv --id-col ID --html-out report.html
```

주요 옵션: `--n-factors K`(미지정 시 평행분석 기준 자동, 평행분석 끄면 Kaiser), `--correlation pearson|polychoric`(상관 방식),
`--extraction pca|paf|ml`(추출 방식), `--fit-scan`(ML 요인 수별 적합도 표), `--rotation varimax|promax|none`,
`--reverse Q1,Q2 --scale-min 1 --scale-max 5`(역문항), `--parallel-iter N`(평행분석 반복, 0이면 생략),
`--bootstrap N`(재표본 N개로 적재 CI·요인 수 안정성·α/ω 구간; 0이면 생략, 500 권장),
`--group-col 이름`(집단별 구조 재현성 — Tucker φ),
`--seed`(재현), `--min-loading 0.40`(주적재/교차적재 임계값, 0~1), `--na 값`(결측 문자열 추가),
`--sheet 이름`(엑셀 시트 선택), `--delimiter ';'`(구분자 직접 지정), `--encoding cp949`(UTF-8이 아닌 CSV),
`--missing listwise|pairwise`(상관행렬 추정의 결측 처리),
`--html-out 경로`(스크리 도표 SVG가 들어간 단일 파일 HTML 보고서),
`--csv-out 경로`(문항×요인 적재표+요약행을 CSV로 — 논문 부록·엑셀용),
`--eigen-out 경로`(고유값·평행분석 기준선 CSV — 엑셀에서 스크리 도표),
`--scores-out 경로 --score-method sum|mean|regression`(응답자별 하위척도 점수를 CSV로 — 후속 타당도 분석용),
`--score-missing listwise|prorate --max-missing-prop 0.2`(비례배분 채점).

> **CSV 내보내기**: `--csv-out` 은 문항별 적재·공통성·MSA·문항-총점 + **요약행**(적재제곱합·설명분산%·누적%·
> ω·α·**α의 95% CI(Feldt)**, 그리고 요인상관 Φ)을 담아 표 하나로 완결됩니다(집계값만, 개인정보 없음).
> `--bootstrap` 을 함께 주면 문항 행에 **주적재의 95% CI 두 열**(`primary_loading_ci_lo/hi`)과
> 요약행에 α·ω의 부트스트랩 구간이 추가되어, 논문 표에 `λ = .82 [.73, .88]` 형태로 그대로 옮길 수 있습니다.
> Φ 행은 회전 방식과 무관하게 나오지만 **이름이 다릅니다**: 직교회전(varimax/none)에서는 promax로
> 따로 추정한 값이라 `_factor_correlation(promax_estimate;varimax해는Φ=I)`, 사교회전에서는 실제 해라
> `_factor_correlation(promax)` 입니다 — 직교 결과를 보고할 때 추정치 Φ를 함께 싣지 마세요. `--scores-out` 은
> 요인분석에 실제 쓰인(결측제거) 응답자마다 하위척도 합/평균 점수를 ID와 함께 내보내, 요인구조 확인 후
> 곧바로 집단비교·수렴타당도 분석에 넘길 수 있습니다(역문항 재점수화 반영). `--id-col` 을 주지 않으면
> ID 대신 **원본 파일 행번호(`row`)** 열이 나갑니다(결측 삭제로 순번이 어긋나지 않게 원본 기준).
> 세 파일 모두 utf-8-sig(BOM)라 한국어 엑셀에서 바로 열립니다.
>
> ⚠ **개인정보 주의**: `--scores-out` 파일은 **응답자 식별정보(ID)와 개인별 점수가 담긴 식별가능 자료**입니다.
> 집계 표(`--csv-out`)와 달리 그대로 외부 공유·게시하지 말고 기관 규정에 따라 취급하세요.

## 입력 형식 · 설정 파일

- CSV: 행=응답자, 열=문항. ID/텍스트 열은 자동 제외되거나 `--id-col`로 지정.
- 결측: 빈칸, `NA`, `N/A`, `null`, `.`, `-` 등을 자동 인식(추가는 `--na`).
- 설정 JSON(선택):
  ```json
  {
    "id_cols": ["ID"],
    "items": ["Q1", "Q2", "Q3", "Q4"],
    "reverse": ["Q1"],
    "scale_range": [1, 5],
    "structure": {
      "수면의질": ["Q1", "Q2"],
      "주간기능": ["Q3", "Q4"]
    }
  }
  ```
  `structure`(선택)는 **연구자가 미리 정한 하위척도 배정표**입니다. 주면 `[3-4]` 섹션에서
  실제 요인해와 대조해 줍니다 — 아래 참고.

### 가설(a priori) 요인구조 대조 (`structure`)

척도 개발·번안 논문은 늘 가설을 갖고 시작합니다("Q1–Q4는 수면의 질, Q5–Q8은 주간 기능").
그런데 EFA는 그 가설을 모른 채 요인을 뽑고 요인 번호는 고유값 크기 순일 뿐이라, 지금까지는
표를 눈으로 대조해야 했습니다(40~60문항 척도에서 실수가 나는 지점입니다). 설정에 `structure`를
넣으면 자동으로 답합니다:

```
$ factorscan examples/sleep_scale.csv --config examples/sleep_config_가설어긋남.json

[ 3-4. 가설 요인구조 대조 (설정의 structure) ]
  문항 배정 일치율: 6/8 (75%) 이 가설한 하위척도에 **최대** 적재
  주적재 기준(|λ|≥0.40)까지 만족: 6/8 (75%)
  가설 하위척도    문항수   대응요인    목표φ       α          α 95% CI
  수면의질            4   F2         0.777    0.751   [0.645, 0.831]
  주간기능            4   F1         0.772    0.747   [0.640, 0.828]
  문항별 가설 요인 적재:
  문항              가설 하위척도    가설요인λ   최대적재         판정
  ...
  Q4_수면만족       주간기능             0.150   수면의질(+0.858) ✗ 다른 요인으로
  Q5_주간졸림       수면의질             0.137   주간기능(+0.882) ✗ 다른 요인으로
  ...
  α는 요인해의 argmax 배정이 아니라 **가설한 문항 묶음 그대로** 계산한 값입니다.
```

- **일치율을 두 가지로** 냅니다: ⑴ 최대적재(argmax) 기준과 ⑵ **주적재 기준(|λ|≥`--min-loading`)**
  까지 만족한 비율. 둘을 나누는 이유는 argmax만 보면 적재가 0.20인 잡음 문항도 **어딘가에는**
  배정되어 "100% 일치"로 세어지기 때문입니다. 논문에는 ⑵를 쓰세요 —
  `"8문항 중 6문항(75%)이 이론적으로 배정된 하위척도에 |λ|≥.40으로 주적재되었다"`.
- **문항별 대조표**를 전부 인쇄합니다(일치한 문항 포함). 각 문항의 **가설 요인 적재**와 실제
  최대적재를 나란히 놓아, '배정은 맞는데 적재가 약한' 문항(△)이 숨지 않게 했습니다.
- 어긋난 문항은 행선지를 이름·적재량과 함께 보여 주어 삭제·재배치를 정당화할 근거가 됩니다.
- **가설 하위척도별 α(+ Feldt CI)** 는 요인해의 argmax 배정이 아니라 **연구자가 정한 문항 묶음
  그대로** 계산합니다 — 배정이 어긋난 문항이 있어도 "원래 의도한 하위척도의 신뢰도"를 알 수 있어야
  하기 때문입니다.
- **요인 대응은 자동**입니다(요인 번호는 임의이므로 |φ| 합이 최대가 되는 1:1 대응을 찾습니다).
- **목표φ는 적재의 '크기'가 아니라 '패턴'만 잽니다** — 모든 적재가 .30이어도 교차적재만 없으면
  1.000이 나옵니다. 하위척도가 강한지는 α와 [3]의 적재량으로 보고, 목표φ로는 '깨끗한지'만
  판단하세요. [3-3]의 φ 기준(.95/.85)은 **두 요인해를 비교할 때** 값이라 여기엔 적용되지 않습니다.
  요인 부호는 관례상 임의라 목표φ는 **크기만** 보고하고, 부호가 뒤집힌 경우 따로 알립니다.
- 가설 요인 수와 실제 적용된 요인 수가 **다르면 그 자체가 결과**이므로 경고하고, 문항 배정 대조는
  생략한 채 하위척도별 α만 제공합니다(`--n-factors <가설 요인 수>` 로 강제 비교할 수 있습니다).
- 가설에 없는 문항은 대조에서 제외하고 그 사실을 알립니다. 없는 문항 이름·중복 배정은 오류로 막습니다.

## 해석 가이드 (관례적 기준)

- **KMO** ≥ 0.6 적합, ≥ 0.8 우수 / **Bartlett** p < .05 이면 요인분석 적합.
- 요인 수: 세 기준(**Kaiser** 고유값>1 · **Horn 평행분석(★)** · **Velicer MAP**)을 나란히 보여 줍니다.
  Kaiser는 과대추정 경향이 있어 **기본값으로 평행분석 결과를 적용**하며(평행분석을 끄면 `--parallel-iter 0`
  Kaiser로 대체), MAP는 편상관 기반의 독립적 제3 근거입니다. 세 기준이 어긋나면 보고서가 알려 주고,
  `--n-factors K` 로 직접 지정할 수 있습니다.
- **추출**: 기본은 주성분(PCA, SPSS 기본). 공통요인 모형이 필요하면 `--extraction paf`(주축분해).
  PAF는 공통분산만 모형화해 ω·RMSR이 덜 낙관적이며, 리뷰어가 공통요인 결과를 요구할 때 씁니다.
- **적합도지수**(`--extraction ml`): **RMSEA ≤ .05 우수 / ≤ .08 수용**, **CFI·TLI ≥ .95 우수 / ≥ .90 수용**,
  **χ² p ≥ .05** 면 모형이 기각되지 않음(단, 표본이 크면 쉽게 유의해지므로 RMSEA·CFI를 함께 봅니다).
  `--fit-scan` 은 요인 수 후보별로 이 표를 훑어 **χ²가 비유의해지는 최소 k**와 **BIC 최소 k**를 제시합니다.
- 적재량 **|.40| 이상(\*)** 을 주요 적재로 봅니다. 두 요인에 모두 .40↑이면 **교차적재**.
- **공통성 낮음**(PCA는 <0.3, **PAF/ML은 <0.2** — 공통요인 추출은 공통분산만 모형화해 h²가
  체계적으로 낮습니다. 0.3을 그대로 적용하면 진적재 .50짜리 정상 문항까지 대부분 플래그됩니다),
  **문항-총점 < 0.3**, **문항별 MSA < 0.5** 문항은 제거/수정 검토.
- **문항-총점('요인총점')** 은 각 문항이 주적재된 **요인(하위척도) 내 총점** 기준입니다(다차원 척도 권장).
  요인 배정은 |적재|최대(argmax)이므로 교차·저적재 문항은 배정이 불안정합니다 — 전체합 기준 값도
  JSON(`item_total_overall`)에 함께 제공되니 함께 확인하세요.
- **McDonald ω**(적재기반 합성신뢰도)와 **Cronbach α**(응답분산기반)를 요인별로 나란히 제시합니다
  (대략 ≥.70). 다만 **.70은 Nunnally(1978)가 '연구 초기 단계'에 한해 제시한 값**이며, 같은 출처는
  개인 단위 판단에 쓰는 도구라면 **≥.90**을 요구합니다 — 임상 의사결정용 척도라면 그 기준을 함께
  보고하세요. ω는 추출 방식에 따라 낙관적일 수 있어(PCA) α와 함께 보고하는 것이 안전합니다.
  요인 내 문항이 2개 미만이면 둘 다 정의 불가('—'). **RMSR** 은 재현 상관행렬 잔차(작을수록 적합, 대략 <.08).

## 한계 / Notes

- **쌍별 삭제(`--missing pairwise`)의 범위와 대가**: 쌍별 삭제는 **상관행렬과 거기서 나오는 것**
  (고유값·평행분석·Velicer MAP·KMO·Bartlett·적재량·공통성·잔차·ML 적합도)에만 적용됩니다.
  α·문항-총점·제거시 α·부트스트랩·집단 재현성·요인점수는 응답자별 **총점**이 필요해 쌍별로
  대체할 수 없으므로 **언제나 완전응답자 기준**이며, 보고서가 두 표본 크기를 나란히 표시합니다
  (논문에는 반드시 둘 다 적으세요). 대가는 셋입니다: ⑴ 셀마다 표본이 달라 결과 행렬이 양의
  정부호가 아닐 수 있습니다 — 그때는 고유값 보정을 적용해 **적재량 추출은 계속하되 KMO·Bartlett·
  ML 적합도는 생략**합니다(보정은 최소 고유값을 하한 1e-6으로 올리는데, 그러면 ln|R|이 사실상
  ln(1e-6)이 되어 Bartlett χ²의 대부분이 자료가 아니라 하한값에서 나옵니다 — 중복 문항 실측에서
  χ² 6872 중 6841이 하한 몫이었습니다). ⑵ **ML 적합도지수(χ²·RMSEA·CFI·TLI·AIC/BIC)는
  `--missing pairwise` 에서 아예 계산하지 않습니다**: χ² ≈ (N−1)·F 로 표본 크기에 직접 비례하는데
  쌍별 삭제에는 단일한 N이 없고, '보수적'이라며 최솟값을 넣으면 오히려 χ²가 줄어 기각될 모형이
  완벽해 보입니다(실측: 600명·12문항 중 한 문항만 55명이 응답한 자료에서 RMSEA 0.101→0.000,
  CFI 0.896→1.000). 적합도지수가 필요하면 `--missing listwise` 로 완전응답자 기준 값을 보고하세요.
  Bartlett·평행분석은 방향이 반대(작은 N일수록 보수적)라 최소 쌍별 N을 그대로 씁니다.
  ⑶ **MCAR/MAR을 벗어난 결측**에서는 쌍별 추정도 편향됩니다 — 보고서의 '삭제 편향
  점검'이 신호를 주면 결측 사유를 먼저 확인하세요. 결측이 무작위가 아니라고 판단되면 다중대체(MI)나
  FIML을 쓰는 전용 도구가 필요하며, factorscan은 그것을 제공하지 않습니다.
- **HTML 보고서(`--html-out`)** 는 텍스트 보고서와 **같은 값**을 다시 배치할 뿐, 여기서만 계산하는
  통계는 없습니다. 담는 범위는 적합성·요인 수(스크리 도표)·적재표·신뢰도·적합도 요약이며,
  결측 구조표·응답 범주표·부트스트랩·집단 재현성 등 세부 절은 텍스트/JSON 출력에만 있습니다.
  적재표에는 **문항명**이 들어가므로 개인정보는 아니지만 미공개 척도 문항이면 공유에 유의하세요.
- 추출은 **주성분(PCA, 기본)** · **주축분해(PAF, `--extraction paf`)** · **최대우도(ML, `--extraction ml`)**
  를 제공합니다. PCA는 SPSS 기본과 동일하고, PAF는 SMC 초기·반복 방식, ML은 R의 `factanal`과 같은 계열의
  프로파일 우도 F(Ψ) 최소화(사영 Barzilai-Borwein, scipy 불필요)입니다. **적합도지수(χ²·RMSEA·CFI·TLI)는
  확률모형인 ML에서만 정의되므로 `--extraction ml` 에서만 출력**됩니다(PCA/PAF에서는 RMSR만).
  PAF/ML에서 공통성이 1에 닿는(고유분산이 하한 0.005에 붙는) **Heywood 케이스**는 절단하고 경고합니다
  (요인 수 과다·표본 부족 신호).
- **ML의 국소최소**: 프로파일 우도 F(Ψ)는 다봉(multi-modal)이라 시작값에 따라 다른 해로 수렴할 수
  있습니다. 이는 R `factanal`도 같으며(R은 `nstart`로 완화), factorscan은 factanal 기본과 동일한
  **단일 시작값**을 씁니다 — 다중 시작 오라클과 비교한 독립 검증에서 무작위 자료의 약 18%가 최적해가
  아닌 정류점에 멈췄습니다(같은 조건의 단일 시작 L-BFGS-B는 약 13%). 즉 **대부분은 목적함수의
  다봉성 때문이지만 최적화기 차이도 일부 있습니다**. 검증 설계는 HARDENING.md 참고. 요인 수를 바꿔
  가며 해가 안정적인지 확인하세요.
- **ML 적합도지수의 한계**: χ²는 표본이 크면 사소한 오차에도 쉽게 유의해지므로 RMSEA·CFI와 함께 보세요.
  반대로 **표본이 작으면 χ²는 검정력이 없어** 비유의(기각 안 됨)가 '적합의 증거'가 되지 못합니다 —
  보고서는 n<200에서 그 사실을 명시합니다. RMSEA 판정도 점추정이 아니라 **90% CI**로 읽습니다
  (**90% CI 상한이 .10을 넘고 하한이 .08 이하이면** '결론 보류'로 표시 — 구간이 넓은 원인은 표본만이
  아니라 자유도 부족일 수도 있어 메시지가 둘 다 언급합니다). TLI>1은 우수함이 아니라 과다모수화 신호입니다.
  AIC/BIC는 χ² 기준 **상대값**(χ²−2df, χ²−df·ln n)이라 절대 크기는 의미가 없고 **같은 자료의 k 비교**에만
  씁니다. `--fit-scan` 은 **식별 가능한 k(df>0) 범위만** 훑습니다(df≤0인 k는 애초에 검정이 불가). 그 범위
  안에서 수렴 실패·수치 오류·Heywood가 난 k는 조용히 건너뛰지 않고 '계산 불가'/'⚠수렴실패'/
  '⚠Heywood'로 표에 남깁니다. 문항이 너무 적어 df>0인 k가 하나도 없으면 그 사실을 경고합니다.
  다변량 정규성을 가정하므로 폴리코릭 입력과 함께 쓰면 근사이며, 보고서가 그 사실을 알립니다.
- 회전은 **직교(Varimax)** 와 **사교(Promax)** 를 제공합니다. 기본은 Varimax이며, 요인 상관 추정치가
  크면(|r|≥.32) 보고서가 Promax 검토를 안내합니다. `--rotation promax` 로 사교 패턴적재와 요인 상관행렬 Φ를 얻습니다.
- 결측 처리는 **listwise 제거(기본)** 와 **쌍별 삭제(`--missing pairwise`)** 두 가지이며, **대체(imputation)·다중대체(MI)·FIML은 지원하지 않습니다**. 어느 쪽이든 **무엇을 잃었는지 숨기지 않습니다**:
  문항별 결측률, 삭제된 표본 규모와 유발 문항, 그리고 완전응답자 vs 삭제된 응답자의 응답 분포 차이를
  **Cohen's d** 로 비교해 결측이 무작위(MCAR)가 아닐 수 있다는 신호를 알립니다. **판정은 d의 크기가
  아니라 d의 신뢰구간이 0을 배제하는지**로 하며, 문항 수만큼 **Bonferroni 보정**합니다 — 고정 임계값
  (|d|≥0.2)을 쓰면 완전 무작위 결측 자료에서도 24문항 중 평균 4~13개가 걸려 경고가 사실상 항상
  켜집니다(모의 실측). 보정 후 실행당 오경보율은 3~6%로 명목 5%에 맞습니다. 이는 문항별
  간이 진단으로 **Little의 MCAR 검정을 대체하지 않습니다**. 두 군(완전응답군·삭제군) 중 어느 쪽이든
  그 문항의 유효응답이 **10명 미만이면 그 문항은 건너뜁니다** — 삭제된 응답자가 10명 미만이면 점검
  자체가 표시되지 않습니다(번들 예시가 그런 경우입니다: 삭제 3명). **표시되지 않는 것은 '편향 없음'이
  아니라 '표본이 작아 검정하지 않았음'입니다.** 표본이 작을 때(문항당 5명 미만·n<문항수) 경고를 출력합니다.
- **요인점수**: `--score-method sum|mean` 은 |적재|최대 요인에 배정된 문항만 더하는 단순 합/평균이고,
  `regression` 은 **Thurstone 회귀 요인점수**(W = R⁻¹S, 전 문항 적재를 가중치로 반영, 표준화 스케일)입니다.
  회귀점수는 요인해와 표본에 의존해 다른 표본으로 그대로 옮기기 어렵고 척도 단위가 사라지므로, 척도 개발
  단계에서는 합산점수를 함께 보는 것이 관례입니다. 사교(promax) 회전에서만 Φ를 반영합니다.
- 상관은 기본이 **피어슨**(리커트를 연속형으로 취급 — 실무 관행)이며, 순서형을 제대로 다루려면
  `--correlation polychoric`(2단계 ML, Genz 이변량 정규적분·scipy 불필요)을 씁니다. 폴리코릭은 소수 범주
  (대개 ≤7)에 적합하고 하향편의를 보정하지만, 쌍별 추정이라 상관행렬이 양의 정부호가 아닐 수 있습니다
  (그때는 KMO/Bartlett가 생략될 수 있으며 보고서가 알립니다). 범주가 많거나 값이 정수가 아니면 경고합니다.
- **문항-총점 상관**은 (자신 제외) 원점수 합을 총점으로 씁니다. 문항들의 척도범위가 크게 다르면
  (예: 0–100 슬라이더와 1–5 리커트 혼재) 넓은 범위 문항이 총점을 지배해 값이 왜곡될 수 있으니
  같은 척도의 문항끼리 분석하세요. (요인분석 자체는 상관행렬 기반이라 이 영향을 받지 않습니다.)
- **RMSR·ω 는 추출 방식에 따라 달라집니다**(두 지표의 방향은 반대). 기본(PCA)은 공통성을 다소 크게
  추정하므로 **RMSR은 공통요인보다 크게(보수적)**, **ω는 공통요인 ω·Cronbach α보다 높게(낙관적)** 나오는
  경향이 있습니다. 덜 낙관적인 값이 필요하면 `--extraction paf`(공통요인)로 다시 돌려 보세요 — 예시
  데이터에서 ω가 0.911→0.874, RMSR이 0.068→0.036으로 바뀝니다. 어느 방식이든 **Cronbach α(응답분산기반)**
  를 함께 제시하니 신뢰도는 ω·α를 같이 보고하세요. 두 적합 지표는 절대 기준보다 상대 비교에 적합합니다.
- **요인별 ω·요인총점은 |적재|최대(argmax) 배정**에 기반하므로 교차적재·저적재 문항, 그리고 비회전
  (`--rotation none`) 결과에서는 배정이 불안정해 값이 왜곡될 수 있습니다(참고용). 요인 내 문항이 2개
  미만이면 ω는 정의되지 않습니다.
- **부트스트랩(`--bootstrap N`)의 성격과 한계**: 응답자를 복원추출로 재표집해 상관행렬부터 회전까지
  전 과정을 다시 돌리고, 각 재표본의 해를 **직교 Procrustes**로 본해에 정렬한 뒤 백분위 구간을 냅니다
  (정렬하지 않으면 요인 순서·부호가 재표본마다 임의라 안정적인 적재도 '0을 포함하는 넓은 구간'으로
  보입니다). 다만 Procrustes는 ‖ΛT − Λ_ref‖를 **최소화**하는 회전을 고르므로 재표본 해를 본해 쪽으로
  끌어당깁니다 — 구간은 그만큼 **좁게(낙관적으로)** 나옵니다. 유의할 점:
  ⑴ **백분위법**이며 편향보정(BCa)은 하지 않습니다(모의 검증에서 실제 포함률 ≈93%, 명목 95%). ⑵ 부트스트랩은 **원표본이
  모집단을 대표한다는 가정** 위에서 정밀도만 재므로, 표집 자체가 편향됐다면 좁은 구간이 나와도 그것은
  '정확하다'는 뜻이 아닙니다. ⑶ α·ω 구간의 문항→요인 배정은 **본해로 고정**합니다(재표본마다 argmax를
  다시 하면 서로 다른 문항조합의 신뢰도가 섞여 구간의 의미가 사라집니다). ⑷ 분산 0 문항·특이행렬·수치 오류, 그리고 **PAF/ML이
  수렴하지 않은** 재표본은 건너뛰고 성공 개수(`n_ok`)를 보고합니다(비수렴은 예외를 던지지 않으므로
  명시적으로 걸러냅니다). **Heywood 케이스는 실패가 아니라 경계해라서 제외하지 않고 포함**하되,
  개수를 `n_heywood`로 함께 보고합니다 — 비율이 높으면 요인 수 과다·표본 부족 신호입니다.
  `n_ok < N` 이면 구간이 낙관적일 수 있다는 경고가 나갑니다. ⑸ `--correlation polychoric` 과 함께 쓰면 재표본마다 폴리코릭 행렬을
  다시 추정하므로 **매우 느립니다** — 문항 수에 따라 피어슨의 수십~수백 배입니다(실측: 재표본당
  6문항·200명에서 약 0.2초, 20문항·300명에서 약 2.6초 → **500회면 각각 2분·22분**, 기기에 따라
  다릅니다). 실행 전에 알림을 띄웁니다.
  ⑹ 권장 N은 500 이상이며, 100 미만이면 경고합니다. **유효 재표본이 50개 미만이면 구간을 아예 내지
  않습니다** — 3개짜리 백분위 구간은 오히려 좁고 확신에 차 보여(점추정을 벗어나기도 합니다) 그대로
  논문에 실릴 위험이 큽니다. `--bootstrap 1` 은 인자 검증에서 거절합니다.
- **α 신뢰구간은 Feldt(1965)** 의 모수적 구간입니다: (1−α)/(1−α̂) ~ F(n−1, (n−1)(k−1)) 라는 결과에
  기대므로 **본질적 타우동등(essentially tau-equivalent)과 정규성**을 가정합니다. 이 가정이 의심스러우면
  `--bootstrap` 의 비모수 α 구간과 나란히 보세요(둘이 크게 다르면 가정이 깨진 신호입니다). α̂ ≥ 1 이거나
  요인 내 문항이 2개 미만이면 구간은 정의되지 않습니다('—').
- **집단별 재현성(`--group-col`)은 CFA 측정동일성 검정이 아닙니다.** 각 집단에서 **같은 요인 수·같은
  추출/회전**으로 EFA를 다시 적합해 전체 해에 Procrustes 정렬한 뒤 Tucker φ를 보는 **탐색적 선별**입니다
  (Lorenzo-Seva & ten Berge 2006: φ≥.95 동일 · .85~.94 유사 · <.85 다름). 형태·측정단위·절편 동일성을
  단계적으로 검정하려면 CFA/다집단 SEM이 필요합니다. 실무적 주의: ⑴ **집단마다 표본이 충분해야**
  의미가 있습니다. 세 단계로 거릅니다: `n < max(20, 문항수+1, 요인수+1)` 인 집단은 **완전히 제외**
  하고 사유를 표에 남기며, 문항당 3명 미만·KMO<.50·Heywood 인 집단은 **'판정보류'로 표시해 경고와
  최소 φ 산출에서 뺍니다**(값은 참고로 보여 줍니다). 그 문턱을 넘겨도 문항당 5명 미만이면 '불안정'
  메모를 붙입니다. 나아가 **고정 임계값에 의존하지 않습니다** — 같은 모집단을 같은 크기로 무작위
  분할했을 때 기대되는 최소 φ를 자기 자료에서 직접 구해(기본 200회) 그 하위 5백분위를 판정 기준으로
  씁니다. φ의 표집분포는 표본 크기뿐 아니라 **공통성 크기와 요인당 문항 수**에 좌우되어 어떤 고정
  기준도 오경보율을 통제할 수 없기 때문입니다(모의 실측: 고정 기준에서 동일 모집단 오경보율이
  최대 89%였고, 널 기준선 도입 후 0~10%로 내려갔습니다. 진짜 구조 차이 검출력은 대부분 100% 유지).
  폴리코릭 상관에서는 비용 때문에 널 기준선을 만들지 않고 고정 기준(.85)으로 되돌아갑니다. ⑵ φ는 **적재 패턴의 코사인 유사도**라 두 해가 같은 방향이면 크기 차이에 둔감합니다.
  ⑶ 그래서 **집단 쌍 직접 비교**를 함께 냅니다 — 전체 해는 집단들의 평균이라, 두 집단이 각각 전체와는
  닮았지만 서로는 다른 경우를 전체 대비 φ만으로는 놓칩니다. ⑷ 집단 열은 문항 자동선택에서 **제외**되며
  (숫자 코드 0/1 이 '문항'으로 섞이는 사고 방지), 값이 빈 응답자는 집단 비교에서만 빠집니다(전체
  요인분석에는 포함). ⑸ 집단이 12개를 넘으면 연속형 변수를 잘못 지정한 것으로 보고 **집단별 비교만 생략**합니다
  (전체 요인분석은 그대로 진행하고 종료코드도 0입니다). ⑹ `NA`·`N/A`·`nan`·`none`·`.`·`-`·`missing`
  같은 결측 토큰은 '집단 이름'이 아니라 결측으로 처리합니다(문항 열과 같은 규칙).
- **비례배분 채점(`--score-missing prorate`)의 범위와 한계**: 요인분석 **자체는 언제나 완전응답자
  (listwise)** 로 하고, **채점만** 넓힙니다 — 요인구조 추정은 결측 대체에 민감하지만, 하위척도
  점수는 거의 모든 PRO 채점 매뉴얼(SF-36·EORTC QLQ-C30 등)이 비례배분 규칙을 두기 때문입니다.
  규칙: 하위척도 문항 중 결측 비율이 `--max-missing-prop`(기본 0.2) 이하이면
  `점수 = 응답한 문항의 평균 × 그 하위척도의 문항 수`, 초과하면 **빈칸으로 남깁니다**(억지로
  만들지 않습니다). 대체된 문항 응답 수를 `대체된_문항응답수` 열로 함께 내보내므로 논문에
  "N명에서 평균 M문항을 비례배분했다"고 정확히 보고할 수 있습니다. 회귀 요인점수(`regression`)는
  모든 문항의 적재를 가중치로 쓰므로 비례배분과 함께 쓸 수 없고, 명확히 거절합니다.
  ⚠ 비례배분은 **결측이 그 하위척도 안에서 무작위**라는 가정에 기댑니다 — 위 [0] 결측 진단에서
  MCAR 위배 신호가 떴다면 그 가정이 의심스러우니 민감도 분석을 함께 하세요.
- **열 이름 비교는 유니코드 NFC로 정규화**합니다. macOS가 만든 CSV는 한글을 NFD(자모 분리)로
  저장하는데 손으로 친 설정 파일은 NFC라, 화면에서 똑같아 보이는 이름이 안 맞는 일이 있습니다.
  제로폭 공백·BOM·헤더 셀의 줄바꿈(엑셀 Alt+Enter)도 함께 정리합니다.
- 인코딩은 기본 UTF-8(BOM 허용). 한국어 엑셀이 저장한 **CP949/EUC-KR** CSV는 `--encoding cp949` 로 지정하세요.
- **엑셀 입력**(`.xlsx`/`.xlsm`)은 표준 라이브러리(zipfile+ElementTree)로 직접 읽습니다(openpyxl/pandas 불필요).
  첫 행이 헤더인 단순 표를 가정하며, 수식 셀은 **엑셀이 저장해 둔 계산값**을 씁니다(값이 없으면 결측).
  병합 셀·여러 헤더 행·구형식 `.xls` 는 지원하지 않습니다(`.xls` 는 명확한 오류로 안내). 시트는
  `--sheet` 로 고르고, 기본은 첫 시트입니다. `--encoding` 은 엑셀에 적용되지 않습니다(항상 UTF-8 XML).
