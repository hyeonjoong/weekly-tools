# factorscan — 설문 척도 요인분석·타당도 진단기

설문 응답 파일(**CSV · TSV · 엑셀 .xlsx**)을 넣으면 **탐색적 요인분석(EFA)** 과 척도 타당도 진단을
한 번에 출력합니다: 요인분석 적합성(KMO·Bartlett), 몇 개의 요인으로 이루어졌는지(고유값·Kaiser·평행분석·MAP),
요인 적재량(Varimax/Promax 회전)·공통성, 최대우도(ML) 적합도지수(χ²·RMSEA·CFI·TLI),
결측 구조 진단, 그리고 수정된 문항-총점 상관까지.

## 목적 / Why this exists

**한국어** — 설문 척도로 논문을 쓸 때, 리뷰어는 거의 항상 *"이 척도가 요인분석에 적합한가(KMO·Bartlett), 몇 개
차원인가, 각 문항이 어느 요인에 얼마나 실리는가(적재량), 겉도는 문항은 없는가"* 를 묻습니다. SPSS로 매번
클릭해 뽑던 이 표들을 CSV 하나로 재현 가능하게(시드 고정) 뽑아 줍니다. 신뢰도(Cronbach α)를 다루는
`surveyscan`과 짝을 이루어, 이 도구는 **차원성·구성타당도** 쪽을 담당합니다. 임상·제약 연구자가
자체 개발 설문(예: BELL-001 수면 자가진단, 와우핏 청능재활 설문)을 검증하거나 게재 전 표를 준비할 때 씁니다.

**English** — When publishing with a survey scale, reviewers almost always ask whether the scale is
*factorable* (KMO, Bartlett), *how many dimensions* it has, *how each item loads* on the factors, and
*which items misbehave*. factorscan reproduces those exact tables — the ones you'd otherwise click through
in SPSS — from a single CSV, reproducibly (fixed seed). It is the *dimensionality / construct-validity*
companion to `surveyscan` (which covers *reliability*, Cronbach's α). Built for a clinical/pharma researcher
validating an in-house questionnaire or preparing a scale-validation table before submission.

**이 도구가 하는 것 / What it computes**
- **요인분석 적합성**: Bartlett 구형성 검정(χ², df, p), KMO 전체 + 문항별 MSA(표에 함께 표시)
- **요인(차원) 수**: 상관행렬 고유값·설명분산, Kaiser 기준(고유값>1), Horn 평행분석(정규난수·95백분위),
  **Velicer MAP(최소평균편상관)** — 세 기준을 나란히 제시(서로 독립적 근거)
- **상관·추출·회전**: 피어슨 또는 **폴리코릭(순서형 리커트 잠재상관)** 상관행렬(`--correlation`) →
  **주성분(PCA)** · **주축분해(PAF, 공통요인)** · **최대우도(ML)** 추출(`--extraction`) + Varimax 직교회전 /
  Promax 사교회전(요인 간 상관행렬 Φ 함께) / 비회전, 공통성
- **모형 적합도(ML 추출)**: χ² 적합도 검정, **RMSEA + 90% CI · PCLOSE**, **CFI · TLI**, AIC/BIC —
  게재 표에 그대로 옮길 수 있는 공식 지표. `--fit-scan` 으로 **요인 수 k=1..최대의 적합도를 훑어**
  χ²가 비유의해지는 최소 k / BIC 최소 k를 요인 수 근거로 제시
- **결측 구조 진단**: 문항별 결측률, listwise 삭제로 잃은 표본 규모와 **유발 문항**,
  그리고 완전응답자 vs 삭제된 응답자의 응답 분포 차이(Cohen's d)로 **MCAR 위배 신호**를 점검
- **문항 기술통계(척도 논문 Table 1)**: 평균·SD·왜도·첨도·**바닥/천장 효과** — 응답이 척도
  끝에 몰려 변별력이 없는 문항을 짚고, |왜도|>2·|첨도|>7이면 폴리코릭 전환을 권고
- **역문항 미처리 탐지**: 주적재가 음수인 문항을 찾아 **실행할 명령(`--reverse ...`)** 을 제시하고,
  방향이 뒤섞인 채로는 합산점수를 만들지 않음(조용히 오염된 점수를 내보내지 않음)
- **제거 시 α(alpha-if-deleted)**: "이 문항을 빼면 신뢰도가 오르나?"에 직접 답하는 플래그
- **요인별 신뢰도·적합도**: McDonald ω(적재기반 합성신뢰도) + **Cronbach α(응답분산기반)** 를 함께,
  RMSR·비중복잔차(재현 상관행렬 적합도), 상관행렬 행렬식(다중공선성)
- **문항 품질**: 수정된 문항-총점 상관(소속 요인/하위척도 기준), 저(低)공통성·저MSA·교차적재·저적재 자동 플래그
- **입력 형식**: CSV · TSV · **엑셀 .xlsx**(확장자로 자동 판별, `--sheet` 로 시트 선택) — 엑셀을
  CSV로 다시 저장할 필요 없음. 날짜 서식 셀은 날짜로 인식해 문항으로 오인하지 않고, 분석에서
  빠진 열은 사유와 함께 보고. 구분자 지정(`--delimiter`), 인코딩 지정(`--encoding`, CP949 등)
- **역문항 재점수화**, 결측(listwise) 처리, JSON 출력, **논문 부록용 적재표 CSV 내보내기**(`--csv-out`),
  응답자별 **하위척도 점수 CSV**(`--scores-out`, 합산·평균·**Thurstone 회귀 요인점수**)

> 추출은 기본이 **주성분(PCA)** 으로 SPSS 요인분석의 기본 추출과 동일합니다. 공통요인 모형이 필요하면
> `--extraction paf`(주축분해, SMC 초기·반복)를, **적합도지수(χ²·RMSEA·CFI·TLI)가 필요하면
> `--extraction ml`**(최대우도)을 쓰세요 — 둘 다 ω·RMSR이 덜 낙관적으로 나옵니다(아래 한계 참고).

## Install

```bash
cd factorscan-설문요인분석
python3 -m pip install -e .        # numpy만 설치됩니다
# 또는 설치 없이 바로:  python3 -m factorscan.cli ...
```

의존성은 `numpy` 하나입니다(카이제곱 p값 등 통계는 자체 구현, scipy 불필요).

## Usage

```bash
# 1) 설정 파일로(역문항·척도범위·문항목록 지정) — 가장 권장
factorscan examples/sleep_scale.csv --config examples/sleep_config.json

# 2) 열을 직접 지정
factorscan responses.csv --items Q1,Q2,Q3,Q4,Q5,Q6 --id-col ID

# 3) 요인 수를 직접 지정 + 회전 끄기 + JSON
factorscan responses.csv --id-col ID --n-factors 3 --rotation none --json
```

```bash
# 4) 공통요인 추출(PAF) + 적재표 CSV + 응답자별 하위척도 점수 CSV 저장
factorscan responses.csv --id-col ID --extraction paf \
    --csv-out loadings.csv --scores-out scores.csv

# 5) 엑셀 파일을 그대로 + 최대우도(ML) 적합도지수 + 요인 수 스캔
factorscan 설문결과.xlsx --sheet 응답 --id-col 환자ID --extraction ml --fit-scan

# 6) Thurstone 회귀 요인점수로 내보내기(전 문항 적재 가중·표준화)
factorscan responses.csv --id-col ID --scores-out scores.csv --score-method regression

# 7) 스크리 도표용 표(고유값 + 평행분석 기준선)를 엑셀로
factorscan responses.csv --id-col ID --eigen-out scree.csv
```

주요 옵션: `--n-factors K`(미지정 시 평행분석 기준 자동, 평행분석 끄면 Kaiser), `--correlation pearson|polychoric`(상관 방식),
`--extraction pca|paf|ml`(추출 방식), `--fit-scan`(ML 요인 수별 적합도 표), `--rotation varimax|promax|none`,
`--reverse Q1,Q2 --scale-min 1 --scale-max 5`(역문항), `--parallel-iter N`(평행분석 반복, 0이면 생략),
`--seed`(재현), `--min-loading 0.40`(주적재/교차적재 임계값, 0~1), `--na 값`(결측 문자열 추가),
`--sheet 이름`(엑셀 시트 선택), `--delimiter ';'`(구분자 직접 지정), `--encoding cp949`(UTF-8이 아닌 CSV),
`--csv-out 경로`(문항×요인 적재표+요약행을 CSV로 — 논문 부록·엑셀용),
`--eigen-out 경로`(고유값·평행분석 기준선 CSV — 엑셀에서 스크리 도표),
`--scores-out 경로 --score-method sum|mean|regression`(응답자별 하위척도 점수를 CSV로 — 후속 타당도 분석용).

> **CSV 내보내기**: `--csv-out` 은 문항별 적재·공통성·MSA·문항-총점 + **요약행**(적재제곱합·설명분산%·누적%·
> ω·α, 그리고 요인상관 Φ)을 담아 표 하나로 완결됩니다(집계값만, 개인정보 없음). Φ 행은 회전 방식과
> 무관하게 나오지만 **언제나 promax 기준 추정치**이므로 `_factor_correlation(promax_estimate)` 로
> 이름 붙여 둡니다 — Varimax 해는 정의상 Φ=I 이니 직교 결과와 함께 보고하지 마세요. `--scores-out` 은
> 요인분석에 실제 쓰인(결측제거) 응답자마다 하위척도 합/평균 점수를 ID와 함께 내보내, 요인구조 확인 후
> 곧바로 집단비교·수렴타당도 분석에 넘길 수 있습니다(역문항 재점수화 반영). `--id-col` 을 주지 않으면
> ID 대신 **원본 파일 행번호(`row`)** 열이 나갑니다(결측 삭제로 순번이 어긋나지 않게 원본 기준).
> 세 파일 모두 utf-8-sig(BOM)라 한국어 엑셀에서 바로 열립니다.
>
> ⚠ **개인정보 주의**: `--scores-out` 파일은 **응답자 식별정보(ID)와 개인별 점수가 담긴 식별가능 자료**입니다.
> 집계 표(`--csv-out`)와 달리 그대로 외부 공유·게시하지 말고 기관 규정에 따라 취급하세요.

### 적합도지수 · 요인 수 스캔 (`--extraction ml --fit-scan`)

```
$ factorscan examples/sleep_scale.csv --config examples/sleep_config.json \
      --extraction ml --fit-scan

[ 3-1. 모형 적합도 (최대우도 ML) ]
  χ²(13) = 18.00, p = 0.1575  → 모형 기각 안 됨 — 단 표본이 작아 검정력이 낮습니다(적합의 증거로 보기 어려움)
  χ²/df = 1.38  (관례: <3 이면 양호)
  RMSEA = 0.071  90% CI [0.000, 0.143]  → 결론 보류 — 90% CI가 넓어 적합/부적합을 가릴 수 없습니다(표본 부족)
  PCLOSE(근접적합 H0: RMSEA≤.05) p = 0.2991
  CFI = 0.984   TLI = 0.965  (관례: ≥.95 우수, ≥.90 수용)
  AIC = -8.00   BIC = -38.47  (χ² 기준 상대값 — 요인 수 k 비교에만 사용, 작을수록 좋음)

  ── 요인 수별 적합도 스캔 (k=1..최대) ──
    k     χ²      df       p     RMSEA     CFI     TLI       AIC       BIC
    1    155.8    20 4.77e-23    0.299   0.558   0.382     115.8      69.0
    2     18.0    13    0.157    0.071   0.984   0.965      -8.0     -38.5 ←BIC 최소
    3      6.3     7     0.51    0.000   1.000   1.010      -7.7     -24.2
    4      1.8     2    0.397    0.000   1.000   1.007      -2.2      -6.8 ⚠Heywood
    해석: χ² p≥.05 가 되는 '가장 작은 k', 또는 BIC/RMSEA가 최소인 k를 요인 수 근거로 씁니다.
```

k=1은 강하게 기각되고 k=2에서 χ²가 비유의해지며 BIC도 최소 — 평행분석·Kaiser·MAP과 **독립적인**
네 번째 근거가 같은 2요인을 가리킵니다. k=4는 Heywood 케이스로 표시되어 과다추출을 걸러 냅니다.

주의 깊게 보세요: 이 예시는 n=77이라 **χ² 비유의가 '적합'의 증거가 아니고**(검정력 부족),
**RMSEA 90% CI가 [.000, .143]로 넓어** 우수와 미흡을 가릴 수 없습니다. 보고서는 점추정만 보고
'우수'라 하지 않고 이 사실을 그대로 적습니다 — 작은 표본에서 확신을 주는 것이 이 도구의 일이 아닙니다.

## 입력 형식 · 설정 파일

- CSV: 행=응답자, 열=문항. ID/텍스트 열은 자동 제외되거나 `--id-col`로 지정.
- 결측: 빈칸, `NA`, `N/A`, `null`, `.`, `-` 등을 자동 인식(추가는 `--na`).
- 설정 JSON(선택):
  ```json
  {
    "id_cols": ["ID"],
    "items": ["Q1", "Q2", "Q3", "Q4"],
    "reverse": ["Q1"],
    "scale_range": [1, 5]
  }
  ```

## 해석 가이드 (관례적 기준)

- **KMO** ≥ 0.6 적합, ≥ 0.8 우수 / **Bartlett** p < .05 이면 요인분석 적합.
- 요인 수: 세 기준(**Kaiser** 고유값>1 · **Horn 평행분석(★)** · **Velicer MAP**)을 나란히 보여 줍니다.
  Kaiser는 과대추정 경향이 있어 **기본값으로 평행분석 결과를 적용**하며(평행분석을 끄면 `--parallel-iter 0`
  Kaiser로 대체), MAP는 편상관 기반의 독립적 제3 근거입니다. 세 기준이 어긋나면 보고서가 알려 주고,
  `--n-factors K` 로 직접 지정할 수 있습니다.
- **추출**: 기본은 주성분(PCA, SPSS 기본). 공통요인 모형이 필요하면 `--extraction paf`(주축분해).
  PAF는 공통분산만 모형화해 ω·RMSR이 덜 낙관적이며, 리뷰어가 공통요인 결과를 요구할 때 씁니다.
- **적합도지수**(`--extraction ml`): **RMSEA ≤ .05 우수 / ≤ .08 수용**, **CFI·TLI ≥ .95 우수 / ≥ .90 수용**,
  **χ² p ≥ .05** 면 모형이 기각되지 않음(단, 표본이 크면 쉽게 유의해지므로 RMSEA·CFI를 함께 봅니다).
  `--fit-scan` 은 요인 수 후보별로 이 표를 훑어 **χ²가 비유의해지는 최소 k**와 **BIC 최소 k**를 제시합니다.
- 적재량 **|.40| 이상(\*)** 을 주요 적재로 봅니다. 두 요인에 모두 .40↑이면 **교차적재**.
- **공통성 < 0.3**, **문항-총점 < 0.3**, **문항별 MSA < 0.5** 문항은 제거/수정 검토.
- **문항-총점('요인총점')** 은 각 문항이 주적재된 **요인(하위척도) 내 총점** 기준입니다(다차원 척도 권장).
  요인 배정은 |적재|최대(argmax)이므로 교차·저적재 문항은 배정이 불안정합니다 — 전체합 기준 값도
  JSON(`item_total_overall`)에 함께 제공되니 함께 확인하세요.
- **McDonald ω**(적재기반 합성신뢰도)와 **Cronbach α**(응답분산기반)를 요인별로 나란히 제시합니다
  (둘 다 대략 ≥.70 권장). ω는 추출 방식에 따라 낙관적일 수 있어(PCA) α와 함께 보고하는 것이 안전합니다.
  요인 내 문항이 2개 미만이면 둘 다 정의 불가('—'). **RMSR** 은 재현 상관행렬 잔차(작을수록 적합, 대략 <.08).

## 한계 / Notes

- 추출은 **주성분(PCA, 기본)** · **주축분해(PAF, `--extraction paf`)** · **최대우도(ML, `--extraction ml`)**
  를 제공합니다. PCA는 SPSS 기본과 동일하고, PAF는 SMC 초기·반복 방식, ML은 R의 `factanal`과 같은 계열의
  프로파일 우도 F(Ψ) 최소화(사영 Barzilai-Borwein, scipy 불필요)입니다. **적합도지수(χ²·RMSEA·CFI·TLI)는
  확률모형인 ML에서만 정의되므로 `--extraction ml` 에서만 출력**됩니다(PCA/PAF에서는 RMSR만).
  PAF/ML에서 공통성이 1에 닿는(고유분산이 하한 0.005에 붙는) **Heywood 케이스**는 절단하고 경고합니다
  (요인 수 과다·표본 부족 신호).
- **ML의 국소최소**: 프로파일 우도 F(Ψ)는 다봉(multi-modal)이라 시작값에 따라 다른 해로 수렴할 수
  있습니다. 이는 R `factanal`도 같으며(R은 `nstart`로 완화), factorscan은 factanal 기본과 동일한
  **단일 시작값**을 씁니다 — 독립 검증에서 무작위 자료의 약 18%가 최적해가 아닌 정류점에 멈췄습니다
  (단일 시작 L-BFGS-B는 약 13%로, 최적화기가 아니라 목적함수의 성질입니다). 요인 수를 바꿔 가며
  해가 안정적인지 확인하세요.
- **ML 적합도지수의 한계**: χ²는 표본이 크면 사소한 오차에도 쉽게 유의해지므로 RMSEA·CFI와 함께 보세요.
  반대로 **표본이 작으면 χ²는 검정력이 없어** 비유의(기각 안 됨)가 '적합의 증거'가 되지 못합니다 —
  보고서는 n<200에서 그 사실을 명시합니다. RMSEA 판정도 점추정이 아니라 **90% CI**로 읽습니다
  (CI가 .05~.10을 가로지르면 '결론 보류'로 표시). TLI>1은 우수함이 아니라 과다모수화 신호입니다.
  AIC/BIC는 χ² 기준 **상대값**(χ²−2df, χ²−df·ln n)이라 절대 크기는 의미가 없고 **같은 자료의 k 비교**에만
  씁니다. `--fit-scan` 은 **식별 가능한 k(df>0) 범위만** 훑습니다(df≤0인 k는 애초에 검정이 불가). 그 범위
  안에서 수렴 실패·수치 오류·Heywood가 난 k는 조용히 건너뛰지 않고 '계산 불가'/'⚠수렴실패'/
  '⚠Heywood'로 표에 남깁니다. 문항이 너무 적어 df>0인 k가 하나도 없으면 그 사실을 경고합니다.
  다변량 정규성을 가정하므로 폴리코릭 입력과 함께 쓰면 근사이며, 보고서가 그 사실을 알립니다.
- 회전은 **직교(Varimax)** 와 **사교(Promax)** 를 제공합니다. 기본은 Varimax이며, 요인 상관 추정치가
  크면(|r|≥.32) 보고서가 Promax 검토를 안내합니다. `--rotation promax` 로 사교 패턴적재와 요인 상관행렬 Φ를 얻습니다.
- 결측은 **listwise** 제거만 지원합니다(대체/pairwise 미지원). 대신 **무엇을 잃었는지 숨기지 않습니다**:
  문항별 결측률, 삭제된 표본 규모와 유발 문항, 그리고 완전응답자 vs 삭제된 응답자의 응답 분포 차이를
  **Cohen's d** 로 비교해 결측이 무작위(MCAR)가 아닐 수 있다는 신호를 알립니다(|d|≥0.2). 이는 문항별
  간이 진단으로 **Little의 MCAR 검정을 대체하지 않습니다**. 두 군(완전응답군·삭제군) 중 어느 쪽이든
  그 문항의 유효응답이 **5명 미만이면 그 문항은 건너뜁니다** — 삭제된 응답자가 5명 미만이면 점검
  자체가 표시되지 않습니다(번들 예시가 그런 경우입니다: 삭제 3명). 표본이 작을 때(문항당 5명 미만·n<문항수) 경고를 출력합니다.
- **요인점수**: `--score-method sum|mean` 은 |적재|최대 요인에 배정된 문항만 더하는 단순 합/평균이고,
  `regression` 은 **Thurstone 회귀 요인점수**(W = R⁻¹S, 전 문항 적재를 가중치로 반영, 표준화 스케일)입니다.
  회귀점수는 요인해와 표본에 의존해 다른 표본으로 그대로 옮기기 어렵고 척도 단위가 사라지므로, 척도 개발
  단계에서는 합산점수를 함께 보는 것이 관례입니다. 사교(promax) 회전에서만 Φ를 반영합니다.
- 상관은 기본이 **피어슨**(리커트를 연속형으로 취급 — 실무 관행)이며, 순서형을 제대로 다루려면
  `--correlation polychoric`(2단계 ML, Genz 이변량 정규적분·scipy 불필요)을 씁니다. 폴리코릭은 소수 범주
  (대개 ≤7)에 적합하고 하향편의를 보정하지만, 쌍별 추정이라 상관행렬이 양의 정부호가 아닐 수 있습니다
  (그때는 KMO/Bartlett가 생략될 수 있으며 보고서가 알립니다). 범주가 많거나 값이 정수가 아니면 경고합니다.
- **문항-총점 상관**은 (자신 제외) 원점수 합을 총점으로 씁니다. 문항들의 척도범위가 크게 다르면
  (예: 0–100 슬라이더와 1–5 리커트 혼재) 넓은 범위 문항이 총점을 지배해 값이 왜곡될 수 있으니
  같은 척도의 문항끼리 분석하세요. (요인분석 자체는 상관행렬 기반이라 이 영향을 받지 않습니다.)
- **RMSR·ω 는 추출 방식에 따라 달라집니다**(두 지표의 방향은 반대). 기본(PCA)은 공통성을 다소 크게
  추정하므로 **RMSR은 공통요인보다 크게(보수적)**, **ω는 공통요인 ω·Cronbach α보다 높게(낙관적)** 나오는
  경향이 있습니다. 덜 낙관적인 값이 필요하면 `--extraction paf`(공통요인)로 다시 돌려 보세요 — 예시
  데이터에서 ω가 0.911→0.874, RMSR이 0.068→0.036으로 바뀝니다. 어느 방식이든 **Cronbach α(응답분산기반)**
  를 함께 제시하니 신뢰도는 ω·α를 같이 보고하세요. 두 적합 지표는 절대 기준보다 상대 비교에 적합합니다.
- **요인별 ω·요인총점은 |적재|최대(argmax) 배정**에 기반하므로 교차적재·저적재 문항, 그리고 비회전
  (`--rotation none`) 결과에서는 배정이 불안정해 값이 왜곡될 수 있습니다(참고용). 요인 내 문항이 2개
  미만이면 ω는 정의되지 않습니다.
- 인코딩은 기본 UTF-8(BOM 허용). 한국어 엑셀이 저장한 **CP949/EUC-KR** CSV는 `--encoding cp949` 로 지정하세요.
- **엑셀 입력**(`.xlsx`/`.xlsm`)은 표준 라이브러리(zipfile+ElementTree)로 직접 읽습니다(openpyxl/pandas 불필요).
  첫 행이 헤더인 단순 표를 가정하며, 수식 셀은 **엑셀이 저장해 둔 계산값**을 씁니다(값이 없으면 결측).
  병합 셀·여러 헤더 행·구형식 `.xls` 는 지원하지 않습니다(`.xls` 는 명확한 오류로 안내). 시트는
  `--sheet` 로 고르고, 기본은 첫 시트입니다. `--encoding` 은 엑셀에 적용되지 않습니다(항상 UTF-8 XML).
