## 2. 임상 해석까지 붙이기

```bash
python3 -m longistat.cli 내파일.csv --id 대상 --time 방문 --value ISI --group 군 \
    --mcid 6 --direction lower \
    --reliability 0.9 --recovery-cutoff 7
```

- `--mcid 6` : 6점 이상 좋아지면 "반응자". (`--mcid-percent` 를 붙이면 6% 개선 기준)
- `--direction lower` : **점수가 낮아지는 게 호전**이라는 뜻 (ISI, PHQ-9 등).
  청력 점수처럼 높아지는 게 좋으면 `--direction higher`.
  ← 이걸 안 쓰면 오류가 납니다. 방향을 잘못 잡으면 반응률이 정반대로 나오기 때문입니다.
- `--reliability 0.9` : 도구의 검사-재검사 신뢰도. 개인별 "믿을 만한 변화(RCI)" 계산.
- `--recovery-cutoff 7` : ISI ≤ 7 이면 "회복"으로 셈 (`--direction higher` 면 ≥ 로 해석).
- `--responder-denominator randomized` : 탈락자를 **비반응자로** 세는 ITT식 반응률(NRI).
- `--primary-time 8주` : 계획서에 정한 **주요 시점**. 그 시점은 다중비교 보정 없이,
  나머지 시점들끼리만 보정합니다.
- `--labels-en "기저=Baseline,능동자극=Active"` : 영문 결과 문장에 쓸 이름.

## 2-1. 방문 간격이 불규칙하면 (0·4·12·24주 등) — 꼭 알려주세요

```bash
python3 -m longistat.cli 내파일.csv --id 대상 --time 방문 --value ISI --group 군 \
    --time-order 기저,4주,12주,24주 \
    --time-values 0,4,12,24 --time-unit 주
```

- `--time-values` : 방문의 **실제 간격**(숫자, 시점 순서대로). `[4b] 시점 추세`의
  선형·이차 대비와 개인별 기울기가 이 값 위에서 계산됩니다.
- `--time-unit 주` : 기울기 표의 단위 표시용. 주면 `ISI/주`, 안 주면
  `ISI / 시점 1단위` 로 표시됩니다.
- 지정하지 않으면 시점 이름에서 숫자를 읽어 보고(`wk0,wk4,wk12` 는 자동 인식),
  그것도 안 되면 **등간격으로 가정**하고 리포트 맨 아래에 경고를 답니다.
  `기저,4주,12주` 처럼 첫 이름에 숫자가 없으면 자동 인식이 안 됩니다.
- ⚠ **가장 조심할 것**: 이름에 든 숫자가 방문 *순번*이면(`1차,2차,3차`) 도구는 그게
  순번인지 주(週)인지 알 수 없어 **1,2,3 을 간격으로 쓰고 경고도 하지 않습니다.**
  실제 방문이 0·4·24주였다면 선형·이차 추세가 통째로 달라집니다.
  `[4b]` 제목의 `간격 …` 표시를 **항상** 확인하세요.
  (`방문1(0주)` 처럼 숫자가 둘이면 도구가 알아채고 등간격 + 경고로 넘어갑니다.)
- 추세 구획이 필요 없으면 `--no-trend`. **시점이 2개면 [4b]는 아예 나오지 않습니다**
  (그때 선형 추세는 [5]의 변화량과 같은 값입니다).

## 2-2. 탈락이 있는 자료의 안정성 점검 (기본값 켜짐)

**기저 이후 방문에** 결측이 있으면 `[5]` 아래에 **LOCF·BOCF 민감도 표**가 자동으로
붙습니다 (기저값만 결측이면 대체할 것이 없어 표가 나오지 않습니다).
"관측값 / LOCF / BOCF 세 분석의 결론이 같은가"만 보는 표입니다.

재계산하는 값은 위의 **군간 변화량 차이**(군이 없으면 기저 대비 변화량)입니다 —
바로 위에 있는 **ANCOVA 조정평균차는 다시 계산하지 않습니다.** ANCOVA 를 주분석으로
보고할 계획이라면 이 표는 "같은 자료의 다른 추정치"라는 점을 밝혀 주세요.

```bash
--sensitivity none        # 끄기
--sensitivity locf        # LOCF 만
--sensitivity locf,bocf   # 기본값(auto)과 같음
```

- **LOCF** = 결측 방문에 그 사람의 **직전 관측값**을 넣습니다("탈락 시점에 멈췄다").
- **BOCF** = 결측 방문에 그 사람의 **기저값**을 넣습니다("효과가 사라졌다" — 보수적).
- 기저값 자체가 결측인 사람은 **어떤 방법으로도 대체하지 않습니다.**
- 대체는 **기저 이후 방문에만** 적용됩니다 (`--baseline` 을 첫 시점이 아닌 곳으로
  지정해도 그 앞 방문은 두 방법 모두 비워 둡니다 — 시간을 거슬러 값을 만들지 않습니다).
- 세 결론이 갈리면 `⚠` 로 표시하고 리포트 맨 아래 주의에도 올립니다. 그때 볼 곳은
  단일 대체가 아니라 바로 아래에서 설명하는 **[4c] MMRM** 입니다.
- 관측값 쪽에 결과가 아예 없는 시점(그 방문을 아무도 안 온 경우)은 **"비교 불가"**
  로 표시합니다 — 일치한다고 주장하지 않습니다.
- 대체값이 절반을 넘는 시점은 따로 알려 줍니다 (측정 결과보다 가정의 결과에 가깝습니다).
- 이 표의 p는 세 분석을 나란히 비교하려고 **다중비교 보정 없이** 계산하며, 세 열
  모두 **모수 t-검정** 기준입니다 (권장 트랙이 순위검정이면 [5]와 숫자가 다릅니다).

## 2-3. 일부 방문만 마친 사람도 쓰는 답 — `[4c] MMRM` (기본값 켜짐)

`[4]` ANOVA 와 `[5]` 변화량은 **모든 방문을 마친 사람만** 씁니다. 8주에 5명이
빠지면 그 5명은 4주 자료까지 통째로 버려집니다. `[4c] MMRM`(혼합모형 반복측정)은
**중간까지라도 측정된 사람을 그대로 쓰는** 구획입니다 — 아무 옵션 없이 자동으로 나옵니다.
(군이 있는 모형에 들어가려면 기저값 1개와 기저 이후 관측 1개가 필요합니다. 기저값이
없는 사람, 기저값만 있고 이후 방문이 없는 사람은 [4c]에서도 빠지며, 그 인원은
표 아래 `※` 에 적힙니다.)

```
[4c] MMRM — 혼합모형 반복측정 (REML · 비구조화 공분산 · MAR 가정)
  응답변수: 기저 대비 변화량 (기저값 공변량 보정)   모형 대상 48명 / 관측 86개 (완전자료 38명)
```

읽는 법:

- **군이 있으면** 표의 `추정치` = 그 방문에서의 **기저값 보정 LS 평균차**
  (= "군간 변화량 차이"의 MMRM 판). 논문 초록에 넣을 숫자로 이쪽이 더 표준입니다.
- **군이 없으면** `추정치` = 기준시점 대비 평균 변화, 다만 관측된 자료를 전부 써서
  계산한 값입니다.
- `LS 평균` 표는 **군이 있으면** 군별·시점별 조정 평균 **변화**(기저값을 전체 평균에
  맞춘 값), **군이 없으면** 기저 시점을 포함한 시점별 평균 **관측값**입니다
  (군이 없을 때는 변화량이 아닙니다 — 와우핏 예제의 `전체 기저 50.51` 은 기저 점수).
- 표 아래 `※ 완전사례 분석([4]·[5])이 쓰는 N명보다 …` 줄이 **몇 명을 더 살렸는지**
  알려 줍니다.
- 완전사례 결론과 MMRM 결론의 **유의성 판정이 갈리면** 맨 아래 주의에 경고가 뜹니다.
  그 경고는 "어느 쪽이 사전 지정된 분석인지 확인하라"는 뜻입니다 — 유의하게 나온
  쪽을 골라 주분석으로 바꾸면 안 됩니다(ICH E9).
- 논문에 쓸 방법·결과 문장은 **[10] 논문용 문장** 에 MMRM 전용 한/영 문장으로
  이미 나옵니다. 그대로 붙여넣고 숫자만 확인하세요.

언제 안 나오나 / 무엇을 조심하나:

- 시점이 12개를 넘거나, 두 시점을 함께 측정한 사람이 2명 미만이거나, **대상 수가
  공분산 모수 수보다 적으면**(시점 T개 → T(T+1)/2 개, 예: 9시점이면 45명 필요)
  `[4c] MMRM 미수행: …` 으로 **이유를 적고** 건너뜁니다. 자료가 아주 크면
  (대상 수 × 시점 수² > 320,000) 실행시간 때문에도 건너뜁니다.
- 모형이 **수렴하지 않으면** 표 아래·리포트 맨 아래·논문용 문장 모두에 "인용하지
  마십시오" 라고 적습니다. 그 경우 숫자를 쓰지 마세요.
- 자유도는 `해당 시점 관측 수 − 그 시점의 평균 모수 수` 입니다. 완전자료에서는 정확한
  값이지만 결측이 있으면 **근사**이고 **Kenward–Roger 가 아닙니다**. 군당 30명 미만에
  탈락이 심하면 R `mmrm` / SAS `PROC MIXED ddfm=kr` 쪽 구간이 조금 더 넓습니다.
- 공분산 구조는 **비구조화 하나**뿐입니다 (AR(1) 등을 고를 수 없습니다).
- MAR 가정입니다. 그것도 **모형에 들어간 변수(시점·군·기저값)로 설명되는 결측**이라는
  뜻입니다 — 탈락이 나이·중증도처럼 모형 밖 변수로 결정된다면 MMRM 도 편향됩니다.
  "나빠져서 말없이 사라졌다"(MNAR)면 더더욱 답이 아니니 LOCF/BOCF 민감도 표와 함께
  보고하세요.
- 공변량은 **기저값 하나**뿐입니다 — 나이·성별·기관 보정이 필요한 계획서라면 이
  도구로는 그 모형을 돌릴 수 없습니다.
- 결과지표가 **연속형이고 대략 정규**여야 합니다. `[3]` 에서 "권장 분석: 비모수" 가
  떴다면 [4c] 를 단독으로 보고하지 마세요 (리포트도 그 경우 경고를 답니다).
- 강건(sandwich) 표준오차, tipping-point(delta) 민감도, 다중대체는 없습니다. 규제
  제출용 확증분석이면 R `mmrm` / SAS `PROC MIXED` 로 한 번 더 확인하세요.
- 필요 없으면 `--no-mmrm` 으로 끕니다.

## 3. 결과 읽는 법

| 구획 | 무엇을 보나 |
|------|------------|
| **[1] 결측·탈락** | 군별·시점별 관측 수(= CONSORT 흐름도 숫자). 완전자료 80% 이하이거나 군별 탈락률이 10%p 이상 벌어지면 경고가 뜹니다. |
| **[2] 기술통계** | 군 × 시점별 평균·SD·95% CI·중앙값[IQR] (관측된 값 기준). |
| **[3] 가정 점검** | 구형성이 "위배"면 아래 ANOVA의 시점 관련 p값에 자동으로 GG/HF 보정이 걸립니다. |
| **[4] 주 분석** | `그룹 × 시점`이 유의하면 = **군에 따라 변화 양상이 다르다** (보통 이게 핵심). |
| **[4b] 시점 추세** *(시점 3개 이상일 때만)* | 변화가 **한 방향으로 쭉**(선형)인지 **꺾이는지**(이차)를 성분별로 나눠 봅니다 — 각 행은 시점 점수 하나에 대한 검정이라 **구형성 보정이 필요 없어서**, Mauchly가 기각됐을 때 특히 쓸모 있습니다. 아래 **개인별 기울기**는 `점/주`(`--time-unit` 지정 시) 단위라 그대로 읽히고, 방문을 **2회 이상** 마친 사람은 탈락자도 들어갑니다. |
| **[4c] MMRM** | 부분 관측 대상을 버리지 않는 구획. 결측이 있는 연속형 결과에서는 이 모형을 **계획서에 주분석으로 사전 지정**하는 것이 표준입니다. 이미 완전사례를 사전 지정했다면 [4c]는 **사전 지정된 민감도 분석**으로 보고하세요 (위 2-3 참고). |
| **[5] 변화량** | 결측이 **없으면** "군간 변화량 차이"의 **95% CI**(또는 아래 ANCOVA 조정평균차)가 논문 초록에 들어갈 숫자입니다. 결측이 있으면 [5]는 완전사례이므로 **[4c] MMRM** 쪽을 쓰세요. 바로 아래 **ANCOVA**(기저값 보정) 표가 요즘 리뷰어가 더 자주 요구하는 값입니다. 결측이 있으면 **LOCF·BOCF 민감도 표**도 함께 나옵니다. |
| **[6] 시점 간 사후비교** | 어느 방문 사이에서 실제로 좋아졌는지. `보정 p` 를 보세요. |
| **[7] 시점별 군간 비교** | 각 방문에서 두 군의 차이. 기저 행은 **참고값**이며 검정하지 않습니다. |
| **[8] 반응자** | "MCID 이상 좋아진 사람 비율"과 군간 차이(RD/RR/OR/NNT). |
| **[9] RCI** | 개인 단위로 "측정오차보다 큰 변화"였는지 (신뢰적 호전/무변화/악화). |
| **[10] 논문용 문장** | 한/영 문장. 숫자만 확인하고 그대로 붙여넣으면 됩니다. |

별표는 **보정된 p** 기준입니다: `*` p<α, `**` p<.01, `***` p<.001.

## 4. 파일로 저장

```bash
python3 -m longistat.cli 내파일.csv --id 대상 --time 방문 --value ISI \
    --format md   -o 결과.md          # 논문/Word 에 붙여넣을 표
python3 -m longistat.cli 내파일.csv --id 대상 --time 방문 --value ISI \
    --format csv  -o 결과.csv         # 엑셀에서 열기
python3 -m longistat.cli 내파일.csv --id 대상 --time 방문 --value ISI \
    --format json -o 결과.json        # 다른 스크립트에서 재사용
```

> 같은 이름의 파일이 이미 있으면 **저장하지 않습니다**. 덮어쓰려면 `--overwrite` 를
> 붙이세요. 입력 CSV 와 같은 이름으로는 저장할 수 없습니다(원자료 보호).

## 5. 자주 나는 오류

| 메시지 | 해결 |
|--------|------|
| `같은 (대상, 시점) 조합이 여러 번 있습니다` | 중복 측정이 있다는 뜻. `--duplicates mean` 또는 `first` 를 붙이거나 원자료를 정리하세요. |
| `--time-order 의 시점 ... 이(가) 자료에 없습니다` | 오타이거나 공백이 섞였습니다. 오류 메시지에 자료의 실제 시점 목록이 함께 나옵니다. |
| `--mcid ... --direction lower|higher 로 ... 지정해야` | 호전 방향을 지정하세요. |
| `숫자로 해석할 수 없는 값` | 값 열에 문자가 섞여 있습니다. 결측이면 빈칸이나 `NA` 로 두세요. |
| `ANOVA 미수행: 모든 시점이 관측된 대상이 2명 미만…` | 오류가 아니라 ANOVA만 건너뛴 것입니다(나머지 리포트는 나옵니다). 시점을 줄이거나(`--time-order` 로 일부만 지정) 결측을 확인하세요. |
| `시점이 60개를 넘습니다 — --time 열이 방문일(날짜)…` | `--time` 이 방문 라벨이 아니라 날짜 열을 가리키고 있습니다. |
| `출력 파일이 입력 CSV 와 같습니다` | `-o` 에 원본 파일 이름을 넣었습니다. 다른 이름을 쓰세요. |
| `'…' 파일이 이미 있습니다` | `--overwrite` 를 붙이세요. |
| `--direction 은 --mcid 또는 --reliability 와 함께…` | 혼자 쓰면 아무 효과가 없어 막아 둔 것입니다. |
| `--time-values 는 시점 개수(…)와 같은 개수의 숫자여야` | 시점 수만큼 적으세요. `--time-order` 로 시점을 추린 경우 그 개수 기준입니다. |
| `--time-values 는 시점 순서대로 증가해야 합니다` | `--time-order` 순서와 같은 순서로 적으세요. |
| `--time-unit 은 --time-values 와 함께 쓰세요` | 단위만 붙이면 간격은 여전히 추정값이라 `점/주` 라벨이 거짓말이 됩니다. |
| `--no-trend 와 --time-values/--time-unit 은 함께 쓸 수 없습니다` | 추세를 끄면 간격이 쓰이지 않습니다. 둘 중 하나만 쓰세요. |
| `--sensitivity 의 'auto' 은(는) 단독으로만 쓸 수 있습니다` | `auto,locf` 처럼 섞어 쓸 수 없습니다. `auto` / `none` / `locf` / `bocf` / `locf,bocf` 중에서 고르세요. |
