# 사용법 (한글 빠른 시작)

## 0. 가장 빠른 방법

폴더 안의 **`실행.command` 를 더블클릭**하세요. 번들된 예제 두 개(불면 ISI 2군 3시점,
와우핏 단어인지도 1군 4시점)로 리포트가 바로 나옵니다.

## 1. 내 파일로 돌리기

### 자료가 "한 행 = 한 사람 × 한 시점" 이면 (긴 형식)

```
대상,군,방문,ISI
A01,능동자극,기저,23
A01,능동자극,4주,18
A01,능동자극,8주,18
A02,가짜자극,기저,17
...
```

```bash
cd ~/Downloads/02_프로젝트/깃헙/longistat-반복측정추이분석
python3 -m longistat.cli 내파일.csv --id 대상 --time 방문 --value ISI --group 군 \
    --time-order 기저,4주,8주
```

> `--time-order` 는 시점이 숫자가 아닐 때 **꼭** 지정하세요. 안 하면 파일에 나온
> 순서를 그대로 씁니다(경고를 띄웁니다).

### 자료가 "한 행 = 한 사람, 시점마다 열" 이면 (넓은 형식)

```
환자,기저,4주,8주,12주
W01,58.1,59.9,71.5,69.9
```

```bash
python3 -m longistat.cli 내파일.csv --wide --id 환자 --columns 기저,4주,8주,12주
```

## 2. 임상 해석까지 붙이기

```bash
python3 -m longistat.cli 내파일.csv --id 대상 --time 방문 --value ISI --group 군 \
    --mcid 6 --direction lower \
    --reliability 0.9 --recovery-cutoff 7
```

- `--mcid 6` : 6점 이상 좋아지면 "반응자". (`--mcid-percent` 를 붙이면 6% 개선 기준)
- `--direction lower` : **점수가 낮아지는 게 호전**이라는 뜻 (ISI, PHQ-9 등).
  청력 점수처럼 높아지는 게 좋으면 `--direction higher`.
  ← 이걸 안 쓰면 오류가 납니다. 방향을 잘못 잡으면 반응률이 정반대로 나오기 때문입니다.
- `--reliability 0.9` : 도구의 검사-재검사 신뢰도. 개인별 "믿을 만한 변화(RCI)" 계산.
- `--recovery-cutoff 7` : ISI ≤ 7 이면 "회복"으로 셈 (`--direction higher` 면 ≥ 로 해석).
- `--responder-denominator randomized` : 탈락자를 **비반응자로** 세는 ITT식 반응률(NRI).
- `--primary-time 8주` : 계획서에 정한 **주요 시점**. 그 시점은 다중비교 보정 없이,
  나머지 시점들끼리만 보정합니다.
- `--labels-en "기저=Baseline,능동자극=Active"` : 영문 결과 문장에 쓸 이름.

## 3. 결과 읽는 법

| 구획 | 무엇을 보나 |
|------|------------|
| **[1] 결측·탈락** | 군별·시점별 관측 수(= CONSORT 흐름도 숫자). 완전자료 80% 이하이거나 군별 탈락률이 10%p 이상 벌어지면 경고가 뜹니다. |
| **[2] 기술통계** | 군 × 시점별 평균·SD·95% CI·중앙값[IQR] (관측된 값 기준). |
| **[3] 가정 점검** | 구형성이 "위배"면 아래 ANOVA의 시점 관련 p값에 자동으로 GG/HF 보정이 걸립니다. |
| **[4] 주 분석** | `그룹 × 시점`이 유의하면 = **군에 따라 변화 양상이 다르다** (보통 이게 핵심). |
| **[5] 변화량** | "군간 변화량 차이"의 **95% CI**가 논문 초록에 들어갈 숫자입니다. 바로 아래 **ANCOVA**(기저값 보정) 표가 요즘 리뷰어가 더 자주 요구하는 값입니다. |
| **[6] 시점 간 사후비교** | 어느 방문 사이에서 실제로 좋아졌는지. `보정 p` 를 보세요. |
| **[7] 시점별 군간 비교** | 각 방문에서 두 군의 차이. 기저 행은 **참고값**이며 검정하지 않습니다. |
| **[8] 반응자** | "MCID 이상 좋아진 사람 비율"과 군간 차이(RD/RR/OR/NNT). |
| **[9] RCI** | 개인 단위로 "측정오차보다 큰 변화"였는지 (신뢰적 호전/무변화/악화). |
| **[10] 논문용 문장** | 한/영 문장. 숫자만 확인하고 그대로 붙여넣으면 됩니다. |

별표는 **보정된 p** 기준입니다: `*` p<α, `**` p<.01, `***` p<.001.

## 4. 파일로 저장

```bash
python3 -m longistat.cli 내파일.csv --id 대상 --time 방문 --value ISI \
    --format md   -o 결과.md          # 논문/Word 에 붙여넣을 표
python3 -m longistat.cli 내파일.csv --id 대상 --time 방문 --value ISI \
    --format csv  -o 결과.csv         # 엑셀에서 열기
python3 -m longistat.cli 내파일.csv --id 대상 --time 방문 --value ISI \
    --format json -o 결과.json        # 다른 스크립트에서 재사용
```

> 같은 이름의 파일이 이미 있으면 **저장하지 않습니다**. 덮어쓰려면 `--overwrite` 를
> 붙이세요. 입력 CSV 와 같은 이름으로는 저장할 수 없습니다(원자료 보호).

## 5. 자주 나는 오류

| 메시지 | 해결 |
|--------|------|
| `같은 (대상, 시점) 조합이 여러 번 있습니다` | 중복 측정이 있다는 뜻. `--duplicates mean` 또는 `first` 를 붙이거나 원자료를 정리하세요. |
| `--time-order 의 시점 ... 이(가) 자료에 없습니다` | 오타이거나 공백이 섞였습니다. 오류 메시지에 자료의 실제 시점 목록이 함께 나옵니다. |
| `--mcid ... --direction lower|higher 로 ... 지정해야` | 호전 방향을 지정하세요. |
| `숫자로 해석할 수 없는 값` | 값 열에 문자가 섞여 있습니다. 결측이면 빈칸이나 `NA` 로 두세요. |
| `ANOVA 미수행: 모든 시점이 관측된 대상이 2명 미만…` | 오류가 아니라 ANOVA만 건너뛴 것입니다(나머지 리포트는 나옵니다). 시점을 줄이거나(`--time-order` 로 일부만 지정) 결측을 확인하세요. |
| `시점이 60개를 넘습니다 — --time 열이 방문일(날짜)…` | `--time` 이 방문 라벨이 아니라 날짜 열을 가리키고 있습니다. |
| `출력 파일이 입력 CSV 와 같습니다` | `-o` 에 원본 파일 이름을 넣었습니다. 다른 이름을 쓰세요. |
| `'…' 파일이 이미 있습니다` | `--overwrite` 를 붙이세요. |
| `--direction 은 --mcid 또는 --reliability 와 함께…` | 혼자 쓰면 아무 효과가 없어 막아 둔 것입니다. |
