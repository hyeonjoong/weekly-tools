# HARDENING — longistat 적대적 검토 이력

이 도구는 사람이 검토하지 않고 배포되므로, 각 라운드마다 **독립된 서브에이전트 패널**을
병렬로 띄워 서로 다른 각도에서 공격하고, 나온 결함을 전부 고친 뒤 다음 라운드를 돌립니다.
"머릿속 검토"는 라운드로 치지 않습니다. 각 결함에는 대응하는 회귀 테스트가 있습니다
(`tests/test_hardening_r*.py`).

- 도구: longistat 1.0.0 (반복측정 추이 분석기)
- 검토일: 2026-07-31
- 패널 구성(라운드당 7명, 병렬): 통계 정확성 감사 · 엣지케이스 파괴자 ·
  연구자 유용성 비평(임상시험 통계학자 시점) · 문서 정직성 검토 ·
  테스트 품질 감사(뮤테이션 테스팅) · 보안/임상데이터 안전성 · 성능/수치안정성

### 새로 넣은 것

- **[4b] 시점 추세** — 직교 다항 대비(선형·이차·삼차)와 각 성분의 군 × 시점 상호작용

### 검토진이 "이상 없음"으로 확인한 부분 (기록해 둘 가치가 있음)

- REML 기준식 `-0.5(log|V| + r'V⁻¹r + log|X'V⁻¹X| + (n−p)log2π)` — 독립 numpy
  구현과 1e-13 일치. SAS `PROC MIXED`·`nlme` 와 같은 상수 규약.
- EM의 E-step에서 `X A X'` 항의 **위치**가 맞음(β 불확실성은 `B` 를 통해 결측부로
  전파되어야 하므로 `M W M'` 안에 들어가야 함). EM 고정점이 진짜 REML 최적점의
  정류점임을 수치로 확인(최적점과의 loglik 차 &lt; 3e-13, max|∇| &lt; 7e-6).
- 두 항등식이 균형/불균형(31:17)·3군·4군·기준시점이 중간/마지막인 경우까지 성립.
- 결측 자료에서의 df 보정 상태: 자체 Satterthwaite 대비 27 vs 28.1 (45% 탈락),
  n=10/군·40% 탈락에서 **실측 1종오류 .047–.056** (z 근사는 .072–.105).
- 뮤테이션 25개 중 19개 사망. 살아남은 6개는 아래 D 항목으로 전부 처리.
- PII: `_Subject` 는 대상 ID를 아예 담지 않음. 모든 note는 인원수·시점명·군명뿐.
- CSV 수식 인젝션·JSON HTML 이스케이프가 신규 `mmrm_*` 행/페이로드에도 적용됨.

### C. 성능 / 자원

- `MAX_CELLS`(대상 수 × 시점 수) 는 비용을 잘못 모형화 — EM 비용은 시점 수의
  **제곱**에 비례하고 sweep 수도 함께 늘어납니다. 실측: 2000×6 = 4.4초,
  5000×8 = 27.6초, **5000×12 = 141초**. `MAX_WORK = 320_000`(대상 수 × 시점 수²)로
  교체했고, 한도 경계 형상(2222×12)의 실측은 **22.8초** 입니다.

### D. 테스트 품질 (살아남은 뮤테이션)

| 살아남은 변형 | 왜 안 잡혔나 | 지금 잡는 테스트 |
|---|---|---|
| Holm 보정 삭제 (`p_adj = p_raw`) | `assert p_adj >= p_raw - 1e-12` 는 **보정을 아예 안 해도 참** | `adjust()` 결과와 정확히 비교 + 실제로 커지는지 확인 |
| `both < 2` → `both < 1` (식별성) | 기존 테스트가 `both == 0` 만 만듦 | 정확히 1명이 두 시점을 잇는 패널 |
| `n_obs <= n_cols` 가드 무력화 | 커버는 되지만 결과를 **단언하지 않음** | 8군 8명 3시점 → 거절 문구 단언 |
| `MAX_TIMES = 100` | 테스트가 상수에서 `MAX_TIMES + 1` 을 유도 | 13을 하드코딩 + `MAX_TIMES <= 12` 단언 + **수용측**(12시점은 적합) 테스트 추가 |
| `MAX_CELLS = 10**18` | 테스트가 상수를 monkeypatch | 상수 자체를 단언 (5000×12는 거절, 2000×6은 통과) |
| Σ 대칭화 삭제 | `acc` 가 이미 대칭으로 만들어짐 — **동치 변형**, 무해 | (해당 없음) |
