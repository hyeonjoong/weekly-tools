# HARDENING & IMPROVEMENT LOG — metapool

이 문서는 `metapool`(메타분석기)의 심화 개선·경화(hardening) 기록입니다.
각 회차는 (1) 실질 기능 개선·확장과 (2) 병렬 적대적 리뷰로 찾은 결함 수정 +
회귀 테스트 고정으로 구성됩니다.

### 1) 실질 기능 개선 · 확장

**A. τ² 추정법 2종 추가 — REML · Sidik–Jonkman** (`metapool/meta.py`)

기존에는 DL·PM 둘뿐이었습니다. **REML은 R `metafor::rma`의 기본값**이라, 심사자가
"metafor로 다시 돌려봤다"고 할 때 숫자가 맞아야 합니다. REML 점수함수

    S(τ²) = Σ wᵢ²(yᵢ−μ)² − Σ wᵢ + (Σ wᵢ²)/(Σ wᵢ),   wᵢ = 1/(vᵢ+τ²)

의 근을 이분법으로 구합니다(S(0) ≤ 0 이면 해는 경계값 0). 처음에는 관행적인
고정점 반복으로 구현했다가 **리뷰에서 수렴 실패가 드러나 통째로 바꿨습니다** —
아래 S1 참조. SJ는 구조상 0으로 절단되지 않아, DL이 0으로 붕괴하는
소규모·저이질성 자료에서 보수적인(더 넓은) 구간을 줍니다.

**B. τ²·I²의 신뢰구간 — Q-profile (Viechtbauer 2007)** (`meta.py`, `distributions.py`)

I² 점추정만 보고하면 연구가 적을 때 "I² = 35%니까 이질성이 중간"이라는 잘못된
확신을 줍니다. 일반화 Q(τ²)가 τ²에 대해 단조감소하고 자유도 k−1의 χ²를 따른다는
성질을 이용해

    하한: Q(τ²) = χ²_{1−α/2}(k−1),   상한: Q(τ²) = χ²_{α/2}(k−1)

을 각각 이분법으로 풀고, `I² = τ²/(τ²+s²)` (s² = Higgins–Thompson 전형적 연구내
분산)로 옮깁니다. **I²·H² 점추정도 같은 식으로** 계산해 τ²와 항상 같은 모형을
말하게 했습니다(DL에서는 고전적 (Q−df)/Q, Q/df 와 대수적으로 동일). 이를 위해 `chi2_ppf`(χ² 분위수)를 새로 구현했습니다.
번들 예제에서 I² = 35.4%의 95% CI가 **0.0 % ~ 86.0 %** 로 나옵니다 — "그 자료로는
이질성의 크기를 사실상 모른다"는 정직한 답이며, 결과 문장에도 자동으로 실립니다.

**C. 출판편향 진단을 Egger 하나에서 4종으로** (`metapool/diagnostics.py`)

- **Begg–Mazumdar 순위상관 검정**: 비모수. Egger가 이분형(OR/RR)에서 구조적
  위양성을 내는 상황을 견제하며, 둘을 함께 보고하는 것이 관행입니다.
  p값은 동점이 없고 k ≤ 20이면 **순열 정확검정**(정규근사는 소표본에서
  나올 수 없는 유의성을 만듭니다 — S3 참조).
- **Duval–Tweedie trim-and-fill** (L0/R0, 방향 자동 판정): 누락으로 추정되는 연구를
  통합값 기준 거울상으로 채워 넣고 다시 합성합니다. **보정값은 참값 추정이 아니라
  민감도 분석**이라는 경고를 리포트·JSON·논문 문장 모두에 붙였습니다.
- **텍스트 깔때기그림**: 유사 95 % 구간(μ ± 1.96·SE)을 함께 그려 대칭성을 눈으로
  확인. 겹치는 점은 개수 숫자로 표시.

**D. 임상 해석 — NNT · 절대위험차** (새 모듈 `metapool/clinical.py`)

OR/RR은 "몇 배"만 말합니다. 심사자와 임상의는 "100명 치료하면 몇 명이 달라지나"를
묻고, GRADE 요약표의 '절대효과' 칸이 바로 그것입니다. 가정 대조군 위험(기본값 =
포함 연구들의 대조군 사건률, `--baseline-risk`로 변경)에서
실험군 위험 → 절대위험차 → 1000명당 사건수 → **NNT/NNH**(신뢰구간 포함)를 계산합니다.
CI가 0을 지나면 NNT 구간이 무한대를 지난다는 사실을 감추지 않고 밝힙니다.
도구는 "사건"이 좋은 결과인지 알 수 없으므로 그 점도 함께 적습니다.

**E. 지표 2종 추가 — 상관계수 · 단일군 비율** (`metapool/effects.py`, `io_csv.py`)

- `cor` (`study, r, n`): Fisher z = atanh(r), var = 1/(n−3)에서 합성하고 r로 되돌림.
- `prop` (`study, events, n`): logit에서 합성하고 비율로 되돌림. 0 %·100 % 연구만
  연속성 보정. **비율에는 무효과선이 없다**(logit 0 = 50 %)는 사실을 반영해
  숲그림에 세로선을 긋지 않고, 논문 문장에 유의성 검정을 싣지 않습니다.
- 이를 위해 분석 척도를 `raw|log|fisherz|logit`로 일반화(`MEASURE_SCALE`,
  `back_transform`)하고, 되돌리기가 오버플로하면 예외 대신 경계값으로 포화시킵니다.

**F. 영향력 진단 · 결과 CSV 내보내기 · 새 CLI 옵션**

- leave-one-out에 **잔여 I²** 와 **표준화 잔차**를 추가. |잔차| > 2면 "이상치 후보"로
  표시해, 이질성이 어느 연구에서 오는지 한눈에 보입니다.
- `--csv`: 연구별 + 통합 + 하위군 + leave-one-out + 예측구간 + trim-and-fill 을
  `row_type`으로 구분한 tidy CSV. 원고 표를 만들거나 R/엑셀로 넘길 때 씁니다.
  보고 척도와 분석 척도 값을 함께 담습니다.
- 새 옵션: `--tau2 REML|SJ`, `--baseline-risk`, `--csv`, `--no-funnel`,
  `--no-trimfill`, `--trimfill-estimator L0|R0`.
- 예제 2종 추가(`examples/response_rate_prop.csv`, `examples/adherence_correlation.csv`),
  `실행.command` 데모를 3종 → 5종으로 확장.

#### 통계 정확성 (첫원리 재계산)

| # | 결함 | 영향 | 수정 |

| S1 | **REML τ² 가 수렴하지 않은 값을 반환** (`meta.py`). 고정점 반복의 스텝이 1e-7 수준으로 기어가, "연구 하나만 아주 정밀한" 흔한 배치에서 500회를 돌려도 해 근처에 못 갔다 | τ² = 5.6e-05 (참값 0.1623), 통합값 −0.439 [−0.480, −0.399] **p < .001** ← 참값 −0.291 [−1.029, 0.447] **p = .44**. **결론이 유의 ↔ 비유의로 뒤집히고** 그 숫자가 논문 문장·JSON 에 그대로 실렸다 | 고정점을 버리고 **REML 점수함수 S(τ²)의 근을 이분법**으로 구한다. S(τ²) = Σw²(y−µ)² − Σw + Σw²/Σw 를 유도해 `_reml_score` 로 분리. 이제 metafor 와 소수점 7자리까지 일치 |

NNT 변환, `back()` 일반화는 metafor·손계산과 대조해 **결함 없음**을 확인했습니다.

#### 엣지케이스 (퍼징 1,500회 포함)

- **`--log-input` 이 모든 지표에 적용되어 결과 전체를 지수변환**했다. `-m rd --log-input` 이
  위험차 −0.104 를 **+0.901** 로 뒤집고, 같은 리포트의 절대효과 칸은 −10.4%p 라고 적어
  스스로 모순됐다. `cor --log-input` 은 **r = 1.776** 을 보고했다.
  → CLI 가 거부하고, 라이브러리도 `measure == "generic"` 일 때만 log 척도로 본다.
- **`se` 열이 `NA` 면 신뢰구간이 있어도 연구를 통째로 버렸다** (경고는 "열이 비어 있습니다"라고
  엉뚱하게 말했다). 일부만 SE 를 보고하는 실제 추출표의 전형적 모양이라, k=4 가 조용히 k=2 가 됐다.
  → 결측 표기(`NA/n/a/null/./-/—/?` …)를 빈 칸과 동일하게 처리하는 `is_missing` 도입.
- 같은 원인으로 **표시용 선택 열 `n` 에 `NA` 가 있으면 멀쩡한 효과크기가 버려졌다**.
  → n 은 읽지 못해도 연구를 유지하고 경고만 남긴다.
- **`subgroup` 열의 `NA`·`-` 가 진짜 하위군 수준이 되어** Q_between 이 쓰레기 위에서 계산되고
  논문 문장에 `NA 0.500` 이 실렸다. → 결측 표기는 하위군 미지정으로 처리.
- **Egger 가 정의되지 않으면(정밀도가 모두 동일) Begg·trim-and-fill·깔때기그림이 통째로 사라졌다** —
  JSON 에는 있고 텍스트·마크다운에는 없어 출력 형식끼리 답이 달랐다. → 블록 조건을 분리.
- **`--conf 0.999` 가 "100% CI" 로 반올림**됐다(= (−∞, ∞)). → `_conf_pct` 로 100 미만이 될 때까지
  자릿수를 늘린다.
- 준정규수 분산(se = 1e-160)이 **분석 전체를 죽였다** → 그 행만 버리고 이유를 남긴다.
- `.xlsx` 를 "깨진 UTF-16" 이라고 했다 → zip/OLE/PDF 서명을 알아보고 이름을 불러 준다.
- 두 군 모두 100% 발생인 자료에서 `rr` 만 **보정으로 만들어낸 가짜 CI** 를 냈다(or·rd 는 거부) → 거부.
- HK 경고 문구가 실제 출력과 어긋났다(구간이 넓어졌는데 "좁아졌습니다") → 실제 폭을 비교해 사실대로.
- `a,b,c,d` 형식이 파일의 `n1/n2` 를 말없이 덮어썼다 → 경고를 남긴다.

인코딩(cp949·euc-kr·UTF-16·BOM), 적대적 연구명, 축퇴 구조(빈 파일·1행·전부 무효),

#### 문서 정직성

- 예제 명령이 `--outcome` 없이 `ISI 총점` 이 든 출력을 "실제 출력"으로 보여 줬다 → 명령 수정.

- **`prop` 에서 통합 효과 표에 z·p 가 찍혔다** — logit 0 = 50% 검정이라 무의미한데 화면에서 가장
  베끼기 쉬운 숫자였다 → 텍스트·마크다운·CSV 모두에서 제거하고 이유를 적는다. 숲그림 범례의
  "│ 무효과선"도 실제로 선을 긋지 않을 때는 빼도록 고쳤다.
- **`prop` 에서 Egger 가 깨끗한 합성 자료에 p < .001 을 냈다** — 분산 1/e + 1/(n−e) 가 효과크기의
  함수라 비대칭이 구조적으로 보장된다. 연구자가 없는 출판편향을 보고할 뻔했다
  → 비대칭 판정 문구를 내보내지 않고 사유를 결과 옆·JSON note 에 적는다.
- Egger 는 k<10 에서 논문 문장에 안 실으면서 **trim-and-fill 은 모든 k 에서 실렸다** → 셋 다 k≥10 기준으로 통일.
- 영어 문장의 `1 study(ies)`, 비문 → 단·복수 처리(`_plural`)와 문장 수정. 영어는 "손을 본 뒤 쓰라"고 한계에 명시.
- REML 비수렴·SJ 의 구조적 양수성·Begg 동점·Q-profile 과 추정법의 관계를 한계 절에 추가.

#### 테스트 품질 · 보안

- **`--csv` 가 엑셀 수식 주입에 무방비**였다(`=cmd|' /C calc'!A0` 가 그대로 셀 선두에). 엑셀로
  넘기라고 만든 출력이라 실제 위험 → `=`·`+`·`-`·`@`·탭·CR 로 시작하는 셀 앞에 아포스트로피.
- **열 이름(헤더)은 정화되지 않았다** — 연구명은 제어문자를 걸렀지만 헤더는 ANSI 이스케이프가
  stdout 까지 살아 나가 이미 출력된 숫자를 덮어쓸 수 있었다. 또 헤더를 **길이 제한 없이** 되실어,
  100 KB 짜리 열 이름이 135 KB 오류 메시지가 됐다(임상 CSV 헤더에 식별자가 들어가는 일이 있다)
  → `_safe_name`/`_safe_header` (제어문자 제거 + 40자 절단 + 20열 제한).
- 마크다운 산문에 연구명이 escape 없이 들어가 `[클릭](javascript:…)` 이 링크로 렌더링됐다
  → `sentences(escape=…)` 로 사용자 입력만 무해화(숫자·고정 문구는 그대로).
- 끊어진 심볼릭 링크에 `--out` 하면 덮어쓰기 경고가 안 떴다 → `os.path.lexists`.
- **무력한 테스트 교체**: 깔때기그림 "점 개수" 검사는 축 라벨의 숫자까지 세어 **점을 전부 지워도
  통과**했다 → 격자만 떼어 내 좌표를 독립적으로 재계산해 대조. trim-and-fill 거울상은 `isfinite`
