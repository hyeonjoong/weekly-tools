# metapool 빠른 사용법 (한국어)

## 1. 제일 쉬운 방법 — 더블클릭

폴더 안의 **`실행.command`를 더블클릭**하세요. 예제 3종(연속형 SMD·이분형 OR·이미 계산된 효과크기)이
차례로 돌아가면서 결과가 어떻게 생겼는지 바로 보여 줍니다.

## 2. 내 데이터로 돌리기

엑셀에서 **CSV로 저장**한 뒤 터미널에서:

```bash
cd ~/Downloads/02_프로젝트/깃헙/metapool-메타분석
python3 -m metapool 내파일.csv
```

한 번만 설치해 두면 어디서든 `metapool 내파일.csv` 로 실행됩니다:

```bash
python3 -m pip install -e .
```

## 3. CSV는 이렇게 만들면 됩니다 (셋 중 편한 것)

**(가) 이미 효과크기와 표준오차가 있을 때**

```csv
study,effect,se
Kim 2021,0.42,0.15
Lee 2022,0.31,0.22
```

`se` 대신 `ci_low,ci_high` 를 적어도 됩니다.

**(나) 두 군의 평균·표준편차가 있을 때** (→ 표준화 평균차 Hedges g)

```csv
study,n1,mean1,sd1,n2,mean2,sd2
Kim 2021,32,-6.2,4.1,31,-3.1,4.4
```

> `1`이 처치군, `2`가 대조군입니다. 효과는 항상 **처치군 − 대조군**.

**(다) 사건 수(이분형)일 때** (→ 오즈비)

```csv
study,events1,n1,events2,n2
Trial A,42,80,30,80
```

**하위군을 보고 싶으면** `subgroup` 열을 추가하세요 (예: `device` / `app`, `성인` / `노인`).

열 이름이 달라도 흔한 형태(`ne`, `Mean.e`, `Author`, `연구`, `실험군n` …)는 알아서 인식합니다.
그래도 못 알아들으면 이렇게 알려주세요:

```bash
python3 -m metapool 내파일.csv --map 실험군수=n1 --map 대조군수=n2
```

논문에서 **오즈비와 95% 신뢰구간을 그대로 옮겨 적었다면** (`effect, ci_low, ci_high` 열):

```bash
python3 -m metapool 내파일.csv --measure generic --log-input
```

(로그 척도에서 합성한 뒤 다시 오즈비로 되돌려 보여 줍니다. 이 경우 `se` 열만 있으면
척도를 알 수 없어 거부하니, 신뢰구간 열을 넣어 주세요.)

## 4. 결과 읽는 법

| 보이는 것 | 뜻 |
|---|---|
| **통합(변량효과)** | 연구마다 참효과가 다르다고 보는 모형. 보통 이 값을 논문에 씁니다. |
| **통합(고정효과)** | 모든 연구의 참효과가 같다고 보는 모형. 참고용으로 함께 봅니다. |
| **95% 예측구간** | *다음* 연구 한 편의 참효과가 놓일 범위. CI보다 훨씬 넓은 게 정상입니다. |
| **I²** | 연구 간 차이가 얼마나 큰지. 25/50/75%가 대략 낮음/중간/큼의 기준. |
| **τ² (타우제곱)** | 연구 간 참효과의 분산. OR/RR이면 로그 척도 값입니다. |
| **Q_between** | 하위군끼리 효과가 다른지 검정. p < .05면 하위군 차이가 유의. |
| **하나씩 제외** | 한 연구를 빼도 결론이 유지되는지. "결론이 바뀜"이 뜨면 결과가 취약하다는 뜻. |
| **Egger** | 깔때기그림 비대칭(출판편향 의심). **연구 10편 미만이면 믿지 마세요** — 경고가 붙고, 논문 문장에는 수치가 들어가지 않습니다. 오즈비/위험비에서는 위양성이 잦습니다. |
| **숲그림의 `│`** | 무효과선(효과 0, OR/RR이면 1). 신뢰구간이 이 선을 지나면(`┼`) 유의하지 않습니다. |

맨 아래 **"논문에 붙일 문장"** 은 한국어·영어로 그대로 복사해 쓸 수 있게 만든 결과 문단입니다.
숫자만 다시 확인하고 붙여 넣으세요.

## 5. 자주 쓰는 옵션

```bash
python3 -m metapool 내파일.csv --outcome "ISI 총점"     # 논문 문장에 결과변수 이름 넣기
python3 -m metapool 내파일.csv --measure rr            # 위험비로 계산
python3 -m metapool 내파일.csv --tau2 PM              # 연구 수가 적을 때 권장(Paule–Mandel)
python3 -m metapool 내파일.csv --subgroup 센터          # 특정 열로 하위군 분석
python3 -m metapool 내파일.csv --sort effect          # 효과 크기 순으로 정렬
python3 -m metapool 내파일.csv --md -o 결과.md         # 마크다운으로 저장
python3 -m metapool 내파일.csv --json -o 결과.json     # 다른 프로그램에 넘길 때
```

## 6. 자주 나오는 상황

- **"지표를 자동으로 판별하지 못했습니다"** → 열 이름을 못 알아본 경우입니다. 오류 메시지에 필요한
  열 조합이 나오니 `--map` 으로 연결해 주세요.
- **"행 N 제외"** 경고 → 그 행에 숫자가 아니거나 비어 있는 값이 있어서 뺐다는 뜻입니다. 나머지는 정상 분석됩니다.
- **"연속성 보정"** 경고 → 사건 수가 0인 칸이 있어 네 칸에 0.5씩 더했습니다. 이런 연구가 많으면 결과 해석에 주의.
- **연구가 2편 이하** → 예측구간·민감도·Egger는 계산하지 않고, 논문 문장도 만들지 않습니다(통계적으로 의미가 없어서).
- **"Hartung–Knapp 신뢰구간이 ... 좁아졌습니다"** 경고 → 연구 간 차이가 거의 없을 때 생기는 알려진 현상입니다.
  `--no-hksj` 로 한 번 더 돌려 두 결과를 함께 확인하세요.
- **엑셀에서 "0,5"처럼 소수점에 쉼표를 쓴 파일** → 10배 틀린 값을 조용히 내놓느니 해당 행을 제외합니다.
  엑셀에서 소수점을 마침표(`.`)로 바꿔 저장하세요.
- **`--out` 으로 원본 CSV를 지정** → 원자료를 덮어쓰지 않도록 거부합니다. 다른 이름을 쓰세요.
