# _기획 — 툴 기획서 보관함

여기에 자동화가 **만들기 전에 먼저 쓴 기획서**가 쌓입니다. 툴을 즉흥적으로 정하지 않고,
기획 세션이 "정말 쓸만한가"를 따져 한 건만 확정한 뒤, 다음 실행이 그 기획서를 그대로 구현합니다.

- `STATUS: 대기` → 아직 안 만든 기획 (다음 빌드가 이걸 구현)
- `STATUS: 구현완료 (날짜)` → 이미 만들어진 기획

**직접 개입하는 법:** 이 폴더에 같은 형식으로 파일을 하나 쓰고 첫 줄을 `STATUS: 대기`로 두면,
자동화가 자기 아이디어 대신 그걸 먼저 만듭니다. 저장소 루트의 `IDEAS.md`에
`- [ ] ... [우선]` 로 적어두는 것도 기획 세션이 최우선으로 반영합니다.
