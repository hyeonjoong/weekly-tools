# medpath 사용법 (한국어)

> X(원인) → M(매개) → Y(결과) 열이 있는 CSV → 간접효과 부트스트랩 보고서.
> 설치 없이 **Python 3.9 이상**만 있으면 됩니다.

---

## 1. 가장 빠른 시작

1. **`실행.command` 를 더블클릭**하세요. 동봉 예제로 전체 기능이 한 번에 돕니다.
   (macOS에서 "확인되지 않은 개발자" 경고가 뜨면 파일을 **우클릭 → 열기**)
2. 내 데이터로 돌리려면 터미널에서:

```bash
cd ~/Downloads/02_프로젝트/깃헙/medpath-매개효과분석
python3 -m medpath 내파일.csv --x 원인열 --m 매개열 --y 결과열
```

열 이름이 기억나지 않으면 먼저:

```bash
python3 -m medpath 내파일.csv --list-columns
```

## 2. 내 데이터를 어떻게 만들어야 하나요

**한 행 = 한 사람(한 관측)** 이고, 아래 세 열만 있으면 시작할 수 있습니다.

| 필요한 열 | 설명 | 예 |
|---|---|---|
| **X** (독립·노출) | 중재군/대조군, 용량, 노출량 — 숫자 또는 두 수준의 문자열 | `arm`, `투여군`, `weekly_sessions` |
| **M** (매개) | X가 바꾸고, 그것이 Y를 바꾼다고 가정하는 **연속형** 변수 | `rmssd_ms`, `순응도`, `염증수치` |
| **Y** (종속·결과) | 최종 결과 — **연속형** 권장 | `sws_min`, `증상점수` |
| (선택) 공변량 | 보정할 변수. 연속형/범주형 모두 가능 | `age`, `성별`, `기저값` |

```csv
subject_id,arm,age,rmssd_ms,sws_min
S001,device,41,23.2,64.7
S002,sham,49,19.8,63.0
S003,device,55,,61.2      ← M 결측 → 자동 제외(건수 보고)
S004,sham,,20.1,58.4      ← 공변량 결측 → 자동 제외
```

**자동으로 처리되는 것들**

- 인코딩: UTF-8 / UTF-8+BOM / CP949(한글 엑셀) / latin-1 자동 판별
- 구분자: `,` `;` `\t` `|` 자동 인식 (`--delimiter ';'`, `--delimiter tab` 으로 강제 가능)
- 결측 표기: 빈칸, `NA`, `N/A`, `#N/A`, `null`, `.`, `-`, `결측`, `없음`,
  `미측정`, `측정안함`, `무응답`, `해당없음`
- 숫자: `1,024.0`(천단위 쉼표), `1,5`(유럽식 소수점 — `--decimal comma` 로 강제)
- 범주형 X: 두 수준이면 자동 0/1 코딩 (대조군으로 보이는 쪽을 0으로)
- 범주형 공변량: 자동 가변수화(dummy)

**제외된 행은 반드시 보고됩니다.** 보고서 첫머리의
`표본: 파일 120행 → 분석 116행 (결측 등으로 4행 제외)` 와 "결측 현황" 표를
꼭 확인하세요.
(`--brief` 에서는 "결측 현황" 표가 생략되고 첫머리 `표본:` 줄만 남습니다.
`--x-levels` 로 고르지 않은 수준의 행도 이 표에서 X열의 건수에 합산됩니다.)

## 3. 세 가지 모형

### (a) 단순매개 — 매개변수 1개

```bash
python3 -m medpath examples/sleep_breathing_hrv.csv \
    --x arm --m rmssd_ms --y sws_min --covariates age
```

> 중재(arm)가 심박변이도(rmssd_ms)를 올리고, 그것이 서파수면(sws_min)을 늘렸는가?

### (b) 병렬 다중매개 — 매개변수 여러 개를 **동시에**

```bash
python3 -m medpath examples/sleep_breathing_hrv.csv \
    --x arm --m rmssd_ms,resp_rate_bpm --y sws_min
```

각 경로의 간접효과가 **서로를 통제한 상태에서** 계산되고, "어느 경로가 더
큰가"를 묻는 **대비(contrast)** 표까지 나옵니다.
대비는 다중비교 보정을 하지 않으므로, 여러 개일 때는 "그중 하나가 유의했다"에
큰 의미를 두지 마세요(보고서에 기대 오탐 수가 함께 표시됩니다).

### (c) 직렬(연쇄) 매개 — 순서가 있는 사슬 `--serial`

```bash
python3 -m medpath examples/sleep_breathing_hrv.csv \
    --x arm --m rmssd_ms,sws_min --y isi_change --serial
```

`--m` 에 적은 **순서 그대로** X→M1→M2→Y 로 연결됩니다. 순서를 바꾸면 다른
모형이므로, 그 순서에 이론적 근거가 있어야 합니다. 매개 2개면 3개 경로,
3개면 7개 경로가 모두 보고됩니다(2~3개 권장).

## 4. 결과 읽는 법

```
  효과                                        추정치   SE        95% CI       판정
  총효과 c (arm → sws_min)                     4.155  1.813   [0.564, 7.746]  p = .024
  직접효과 c' (arm → sws_min, 매개변수 통제)   1.193  1.774  [-2.321, 4.707]  p = .502
  간접효과 arm → rmssd_ms → sws_min            2.961  1.044   [1.170, 5.279]  0 미포함
```

| 줄 | 뜻 |
|---|---|
| **총효과 c** | 매개변수를 넣지 않았을 때 X가 Y에 주는 전체 효과 |
| **직접효과 c'** | 매개변수를 통제한 뒤 남은 X→Y 효과 |
| **간접효과 ab** | X → M → Y 로 흐른 부분. **이 줄의 CI가 핵심입니다** |

- **판정 `0 미포함`** = 부트스트랩 신뢰구간이 0을 배제 → 그 경로를 통한 매개가
  자료와 일치합니다("효과가 입증됐다"가 아닙니다).
- **판정 `검정 안 함`** = 구간이 없다는 뜻이며 "유의하지 않다"와 다릅니다
  (`--bootstrap 0`이거나 재표본이 부족했을 때).
- **`a`와 `b` 각각의 p값이 아니라 곱 `ab`의 구간**으로 판단합니다.
- **총효과 c가 유의하지 않아도** 간접효과는 유의할 수 있습니다(경로 상쇄·억제).
- **`c = c' + Σ(간접효과)`** 가 항상 정확히 성립합니다(검산에 쓰세요).

### 하면 안 되는 해석

- ❌ "직접효과가 유의하지 않으니 **완전매개**다" → 검정력 문제일 뿐입니다.
- ❌ "간접효과가 유의하니 **기전이 입증됐다**" → 상관 구조입니다. X→M→Y의
  시간 순서와 미측정 교란 부재가 자료로 보장돼야 인과입니다.
- ❌ 매개비율 138%를 그대로 보고 → 부호가 엇갈릴 때 생기는 허수입니다
  (medpath가 경고합니다).

## 5. 자주 겪는 상황

### 계수 부호가 반대로 나와요 (기준군이 뒤바뀜)

```bash
python3 -m medpath 내파일.csv --x 군 --m ... --y ... --reference 대조군
```

보고서 맨 아래 "데이터 처리 메모"에 어떤 값을 0으로 잡았는지 적혀 있습니다.

### X가 3군 이상이에요 (예: 저용량/고용량/위약)

두 군만 골라 비교합니다(기준,비교 순서):

```bash
python3 -m medpath 내파일.csv --x 용량군 --m ... --y ... --x-levels 위약,고용량
```

### 논문 제출용으로 더 엄밀하게

```bash
python3 -m medpath 내파일.csv --x ... --m ... --y ... \
    --ci bca --bootstrap 10000 --markdown --out 결과.md
```

- `--ci bca` : 편향·왜도까지 보정한 BCa 구간 (느립니다. N > 20,000이면 거부됩니다)
- `--bootstrap 10000` : 보고용 권장 5,000회 이상
- `--seed` 는 기본 고정이라 **같은 명령은 항상 같은 결과**를 줍니다(재현성)

### 잔차 이분산 경고가 떠요

```bash
python3 -m medpath ... --robust hc3
```

경로계수의 표준오차만 강건 추정으로 바뀝니다. 간접효과의 부트스트랩 구간은
원래 이분산에 비교적 견고합니다.

### 다른 프로그램으로 넘기고 싶어요

```bash
python3 -m medpath ... --json --out 결과.json
```

숫자가 없으면 `null`로 나오는 **엄격한 JSON**입니다(NaN 없음).

### 결과가 너무 길어요

```bash
python3 -m medpath ... --brief              # 핵심만
python3 -m medpath ... --no-diagnostics     # 진단 생략(대용량에서 빠름)
```

## 6. 옵션 요약

| 옵션 | 기본값 | 설명 |
|---|---|---|
| `--x` / `--m` / `--y` | (필수) | X · M(쉼표로 여러 개) · Y 열 이름 |
| `--covariates` | 없음 | 공변량, 쉼표로 여러 개 |
| `--serial` | 꺼짐 | 직렬(연쇄) 매개모형 |
| `--reference` | 자동 | 범주형 X의 기준(0) 수준 |
| `--x-levels 기준,비교` | 없음 | 3수준 이상 X에서 비교할 두 수준 |
| `--bootstrap N` | 5000 | 부트스트랩 반복(0이면 구간 없음) |
| `--ci` | percentile | `percentile` / `bc` / `bca` |
| `--conf` | 95 | 신뢰수준 |
| `--seed` | 20260731 | 난수 시드 |
| `--robust` | none | `hc3` = 이분산 강건 SE |
| `--jobs N` | 1 | 부트스트랩 병렬 프로세스(결과는 동일) |
| `--delimiter` / `--decimal` | 자동 | CSV 구분자 / 소수점 기호 강제 |
| `--digits` | 3 | 소수점 자리수 |
| `--brief` / `--no-diagnostics` | 꺼짐 | 출력 줄이기 |
| `--json` / `--markdown` / `--out` | 표 출력 | 출력 형식·저장 |
| `--list-columns` | — | 열 이름만 보고 종료 |

전체 목록: `python3 -m medpath --help`

## 7. 오류가 났을 때

| 메시지 | 뜻과 해결 |
|---|---|
| `--x, --m, --y 옵션이 필요합니다` | 열 이름을 지정하세요. `--list-columns` 로 확인 |
| `'…' 열이 CSV에 없습니다` | 오탈자·공백·BOM. `--list-columns` 출력과 정확히 맞추세요 |
| `… 숫자로 해석되지 않아 결측으로 처리했습니다` | 단위 문자(`23.2 ms`)나 범위 표기가 섞인 칸입니다. 그 칸만 고치거나 비우세요 |
| `… 값 대부분이 숫자가 아닙니다` | 절반 이상이 비숫자입니다. 열을 잘못 지정했을 가능성이 큽니다 |
| `'…' 열이 다른 열들과 완전히 겹칩니다(공선성)` | 중복이거나 다른 변수들의 합인 열이 있습니다. 하나를 빼세요 |
| `… 값이 전부 같습니다(상수)` | 분석 대상 행에서 변하지 않는 열입니다. 빼고 실행하세요 |
| `--serial 은 매개변수를 2개 이상` | `--m A,B` 처럼 두 개 이상 지정 |
| `BCa는 … N=…에서는 매우 느립니다` | `--ci percentile` 또는 `--ci bc` 사용 |
| `부트스트랩 재표본 …개가 특이행렬로 실패` | 표본이 작거나 거의 상수인 변수가 있습니다. 실패율 5% 초과면 결과를 믿지 마세요 |
| `사용 가능한 부트스트랩 재표본이 …개뿐이라` | 100개 미만이면 구간을 만들지 않습니다. `--bootstrap` 을 늘리거나 변수 구성을 줄이세요 |
| `구분자로 쓸 수 없는 문자입니다` | `--delimiter` 에 따옴표·줄바꿈 등은 쓸 수 없습니다 |

## 8. 개인정보 주의

- CSV에 이름·주민번호·연락처 등 **직접 식별자를 넣지 마세요.** 분석에 전혀
  필요하지 않습니다(ID는 익명 일련번호면 충분).
- medpath는 **네트워크에 아무것도 보내지 않으며**, 결과 파일에는 열 이름·요약
  통계·행 번호만 들어갑니다. 다만 `--out` 파일에 **열 이름이 그대로 남으므로**
  열 이름에 식별정보를 넣지 마세요.
- 동봉 예제는 전부 합성 데이터이며 실제 환자 정보가 아닙니다.
