# HARDENING — medpath 개선·검증 이력

이 파일은 medpath가 어떤 결함을 어떻게 고쳤는지 남기는 기록입니다.
"무엇을 고쳤다"보다 **"어떤 잘못된 숫자가 나올 수 있었는가"** 를 남기는 데
목적이 있습니다.

---

## 2026-08-06 — 도구 완성 + 병렬 적대적 리뷰 1라운드

이전 실행이 중단돼 코드·테스트만 있고 배포에 필요한 파일이 없던 상태에서
시작했습니다.

### 새로 추가한 것

- `pyproject.toml` (콘솔 스크립트 `medpath` 포함), `LICENSE` (MIT)
- `README.md` — 목적·정직한 능력 기술·한계·실행법
- `사용법.md` — 단계별 한국어 안내, 오류 메시지 대응표
- `실행.command` — 더블클릭 데모 6종 (동봉 예제로 전체 기능 시연)

### 리뷰 방식

독립 서브에이전트 4개를 병렬로 돌려 (1) 통계 정확성, (2) 지저분한 임상 CSV
경계조건, (3) 문서 정직성, (4) 테스트 품질·개인정보 안전을 각각 검토했습니다.
각 에이전트는 지적한 내용을 실제로 재현·수치 검증하도록 요구했고, 아래는
그중 **재현이 확인된 것만** 반영한 결과입니다.

### 고친 것 — 잘못된 숫자를 만들던 결함

1. **수치형 2수준 X의 부분표준화가 (두 수준 차이)배만큼 틀렸습니다.**
   용량이 0/5로 코딩된 열의 회귀계수는 *1단위당* 값인데 이를 그대로 `SD(Y)`로
   나눠 집단 차이의 1/5로 보고했습니다. `Design.x_span`을 도입해 두 수준의
   간격을 반영합니다. 0/1 가변수 결과는 그대로입니다.
   → `test_partially_standardized_effect_is_invariant_to_the_group_coding`

2. **쉼표 하나가 파일 전체를 유럽식 소수점으로 뒤집어 값을 1000배로 만들었습니다.**
   분석에 쓰지도 않는 열의 다중선택 코드 `"1,2"` 한 칸이 `_sniff_decimal`을
   comma 모드로 넘겼고, 그러면 `0.931` 같은 3자리 소수가 `931`로 재해석돼
   간접효과의 유의성이 뒤집혔습니다(실제 재현: `ab = -12.6 유의` → `-1.09 비유의`).
   이제 쉼표 소수 증거가 점 소수 증거와 천단위 증거를 **모두 넘어설 때만**
   comma 모드로 갑니다.
   → `test_one_stray_multiselect_cell_does_not_flip_the_file_to_comma_decimal`

3. **재표본 1개로 폭 0짜리 "95% 신뢰구간"을 만들고 유의하다고 판정했습니다.**
   `--bootstrap 1`이나 대부분의 재표본이 특이행렬로 실패한 경우, 살아남은
   몇 개 위로 분위수가 붕괴해 항상 0을 배제했습니다. 이제 사용 가능한 재표본이
   `MIN_BOOT_FOR_CI`(100) 미만이면 구간을 만들지 않고 "검정 안 함"으로 표시합니다.
   → `test_too_few_resamples_yield_no_interval_rather_than_a_fake_one`

4. **총효과가 0과 구분되지 않을 때도 매개비율(%)을 그대로 찍었습니다.**
   분모가 0 근처인 비율이라 `57.6% 매개`처럼 그럴듯한 숫자가 나오지만 의미가
   없습니다. 총효과의 신뢰구간이 0을 포함하면 계산하지 않고 이유를 밝힙니다.
   (동봉 직렬 예제가 정확히 이 경우였습니다.)
   → `test_proportion_is_withheld_when_the_total_effect_ci_covers_zero`

5. **오타 한 칸이 연속형 공변량을 조용히 가변수 묶음으로 바꿨습니다.**
   나이 열의 `"45 세"` 한 칸 때문에 `age`가 10개 가변수로 분해돼 모형이
   달라지고(직접효과 p = .050 → .066) 부트스트랩 실패율이 치솟았습니다.
   이제 X/M/Y와 동일한 규칙(비숫자 50% 미만이면 숫자열 유지 + 경고)을 씁니다.
   → `test_one_bad_cell_keeps_a_continuous_covariate_continuous`

6. **논문용 문장이 하지 않은 일을 했다고 썼습니다.** 재표본을 전부 실패한
   경우에도 "부트스트랩을 실행하지 않아 / No bootstrap resamples were drawn"
   이라고 출력했습니다. 두 상황을 구분해 서술합니다.
   → `test_all_resamples_failed_is_not_reported_as_never_run`

7. **작은 값의 열을 상수로 오판했습니다.** `round(v, 15)`는 유효숫자가 아니라
   소수점 15자리라, 1e-15 미만의 열이 전부 0으로 붕괴해 유효한 데이터를
   거부했습니다. 상대 허용오차로 바꿨습니다.
   → `test_tiny_magnitude_column_is_not_mistaken_for_a_constant`

### 고친 것 — 개인정보

8. **`--x`를 잘못 지정하면 식별자 열 전체가 화면에 쏟아졌습니다.** 수준 목록을
   제한 없이 출력해, 60행짜리 파일에서 MRN 60개가 그대로 stderr로 나갔습니다
   (N=10,000이면 10,000개). 8개까지만 보여주고 나머지는 개수로만 알립니다.
   → `test_level_listing_in_errors_is_capped`

리뷰에서 확인된 나머지 항목: 네트워크 접속·외부 쓰기 없음(소켓/urllib/subprocess
호출 0건), 동봉 예제 CSV는 `make_examples.py`로 바이트 단위 재생성되는 합성
데이터, 테스트는 `tmp_path` 밖에 쓰지 않음.

### 테스트

리뷰어가 확인한 **커버리지 공백**(변형을 가해도 테스트가 통과하던 지점)을
메웠습니다. 특히:

- **직렬 모형은 한 번도 부트스트랩되지 않았습니다** — `EffectPlan`의 직렬 분기에서
  d 경로를 삭제해도 전 테스트가 통과했습니다.
- **BCa가 가속(acceleration) 없이 BC로 조용히 대체돼도** 경로 효과 쪽에서는
  잡히지 않았습니다(대비 쪽에는 이미 방어 테스트가 있었습니다).
- **`--robust` / `--reference` / `--x-levels` 가 실제로 전달되는지** 확인하는
  테스트가 없었습니다(과거에 한 번 조용히 무시된 전력이 있는 지점입니다).
- **소수점 쉼표 경로 전체가 무테스트**였습니다 — 모듈 주석이 스스로 "silent
  factor-of-1000 error"라 부르는 코드입니다.
- 범주형 공변량 가변수의 **값**을 확인하는 테스트가 없어, 전부 뒤집어도 통과했습니다.
- 이분산·영향점 진단이 **사용자 경고로 올라가는지**는 검증되지 않았습니다.

추가한 파일: `tests/test_review_round.py` (46개). 여기에는 QR 경로와 부트스트랩
Cholesky 경로가 어긋날 때 뜨는 "수치 점검" 경고가 **정상 데이터에서는 뜨지
않는다**는 단언이 포함되는데, 이 한 줄이 직렬 분기의 여러 변형을 한꺼번에
잡아냅니다.

전체: `python3 -m pytest` → **269 passed** (표준 라이브러리만이면 242 passed).

### 고치지 않고 남긴 것

- `_delta_se` 독스트링이 "서로 다른 회귀에서 왔으므로 독립"이라고 설명하는데,
  이는 논리적 비약입니다(실제 근거는 매개변수 오차항의 상호 독립 가정).
  **공식 자체는 검증 결과 정확**하므로 숫자에는 영향이 없습니다.
- 조절매개, 로지스틱/반사실적 인과매개, 다층·잠재변수 모형은 여전히 지원하지
  않습니다. README의 "할 수 없는 것"에 명시돼 있습니다.

### 리뷰에서 "이상 없음"으로 확인된 것 (참고)

병렬/직렬 모형 설정, 경로 열거(2^k−1), `c = c' + Σab` 항등식(기계 정밀도),
Sobel/델타법 공식, 케이스 재표본 방식, 백분위/BC/BCa 공식과 z0 무한대 처리,
잭나이프 가속 공식과 부호, HC3·VIF·Breusch–Pagan·Cook's D(statsmodels 대조
일치), `special.py`의 분포 함수 정확도(scipy 대조), 완전표준화 효과,
부트스트랩 통계량 인덱싱 — 모두 독립 재계산으로 일치를 확인했습니다.
