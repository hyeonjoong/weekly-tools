# rsalink 사용법

## 설치

```bash
cd rsalink-호흡심박연동분석
python3 -m pip install -e .        # 또는 설치 없이: python3 -m rsalink ...
rsalink --help
```

Python 3.9 이상, 표준 라이브러리만 사용. 네트워크 접근 없음.

## 입력 파일

### 호흡 (첫 번째 인자)

| 형태 | 형식 | 비고 |
|---|---|---|
| 파형 | `timestamp,value` 두 열 | 값이 클수록 흡기(흉곽 확장). 반대면 `--invert`. 샘플링레이트는 Δt 중앙값으로 추정. 값 셀이 빈칸·NA·nan/inf 면 제외하고 건수를 자백. 디트렌드 전 \|z\| > 10·MAD 스파이크는 클리핑하고 건수를 자백 |
| 흡기 시작 이벤트 | `timestamp` 한 열 | 열 수로 자동 인식(`--events` 플래그 없음). 파형이 없으면 결맞음·교차상관 제안은 생략되고, 흡기 끝은 주기의 40% 지점으로 가정. `--invert/--smooth-s/--k-mad` 는 적용되지 않으며 주면 "무시됨" 경고 |

호흡 샘플링레이트가 0.2 Hz 미만이면 "타임스탬프 단위 의심"으로 거부(exit 2), 호흡당 샘플이 4개 미만이면 "파형이 너무 성김" 플래그.

### RR / IBI (두 번째 인자) — hrvkit 규격 호환

- 값 열 하나. 단위 자동 인식: 중앙값 < 10 → 초, < 300 → bpm, 그 외 → ms.
- 열 자동 탐색(`rr`, `ibi`, `rri`, `interval`, …). 안 잡히면 `--rr-col 이름` 또는 `--rr-col 번호(0부터)`. NA 가 섞인 열도 숫자 열로 인식(비어 있지 않은 셀의 80% 이상이 숫자면).
- 300–2000 ms 밖 값과 **파싱 실패 셀(빈칸·NA·문자·nan/inf)** 은 모두 "제외"로 세고 개수를 자백한다. 제외된 자리는 값을 버리되 시간축은 중앙값 RR 만큼 진행한다. 보정(보간·대체)은 하지 않는다 — 그건 hrvkit 영역. 제외 > 20% 면 exit 3.
- 박동 시각은 **RR 누적**으로 만든다(타임스탬프 열: 없음 — 있어도 시간축에 쓰지 않고 절대 시각 비교에만 쓴다). 첫 박동 = 첫 RR 이 끝나는 시각.

### 타임스탬프 형식(두 파일 공통)

ISO 8601 (`2026-01-01T09:00:00.250`, 공백 구분 허용) · `HH:MM:SS(.fff)` · epoch 초(≥ 1e9; ms 는 자동 환산) · 시작 기준 초.
모두 "첫 샘플 기준 경과 초"로 바뀐다. 파일 안에서 타임존 유무가 섞이면 거부, 역행이 있으면 거부(추측 정렬 안 함), 전부 같으면 거부, 중복은 개수를 자백하고 첫 값만 쓴다.
두 파일 중 한쪽만 타임존이 있으면 절대 시각 비교를 생략하고 그 사실을 표에 적는다.
인코딩은 utf-8 / utf-8-sig / cp949 를 차례로 시도한다.

### 두 파일의 시계

호흡과 RR 은 각각 자기 파일의 첫 샘플을 0 s 로 본다. 두 장비의 시작이 다르면 `--resp-offset SEC` 로 **사람이** 맞춘다.
부호: **호흡 기록이 RR 기록보다 늦게 시작했으면 양수**(= 호흡 시작 절대시각 − RR 시작 절대시각). 리포트는 교차상관으로
제안값을 **표시만** 하고 적용하지 않는다(가짜 정렬이 더 위험하다). 제안값의 r 이 양수면 호흡 부호가 반대일 수 있으니 `--invert` 를 확인한다.

두 파일이 모두 절대 시각(ISO/epoch)이면 `--inspect` 와 리포트 ① 이 절대 시각 차를 두 가지 규약으로 보여준다:
RR 파일의 첫 타임스탬프가 **첫 간격의 시작**이면 `d`, **첫 박동 시각(간격 끝)**이면 `d + 첫 RR`. 장비 규약에 맞는 쪽을 `--resp-offset` 에 넣는다.

## 실행

```bash
# 기준선 vs 자극 + 6회/분 페이싱
rsalink 호흡.csv RR.csv --baseline 0:00-5:00 --stimulus 5:00-15:00 --pace 6 --out-dir 결과

# 구간 CSV(start,end,label) 로 여러 조건
rsalink 호흡.csv RR.csv --segments 조건.csv --resp-offset 1.5 --out-dir 결과

# 입력 인식만 확인
rsalink 호흡.csv RR.csv --inspect
```

구간 시각은 `M:SS`, `H:MM:SS`, 또는 초. `--segments` 와 `--baseline/--stimulus` 는 함께 쓸 수 없다.
구간끼리 겹치면 exit 2("구간 겹침"; `0:00-5:00` / `5:00-15:00` 처럼 끝과 시작이 같은 것은 된다). 음수 시각(`-1:00-5:00`)이나 한쪽이 빈 구간(`5:00-`)도 exit 2.
구간을 하나도 안 주면 두 신호의 공통 범위를 한 구간("전체")으로 분석한다.

구간이 데이터 범위를 넘으면 공통 범위로 **잘라서** 쓰고 표에 "(요청 M:SS–M:SS, 데이터 범위로 N% 잘림)"을 적는다.
잘린 뒤 2분 미만이면 그 구간의 스펙트럼·판정은 생략한다("구간 데이터 부족" → 판정 보류).

### `--segments` CSV

- 헤더 `start,end,label`. 헤더가 없어도 3열이고 첫 두 셀이 시각이면 데이터로 읽는다. 그 밖의 헤더면 exit 2("헤더 start,end,label 필요").
- 라벨이 비면 `구간N`. 라벨 중복은 exit 2(조건비교.csv 의 열 값이라 유일해야 한다).
- 기준선 폴백 규칙: 라벨에 `기준`·`baseline`·`base` 가 들어간 첫 구간이 기준선, 없으면 **첫 행**이 기준선. 나머지 구간은 각각 기준선과 비교된다.

### 주요 옵션

| 옵션 | 기본 | 뜻 |
|---|---|---|
| `--min-breath-s` / `--max-breath-s` | 1.5 / 15 | 이 밖의 호흡은 아티팩트(short/long). 3–4회/분 페이싱은 주기 15–20 s 라 `--max-breath-s 25` 로 올릴 것 |
| `--k-mad` | 3.0 | 골 돌출 임계 = max(k × 잡음 MAD·1.4826, 0.15 × 60 s 창별 (p95−p5)). 잡음 MAD = 평활 잔차의 MAD. 흡기 시작은 골에서 봉우리 쪽 상승 발치로 보정한다(매끈한 파형은 골 그대로) |
| `--smooth-s` | 0.5 | 파형 이동평균 창(초, 0–30) |
| `--invert` | — | 파형 부호 반전 |
| `--rsa-lag` | 1.0 | RSA 창을 뒤로 미는 초(호흡→RR 생리적 위상 지연 허용치, 0–5). 20회/분 이상에 지연이 거의 없으면 0.5 |
| `--resp-offset` | 0 | 호흡 시각에 더할 초(부호 규약은 위 "두 파일의 시계") |
| `--resp-band-halfwidth` | 0.04 | 호흡중심 대역 = 평균 호흡주파수 ± 이 값(Hz, 0–0.5) |
| `--nperseg` | 256 | Welch 세그먼트 샘플 수(4 Hz → 64 s, Δf 0.0156 Hz). 기록이 짧으면 자동 축소(최소 64). 구간별 실제 값은 표 아래 각주와 조건비교.csv 에 |
| `--subject` | "" | 조건비교.csv 의 `subject` 열 — 여러 피험자 병합용 |
| `--out-dir` | 없음 | 없으면 터미널 리포트만. 있으면 아래 세 파일. `~` 확장·심볼릭링크는 실제 경로로 해석해 출력 |
| `--quiet` | — | 터미널 리포트 생략 |

옵션 값이 nan/inf 이거나 범위 밖이면 한국어 오류로 exit 2(트레이스백 없음).

## 산출물 (모두 `--out-dir` 안, 경로는 파일 이름만 기록)

| 파일 | 내용 |
|---|---|
| `연동리포트.md` | 커버리지 자백 → 호흡 검출 → RSA → 구간표 → 페이싱 → 조건 비교·판정 두 줄 → Methods/Results(KR/EN) → 근거 6편 → 면책 |
| `호흡별.csv` | 호흡 한 줄: onset/peak/end 시각(호흡 시계, 초), 주기, 호흡수, 플래그, 박동 수, 흡기 최소 RR, 호기 최대 RR, RSA_pv, 판정불가 사유, `RR최소_위상`·`RR최대_위상`(극값이 놓인 호흡 주기 내 위상 0–1, 0 = 흡기 시작; lag 만큼 1 을 넘을 수 있음). 구간 라벨은 `--resp-offset` 을 적용한 RR 시계 기준으로 붙인다 |
| `조건비교.csv` | 구간 한 줄(long 형식): 시작·끝(잘린 값)과 요청 시작·끝·잘린 비율, 호흡수 평균·SD, RSA_pv 중앙값·IQR·n·판정불가·호흡당 박동, LF·HF고정·호흡중심 파워, 결맞음·null95·Welch L·nperseg·Δf, 평균 RR, 페이싱 지표, 플래그(짧음·느린 호흡·호흡수 CV>15%) |

산출물 3종은 **하나라도 쓰기 전에** 모두 검사한다: 심볼릭링크·하드링크(연결 수 > 1)·입력 파일과 같은 실제 경로면 exit 2. 쓰기는 임시파일 후 교체(절반만 쓰인 파일이 남지 않는다).
쓰기 권한 프로브는 난수 이름의 임시파일이다(고정 이름 링크를 따라가지 않는다).

여러 피험자를 모을 때는 `--subject ID` 로 실행해 `조건비교.csv` 들을 그대로 이어 붙이면 `subject, segment, …` long 형식이 된다
(statwise / longistat 투입 형태). CSV 는 utf-8-sig(BOM) 이라 엑셀에서 바로 열린다. 문자열 셀이 `= + - @ 탭 CR` 로 시작하면 `'` 를 붙여 수식 실행을 막는다(구간 라벨·`--subject` 값 포함). 마크다운 표에서는 라벨의 `|` 와 개행을 이스케이프한다.

## 판정 두 줄 읽는 법 (3상태)

1. **"HF 변화가 호흡수 변화와 동반됨 / 비동반 / 판정 보류"** — HF 고정 파워의 |ln(자극/기준)| 이 **잡음 마진 M** 을 넘었을 때(정확히 경계값은 변화 없음), 호흡수도 (|Δ| ≥ max(1회/분, 기준의 10%)) 변했으면 "동반됨", 임계 미만이면 "비동반".
   - 잡음 마진 M = max(ln 1.25, 1.96·√(2/L_eff)), L_eff = min(Welch L 기준, 자극) × (HF 대역 안 빈 수 × 0.5). 5분 구간(L=8, 세그먼트 256 이면 빈 16개)이면 M = 0.35 → ±29%(비율 0.71 배 미만 또는 1.41 배 초과면 변화); L 이 크면 바닥 ln 1.25 → ±20%(비율 0.80–1.25). 리포트가 M 을 %와 비율 경계로 찍는다("잡음 마진 ±29% (…)" 줄과 판정 기준 줄).
   - 판정 보류 ①: |ln 비| 가 마진 안 — "판정 보류(HF 변화 |ln비| ≤ 잡음 마진 ±M%)".
   - 판정 보류 ②(자료 부족): HF 고정 < 30 ms² 는 30 으로 놓고 본 |ln 비| 가 마진 안일 때(밖이면 판정하고 주석만), Welch 세그먼트 L < 6, 구간의 RSA 판정불가 우세(호흡당 박동 평균 < 3 또는 판정불가 > 판정), 스펙트럼 없음, 구간 데이터 부족(잘린 뒤 < 2분). 사유를 괄호에 적는다.
2. **"호흡중심 대역 기준 결론 동일 / 상이 / 판정 보류"** — HF 고정의 방향(↑/↓/→)과 호흡중심 대역의 방향(같은 M 으로 판정)이 같으면 "동일", 다르면 "상이". 1행이 자료 부족으로 보류면 2행도 보류.

판정 줄 옆에 Welch L(기준/자극)을 적고, 호흡수와 HF 고정이 같은 방향으로 움직이면 "Hirsch & Bishop 1981 롤오프 방향과 불일치" 한 줄을 붙인다(관찰 방향의 기술일 뿐).
잡음 마진(바닥 ±20%, L·대역 빈 수 기반) · 30 ms² · L ≥ 6 은 문헌 근거 없는 이 툴의 관례다. "동반됨"은 같은 기록에서 두 변화가 함께 관찰됐다는 뜻이며 기전을 말하지 않는다.
RSA 는 호흡수와 깊이 모두에 의존하는데 이 툴은 깊이를 측정하지 않는다(Hirsch & Bishop 1981; Grossman & Taylor 2007).

## 자주 걸리는 것

- **RSA_pv 가 음수**: 위상 지연 의심. `--rsa-lag` 를 확인하고 호흡별.csv 의 `RR최소_위상`·`RR최대_위상` 열로 극값이 어느 위상에 놓였는지 본다(정상은 최소 ≈ 0.4–0.6, 최대 ≈ 0.9–1.1). 부호 반전 장비면 `--invert`.
- **호흡당 박동 < 3**: 그 호흡은 "판정 불가"로 값을 내지 않는다. 빠른 호흡 + 느린 심박에서 흔하다(HR 40·호흡 20/분 = 박동 2/호흡). 구간의 호흡당 박동 평균이 3 미만이거나 판정불가가 판정보다 많으면 "RSA 판정불가 우세"로 판정 보류. 스펙트럼 지표는 그대로 나온다.
- **호기 말 정지가 긴 파형**: 흡기 시작은 정지 구간 안의 잡음 최저점이 아니라 상승 발치 근처로 보정된다(봉우리에서 내려오다 되오름 직전의 누적 최소). σ 0.10 잡음에서도 발치보다 평균 1.5 s 앞에 놓일 수 있어 호흡별 RSA 창은 그만큼 흔들린다 — 호흡수 CV 와 위상 열로 확인.
- **판정 보류(잡음 마진 안)**: 5분 구간은 마진이 ±29%(비율 0.71–1.41)라 HF 가 30% 변해도 보류가 된다. 구간을 길게 잡거나(L↑) `--nperseg 128`(빈 수는 절반, L 은 두 배 — 마진은 같다) 대신 더 긴 기록으로.
- **호흡 ≤ 9회/분 구간**: RSA 파워가 고정 HF(0.15–0.40 Hz) 밖(LF 쪽)으로 이동한다. 리포트가 "고정 HF 는 이 구간의 RSA 를 과소평가" 를 붙인다.
- **3–4회/분 페이싱**: 주기 15–20 s 가 기본 `--max-breath-s 15` 에 걸려 long 아티팩트가 된다 → `--max-breath-s 25`.
- **5분 미만 구간**: 스펙트럼에 "짧음" 플래그(Task Force 1996 의 단기 5분 권장).
- **구간 호흡수 CV > 15%**: 호흡중심 대역의 "평균 중심"이 무의미할 수 있다는 플래그(이봉/불안정). > 40% 는 "호흡 검출 불안정", > 60% 는 exit 3.
- **결맞음이 독립 신호에서도 0 이 아님**: Welch 세그먼트 수 L 에 대해 독립 기대값 ≈ 1/L, null 95% ≈ 1 − 0.05^(1/(L−1)). 리포트에 셋 다 적는다.
