# rsalink 사용법

## 설치

```bash
cd rsalink-호흡심박연동분석
python3 -m pip install -e .        # 또는 설치 없이: python3 -m rsalink ...
rsalink --help
```

Python 3.9 이상, 표준 라이브러리만 사용. 네트워크 접근 없음.

## 입력 파일

### 호흡 (첫 번째 인자)

| 형태 | 형식 | 비고 |
|---|---|---|
| 파형 | `timestamp,value` 두 열 | 값이 클수록 흡기(흉곽 확장). 반대면 `--invert`. 샘플링레이트는 Δt 중앙값으로 추정 |
| 흡기 시작 이벤트 | `timestamp` 한 열 | 파형이 없으면 결맞음·교차상관 제안은 생략되고, 흡기 끝은 주기의 40% 지점으로 가정 |

### RR / IBI (두 번째 인자) — hrvkit 규격 호환

- 값 열 하나. 단위 자동 인식: 중앙값 < 10 → 초, < 300 → bpm, 그 외 → ms.
- 열 자동 탐색(`rr`, `ibi`, `rri`, `interval`, …). 안 잡히면 `--rr-col 이름` 또는 `--rr-col 번호(0부터)`.
- 300–2000 ms 밖 값은 **제외만** 하고 개수를 자백한다. 보정(보간·대체)은 하지 않는다 — 그건 hrvkit 영역.
- 타임스탬프 열이 있어도 박동 시각은 RR 누적으로 만든다(첫 박동 = 0 s 기준).

### 타임스탬프 형식(두 파일 공통)

ISO 8601 (`2026-01-01T09:00:00.250`, 공백 구분 허용) · `HH:MM:SS(.fff)` · epoch 초(≥ 1e9; ms 는 자동 환산) · 시작 기준 초.
모두 "첫 샘플 기준 경과 초"로 바뀐다. 파일 안에서 타임존 유무가 섞이면 거부, 역행이 있으면 거부(추측 정렬 안 함), 중복은 개수를 자백하고 첫 값만 쓴다.
인코딩은 utf-8 / utf-8-sig / cp949 를 차례로 시도한다.

### 두 파일의 시계

호흡과 RR 은 각각 자기 파일의 첫 샘플을 0 s 로 본다. 두 장비의 시작이 다르면 `--resp-offset SEC`(호흡 시각에 더할 초)로
**사람이** 맞춘다. 리포트는 교차상관으로 제안값을 **표시만** 하고 적용하지 않는다(가짜 정렬이 더 위험하다).
`--inspect` 로 두 파일의 절대 시각 차이(ISO/epoch 일 때)를 볼 수 있다.

## 실행

```bash
# 기준선 vs 자극 + 6회/분 페이싱
rsalink 호흡.csv RR.csv --baseline 0:00-5:00 --stimulus 5:00-15:00 --pace 6 --out-dir 결과

# 구간 CSV(start,end,label) 로 여러 조건
rsalink 호흡.csv RR.csv --segments 조건.csv --resp-offset 1.5 --out-dir 결과

# 입력 인식만 확인
rsalink 호흡.csv RR.csv --inspect
```

구간 시각은 `M:SS`, `H:MM:SS`, 또는 초. `--segments` 와 `--baseline/--stimulus` 는 함께 쓸 수 없다.
구간을 하나도 안 주면 전체 기록을 한 구간("전체")으로 분석한다.

### 주요 옵션

| 옵션 | 기본 | 뜻 |
|---|---|---|
| `--min-breath-s` / `--max-breath-s` | 1.5 / 15 | 이 밖의 호흡은 아티팩트(short/long) |
| `--k-mad` | 1.0 | 골(흡기 시작) 돌출 임계 = k × MAD |
| `--smooth-s` | 0.5 | 파형 이동평균 창(초) |
| `--invert` | — | 파형 부호 반전 |
| `--resp-band-halfwidth` | 0.04 | 호흡중심 대역 = 평균 호흡주파수 ± 이 값(Hz) |
| `--nperseg` | 256 | Welch 세그먼트 샘플 수(4 Hz → 64 s, Δf 0.0156 Hz). 기록이 짧으면 자동 축소(최소 64) |
| `--subject` | "" | 조건비교.csv 의 `subject` 열 — 여러 피험자 병합용 |
| `--out-dir` | 없음 | 없으면 터미널 리포트만. 있으면 아래 세 파일 |
| `--quiet` | — | 터미널 리포트 생략 |

## 산출물 (모두 `--out-dir` 안, 경로는 파일 이름만 기록)

| 파일 | 내용 |
|---|---|
| `연동리포트.md` | 커버리지 자백 → 호흡 검출 → RSA → 구간표 → 페이싱 → 조건 비교·판정 두 줄 → Methods/Results(KR/EN) → 근거 6편 → 면책 |
| `호흡별.csv` | 호흡 한 줄: onset/peak/end 시각, 주기, 호흡수, 플래그, 박동 수, 흡기 최소 RR, 호기 최대 RR, RSA_pv, 판정불가 사유 |
| `조건비교.csv` | 구간 한 줄(long 형식): 호흡수 평균·SD, RSA_pv 중앙값·IQR, LF·HF고정·호흡중심 파워, 결맞음, 평균 RR, 페이싱 지표, 플래그 |

여러 피험자를 모을 때는 `--subject ID` 로 실행해 `조건비교.csv` 들을 그대로 이어 붙이면 `subject, segment, …` long 형식이 된다
(statwise / longistat 투입 형태). CSV 는 utf-8-sig(BOM) 이라 엑셀에서 바로 열린다. 문자열 셀이 `= + - @` 로 시작하면 `'` 를 붙여 수식 실행을 막는다.

## 판정 두 줄 읽는 법

1. **"HF 변화가 호흡수 변화와 동반됨 / 비동반"** — HF 고정 파워가 ±20% 밖으로 변했을 때, 호흡수도 (|Δ| ≥ max(1회/분, 기준의 10%)) 변했으면 "동반됨", 안 변했으면 "비동반". HF 자체가 ±20% 안이면 "판정 보류".
2. **"호흡중심 대역 기준 결론 동일 / 상이"** — HF 고정의 방향(↑/↓/→)과 호흡중심 대역의 방향이 같으면 "동일", 다르면 "상이".

"동반됨"은 같은 기록에서 두 변화가 함께 관찰됐다는 뜻이며 방향이나 기전을 말하지 않는다.
RSA 는 호흡수와 깊이 모두에 의존하는데 이 툴은 깊이를 측정하지 않는다(Grossman & Taylor 2007; Hirsch & Bishop 1981).

## 종료 코드

| 코드 | 뜻 |
|---|---|
| 0 | 정상 |
| 2 | 입력·인자 오류: 파일 없음/형식/인코딩, 타임스탬프 역행·tz 혼재, `--out-dir` 이 기존 파일, 쓰기 권한 없음, 산출물 경로가 심볼릭링크 또는 하드링크 |
| 3 | 신뢰 불가(리포트는 그래도 출력): 유효 호흡 < 60% **또는** 사용 가능 구간 < 2분 **또는** RR 제외 > 20% |

## 자주 걸리는 것

- **RSA_pv 가 음수**: RR 극값이 흡기/호기 창과 어긋난 것. `--resp-offset`(제안값은 리포트에 표시) 또는 `--invert` 를 확인.
- **호흡당 박동 < 3**: 그 호흡은 "판정 불가"로 값을 내지 않는다. 빠른 호흡 + 느린 심박에서 흔하다. 스펙트럼 지표는 그대로 나온다.
- **호흡 ≤ 9회/분 구간**: RSA 파워가 고정 HF(0.15–0.40 Hz) 밖(LF 쪽)으로 이동한다. 리포트가 "고정 HF 는 이 구간의 RSA 를 과소평가" 를 붙인다.
- **5분 미만 구간**: 스펙트럼에 "짧음" 플래그(Task Force 1996 의 단기 5분 권장).
- **결맞음이 독립 신호에서도 0 이 아님**: Welch 세그먼트 수 L 에 대해 독립 기대값 ≈ 1/L. 리포트에 L 과 1/L 을 같이 적는다.
