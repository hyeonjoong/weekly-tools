# rsalink — 호흡·심박 연동 분석

**실측 호흡 신호**(밴드/비접촉 파형 또는 흡기 시작 이벤트)와 **RR 간격**을 함께 읽어
호흡별 호흡수 · **RSA peak-valley**(Grossman 1990) · **고정 HF 대역 vs 호흡중심 대역** 파워 ·
호흡–심박 **결맞음** · **페이싱 동조율**을 계산하고, 조건(기준선 vs 자극)별 비교표로
**"HRV 변화가 호흡 변화와 함께 갔는가"** 를 숫자로 보여주는 오프라인 CLI.
인과를 주장하지 않는다 — 함께 변했는지, 호흡을 고려하면 다른 그림이 나오는지를 보여주고 끝난다.

**EN** — Offline CLI that reads a measured respiration signal (band/contactless waveform, or inspiration-onset
events) together with RR intervals and reports breath-by-breath rate, peak-valley RSA (Grossman 1990),
fixed-HF vs respiration-centred band power, respiration–RR coherence, and paced-breathing entrainment, with a
baseline-vs-stimulus comparison table that answers one question: *did the HRV change go together with a change
in breathing?* It makes no causal claim.

Python 3.9+, 표준 라이브러리만, 네트워크 0, 입력은 읽기 전용, 산출물은 `--out-dir` 안에만.

## 왜

> 리뷰어: "HF-HRV 가 올랐다는데, 그건 자극 중에 호흡이 느려져서 아닌가요? 호흡수를 통제했습니까?"

RR 만 받는 HRV 툴은 호흡을 RR 스펙트럼에서 *추정*한다. 6회/분 호흡의 RSA 피크와, 압반사 공명 기전으로 통상
해석되는 0.1 Hz 부근 피크(Lehrer & Gevirtz 2014, 기전 리뷰)는 호흡을 실측하지 않으면 RR 만으로는 구분할 수 없다.
rsalink 는 실측 호흡을 받아 그 질문에 표 한 장으로 답한다.

| 툴 | 입력 | 하는 일 | 안 하는 일 |
|---|---|---|---|
| **rsalink** (이 툴) | 호흡 파형/이벤트 + RR | 호흡별 RSA_pv, 고정 HF vs 호흡중심 대역, 결맞음, 페이싱 동조, 조건별 "동반/비동반" 판정 | HRV 전체 패널, 이상박동 보정, 시계 자동 정렬 |
| hrvkit | RR 만 | SDNN·RMSSD·LF/HF·비선형 등 HRV 패널, 이상박동 보정 | 호흡 실측 연동 |
| agreestat | 두 측정법의 짝지은 값 | Bland–Altman·ICC·kappa 등 측정 일치도 | 생리 신호 처리 |

RR 입력 규격만 hrvkit 과 호환한다(`examples/session_20min.csv` 파싱 테스트).

## 빠른 시작

```bash
python3 -m pip install -e .
rsalink 호흡.csv RR.csv --baseline 0:00-5:00 --stimulus 5:00-15:00 --pace 6 --out-dir 결과
rsalink 호흡.csv RR.csv --segments 조건.csv --resp-offset 1.5 --out-dir 결과
rsalink 호흡.csv RR.csv --inspect
bash 실행.command        # 합성 예시(examples/paced_6bpm) 실행
```

입력 형식·옵션·산출물 열 규칙은 [사용법.md](사용법.md). 호흡 파일이 한 열이면 흡기 시작 이벤트, 두 열이면 파형으로
자동 인식한다 — `--events` 같은 플래그는 없다.

'동반됨'은 두 변화가 같은 기록에서 함께 관찰됐다는 뜻이며 기전을 말하지 않는다.

읽는 법: 페이싱 예시에서 고정 HF 는 *내려갔지만*(RSA 파워가 0.1 Hz 로 이동해 0.15–0.40 Hz 밖으로 나감)
호흡중심 대역은 *올라갔다*. 고정 HF 만 보면 "HF 감소"로 읽히고, 호흡을 고려하면 반대 그림이다.
이 툴이 보여주는 것은 거기까지다.

## 무엇을 계산하나

| 지표 | 방법 |
|---|---|
| 호흡 검출 | 스파이크 클리핑(\|z\| > 10·MAD) → 선형 디트렌드 → 이동 중앙값(2×max-breath-s = 30 s) 기준선 제거 → 0.5 s 이동평균 → 국소 최솟값 = 골. 채택 임계 = max(k × 잡음 MAD·1.4826, 0.15 × **60 s 창별** (p95−p5)), k 기본 3.0 — 잡음 MAD 는 신호가 아니라 평활 잔차의 MAD(호기 말 정지 파형에서 신호 MAD 가 붕괴하는 것을 막는다); 바닥을 창별로 두는 것은 진폭 1.0 조건 뒤의 진폭 0.12 조건(8:1)이 전역 바닥에 지워지지 않게 하기 위해서다. 최소 간격 1.5 s. 흡기 시작 = 봉우리에서 골 쪽으로 내려오다 신호가 누적 최소보다 max(3·σ_smooth, 흡기 진폭의 10%) 이상 되오르기 직전의 누적 최소 자리(매끈한 파형은 골 그대로, 평탄한 정지 구간은 상승 발치 근처). 호흡 = 흡기 시작 → 다음 흡기 시작, 사이 최댓값 = 흡기 끝 |
| RSA_pv | 호흡마다 호기 창 최대 RR − 흡기 창 최소 RR (ms). RR 값은 **간격 중점 시각**에 배정하고, 흡기/호기 창을 `--rsa-lag`(기본 1.0 s) 만큼 뒤로 밀어 호흡→RR 생리적 위상 지연을 허용한다. 호흡당 박동 < 3 이면 판정 불가. 극값이 놓인 호흡 위상(0–1)을 호흡별.csv 에 기록. 중앙값·IQR |
| 스펙트럼 | RR 4 Hz 선형 보간(격자는 데이터 끝까지만) → 자체 radix-2 FFT → Welch(Hann, 50% 겹침, 64 s 세그먼트, 세그먼트별 평균 제거). LF 0.04–0.15, HF 고정 0.15–0.40, 호흡중심 = 실측 평균 호흡주파수 ±0.04 Hz. 구간별 세그먼트 길이·Δf·L 을 표기 |
| 결맞음 | 같은 Welch 세그먼트로 호흡 파형과 RR 의 magnitude-squared coherence, 호흡주파수에 가장 가까운 단일 빈. 독립 기대 1/L 과 null 95% = 1 − 0.05^(1/(L−1)) 병기 |
| 페이싱 | 목표 ±10% 안 호흡 비율, 연속 5호흡 첫 동조 시각, 동조 중 호흡수 SD |
| 판정 | 1행 "HF 변화가 호흡수 변화와 **동반됨 / 비동반 / 판정 보류(HF 변화 \|ln비\| ≤ 잡음 마진 ±M%) / 판정 보류(자료 부족: HF < 30 ms² 바닥, L < 6, RSA 판정불가 우세, 스펙트럼 없음, 구간 데이터 부족)**", 2행 "호흡중심 대역 기준 결론 **동일 / 상이 / 판정 보류**". HF 변화 = \|ln(자극/기준)\| > M, M = max(ln 1.25, 1.96·√(2/L_eff)), L_eff = min(Welch L)·(HF 대역 빈 수 × 0.5) — 5분 구간(L=8, 빈 16)이면 M = 0.35(±29%, 비율 0.71–1.41), L 이 크면 바닥 ±20%(비율 0.80–1.25). 호흡중심 대역의 방향도 같은 M 으로 본다. 판정어는 이 목록 밖으로 나가지 않는다 |

## 한계

- **호흡 깊이 미측정.** 파형 진폭은 비보정이라 일회호흡량을 말할 수 없다. RSA 는 호흡수와 깊이 모두에 의존한다(Hirsch & Bishop 1981; Grossman & Taylor 2007). 깊이 변화는 이 툴이 볼 수 없는 교란 후보다.
- **RSA_pv 의 위상 지연 허용치와 박동 이산화.** 호흡→RR 지연 τ 를 `RR_i = m − A·sin(θ(t_i − τ))`(t_i = 박동 시각)로 넣은 합성에서 RSA_pv 중앙값 / 2A 의 실측 회복률(사인 호흡, A = 40 ms, 300 s):

  | 호흡수 | RR | τ = 0 | τ = 0.5 s | τ = 1.0 s | τ = 1.5 s |
  |---|---|---|---|---|---|
  | 6/분 | 900 ms | 0.99 | 0.99 | 0.99 | 0.94 |
  | 12/분 | 900 ms | 0.95 | 0.95 | 0.95 | 0.76 |
  | 15/분 | 900 ms | 0.93 | 0.93 | 0.93 | 0.64 |
  | 20/분 | 900 ms | 0.60 | 0.83 | 0.85 | 0.39 |
  | 12/분 | 500 ms | 0.99 | 0.99 | 0.99 | 0.79 |
  | 15/분 | 500 ms | 0.98 | 0.98 | 0.97 | 0.66 |

  기본 `--rsa-lag 1.0` 기준(라운드 0 의 끝 박동 배정·lag 0 은 12/분 τ 0.5 에서 0.33, τ 1.0 에서 −0.24 였다). τ = 0 은 두 방향 이산화 손실만 남는 바닥이며 호흡당 박동이 적을수록(15/분·RR 900 → 4.4개) 크다. 20/분 이상에서 지연이 거의 없으면 `--rsa-lag 0.5`. 호흡당 박동 수를 표에 같이 적는다.
- **잡음 큰 파형.** 임계는 잡음 MAD 기반(k 3.0)에 진폭 바닥(0.15·60 s 창별 (p95−p5))을 더한 것이라 정지형 파형에서도 6/분·σ 0.10(SNR ≈ 9 dB)을 복원한다: 흡기 1.0 s·τ 0.9 s 의 뾰족한 정지형 20 seed 에서 6.0–6.3/분·유효 ≥ 96%(상승 발치 보정 전에는 정지 구간 안의 잡음 최저점이 흡기 시작이 되어 주기가 4–14 s 로 흔들리고 rate 평균이 6.2–6.9/분까지 올라갔다). 보정 뒤에도 σ 0.10 에서 흡기 시작은 상승 발치에서 평균 1.5 s(최대 5 s) 앞에 놓일 수 있다 — 호흡수는 맞지만 RSA 창은 그만큼 흔들린다. σ 0.3(SNR ≈ −1 dB)부터 사인 파형도 6.4/분으로 조금 더 센다. 검출 호흡 수·아티팩트 비율·호흡수 CV 를 항상 찍고, 구간 CV > 40% 는 "불안정" 플래그, > 60% 는 exit 3. `--k-mad`, `--smooth-s` 조정.
- **시계 정렬은 사람이.** `--resp-offset` 만 적용, 교차상관 제안값은 표시만(±5 s 탐색, 호흡 주기 배수만큼 모호). 오프셋 오차는 지연 허용치를 잠식한다 — 실측(τ 0.7 s, RR 900, 기본 lag): 오차 −1.0 s 에서 회복 12/분 0.60·15/분 0.42, −1.5 s 에서 15/분 부호 반전(−0.28); +1.0 s 까지는 ≥ 0.86. 결맞음은 오프셋에 둔감하므로 대조 지표로 병기.
- **결맞음 바이어스.** 독립 신호도 ≈ 1/L(세그먼트 수). L, 1/L, null 95% 를 같이 표시.
- **판정 임계는 관례.** 잡음 마진(바닥 ±20%, 1.96·√(2/L_eff); L_eff = min(L)·HF 빈 수/2 — Hann 50% 겹침의 빈·세그먼트 상관을 "절반이 독립"으로 놓은 근사), 30 ms² 바닥, L ≥ 6 은 문헌 근거 없는 이 툴의 관례다(리포트에 명시). 실측: 호흡 12/분 고정·RSA 3 ms·RR 백색잡음 σ 15–30 ms 의 5분/5분 합성 20 seed 에서 옛 ±20% 규칙은 5/20(25%)을 "변화"로 판정했고, 마진 뒤 1/20(5%); 로그비 RMS 0.176 vs 이론 √(2/64) = 0.177. 5분 구간의 마진은 ±29%(비율 0.71–1.41)라 실제 변화가 이보다 작으면 판정 보류가 나온다.
- **구간 호흡당 박동이 적으면 판정 보류.** 구간의 호흡당 박동 평균 < 3 이거나 RSA 판정불가가 판정보다 많으면 "RSA 판정불가 우세"로 보류한다(HR 40·호흡 20/분 = 박동 2/호흡). 스펙트럼 지표는 그대로 나온다.
- **이상박동 보정 없음.** 300–2000 ms 밖과 파싱 실패 셀은 제외만(개수 자백, 시간축은 중앙값 RR 로 진행). 보정은 hrvkit 영역.
- 수면단계·압반사 이득·전달함수(혈압 필요)·HRV 전체 패널은 범위 밖.

## 면책

이 툴은 두 신호가 **함께 변했는지**를 숫자로 보여줄 뿐, 한쪽이 다른 쪽을 일으켰다는 주장을 하지 않는다(비인과).
의학적 진단·치료 판단에 쓰는 도구가 아니다(비진단). 예시 데이터는 전부 합성이며 어떤 사람의 기록도 아니다.
