# rsalink — 호흡·심박 연동 분석

**실측 호흡 신호**(밴드/비접촉 파형 또는 흡기 시작 이벤트)와 **RR 간격**을 함께 읽어
호흡별 호흡수 · **RSA peak-valley**(Grossman 1990) · **고정 HF 대역 vs 호흡중심 대역** 파워 ·
호흡–심박 **결맞음** · **페이싱 동조율**을 계산하고, 조건(기준선 vs 자극)별 비교표로
**"HRV 변화가 호흡 변화와 함께 갔는가"** 를 숫자로 보여주는 오프라인 CLI.
인과를 주장하지 않는다 — 함께 변했는지, 호흡을 고려하면 다른 그림이 나오는지를 보여주고 끝난다.

**EN** — Offline CLI that reads a measured respiration signal (band/contactless waveform, or inspiration-onset
events) together with RR intervals and reports breath-by-breath rate, peak-valley RSA (Grossman 1990),
fixed-HF vs respiration-centred band power, respiration–RR coherence, and paced-breathing entrainment, with a
baseline-vs-stimulus comparison table that answers one question: *did the HRV change go together with a change
in breathing?* It makes no causal claim.

Python 3.9+, 표준 라이브러리만, 네트워크 0, 입력은 읽기 전용, 산출물은 `--out-dir` 안에만.

## 왜

> 리뷰어: "HF-HRV 가 올랐다는데, 그건 자극 중에 호흡이 느려져서 아닌가요? 호흡수를 통제했습니까?"

RR 만 받는 HRV 툴은 호흡을 RR 스펙트럼에서 *추정*한다. 6회/분 호흡의 RSA 피크와 압반사 기원의 LF 피크는
호흡을 실측하지 않으면 RR 만으로는 구분할 수 없다. rsalink 는 실측 호흡을 받아 그 질문에 표 한 장으로 답한다.
HRV 전체 패널(SDNN·RMSSD·비선형)은 계산하지 않는다 — hrvkit 영역. RR 입력 규격만 hrvkit 과 호환한다.

## 빠른 시작

```bash
python3 -m pip install -e .
rsalink 호흡.csv RR.csv --baseline 0:00-5:00 --stimulus 5:00-15:00 --pace 6 --out-dir 결과
rsalink 호흡.csv RR.csv --segments 조건.csv --resp-offset 1.5 --out-dir 결과
rsalink 호흡.csv RR.csv --inspect
bash 실행.command        # 합성 예시(examples/paced_6bpm) 실행
```

입력 형식·옵션·산출물 열 규칙은 [사용법.md](사용법.md).

## 실제 출력 (examples/paced_6bpm — 100% 합성: 12회/분 5분 → 6회/분 페이싱 10분)

```
## ① 커버리지 자백 (결과보다 먼저)

| 항목 | 값 |
|---|---|
| 호흡 샘플링레이트(Δt 중앙값) | 10.00 Hz |
| 불균등 샘플링(Δt 가 중앙값 ±20% 밖) | 0.0% |
| 호흡 갭(Δt > 3×중앙값) | 0건, 합계 0.0 s |
| 두 신호가 겹치는 사용 가능 구간 | 15.0분 |
| RR 단위 자동 인식 / 열 | ms / `rr_ms` |
| RR 300–2000 ms 밖 제외 | 0/1001 (0.0%) — 보정 없이 제외만 |
| 검출 호흡 / 유효 호흡 | 120 / 120 (아티팩트 0.0%: 없음) |
| 호흡당 박동 수(평균) | 8.2 — 3 미만 호흡은 RSA 판정 불가 (0건) |
| 교차상관 제안 오프셋(표시만, 미적용) | +0.00 s (r = -0.94) |

## ④ 구간별 표

| 구간 | 길이 | 호흡수(회/분) | RSA_pv 중앙값 [IQR] (ms) | n/판정불가 | LF (ms²) | HF 고정 0.15–0.40 (ms²) | 호흡중심 ±0.04 Hz (ms²) | 결맞음 | 평균 RR (ms) | 플래그 |
|---|---|---|---|---|---|---|---|---|---|---|
| 기준선 | 0:00.0–5:00.0 | 12.10 ± 0.90 (n=61) | 40.6 [31.4–49.2] | 61/0 | 33.0 | 275.7 | 269.5 [0.162–0.242] | 0.98 (L=8, 독립 기대 0.12) | 899.3 |  |
| 자극 | 5:00.0–15:00.0 | 6.10 ± 0.24 (n=59) | 87.8 [76.6–94.0] | 59/0 | 1027.9 | 11.2 | 1027.2 [0.062–0.142] | 0.98 (L=17, 독립 기대 0.06) | 899.0 | 호흡 ≤9/분: 고정 HF 는 이 구간의 RSA 를 과소평가 |

## ⑤ 페이싱 동조 (목표 6 회/분, ±10%)

| 구간 | 동조 호흡 비율 | 첫 5연속 동조 시각 | 동조 중 호흡수 SD | 동조 호흡 수 |
|---|---|---|---|---|
| 기준선 | 1.6% (1/61) | 없음 | — | 0 |

| 지표 | 기준선 | 자극 | Δ | 비율 |
|---|---|---|---|---|
| 호흡수(회/분) | 12.10 | 6.10 | -6.00 | 0.50 |
| RSA_pv 중앙값(ms) | 40.60 | 87.80 | 47.20 | 2.16 |
| LF(ms²) | 32.98 | 1027.95 | 994.97 | 31.17 |
| HF 고정(ms²) | 275.66 | 11.23 | -264.43 | 0.04 |
| 호흡중심(ms²) | 269.48 | 1027.22 | 757.74 | 3.81 |
| 결맞음 | 0.98 | 0.98 | -0.00 | 1.00 |
| 평균 RR(ms) | 899.25 | 899.00 | -0.25 | 1.00 |

- HF 변화가 호흡수 변화와 **동반됨** (HF 고정 ↓, 호흡수 12.1→6.1/분 변화)
- 호흡중심 대역 기준 결론 **상이** (HF 고정 ↓ vs 호흡중심 ↑)
```

같은 툴로 `examples/sham`(호흡 12회/분 고정, RSA 진폭만 상승)을 돌리면 판정이
**비동반** / **동일**(HF 고정 ↑, 호흡중심 ↑, 호흡수 12.2→12.2) 로 바뀐다 — 고정 HF 상승이 호흡수 변화 없이 나타난 경우.

읽는 법: 페이싱 예시에서 고정 HF 는 *내려갔지만*(RSA 파워가 0.1 Hz 로 이동해 0.15–0.40 Hz 밖으로 나감)
호흡중심 대역은 *올라갔다*. 고정 HF 만 보면 "부교감 지표 감소"로 읽히고, 호흡을 고려하면 반대 그림이다.
이 툴이 보여주는 것은 거기까지다.

## 무엇을 계산하나

| 지표 | 방법 |
|---|---|
| 호흡 검출 | 선형 디트렌드 → 이동 중앙값(30 s) 기준선 제거 → 0.5 s 이동평균 → 국소 최솟값(돌출 ≥ k·MAD, 최소 간격 1.5 s) = 흡기 시작. 호흡 = 흡기 시작 → 다음 흡기 시작, 사이 최댓값 = 흡기 끝 |
| RSA_pv | 호흡마다 호기 창 최대 RR − 흡기 창 최소 RR (ms). 호흡당 박동 < 3 이면 판정 불가. 중앙값·IQR |
| 스펙트럼 | RR 4 Hz 선형 보간 → 자체 radix-2 FFT → Welch(Hann, 50% 겹침, 64 s 세그먼트). LF 0.04–0.15, HF 고정 0.15–0.40, 호흡중심 = 실측 평균 호흡주파수 ±0.04 Hz |
| 결맞음 | 같은 Welch 세그먼트로 호흡 파형과 RR 의 magnitude-squared coherence, 호흡주파수 빈 |
| 페이싱 | 목표 ±10% 안 호흡 비율, 연속 5호흡 첫 동조 시각, 동조 중 호흡수 SD |
| 판정 | "HF 변화가 호흡수 변화와 동반됨/비동반", "호흡중심 대역 기준 결론 동일/상이" — 두 단어 구조로 고정 |

## 한계

- **호흡 깊이 미측정.** 파형 진폭은 비보정이라 일회호흡량을 말할 수 없다. RSA 는 호흡수와 깊이 모두에 의존한다(Grossman & Taylor 2007; Hirsch & Bishop 1981). 깊이 변화는 이 툴이 볼 수 없는 교란 후보다.
- **peak-valley 의 박동 이산화.** 호흡당 박동이 적으면(12회/분·심박 67 → ≈5.6) 극값을 놓쳐 RSA_pv 가 작게 나온다(합성 검증: 2A=50 → 40.6). 호흡당 박동 수를 표에 같이 적는다.
- **잡음 큰 파형.** SNR ≈ 6 dB 부터 느린 호흡에서 골 근처 잡음을 호흡으로 더 셀 수 있다. 검출 호흡 수·아티팩트 비율을 항상 찍는다. `--k-mad`, `--smooth-s` 조정.
- **시계 정렬은 사람이.** `--resp-offset` 만 적용, 교차상관 제안값은 표시만. 오프셋 1 s 면 위상이 밀려 RSA_pv 가 줄 수 있다. 결맞음은 오프셋에 둔감하므로 대조 지표로 병기.
- **결맞음 바이어스.** 독립 신호도 ≈ 1/L(세그먼트 수). L 과 1/L 을 같이 표시.
- **이상박동 보정 없음.** 300–2000 ms 밖은 제외만(개수 자백). 보정은 hrvkit 영역.
- 수면단계·압반사 이득·전달함수(혈압 필요)·HRV 전체 패널은 범위 밖.

## 종료 코드

0 정상 / 2 입력·인자 오류(파일·형식·`--out-dir` 이 파일·권한·심볼릭/하드링크 타깃) / 3 신뢰 불가(유효 호흡 <60% 또는 사용 가능 구간 <2분 또는 RR 제외 >20%, 리포트는 출력).

## 면책

이 툴은 두 신호가 **함께 변했는지**를 숫자로 보여줄 뿐, 한쪽이 다른 쪽을 일으켰다는 주장을 하지 않는다(비인과).
의학적 진단·치료 판단에 쓰는 도구가 아니다(비진단). 예시 데이터는 전부 합성이며 어떤 사람의 기록도 아니다.
