# 사용법 (빠른 시작)

## 가장 쉬운 방법
- 이 폴더의 **`실행.command` 더블클릭** → 예제 5개(각성/알파 트레이스, 깊은수면/델타
  트레이스, 다채널 CSV, EDF 기록, 그리고 **투약 세션**(전원잡음 제거 + 기저 대비 변화))로
  결과가 바로 나옵니다. 알파 우세 ↔ 델타(SWA) 우세가
  뒤집히는 것과, 채널별 1/f 지수가 복원되는 것을 확인하세요.

## 내 데이터로 돌리기 (터미널)

먼저 한 번만 설치(선택):
```bash
cd ~/Downloads/02_프로젝트/깃헙/eegband-뇌파대역분석
python3 -m pip install -e .
```

### 1) 값 열만 있는 CSV (표본화율을 직접 지정)
CSV가 이런 모양일 때:
```
eeg_uv
13.28
17.63
...
```
```bash
eegband 내데이터.csv --fs 128
# 설치 안 했으면:
python3 -m eegband.cli 내데이터.csv --fs 128
```
`--fs`를 빼먹으면 128 Hz로 가정하고 **경고**합니다(표본화율이 틀리면 모든 주파수가 틀립니다).

### 2) 시간 열이 함께 있는 CSV (fs 자동 추정)
CSV가 이런 모양일 때:
```
time_s,eeg_uv
0.000000,12.3
0.007812,11.8
...
```
```bash
eegband 내데이터.csv --time time_s --value eeg_uv
# 값/시간 열 이름은 대개 자동 감지되므로 그냥: eegband 내데이터.csv
```
시간 열로 fs를 추정하고, `--fs`를 **명시**했는데 1% 넘게 다르면 경고 후 **추정값**을 씁니다.

### 3) 채널이 여러 개인 CSV (와이드) / EDF 기록
```bash
eegband 내데이터.csv --list-channels          # 무슨 열/채널이 있는지 먼저 보기
eegband 내데이터.csv --channels all --fs 256  # 모든 채널
eegband 내데이터.csv --channels Fp1,Cz        # 고른 채널만
eegband 내기록.edf --channels all --epoch 30  # EDF는 fs를 헤더에서 읽음
```
채널마다 리포트가 나오고, 마지막에 **비교표**(총파워·대역%·우세대역·SEF·1/f 지수)가 붙습니다.

### 4) 여러 파일 한 번에 (코호트)
```bash
eegband 피험자*.csv --fs 128 --epoch 30 --csv > cohort.csv
```
`series`(파일/채널 이름)·`source_file` 열이 붙은 한 장의 표로 나옵니다. 일부 파일이
잘못돼도 나머지는 분석되고, 실패한 파일만 화면에 보고됩니다.

### 5) 에폭(구간)별로 보기
```bash
eegband 내데이터.csv --fs 128 --epoch 30
```
30초 에폭마다 대역파워·피크·SEF·1/f 지수를 표로 내고, **SWA density**(delta 우세 에폭 비율),
요약통계(mean±SD, SEM, 95% CI, **자기상관 보정 CI**, 중앙값·IQR), 그리고
**시간 추세**(Mann–Kendall 검정 + Theil–Sen 기울기)를 냅니다.

### 6) 긴 기록에서 일부 구간만
```bash
eegband 내기록.edf --start 3600 --duration 600   # 1시간 지점부터 10분
```
EDF는 그 구간의 레코드만 읽어서 빠릅니다.

### 7) 전원(50/60 Hz) 잡음 확인·제거
```bash
eegband 내데이터.csv --fs 256                 # 기본: 자동 판별해서 "보고"만 함
eegband 내데이터.csv --fs 256 --notch         # 검출된 전원잡음(+고조파)을 빼고 계산
eegband 내데이터.csv --fs 256 --line-freq 60  # 50/60 자동판별 대신 직접 지정
eegband 내데이터.csv --fs 256 --line-freq off # 확인 자체를 끄기
```
임상 기록에는 거의 항상 50 Hz(유럽·한국 일부 장비) 또는 60 Hz(한국·미국 계통) 전원잡음이
섞입니다. ⚠ **기본 gamma 는 30–45 Hz 라서 50/60 Hz 를 포함하지 않습니다** — 즉 기본 설정에서는
`--notch` 를 써도 대역파워가 **바뀌지 않고**, 리포트도 `← (모든 대역 밖 / outside every
reported band)` 이라고 표시합니다(잡음 자체는 기록 품질 지표로 여전히 보고합니다).
오염을 실제로 보려면 `--bands 'delta:0.5-4,theta:4-8,alpha:8-13,beta:13-30,gamma:30-90'`
처럼 gamma 를 넓히세요. 기본값(`auto`)은 50/60 중 어느 쪽인지
자동으로 고르고 **주변 배경 대비 몇 배인지**와 **µV² 단위 초과분**을 [0] 신호 품질 절에
표로 보고합니다(값은 바꾸지 않음). `--notch`를 주면 그 창(기본 ±1 Hz, `--line-bw`로 변경)을
**스펙트럼 보간**으로 메운 뒤 모든 대역파워·SEF·엔트로피·1/f 적합을 계산합니다.
시간영역 필터가 아니라 PSD 위에서 처리하므로 **필터 링잉·위상 왜곡·경계 효과가 없습니다.**

> **에일리어싱 주의**: `fs`가 낮아 전원 주파수가 Nyquist 위에 있으면 잡음은 사라지지 않고
> **더 낮은 주파수로 접혀 들어옵니다**(예: fs=100 Hz에서 60 Hz → 40 Hz). 이 경우 리포트가
> "ALIAS"라고 명시하므로, 그 주파수의 피크를 뇌 활동으로 오독하지 마세요.
>
> 다만 **접힌 위치는 진짜 리듬과 구별할 수 없습니다** (fs=80 Hz면 50 Hz의 3고조파가 정확히
> 10 Hz = 알파 자리). 그래서 기본값 `auto` 는 접힌 고조파를 **스스로 제거하지 않고 경고만**
> 합니다. 정말 제거하려면 `--line-freq 50` 처럼 전원 주파수를 직접 지정하세요 — 그 자리의
> 진짜 뇌 활동도 함께 지워집니다.

### 8) 기저(baseline) 대비 변화 — 약동학/약력학용
```bash
eegband 투약기록.csv --fs 256 --epoch 30 --baseline 600
```
처음 600초(=투약 전)를 **그 피험자 자신의 기저**로 잡고, 이후 에폭들과 지표별로 비교합니다.
피험자간 분산이 큰 절대 대역파워 대신 **"자기 기저 대비 얼마나 변했나"** 를 보는 것이
약력학 분석의 표준이며, 결과는 `[7] 기저 대비 변화` 절에 이렇게 나옵니다:

- `baseline` / `post` 평균, 차이 **Δ**, **Δ%**, 차이의 **95% CI**
- **Hedges' g** (소표본 보정 표준화 효과크기)
- **p** (Welch t-검정) 와 **q(FDR)** (Benjamini–Hochberg 다중비교 보정; `*` = q<0.05)

연속 에폭은 서로 독립이 아니므로 각 군의 분산을 **AR(1) 유효표본수** `n_eff = n(1−ρ̂)/(1+ρ̂)`
로 나눕니다 — **SE·95% CI·자유도가 모두** 보정됩니다. 다만 보정 폭은 ρ̂ 와 에폭 수에 달려
있어, ρ̂ ≤ 0 이거나 창이 짧으면 **거의 0** 일 수 있습니다(`n_eff` 하한은 2). 표의 `n_eff` 열이
`n` 과 같으면 보정이 실제로는 일어나지 않은 것이니 그대로 읽으세요.

⚠ **Hedges' g 해석 주의**: 이 g 는 **한 기록의 에폭간 변동**으로 표준화한 값입니다.
에폭 변동이 작으면 g 가 수십까지 나오며, 문헌의 **피험자간 g 와 직접 비교할 수 없습니다**.

기본 대역에서는 SWA 가 곧 delta 대역이라 `swa_*` 와 `delta_*` 는 **같은 검정**입니다.
이런 구조적 중복은 FDR 가족(m)에서 한 번만 세고 q 를 공유합니다(표의 `BH-FDR family m` 참고).

> 이것은 **한 기록 안의 전·후 비교**입니다. 위약 대조나 피험자간 추론이 아니며, 시간에
> 따른 자연 변화(각성도 저하·수면 진행)와 약효를 구분하지 못합니다. 집단 결론은
> `--csv-summary` 로 뽑은 피험자별 Δ/Δ%를 별도 도구에서 비교하세요.

## 결과 읽는 법
- **[0] 신호 품질**: 진폭 범위·RMS와 함께 클리핑(레일 고정)·평탄 구간·보간 비율. ADC 포화나
  리드 탈락, 과도한 결측이 있으면 ⚠ 경고로 알려줍니다(분석 자체는 바꾸지 않음).
  같은 절에 **전원(50/60 Hz) 잡음** 진단이 붙습니다: 어느 주파수인지, 배경 대비 몇 배인지,
  초과분이 몇 µV²이며 **어느 대역을 오염시키는지**. `--notch` 를 쓰면 제거되었다고 명시합니다.
- **[1] 대역파워**: delta/theta/alpha/beta/gamma의 절대(µV²)·상대(%) 파워와 **대역 내 피크
  주파수**. delta 줄에 `← SWA` 표시.
- **[2] 슬로우파 활동(SWA)**: delta(0.5–4 Hz) 파워 — BELL-001 슬로우파 종말점. 우세대역이
  delta면 "slow-wave/delta dominant".
- **[3] 스펙트럼 요약**: 피크 주파수, SEF95(누적 95% 주파수), **스펙트럼 엔트로피**(1=평탄,
  0=단일 리듬), **알파 피크(IAF)**, 총파워(0.5–45 Hz).
- **[4] 비주기(1/f) 배경**: `exponent`(클수록 급한 배경 — 마취·수면깊이·약물에 민감),
  `offset`, `R²`, 그리고 **배경을 뺀 진동성 파워 `osc`** 와 평탄화 스펙트럼에서 찾은
  대역 피크. 대역파워가 "배경 변화" 때문에 움직인 것인지 "진짜 리듬" 때문인지 구분할 때 봅니다.
- **[5] 대역비**: theta/alpha, delta/beta, 느림지수 (delta+theta)/(alpha+beta).
- **[6] 에폭별**: 에폭 표 + SWA density + 종말점 요약 + 시간 추세.
- **[7] 기저 대비 변화**: `--baseline` 을 준 경우에만. 지표별 기저/이후 평균, Δ, Δ%,
  95% CI, Hedges' g, p, FDR 보정 q. 자기상관 보정된 자유도를 씁니다.
- **[비교]**: 채널/파일이 2개 이상일 때 마지막에 붙는 한 줄 요약표.

## 자주 쓰는 옵션
- `--fs 256` : 표본화율 바꾸기 (미지정 시 128 가정 + 경고)
- `--channels all` / `--channels Fp1,Cz` : 다채널 분석, `--list-channels` : 목록만 보기
- `--epoch 30` : 30초 에폭 분석 (+ 요약·추세)
- `--start 60 --duration 300` : 구간만 분석
- `--nperseg 1024` : Welch 세그먼트 길이(표본) 직접 지정 (주파수 분해능 df = fs/nfft,
  nfft 는 nperseg 이상의 가장 작은 2의 거듭제곱)
- `--detrend linear` : 느린 드리프트(땀·전극 이동)를 세그먼트별 직선으로 제거 → delta 누설 방지
- `--average median` : 세그먼트 중앙값 평균(편향보정 포함) — 움직임/근전위 스파이크에 강건
- `--max-amp 150` : 최대 |진폭| 150 µV 초과 에폭을 아티팩트로 제외(SWA 요약 보호)
- `--max-grad 40` : 인접 표본 변화량 40 µV 초과 에폭 제외(진폭 한계 안의 급격한 스파이크)
- `--line-freq auto|off|60` : 전원잡음 주파수 (기본 auto = 50/60 자동판별 후 보고만)
- `--notch` : 검출된 전원잡음과 고조파를 스펙트럼 보간으로 제거한 뒤 대역파워 계산
- `--line-bw 2` : 전원잡음 창의 반폭(Hz, 기본 1.0) — 잡음이 넓게 퍼졌을 때 키우세요
- `--baseline 600` : 처음 600초를 기저로 잡아 이후 에폭과 비교 (`--epoch` 필요)
- `--aperiodic off` / `--fit-range 2-45` : 1/f 적합 끄기 / 적합 범위 바꾸기
- `--swa-band 0.5-4` : SWA 대역을 명시 (커스텀 `--bands` 에 'delta' 가 없을 때 필요)
- `--bands 'slow:0.5-2,delta:2-4,...'` : 대역 경계 재정의
- `--sef 90` : SEF90 등 백분위 변경
- `--json` : 다른 도구에 넘기기 좋은 JSON 출력
- `--csv` : 대역파워 표를 CSV로 출력 → `... --epoch 30 --csv > out.csv`
- `--csv-summary` : 기록/채널당 한 줄 요약표 (전원잡음 열과, `--baseline` 사용 시
  지표별 `*_base_delta` / `*_base_pct_change` / `*_base_p` / `*_base_q_fdr` 열 포함)
- `--no-comment` : `--csv` 출력에서 맨 앞 `#` 주석 행 생략(base-R/SAS 바로 읽기)

## 팁
- 외부 라이브러리가 필요 없어서 인터넷 없이도 동작합니다(FFT·EDF 파서까지 자체 구현).
- 입력은 **µV 단위**로 가정합니다. EDF는 헤더의 단위를 읽어 mV/V/nV를 µV로 환산합니다.
  다른 단위(예: mmHg)면 경고하고 그대로 쓰므로 파워 단위만 그에 맞게 해석하세요.
- 구분자는 `,` `;` 탭 `|` 를 자동 감지하고, 유럽식 **소수점 쉼표**(`12,3`)도 처리합니다.
  한국 Excel의 **cp949** CSV도 자동으로 읽습니다(UTF-8 권장, 아니면 경고 표시).
- 시간 열은 **초** 단위입니다. `time_ms`/`ms` 는 밀리초로 보고 자동 변환하며, `sample`/
  `index` 같은 표본 카운터는 시간으로 인식하지 않습니다(필요하면 `--time`으로 지정).
- 대역 피크(알파 IAF)는 **뚜렷한 피크일 때만** 표시하고, 잡음 argmax는 `n/a`로 억제합니다.
- **1/f 지수**는 적합 범위 안의 강한 느린진동에 영향을 받습니다. 그런 경우 경고가 나오며,
  `--fit-range 2-45`(또는 문헌에서 쓰는 `30-45`)로 다시 적합해 비교하세요.
- 에폭 요약의 95% CI는 **한 기록 내 분포**입니다(에폭 자기상관 → 피험자간 CI 아님).
  자기상관 보정 CI도 함께 보지만, 집단 추론은 피험자 단위 값으로 따로 하세요.
- `--notch` 는 **스펙트럼을 보간**해 채웁니다. 그 창 안의 대역파워는 "측정값"이 아니라
  "추정된 배경"이므로, 전원 주파수가 관심 대역 한가운데 있을 때는 결과를 그렇게 해석하세요.
- `--baseline` 의 p/q는 **한 기록 내** 전후 비교입니다. 위약 대조가 아니며 시간 경과에 따른
  자연 변화와 약효를 구분하지 못합니다. 집단 결론은 피험자별 Δ를 모아 따로 검정하세요 — `--csv-summary` 의
  `swa_absolute_uv2_base_pct_change`(또는 `..._base_delta`) 열이 그 피험자 단위 값입니다.
- 순수 파이썬이라 아주 긴 기록은 느립니다 — `--start/--duration`이나 채널 선택으로 줄이세요.
- 환자 데이터는 로컬에서만 처리되며 외부로 전송되지 않습니다. EDF 헤더의 **환자 식별
