# HARDENING — logflow

이 문서는 logflow 도구를 심화 개선·강화한 내역을 날짜별로 기록한다.
각 회차는 (1) 실질 기능 개선/확장과 (2) 병렬 적대적 리뷰(여러 독립 리뷰어)로
발견한 결함 수정 + 회귀/속성 테스트 추가로 구성된다.

---

## 2026-07-16 — 통계·출력 심화 + R1/R2 적대적 하드닝

시작 상태: 세션화·집계·DAU/WAU/MAU·리텐션·퍼널을 텍스트로 출력하는 표준라이브러리 전용
도구. 테스트 32개 통과.

### 1) 실질 기능 개선 · 확장 (연구자 관점의 새 역량)

- **비율 신뢰구간(Wilson score interval)**: 리텐션·퍼널 전환율에 95%(설정 가능) 신뢰구간을
  함께 계산·표시. 코호트/표본이 작을 때(임상 유저테스트에서 흔함) Wald 근사보다 안정적이고
  0%/100% 근처에서도 구간이 붕괴하지 않는다. 논문·리포트에 비율을 실을 때 필요한 정직한 불확실성.
  - 새 모듈 `logflow/stats.py`: `wilson_interval`, `z_for_confidence`(+정규 역CDF Acklam 근사),
    `quantile`(numpy type-7 선형보간과 일치), `median`, `describe`. 순수 함수·의존성 없음.
- **퍼널 단계별 소요시간(중앙값)**: 직전 단계→다음 단계에 걸린 시간의 중앙값을 함께 보고
  (도달한 사용자 대상, 조건부). "어디서 얼마나 오래 걸려 이탈하는지"를 파악.
- **세션 분포의 정직한 요약**: 치우친 로그에서 평균만 보면 오해하므로 세션 길이·세션당
  이벤트를 **중앙값**과 함께 표시하고, JSON 에는 사분위수·p90 까지 포함.
- **활동 시간대 분석**: 시(0–23)·요일(월–일)별 이벤트 분포와 피크 시간대. 수면앱처럼 사용
  시간대가 중요한 로그에 유용. 텍스트 리포트에 요일 막대·시간 스파크라인으로 표시.
- **JSON 출력(`--json`) + 파일 저장(`--out`)**: 텍스트 대신 기계가독 JSON 으로 전체 결과를
  출력해 R/엑셀/파이썬 다운스트림 분석·원고 작성에 바로 연결. 텍스트와 JSON 은 단일 결과
  객체(`analyze.Analysis`)에서 렌더링되어 항상 일치.
- **실데이터 관용 로딩**: CSV 구분자 자동감지(콤마/세미콜론/탭/파이프), 헤더 열 이름의
  앞뒤 공백·대소문자 차이 허용, 완전 중복 행 제거(`--dedup`), 기간 필터(`--from`/`--to`).
- **신뢰수준 옵션(`--confidence`)**.

새 CLI 옵션: `--confidence`, `--delimiter`, `--dedup`, `--from`, `--to`, `--json`, `--out`.
README/사용법.md/옵션표/지표정의를 실제 동작에 맞춰 갱신(예시 출력 블록 포함).

### 2) 적대적 하드닝 — Round 1 (4개 독립 패널: 정확성·엣지·문서·테스트/보안)

발견·수정한 결함:

- **[HIGH] 리텐션 큰 day-N 오버플로**: `--retention 3000000` 등에서 `date + timedelta(days=N)`
  가 오버플로해 트레이스백. → date 연산 대신 **정수 비교**(`n > (max_day - c).days`)로 판정하도록
  변경해 오버플로를 원천 차단(의미는 완전 동일). CLI 예외 처리에 `OverflowError` 추가.
- **[LOW-MED] 비유한/극단 입력**: `--gap-min nan/inf`, `--tz-offset nan`, 거대한 `--tz-offset`
  이 애매한 오류/트레이스백을 냄. → CLI 에서 `math.isfinite` 검증 추가, `OverflowError` 를
  깔끔한 오류로 처리.
- **[LOW] 음수 epoch 무단 수용**: `-1000000000` 이 1938년으로 조용히 해석(도크스트링과 모순).
  → `_looks_numeric` 이 부호 붙은 값을 epoch 로 보지 않도록 수정 → 명확한 파싱 오류.
- **[문서] README Usage 의 `logflow` 단축 명령**: 무설치 경로를 안내하면서도 예시는 설치가
  필요한 단축 명령을 씀. → 설치 필요/대체 명령 주석 추가.
- **[문서 nit]** `_inv_norm_cdf` 오차 한계 도크스트링 정정(~3e-9).
- **[보안/PII]** 네트워크·코드실행·외부쓰기 없음 확인(순수 오프라인). 출력에 원시 사용자 ID가
  포함되고 `--out` 이 경로를 덮어쓴다는 점을 README 에 명시(정상 동작이나 공유 시 주의).

테스트: 32 → 109개. `stats.py` 참조값 검증, 활동/퍼널타이밍/세션분포, dataio 구분자·중복·기간·
헤더해석·비UTF8, JSON/`--out`, 그리고 **속성/불변식 테스트**(히스토그램 합=이벤트수,
DAU≤WAU≤MAU, 퍼널 도달 단조감소, 비율∈[0,1], Wilson 구간이 점추정 포함, describe 단조성)와
회귀 테스트(오버플로·비유한·음수epoch·경계) 추가. 전부 통과.

### 3) 심화 개선 + 적대적 하드닝 — Round 2 (3개 독립 패널: 정확성·엣지·유용성/리포트)

**정확성 패널**: 변경된 코드(리텐션 정수-지평선 리팩터, `_looks_numeric` 부호 제거, 퍼널 타이밍,
스파크라인 인덱스, `to_dict` 직렬화, 극단 신뢰수준)를 800개 코호트 날짜×여러 N 로 브루트포스
검증 — **결함 0**. 리팩터가 이전 로직과 정확히 동일하며 오버플로에 대해 더 안전함을 확인.

**엣지 패널**이 지적한 결함 수정:
- **[MED] 다문자 `--delimiter`** (`--delimiter ";;"`) → `csv` 가 `TypeError` 로 트레이스백.
  → CLI 에서 구분자는 정확히 1글자여야 함을 검증(빈 문자열도 거부 → 무단 자동감지 폴백 제거).
- **[LOW] 헤더 열 이름 모호성**: 공백/대소문자만 다른 헤더가 둘 이상이면 조용히 하나를 골라
  잘못된 열을 읽을 수 있었음. → `_resolve_columns` 가 모호하면 명확한 오류를 던지도록.
- **[LOW/풋건] `--out` 이 입력 CSV 와 동일 경로**면 원본을 말없이 덮어씀. → 경로 동일 시 거부.
- (강건성 확인: 200k행 1.1초·160MB, 적대적 문자로도 JSON 유효, `--out` 오류경로 모두 깔끔.)

**유용성/리포트 패널** 반영 — 실질 개선:
- **표시폭(전각) 정렬 버그 수정**: 한글 헤더가 코드포인트 기준으로 패딩돼 모든 표의 열이
  어긋났음. `unicodedata.east_asian_width` 기반 `_dw/_lj/_rj` 헬퍼로 **표시폭 기준 정렬**로
  교체(이벤트·활성·리텐션·퍼널·상위사용자 표 + 소요 열 전각 off-by-one 동시 해결).
- **롤링 리텐션(`--retention-mode rolling`)** 추가: "C+N 이후(포함) 재활성" 정의. 작은 표본에서
  exact day-N 의 요철을 완화. 기존 코호트/eligible/Wilson 로직 재사용. (신규 `mode` 인자)
- **원고용 CSV 표 내보내기(`--csv-dir`)**: DAU/WAU/MAU·리텐션(CI 포함)·퍼널·이벤트·사용자·
  활동 표를 각각 CSV(엑셀 호환 utf-8-sig)로 저장. `analyze.to_csv_tables`.
- **리포트 정직성/가독성**: 퍼널 소요(중앙) 조건부 캐비앗 각주, WAU/MAU 롤링 라벨 명시,
  요일 막대에서 0을 낮은 막대(▁)와 구분(·), 사용자당 세션 요약 라인 추가, 상위사용자 표
  후행 공백 제거.

테스트: 109 → 124개. 롤링 리텐션(의미·단조성·exact 대비), CSV 표(키·유효성·BOM·CLI),
다문자/빈 구분자 거부, `--out`=입력 거부, 모호 열 오류, 표시폭 헬퍼·정렬, 사용자당 세션,
`retention_mode` 직렬화 회귀 테스트 추가. 문서(README/사용법/옵션표/예시출력) 갱신. 전부 통과.

### 4) 적대적 하드닝 — Round 3 (3개 독립 패널: 정확성·엣지·문서/HARDENING 정직성)

- **정확성 패널**: 롤링 리텐션(`(last_day-c).days>=n` = "C+N 이후 활성" 증명), CSV 값이
  텍스트/JSON 과 일치, 표시폭 헬퍼, exact/Wilson 회귀를 브루트포스·손계산으로 검증 — **결함 0**.
- **문서/HARDENING 패널**: 모든 예시 명령 동작, 예시출력 일치, 옵션표 완전성, 새 기능 설명·PII
  주석의 정확성, HARDENING 주장(테스트 수 포함)의 진실성 확인 — **과장·허위 0**.
- **엣지 패널**이 발견한 결함 수정:
  - **[MED] `--out` 링크 우회로 인한 입력 파일 손실**: 기존 가드가 `os.path.abspath`(문자열
    정규화)만 비교해, `--out` 이 입력을 가리키는 **심볼릭/하드 링크**면 우회되어 입력 CSV를
    조용히 덮어쓰고 exit 0 을 반환했음. → `realpath`(심볼릭 해소) + 존재 시 `samefile`(하드링크
    inode 동일) 비교로 교체. 세 가지 링크 시나리오 모두 차단 확인.
  - (추가 강건성 확인: `--csv-dir` 오류경로, 다국어/이모지 구분자, 모호 헤더, 100k 지저분한
    CSV 0.44초 처리, 전체 플래그 동시 스모크 등 — 모두 깔끔.)
- **부수 개선**: 표시폭 `_dw` 가 결합 악센트(NFD)·제로폭 문자를 폭 0 으로 처리하도록 보완.

테스트: 124 → 129개. `--out` 심볼릭/하드/상대-절대 링크 우회 방지(데이터 손실 회귀), 결합/
제로폭 표시폭 회귀 테스트 추가. 전부 통과(129 passed).
