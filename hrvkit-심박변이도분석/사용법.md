# 사용법 (빠른 시작)

## 가장 쉬운 방법
- 이 폴더의 **`실행.command` 더블클릭** → 예제 데이터(안정 호흡 / 느린 호흡)로
  결과가 바로 나옵니다. 두 기록을 비교하면 느린 호흡에서 RMSSD·HF·SD1이 오르고
  LF/HF가 내려가는 것을 볼 수 있습니다.

## 내 데이터로 돌리기 (터미널)

먼저 한 번만 설치(선택):
```bash
cd ~/Downloads/02_프로젝트/깃헙/hrvkit-심박변이도분석
python3 -m pip install -e .
```

### 1) 단일 열 (값만)
CSV가 이런 모양일 때 (RR/IBI ms):
```
rr_ms
812
798
805
...
```
```bash
hrvkit 내데이터.csv
# 설치 안 했으면:
python3 -m hrvkit.cli 내데이터.csv
```

### 2) 시간+값 형식
CSV가 이런 모양일 때 (값 열은 자동 선택, 필요하면 --col 로 지정):
```
time_s,rr_ms
0.000,812
0.812,798
...
```
```bash
hrvkit 내데이터.csv --col rr_ms
```

### 3) 순간 심박수(bpm) 입력
```bash
hrvkit 내HR.csv --unit bpm      # 기본 --unit auto 로도 대개 자동 감지됩니다
```

### 4) 기저 대 개입 짝지은 비교 (BELL-001 핵심 워크플로)
```bash
hrvkit 안정.csv 느린호흡.csv --compare
# → 각 지표의 델타·변화율과 부교감 방향(↑부교감/↓교감), 기전 일치 요약
```

### 5) 여러 피험자 일괄 요약 (장치 검증 파이프라인)
```bash
hrvkit subj01.csv subj02.csv subj03.csv        # 화면 표
hrvkit data/*.csv --format csv > summary.csv    # 스프레드시트용 CSV
```

### 6) 박동 발생시각(누적 시각) 입력
```bash
hrvkit peaks.csv --timestamps   # 발생시각 열을 차분해 RR을 만듭니다
```

## 결과 읽는 법
- **[0] 입력**: 감지된 단위, 입력 박동 수, **이상박동 비율(%)** 과 보정 방법.
- **[1] 시간영역**: median RR·MAD(로버스트), RMSSD(단기·부교감), SDNN(전체 변동성),
  pNN50/pNN20, CVNN, **HRV 삼각지수·TINN**(기하학·이상값에 강건).
- **[2] 주파수영역**: VLF/LF/HF 파워(절대 ms² · 정규화 n.u. · 비율 %), LF/HF, ln(HF),
  **HF 피크 기반 호흡수 추정**. 맨 윗줄에 **분석 방법**(리샘플 Hz, Welch/FFT 설정)이
  함께 표시됩니다.
- **[3] 비선형**: Poincaré SD1/SD2, SD1/SD2, 타원 면적, SampEn, **DFA α1/α2**.
- **[4] 해석**: RMSSD·HF·LF/HF를 BELL-001 기전(부교감 우세 방향)에 연결한 한 줄 요약.

## 자주 쓰는 옵션
- `--compare` : 파일 2개를 기저 대 개입으로 비교 (방향·변화율)
- `--paired manifest.csv` : 여러 피험자 (기저,개입) 짝 → 코호트 통계
  (평균 차이±SD, Cohen's dz, Wilcoxon p값). 장치 검증 연구용.
- `--format text|json|csv` : 출력 형식 (여러 파일은 표/CSV, JSON은 파이프라인 연동)
- `--timestamps` : 값 열이 (간격이 아니라) 누적 박동 발생시각일 때
- `--clean remove` : 이상박동을 보간하지 않고 제거
- `--unit ms|s|bpm` : 단위를 직접 지정 (자동 감지를 끄고 싶을 때)
- `--min-rr 300 --max-rr 2000` : 생리적 범위 조정
- `--no-sampen` : 표본 엔트로피 계산 생략(아주 긴 기록에서 빠르게)

## 팁
- 외부 라이브러리가 필요 없어서 인터넷 없이도 동작합니다.
- 세미콜론·탭 구분자, 유럽식 소수점 쉼표, cp949/euc-kr 인코딩 CSV도 그대로 읽습니다.
- 값이 지표에 어떻게 영향을 주는지(리샘플 주파수·창)를 리포트에 함께 출력하니,
  다른 HRV 도구와 비교할 때는 설정이 같은지 꼭 확인하세요.
- 호흡수 추정은 HF 대역(0.15–0.4 Hz) 피크 기반입니다. **0.15 Hz 미만의 느린 호흡
  (≤9회/분)은 LF 대역**에 나타나므로 그때는 peak LF 를 함께 보세요.
- VLF·DFA α2는 몇 분 이상의 긴 기록에서만 신뢰하세요(짧으면 α2는 NaN으로 표시).
