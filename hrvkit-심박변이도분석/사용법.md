# 사용법 (빠른 시작)

## 가장 쉬운 방법
- 이 폴더의 **`실행.command` 더블클릭** → 예제 데이터(안정 호흡 / 느린 호흡)로
  결과가 바로 나옵니다. 두 기록을 비교하면 느린 호흡에서 RMSSD·HF·SD1이 오르고
  LF/HF가 내려가는 것을 볼 수 있습니다.
- ⚠️ `examples/` 의 CSV는 **합성 데이터**입니다(실제 피험자 기록 아님). 형식과 출력
  모양을 보여주기 위한 것이지, 기전의 증거가 아닙니다.

## 내 데이터로 돌리기 (터미널)

먼저 한 번만 설치(선택):
```bash
cd ~/Downloads/02_프로젝트/깃헙/hrvkit-심박변이도분석
python3 -m pip install -e .
```

### 1) 단일 열 (값만)
CSV가 이런 모양일 때 (RR/IBI ms):
```
rr_ms
812
798
805
...
```
```bash
hrvkit 내데이터.csv
# 설치 안 했으면:
python3 -m hrvkit.cli 내데이터.csv
```

### 2) 시간+값 형식
CSV가 이런 모양일 때 (값 열은 자동 선택, 필요하면 --col 로 지정):
```
time_s,rr_ms
0.000,812
0.812,798
...
```
```bash
hrvkit 내데이터.csv --col rr_ms
```

### 3) 순간 심박수(bpm) 입력
```bash
hrvkit 내HR.csv --unit bpm      # 기본 --unit auto 로도 대개 자동 감지됩니다
```

### 4) 기저 대 개입 짝지은 비교 (BELL-001 핵심 워크플로)
```bash
hrvkit 안정.csv 느린호흡.csv --compare
# → 각 지표의 델타·변화율과 이동 방향(↑부교감 = 부교감 쪽 / ↑교감 = 교감 쪽), 기전 일치 요약
```

### 5) 여러 피험자 일괄 요약 (장치 검증 파이프라인)
```bash
hrvkit subj01.csv subj02.csv subj03.csv        # 화면 표
hrvkit data/*.csv --format csv > summary.csv    # 스프레드시트용 CSV
```

### 5b) 여러 피험자 짝 통계 (연구의 핵심 산출물)
```bash
hrvkit --paired examples/paired/manifest.csv    # 예제(합성 10명)로 바로 확인
hrvkit --paired manifest.csv                    # 기술 표 + 추론 표
hrvkit --paired manifest.csv --format csv > cohort_stats.csv   # 논문 표용
hrvkit --paired manifest.csv --alpha 0.01       # 99% CI, α=0.01
```
`manifest.csv` 는 피험자당 한 행:
```
baseline,intervention,subject
S01_rest.csv,S01_slow.csv,S01
S02_rest.csv,S02_slow.csv,S02
```
지표별로 **Wilcoxon 정확검정 p값**, **Hodges–Lehmann 이동량 + 95% 신뢰구간**,
**Cohen's dz**, **Holm/BH 다중비교 보정 p값**이 나옵니다.

### 5c) 긴 기록의 구간별 추이 (`--window`)
20분·야간 기록을 5분 구간으로 쪼개 "언제 효과가 붙었는지"를 봅니다.
```bash
hrvkit session.csv --window                 # 5분(300초) 구간 — Task Force 표준
hrvkit session.csv --window 120             # 2분 구간
hrvkit session.csv --window 300 --step 60   # 5분 창을 1분씩 미는 슬라이딩
hrvkit session.csv --window --format csv > epochs.csv   # 구간당 1행
```
구간별 지표 표 + 지표별 **Mann–Kendall 추세 검정**(tau·Theil–Sen 기울기·정확 p) +
**SDANN·SDNN index**(Task Force 장기 지표)가 나옵니다.

### 5d) 평행군(독립 2군) 비교 (`--groups`)
약물 대 위약처럼 **각 피험자가 한 군에만 속하는** 설계용입니다.
```bash
hrvkit --groups arms.csv
hrvkit --groups arms.csv --format csv > group_stats.csv
```
`arms.csv` 는 기록당 한 행 (**먼저 나온 군이 기준/대조**):
```
file,group,subject
C01.csv,control,C01
D01.csv,device,D01
```
지표별로 **Mann–Whitney 정확검정 p**, **Hodges–Lehmann 이동량 + 95% 신뢰구간**,
**Hedges g**, **Holm/BH 보정 p** 가 나옵니다.

### 6) 박동 발생시각(누적 시각) 입력
```bash
hrvkit peaks.csv --timestamps   # 발생시각 열을 차분해 RR을 만듭니다
```

## 결과 읽는 법
- **[0] 입력**: 감지된 단위, 입력 박동 수, **이상박동 비율(%)** 과 보정 방법.
- **[1] 시간영역**: median RR·MAD(로버스트), RMSSD(단기·부교감), SDNN(전체 변동성),
  pNN50/pNN20, CVNN, **HRV 삼각지수·TINN**(기하학·이상값에 강건).
- **[2] 주파수영역**: VLF/LF/HF 파워(절대 ms² · 정규화 n.u. · 비율 %), LF/HF, ln(HF),
  **HF 피크 기반 호흡수 추정**. 맨 윗줄에 **분석 방법**(리샘플 Hz, Welch/FFT 설정)이
  함께 표시됩니다.
- **[3] 비선형**: Poincaré SD1/SD2, SD1/SD2, 타원 면적, SampEn, **DFA α1/α2**.
- **[2] 해상도 줄**: 주파수 해상도·Welch 구간 길이·대역별 빈 수 — 각 대역이 실제로
  해상됐는지 확인하는 용도(빈이 0개면 그 대역은 NaN).
- **[4] 해석**: RMSSD·HF·LF/HF를 BELL-001 기전(부교감 우세 방향)에 연결한 한 줄 요약.

## 자주 쓰는 옵션
- `--compare` : 파일 2개를 기저 대 개입으로 비교 (방향·변화율)
- `--paired manifest.csv` : 여러 피험자 (기저,개입) 짝 → 코호트 통계
  (평균 차이±SD, Cohen's dz, Wilcoxon 정확검정 p, HL 이동량 + 신뢰구간,
  Holm/BH 보정 p). 장치 검증 연구용
- `--groups arms.csv` : 평행군(독립 2군) 비교 — Mann–Whitney 정확검정, HL 이동량 +
  신뢰구간, Hedges g, Holm/BH 보정 p
- `--window [초]` : 파일 1개를 구간으로 쪼개 구간별 지표 + 추세 + SDANN/SDNN index
  (값 생략 시 300초). `--step` 으로 슬라이딩, `--min-window-beats` 로 최소 박동 수.
- `--alpha 0.05` : 신뢰구간 수준(1-α)과 유의 판정 기준
- `--nperseg 2048` : Welch 구간을 키움 (**VLF를 보려면 필요** — 아래 팁 참조)
- `--format text|json|csv` : 출력 형식 (여러 파일은 표/CSV, JSON은 파이프라인 연동)
- `--timestamps` : 값 열이 (간격이 아니라) 누적 박동 발생시각일 때
- `--clean remove` : 이상박동을 보간하지 않고 제거
- `--unit ms|s|bpm` : 단위를 직접 지정 (자동 감지를 끄고 싶을 때)
- `--min-rr 300 --max-rr 2000` : 생리적 범위 조정
- `--no-sampen` : 표본 엔트로피 계산 생략(아주 긴 기록에서 빠르게)

## 팁
- 외부 라이브러리가 필요 없어서 인터넷 없이도 동작합니다.
- 세미콜론·탭 구분자, 유럽식 소수점 쉼표·천단위 구분, cp949/euc-kr/UTF-16 인코딩,
  `#` 주석 메타 헤더가 붙은 CSV도 그대로 읽습니다.
- 값이 지표에 어떻게 영향을 주는지(리샘플 주파수·창)를 리포트에 함께 출력하니,
  다른 HRV 도구와 비교할 때는 설정이 같은지 꼭 확인하세요.
- 호흡수 추정은 HF 대역(0.15–0.4 Hz) 피크 기반입니다. **0.15 Hz 미만의 느린 호흡
  (≤9회/분)은 LF 대역**에 나타나므로 그때는 peak LF 를 함께 보세요.
- **VLF는 기본 설정에서 신뢰할 수 없습니다.** VLF 하한(0.003 Hz)의 한 주기는 333초인데
  기본 Welch 구간은 64초라, 그보다 느린 성분은 구간별 평균 제거로 사라집니다. 도구가
  이를 숨기지 않습니다 — 대역에 빈이 없으면 `0.0` 이 아니라 **`NaN`** 을 내고,
  리포트에 대역별 빈 수와 신뢰 여부를 함께 찍습니다. 긴 기록에서 VLF가 필요하면
  `--nperseg 2048`(=512초 구간)처럼 구간을 키우세요. `total_power` 는 정의상 VLF를
  포함하므로 VLF가 NaN이면 함께 NaN이 됩니다.
- **20초 미만 기록**은 주파수영역 분석을 거부하고 경고합니다(HF조차 해상 불가).
- DFA α2는 몇 분 이상의 긴 기록에서만 신뢰하세요(짧으면 NaN으로 표시).
- 결과 표의 `p` 뒤 **`e`는 정확검정**, **`a`는 정규 근사**를 뜻합니다.
- **표본이 작으면 유의할 수 없습니다 — 도구가 그 숫자를 알려 줍니다.** 예: 군당 5명씩
  11개 지표를 보정하면 완전분리여도 Holm p=0.087 이라 α=0.05 를 넘을 수 없습니다.
  "유의하지 않음"이 "효과 없음"이 아니라 **표본 부족**일 때 그렇게 적어 줍니다.
- `--window` 구간의 **VLF·total_power 는 믿지 마세요.** 5분 창은 VLF 주기(333초)보다
  짧아 VLF 가 **NaN 이 아니라 심하게 과소추정된 유한 값**으로 나오고, total_power 는
  정의상 VLF 를 포함해 같은 편향을 갖습니다(`vlf_reliable=False` 로 표시됩니다).
  구간별로는 시간영역·Poincaré 지표를 먼저 보세요.
- `--groups` 는 **매니페스트에 먼저 나온 군이 기준(대조)** 입니다. 행 순서를 바꾸면
  차이의 부호와 방향 화살표가 통째로 뒤집히니 대조군을 위에 두세요.
- SDANN·SDNN index 는 Task Force 가 **24시간 홀터** 지표로 정의한 것입니다. 짧은 기록에
  적용하면 공식은 맞아도 발표된 참고값과 비교할 수 없습니다 — 리포트가 그렇게 적습니다.
