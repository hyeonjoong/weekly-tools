# HARDENING & IMPROVEMENT LOG — hrvkit

이 문서는 `hrvkit`(심박변이도 분석기)의 심화 개선·경화(hardening) 작업 기록입니다.
각 섹션은 날짜별로 무엇을 **더 유용하게 만들었고**, 무엇을 **더 견고하게 고쳤는지**를 남깁니다.

---

## 2026-07-31 — v0.4.0: 구간별 추이(--window) · 평행군 비교(--groups) · 시간축 정직성

버전 0.3.0(250 테스트) → **0.4.0 (396 테스트, 전부 오프라인·순수 표준 라이브러리)**.

독립 리뷰어 **4명을 1라운드 병렬**로 돌렸습니다(정확성 재계산 / 엣지케이스 /
문서 정직성 / 테스트품질·PII). 재현된 결함을 전부 고치고 회귀 테스트로 고정했습니다.

### A. 새 기능 / 더 유용하게

- **`--window [초]` — 구간(epoch)별 추이.** Task Force 표준 지표는 정상성을 가정한
  5분 기록용인데, 20분·야간 기록을 한 덩어리로 계산하면 느린 추세가 SDNN을 부풀리고
  "개입 중 언제 효과가 붙었는가"에 답할 수 없습니다. 기록을 창으로 쪼개
  ① 구간별 전 지표, ② 지표별 **Mann–Kendall 단조 추세 검정**(Kendall tau-b,
  동점 없고 구간 ≤25개면 **정확 분포** — 역위 수 DP, 아니면 동점 보정 정규 근사) +
  **Theil–Sen 기울기**, ③ Task Force **장기 지표 SDANN·SDNN index** 를 냅니다.
  `--step` 으로 슬라이딩, `--min-window-beats` 로 최소 박동 수. text/JSON/CSV 모두 지원.
- **`--groups MANIFEST` — 평행군(독립 2군) 비교.** 기존 `--paired` 는 같은 피험자의
  pre–post 전용이라, 약물 대 위약처럼 각 피험자가 한 군에만 속하는 설계에는 쓸 수
  없었습니다(짝짓기가 임의가 되어 p값이 무의미). `stats.py` 에 **Mann–Whitney U**
  (정확 분포 DP + 동점 보정 정규 근사), **2표본 Hodges–Lehmann 이동량**,
  **분포무관 CI**(정확검정과 쌍대), **Hedges g**, **순위이연 상관·CLES** 를 추가하고
  Holm/BH 보정까지 붙였습니다.
- **`analyze_rr(precleaned_flags=…)`** — 정제를 기록 전체에서 한 번만 하고 구간마다
  재사용하는 경로. 창마다 다시 탐지하면 이미 보간된 값 위에서 돌아 이상박동 비율이
  0%로 잘못 보고됩니다.
- **예제 데이터 추가**(모두 합성): `session_20min.csv`(20분 세션, 개입이 서서히 붙음),
  `parallel_arm/`(대조 5 대 디바이스 5), `paired/`(pre–post 10명). `실행.command` 가
  `--window`·`--groups`·`--paired` 를 **실제로 실행**해 보여 줍니다(과거 `--paired`
  블록은 설명만 찍고 아무것도 돌리지 않았습니다).

### B. 리뷰어가 재현한 결함 → 수정 (전부 회귀 테스트로 고정)

- **[CRITICAL] 시간축을 정제된 RR로 만들어 기록 시간이 사라짐** (정확성·엣지 리뷰어가
  **독립적으로 동시 발견**). 센서 끊김 30 s는 `max_rr` 위반이라 이상박동이고,
  `interpolate` 가 그것을 ~800 ms로 바꿉니다. 그러면 900 s 기록이 **608 s** 로
  보고되고, `5:00` 이라 찍힌 창이 실제로는 벽시계 10:00 에서 시작합니다 — 개입 로그와
  구간을 맞출 수 없게 되는 조용한 오답. `remove` 는 더 심합니다.
  → **경과시간은 원시 RR, 지표는 정제 RR** 로 분리했습니다.
- **[CRITICAL] Theil–Sen 기울기가 빠진 구간만큼 부풀려짐.** `mann_kendall` 이 비유한
  값을 버리고 **압축한** 인덱스로 나눠, 창 절반이 NaN(짧은 창의 SampEn, HF=0의
  LF/HF=inf)이면 기울기가 2배가 됐습니다(실측 `--window 20` 에서 HF n.u.
  0.697/창 vs 참값 0.284/창). S·tau·p는 순서만 쓰므로 영향 없음 — 기울기만 틀림.
  → `positions=` 인자를 추가해 **실제 창 번호**로 나눕니다.
- **[HIGH] `--clean remove` 에서 창별 이상박동 비율이 항상 0.**  남은 박동에 전부
  `False` 를 달았기 때문. 사용자가 "이 구간을 믿을지" 판단하는 바로 그 숫자입니다.
  → 원시 시간축에서 이상박동을 세어 창에 귀속시킵니다.
- **[HIGH] 군 매니페스트의 첫 행 경로에 오타가 있으면 그 행이 조용히 삭제됨.**
  "첫 행에 실제 파일이 하나도 없으면 헤더" 규칙 때문. 3대3이 2대3으로 계산되고 exit 0.
  → 확장자·구분자까지 보는 `_looks_like_path` + **존재하지 않는 파일은 분석 전 거부**.
- **[HIGH] 군 매니페스트가 빈칸·열 부족 행을 조용히 건너뜀** → 군 n이 사용자가 쓴
  것과 달라짐. 중복은 큰소리로 거부하면서 누락은 넘기는 것은 앞뒤가 안 맞습니다.
  → **행 번호와 함께 거부**.
- **[HIGH] `--step` 에 하한이 없어 사실상 무한 실행.** 추세 검정이 창 수의 **제곱**
  비용이라 `--step 0.1` 오타 하나로 야간 기록이 수만 개 창 → 수십 GB. 두 리뷰어가
  독립 확인. → **창 수 상한 2000** + 실행 가능한 `--step` 값을 제안하는 오류,
  그리고 창 300개 초과 시 **SampEn 자동 생략**(100k 박동 22시간 기록: 40 s → 12.7 s).
- **[MEDIUM] 군 비교 리포트에 지표별 n이 없음.** NaN 지표는 그 군에서 빠지므로
  머리글의 5대5와 실제 4대2가 달라질 수 있는데 표에 표시가 없었습니다.
  → `n_a/n_b` 열 + `*` 표시. 구간 추세표에도 지표별 유효 창 수를 넣었습니다.
- **[MEDIUM] 구간별 경고가 `--json` 사용자에게만 보임** → 텍스트 리포트에 구간 번호와
  함께 묶어 출력, CSV에 `warnings`·`vlf_reliable` 열 추가.
- **[정직성] 기준군이 매니페스트 행 순서로 정해지는데 어디에도 안 적혀 있었음.**
  같은 10개 파일을 순서만 바꿔 넣으면 HL 이동량 부호와 방향 화살표가 통째로 뒤집혀
  정반대 결론(`↑부교감` ↔ `↑교감`)이 나오는데도 범례는 늘 "median(개입−대조)".
  → 리포트가 **실제 군 이름으로** `median(device − control)` 을 찍고, 어느 쪽이
  기준인지 머리글에 명시. README·사용법·`--help` 에도 경고와 함께 기재.
- **[정직성] SDANN/SDNN index 를 "Task Force 정의 그대로" 라고만 표기.** 이 둘은
  **24시간 홀터** 지표이고 참고값(127±35 / 54±15 ms)도 24시간 기준인데, 20분 기록에서
  나온 SDANN 0.5 ms 옆에는 아무 말이 없었습니다. → 기록 6시간 미만이면 그 사실을
  같은 자리에 적고, 겹치는 창의 SDNN index 에도 "같은 박동을 여러 번 셈" 을 붙임.
- **[정직성] "5분 창이면 VLF는 항상 NaN" 은 거짓.** 5분 창(fs 4 Hz)이면 VLF 대역에
  빈이 **2개** 잡혀 NaN 이 아니라 **심하게 과소추정된 유한 값**이 나오고,
  `total_power` 가 그 편향을 그대로 물려받습니다. → 문서 수정 + `vlf_reliable` 을
  텍스트·CSV·JSON에 노출하고 구간별 total_power 사용을 만류.
- **[정직성] CI↔검정 쌍대성 주장이 무조건적이었음.** 동점이 있으면 p는 정규 근사로
  가는데 CI 절단 지수는 정확 영분포에서 나오므로 경계에서 어긋날 수 있습니다
  (2표본 616/6600 — 전부 보수적 쪽). → "동점이 없을 때" 로 한정하고 리포트에도 명시.
- **[정직성] "구간 3–8개면 기각 불가" 는 과장.** 실제로는 보정 후 **6개부터** 기각이
  가능합니다(2/6! = 0.0028 × 9 = 0.025). 코드는 이미 맞았고 README만 틀렸습니다.
- **[테스트 품질]** 리뷰어가 `/tmp` 사본에 **45개 변이(mutation)** 를 넣어 살아남는
  것을 찾았습니다. 요청한 7개 변이(CI 절단 지수 3종, HL 부호 반전, 꼬리 포함,
  SDANN ddof=0, 창 경계 `<=`, 3군 절단)는 **전부 잡혔지만**, 살아남은 것들을 고쳤습니다:
  - **정규 근사 경로에 수치 단언이 하나도 없었음** — 연속성 보정 삭제, 동점 보정 분산
    삭제, tau-b→tau-a 변이가 모두 통과. → scipy 교차검증(있을 때) + 고정 z/p 값 추가.
  - **Holm과 BH를 서로 바꿔도 통과** → `p_bh ≤ p_holm` 은 항상 성립하므로 그것을 단언.
  - **`precleaned_flags=` 를 빼도 통과** → 창 결과의 `pct_artifacts` 일치를 단언.
  - **실패한 창을 CSV에서 지워도 통과** → 행 수·`error` 열·빈 지표를 단언.
  - **`stdev`→`pstdev`, 합동 SD→군 SD, n_a/n_b 뒤바꿈이 통과**(픽스처가 대칭이라
    구별 불가) → 비대칭 픽스처로 교체.
  - 항진 단언 2개 제거(`cv == sd/mean` 을 자기 출력끼리 비교, 창 슬라이스 길이를
    구현의 `n_beats` 로 잘라 비교).
  - CSV 헤더 스키마 고정 테스트 추가(열 추가/재정렬이 조용한 파괴가 되지 않도록).
- **[모드 배타성]** `--paired`·`--groups`·`--compare`·`--window` 를 함께 주면 조용히
  하나를 무시하던 것을 **오류로 거부**합니다.

### C. 리뷰어가 첫 원리로 재계산해 "맞다"고 확인한 것

브루트포스 전수열거·재배치(permutation) 검정·scipy 대조로 확인:
`mannwhitney_null_counts` ↔ 모든 C(m+n,m) 배열 직접 계수(m,n ≤ 6 전부 일치),
Mann–Whitney 정확 p ↔ 완전 재배치 검정(300케이스 오차 0) ↔ scipy exact(1.1e-16),
정규 근사(동점 유무 모두) ↔ scipy asymptotic(3.3e-16), **CI 절단 지수 k는 off-by-one
아님** — 400케이스 × 4 alpha × 전 델타 격자 쌍대성 위반 **0**, 해석적 피복률
전 구간 명목 이상, `insufficient-n` 분기도 정확.
`inversion_counts` ↔ 순열 전수열거(n=0..7), Mann–Kendall 정확 p ↔ 완전 순열 열거
(n=5..7 오차 0), tau-b ↔ `scipy.stats.kendalltau(variant="b")`(1.1e-16),
동점 보정 Var(S) ↔ 전수 순열 경험분산(1e-12).
Cohen's d·Hedges g(J 근사 오차 <0.3% at df=4)·rank-biserial·CLES·HL 이동량 ↔ 교과서
재계산(4.4e-16). 창 분할이 박동을 정확히 한 번씩 덮음, 구간 지표 ↔ 그 슬라이스의
직접 `analyze_rr`(오차 0), SDANN·SDNN index ↔ 손계산 일치.

### D. PII / 보안

새 경로(`load_group_manifest` 오류 메시지, `render_windows`, `windows_to_csv`,
`group_compare*`)에 기존 관례(`_short()` 절단, CSV는 `basename`)가 일관 적용됨을
리뷰어가 `/tmp/.env`·`/etc/hosts`·`/etc/passwd` 로 직접 확인 — **유출 없음**.
`--window` JSON의 `input_meta` 에 경로·사용자명·원본 행 없음. 새 예제 파일 11개 전부
첫 줄에 합성 데이터 표기, 피험자 라벨은 `C01`–`D05`·`S01`–`S10` 뿐(날짜·이름·기기 ID 없음).
새 테스트는 전부 시드 고정, `tmp_path` 사용, 저장소 디렉터리에 쓰지 않음.

### 알려진 한계 (고치지 않고 기록)

- `mann_whitney_ci`/`wilcoxon_ci` 의 **정규 근사** 분기(군당 >30, 짝 >25)는 k에 연속성
  항(−0.5)이 없어 피복률이 명목보다 최대 0.5 %p 낮을 수 있습니다(측정: 0.8977 vs 0.90).
  정확 분기가 대부분의 임상 코호트를 덮으므로 그대로 둡니다.
- k 규칙이 `P(U ≤ k) < α/2`(≤ 아님)라 등호가 정확히 성립하는 소수 격자점에서 구간이
  한 칸 넓습니다 — **보수적 방향**이라 그대로 둡니다.
- 3군 이상 비교(Kruskal–Wallis)는 제공하지 않습니다. 2군만 골라 쓰면 다중비교가
  숨으므로, `--groups` 는 군이 2개가 아니면 **거부**합니다.

## 2026-07-16 (2차) — v0.3.0: 코호트 추론 완성 · VLF 정직성 · 열 선택 오답 제거

버전 0.2.0(137 테스트) → **0.3.0 (250 테스트, 전부 오프라인·순수 표준 라이브러리)**.

독립 리뷰어 패널을 **3라운드·병렬**로 돌려(주파수영역 정확성 / 비선형·시간영역 정확성 /
dataio 엣지케이스 / 문서 정직성 / 통계 배선 정확성 / dataio 회귀 사냥 / 최종 통합)
재현된 결함을 전부 고치고 회귀 테스트로 고정했습니다. **리뷰어가 첫 원리로 재계산해
"맞다"고 확인한 것**과 **틀렸다고 재현한 것**을 아래에 나눠 적습니다.

### A. 새 기능 / 더 유용하게

- **`--paired` 코호트 추론을 완성**했습니다. `stats.py` 에 Hodges–Lehmann 추정량,
  분포무관 신뢰구간, Holm–Bonferroni, Benjamini–Hochberg, 정확 부호순위 검정이
  구현·테스트돼 있었으나 **리포트/CLI/문서 어디에도 연결돼 있지 않았습니다**
  (README는 여전히 "정규 근사"라고 설명). 이제 출력이 두 블록입니다:
  - **[A] 기술** — 평균 base→interv, ΔM±SD, ↑n/n
  - **[B] 추론** — HL 이동량, 분포무관 CI, Cohen's dz, Wilcoxon p(정확 `e`/근사 `a`
    표기), `p_holm`(FWER), `p_bh`(FDR), 부교감 방향
- **`--alpha`** — 신뢰구간 수준(1-α)과 유의 판정 기준. 범위 검증 포함.
- **`--nperseg`** — Welch 구간 길이 지정. **VLF를 실제로 신뢰하려면 필수**(아래 C-2).
- **`--paired --format csv`** — 지표당 한 행인 코호트 통계 CSV(논문 표·스프레드시트용).
  기존엔 `--format csv` 가 `--paired` 에서 조용히 무시되고 텍스트가 나왔습니다.
- **`#` 주석/메타 헤더 지원** — Polar·Kubios 등이 파일 앞머리에 붙이는
  `# Device: ...` 블록을 건너뜁니다. 덕분에 `examples/` CSV가 **스스로 합성임을
  밝히는** 헤더를 갖게 됐습니다.
- **주파수 해상도 투명화** — 리포트에 해상도·구간 길이·**대역별 빈 수**·VLF 신뢰
  여부를 함께 찍어, 각 대역이 실제로 해상됐는지 눈으로 확인할 수 있습니다.
- **한글 헤더 인식** — `간격`/`심박수` 등을 값 열 토큰으로 인식.

### B. 조용한 오답 제거 (가장 중요)

리뷰어가 **재현한** 결함만 적습니다. 모두 회귀 테스트로 고정했습니다.

1. **[치명] 값 열 자동 선택이 품질 플래그 열을 골랐다.** 값 열 키워드를
   *부분일치*로 검사해 `"valid"`⊃`"val"`, `"annotation"`⊃`"nn"`, `"thr"`⊃`"hr"`,
   `"beat_ok"`⊃`"beat"` 가 값 열로 뽑혔습니다. 헤더가 `valid,rr_ms` 이고 valid가
   전부 1인 디바이스 익스포트에서 → 단위 자동감지가 `s` 로 보고 **RR=1000 ms 상수
   → "평균 HR 60.0, SDNN 0.00, RMSSD 0.00" 을 경고 하나 없이** 출력(정답:
   mean 801.5, SDNN 27.2, RMSSD 40.7). 상수 열이라 이상박동 0% → 품질 경고도 없음.
   → 헤더를 **토큰 단위 정확 일치**로 점수화(0~3)하고, 동점일 때만 생리적 그럴듯함으로
   가립니다. 어떤 열도 완전히 배제하지 않습니다 — 배제했더니 `time_s,Pulse rate
   (count/min)` 에서 "count" 때문에 진짜 값 열이 탈락하고 **누적 시간축이 값 열로
   뽑히는** 더 나쁜 결과가 났기 때문입니다.
2. **[치명·자책] 유럽식 소수를 1000배로 읽는 회귀를 내가 만들었다가 잡혔다.**
   "탭 파일의 `1,010` 은 천단위 1010" 이라는 1라운드 지적을 자릿수 규칙으로 고쳤더니,
   훨씬 흔한 독일식 엑셀 익스포트의 `0,803`(=0.803)이 `\d+,\d{3}` 에 걸려 **803.0**
   이 됐습니다. 평균 HR은 우연히 정확(64.2)해 리포트가 그럴듯해 보이는데 RMSSD는
   **11배**(8.19 대 90.88), pNN50은 58.5%→0.7% 로 틀렸습니다.
   → 자릿수로 추측하는 것을 포기하고 **파일 로케일**로 결정: 유럽식 파일에서 쉼표는
   **항상** 소수점, 천단위는 점. 쉼표 구분 파일에선 따옴표 안의 `"1,010"` 만 천단위.
   (`0,803` 과 `1,010` 은 토큰만 봐선 원리적으로 구분 불가능합니다.)
3. **[높음] 단위 자동감지가 열 이름을 무시했다.** 중앙값 <300 → bpm 규칙은 성인
   기준이라, 헤더에 `rr_ms` 라고 적힌 **신생아 RR 270 ms** 기록을 bpm으로 오판해
   60000/270 = **222 ms** 로 바꿨습니다. → 이름에 단위가 명시되면(`rr_ms`/`rr_s`/
   `hr_bpm`) 이름을 신뢰하고, 중앙값 규칙과 엇갈리면 경고합니다.
4. **[높음] 한글 헤더가 토큰화되지 않아 시간축이 값 열로 뽑혔다.** `[^A-Za-z0-9]` 로
   쪼개 `"간격"` → `[]` → 점수 0 → 아무 영어 열(`Zeit`)에나 밀렸고, 누적 시간 열이
   값으로 읽혀 SDNN 575 ms 같은 그럴듯한 오답이 나왔습니다. → 유니코드 보존 토큰화.
5. **[높음] 짧은 기록의 VLF가 진짜 0인 것처럼 보고됐다.** 64 s 기록은 df=0.0625 Hz
   라 VLF(0.003–0.04 Hz)에 **빈이 0개**인데 `_band_power` 가 `0.0` 을 반환 →
   "VLF power: 0.0 ms² (0.0%)" 가 실제 0과 구분 불가능. → 빈이 없으면 **NaN**.
   `total_power` 는 정의상 VLF를 포함하므로 함께 NaN(0으로 눙치지 않음).
6. **[중간] 평탄 신호가 '느린/공명 호흡 레짐'으로 오탐됐다.** `_peak` 의 시작값이
   `-1.0` 이라 PSD가 전부 0인 신호(RR 전부 동일)에서도 대역 첫 빈이 '피크'로 뽑혔고,
   `hf_nu` 도 0이라 레짐 조건이 성립해 경고까지 떴습니다. → 파워가 0인 대역엔 피크 없음.
7. **[중간] 4박동(3.2 s) 입력이 전 대역 0.0 · `lf_hf_ratio=inf` 를 조용히 반환했다.**
   → 20 s 미만이면 주파수영역을 거부하고 경고(HF 대역조차 해상 불가).
8. **[중간] 중복 열 이름에서 `--col` 이 조용히 첫 열을 골랐다.** → 모호하면 거부.
9. **[중간] 매니페스트가 중복 피험자를 받아 유사반복(pseudo-replication)으로 n을
   부풀렸다.** 동일한 행 3개가 "n=3" 으로 집계돼 Wilcoxon·CI가 낙관적으로 나왔습니다.
   → 라벨/경로 짝 중복을 거부. 단 라벨 열 탐지도 부분일치라 `"condition_id"` 의
   `"id"` 가 걸려 **멀쩡한 매니페스트가 거부**됐고, `"baseline_id"`(경로 열)가 라벨로
   뽑히기도 했습니다 → 토큰 정확 일치 + 피험자 토큰 요구로 수정.
10. **[중간] 헤더보다 데이터 열이 많아도 침묵했다.** 따옴표 없는 `1,010` 이 두 열로
    쪼개져 col0의 `"1"` 이 **RR=1.0 ms 상수**로 읽혔습니다 → 명시적 경고.
11. **[중간] TINN이 데이터 범위에 갇혀 체계적으로 과소평가됐다.** 삼각형 밑변 탐색
    범위가 `min(nn)~max(nn)` 뿐이라, 참값 156.25 ms 인 꼬리 없는 완전 삼각형에서
    **140.63 ms**(정확히 2빈 부족)를 냈습니다 → 양쪽에 0 카운트 빈을 덧대 해결
    (이제 참값과 정확히 일치).
12. **[낮음] `int("1_0") == 10`** 이라 `--col 1_0` 이 조용히 11번째 열을 골랐습니다
    → 순수 숫자만 인덱스로 인정.
13. **[낮음] `inf`/`Infinity`/`1e400` 이 `float()` 를 통과**해 지표를 오염시켰습니다
    → 비유한 값 거부.
14. **[낮음] UTF-16 파일이 cp949로 디코드**돼 NUL 섞인 쓰레기가 됐습니다 → BOM 판별.

### C. 통계의 핵심 결함 — 신뢰구간이 명목 수준에 미달했다

**[치명] `wilcoxon_ci` 의 `k` 탐색이 1 커서, 모든 신뢰구간이 실제보다 좁았습니다.**

모듈이 내세우는 가장 강한 주장("CI가 0을 배제" ⇔ "p<α")이 **거짓**이었습니다.
독립 리뷰어의 전수 격자 탐색과 제가 새로 쓴 쌍대성 테스트가 **각각 독립적으로 같은
버그**를 잡았습니다: 41,545개 격자점 중 **2,122개(5.1%)에서 불일치**, 그리고 불일치는
**전부 비보수적**(검정은 기각 못 하는데 CI는 배제) 방향이었습니다.

조건이 `P(W+ ≤ k-1) ≤ α/2` 였는데 쌍대성·피복률이 요구하는 것은 `P(W+ ≤ k) < α/2`.
결과적으로 n=6~25 전 구간에서 k가 정확히 +1 컸습니다. 해석적 피복률(명목 95%):

| n | 수정 전 | 수정 후 |
|---|---|---|
| 6 | 0.9375 | **0.9688** |
| 8 | 0.9453 | **0.9609** |
| 10 | 0.9355 | **0.9512** |
| 15 | 0.9446 | **0.9521** |
| 20 | 0.9468 | **0.9516** |

결정적 단서: `n > 25` 의 **정규 근사 분기는 처음부터 올바른 k** 를 계산하고 있어,
n=25↔26 경계에서 피복률이 0.9484 → 0.9507 로 튀었습니다(수정 후 0.9517 → 0.9507).

수정 후 재검증: 격자 60,504점에서 **불일치 0**, n=6~30 피복률 **전부 명목 이상**.

부수 결함 2건도 고쳤습니다:
- **n이 너무 작으면 유한 CI가 존재하지 않는다.** n=4·α=0.05 의 정확검정 최소 p는
  2/2⁴=0.125 라 절대 기각할 수 없는데, 코드는 전체 범위를 `ci_method="exact",
  ci_alpha=0.05` 로 라벨해 **"95% 구간"이라 거짓말**했습니다(실제 피복 0.875).
  → 참인 답인 **(-∞, ∞)** 와 `insufficient-n` 을 내고 리포트에 `†` 로 표시합니다.
- **점추정이 자기 신뢰구간 밖에 놓일 수 있었다.** `hodges_lehmann` 은 모든 차이를,
  `wilcoxon_ci` 는 0을 제외한 차이를 써서 `diffs=[0,0,0,5,6]` → HL=2.5, CI=[5,6].
  → CI와 **같은 표본**에서 점추정을 계산해 항상 구간 안에 들게 했습니다.

  실행.command 에 **합성 데이터임을 명시**하고, 표는 "기전의 증거가 아니라 계산 예시"로

  문서가 말하는 "느린/공명 호흡 레짐(≤9회/분)"에 **해당하지 않음**도 명시했습니다.
- **BELL-001 이 근거 없이 기정사실로 서술됐습니다**(18곳). 인용도 DOI도 없습니다.
  → 상단에 **가상 프로젝트 코드명**임을 밝히고, "느린 호흡→부교감→RSA/HRV↑" 는 확립된
  생리지만 **"→서파수면 증가"는 이 도구가 검정하는 가설**이지 사실이 아님을 명시.
- **VLF의 한계를 숨기지 않습니다** — 기본 구간(64 s)은 VLF 주기(333 s)보다 짧아

  **99.8%**). 리포트 줄에 직접 경고를 붙이고 `--nperseg` 로 해결할 수 있게 했습니다.
- **다중비교 가족의 중복을 밝힙니다** — SD1 = SDSD/√2 ≈ RMSSD/√2 라 RMSSD와 SD1은

  Holm/BH가 **필요 이상으로 보수적**임을 리포트와 README에 적었습니다.
- **DFA 구현이 Peng 원논문과 다릅니다** — 꼬리를 버리지 않는 **양방향 구간 분할**

  같은 300박동 시계열에서 α1이 0.9497(양방향) 대 0.9659(전방향)로 1.7% 다릅니다
  → 실제 방식과 그 영향을 명시.
- **`↓교감` 라벨이 오해를 낳았습니다** — 지표가 *교감 쪽으로* 이동했다는 뜻인데
  "교감이 내려간다"로 읽힙니다 → `↑교감` 으로 교체.
- 테스트 수(137 → 250), `--version`/`-h` 누락 등 표기 갱신.

### E. 리뷰어가 첫 원리로 재계산해 "맞다"고 확인한 것

틀린 것만큼 중요한 정보라 함께 남깁니다.

- **FFT** ↔ `np.fft.fft`: 최대오차 **7.8e-14**. 반복형 radix-2 Cooley–Tukey 정확.
- **Welch PSD** ↔ `scipy.signal.welch`: 최대 상대오차 **2.5e-14**. 주기 Hann,
  `1/(fs·Σw²)` 정규화, DC·Nyquist를 제외한 단측화 모두 정확.
- **리샘플링** ↔ `np.interp`: **1.1e-13**. 타임베이스 off-by-one 없음.
- **대역 적분**: 직사각형 규칙이 Parseval 정합적인 **올바른** 선택(사다리꼴이 아님).
  0.2 Hz 진폭 5 정현파 → HF 12.4998 (참값 12.5).
- **`lf_nu`/`hf_nu`**: `LF/(LF+HF)` = Task Force `LF/(Total−VLF)` 와 동일. 정확.
- **SampEn** ↔ 직접 작성한 O(N²) 브루트포스: **소수 10자리 일치**. 자기매칭 제외,
  Chebyshev 거리, Richman–Moorman 관례 모두 정확.
- **DFA** ↔ 독립 구현: `max|ΔF(n)| = 3.6e-15`. 풀드 RMS(구간별 RMS의 평균이 아님) 정확.
- **Poincaré**: ddof 일관, `SD1² = 0.5·var(diff)` 정확 일치, `SD1 = SDSD/√2` 1e-12.
- **시간영역**: SDNN은 표본 표준편차(Task Force 정합), pNN50 분모 N-1, `mean_hr` 는
  **순간 HR의 평균**(Kubios 관례, 의도된 선택이며 테스트로 고정).
- **정확 Wilcoxon** ↔ `scipy.stats.wilcoxon(method='exact')`: 3000표본 **완전 일치**
  (부동소수점 동일). 정규 근사 ↔ scipy: **2.2e-16**.
- **Holm/BH** ↔ `statsmodels.multipletests`: 오차 **0.0** / **2.2e-16**.
  NaN 제외·단조성·`adj ≥ raw` 모두 정확.
- **이상박동 탐지**: 전형적 PVC(조기수축+보상휴지)를 정확히 2개만 표시, 강한 RSA
  (±20% 정현파)에서 오탐 0.
- **500k 행 부하**: `load_series` 0.44 s. 이상 없음.
- **보안/PII**: 네트워크·eval/exec/pickle 없음. 오류 메시지의 파일 내용 인용을
  16~20자로 잘라 CI 로그·버그 리포트로 비밀이 새지 않게 했습니다.

버전 0.1.0(56 테스트) → **0.2.0 (137 테스트, 전부 오프라인·순수 표준 라이브러리)**.

### A. 새 기능 / 더 유용하게 (실제 신규 작업)

임상 수면/디바이스 검증 연구자 관점에서 실제로 빠져 있던 역량을 추가했습니다.

1. **DFA(상세변동분석) α1·α2** (`nonlinear.py`) — Peng et al. 1995 정의 그대로
   (평균제거 누적적분 → 크기 n 구간별 최소제곱 detrend → F(n) → log-log 기울기).
   양방향 구간으로 꼬리 데이터를 버리지 않음. 백색잡음 α≈0.5·적분잡음 α≈1.5 속성과
   독립 numpy(polyfit) 참조에 rel 1e-6 일치. α2는 데이터가 충분(n≥128)할 때만 계산.
2. **기하학적 시간영역 지표 HTI·TINN** (`timedomain.py`) — Task Force 1/128 s(7.8125 ms)
   히스토그램 기반. HTI=N/최빈빈, TINN=삼각 보간 밑변(정점 좌우로 오차가 분리되는
   성질을 이용한 최소제곱). 이상값에 강건. 추가로 **median RR·MAD**(로버스트 분산).
3. **호흡수 추정 + 호흡 레짐 인식** (`frequency.py`) — HF 피크 기반 호흡수(회/분),
   ln(HF). 그리고 **느린/공명 호흡 레짐 자동 감지**(아래 D 참고).
4. **여러 기록 비교/일괄 처리** (`cli.py`, `report.py`) — `--compare`(기저 대 개입
   델타·변화율·부교감 방향), 다중 파일 **일괄 요약 표**, `--format text|json|csv`
   (단일 파일도 1행 CSV). 배치 CSV의 `source`는 파일명만(경로 PII 완화).
5. **짝지은 코호트 통계 `--paired MANIFEST`** (`stats.py`, `report.py`) — 여러 피험자
   (기저,개입) 짝에 대해 지표별 **평균 차이±SD, Cohen's dz, Wilcoxon 부호순위 검정
   양측 p값**(정규 근사·연속성·동점 보정, `math.erf`만 사용). scipy와 p값 1e-6 일치.
   "장치 검증 파이프라인" 주장을 n=1 방향에서 **실제 통계**로 끌어올림.
6. **지저분한 실측 CSV 강건성** (`dataio.py`) — 인코딩 폴백(UTF-8→cp949/euc-kr→latin-1),
   구분자 자동 감지(,/;/tab/|, 과반 규칙), 유럽식 소수점 쉼표, `--timestamps`(누적
   발생시각 차분), 결측 라벨 확장, ragged 행 감지.

### B. 경화(HARDEN) — 병렬 적대적 리뷰(4개 패널, 라운드 1)에서 발견·수정

독립 리뷰어 서브에이전트를 **병렬**로 돌려 (a)정확성 (b)엣지케이스 (c)유용성
(d)문서 정직성 (e)테스트/보안을 점검하고, 실질 결함을 전부 고쳤습니다.

- **[HIGH] 비생리적 값 ZeroDivision 크래시.** 0/음수 RR이 정제 후에도 남으면
  `60000/x`·`cvnn`에서 크래시. → `analyze_rr`에서 계산 전 비유한·비양수 박동을
  제거하고 경고, 2개 미만이면 깔끔한 오류. `time_domain`에도 방어 검증 추가.
  "`--timestamps` 깜빡" 케이스가 크래시 대신 경고로 안내되도록 함.
- **[HIGH] 좁은 except로 예외가 파일명 없이 새어나감.** CLI가 어떤 예외든 잡아
  `[파일명]`과 함께 exit 2로 보고하도록 확장(배치/`--paired` 포함).
- **[MEDIUM] JSON에 비표준 `Infinity`/`NaN` 토큰.** 퇴화 입력(HF=0→LF/HF=inf 등)에서
  엄격 파서(JS/jq/serde)가 거부. → 비유한 float을 `"inf"/"-inf"/"NaN"` 문자열로
  바꿔 `allow_nan=False`로 직렬화(표준 준수, CSV와 동일 표기).
- **[LOW] 헤더 전용 파일** → 모호한 `max()` 오류를 "데이터 행이 없습니다"로 교체.
- **[LOW] 구분자 스니퍼가 단일 오염 문자에 속음** → 비쉼표 구분자는 과반 라인에
  나타날 때만 채택. `80;5` 한 줄이 단일 열 파일을 쪼개지 않음.
- **[정직성] 호흡·비교 엔진의 레짐 비인식**(가장 중요, 아래 D).
- **[정직성] DFA 캡션** "건강 성인 α1≈1.0"이 모든 값 옆에 규범처럼 인쇄되던 것을
  중립 문구로 교체(느린·공명 호흡에서 낮아짐 명시).
- **[보안/PII]** 배치/CSV의 `source`를 파일명만으로(디렉터리·사용자명 노출 완화).
  네트워크 호출·eval/exec/pickle 없음, 입력은 읽기 전용, 파일 쓰기 없음 재확인.
- **[테스트 품질]** 항진(tautological) 단언 제거(DFA α1), 무의미 단언 강화
  (`--no-sampen` 실제 생략 확인, CSV의 NaN/inf 토큰 실측), α2 유한 경로·경계,
  `--clean remove` 소수박동 오류 경로 등 누락 분기 회귀 테스트 추가.

### C. 검증된 정확성 (첫 원리 재계산)

리뷰어가 첫 원리/독립 참조로 재계산해 일치 확인: `_detrend_rms_sq`↔numpy lstsq,
TINN 분리 최소화↔완전탐색 결합 최소화(164.06 ms 동일), HTI=N/최빈빈, Wilcoxon
p값↔scipy(정규 근사, 동점 포함) 1e-6 일치, FLAT_COLUMNS 27개 키 전부 실값 매핑.

### D. 느린/공명 호흡 레짐 — 핵심 안전장치

느린 호흡(예 6회/분=0.1 Hz)의 RSA는 HF가 아니라 **LF 대역**에 실려, HF n.u./LF/HF의
"부교감 방향" 해석이 **역전**됩니다. BELL-001 같은 느린 호흡 개입에서 도구가 잘못된
"교감 우세" 결론을 낼 위험이 실제로 확인됨(합성 6회/분 데이터에서 LF/HF=2727, HF n.u.=0).
→ 호흡 피크가 LF에 있고 HF n.u.<20이면 **느린/공명 호흡 레짐**으로 감지하여:
(1) 호흡수를 LF 피크에서 추정, (2) 경고, (3) 단일 해석·`--compare`·`--paired` 판정을
대역 무관 시간영역 vagal 지표(RMSSD·SD1·pNN50·HTI) 기준으로 전환하고 HF 기반 지표를
방향 집계에서 제외("레짐?" 표시). 안정·자발호흡 예제는 오탐되지 않음을 테스트로 고정.
