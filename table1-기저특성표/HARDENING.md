# HARDENING LOG — table1 (기저 특성표 생성기)

이 파일은 배포 전, 도구를 무인(無人)으로 출시하기 위해 거친 **다회차 적대적 하드닝**의 기록입니다.
매 라운드마다 Agent 도구로 **독립적인 전문 검토자 패널을 병렬로** 소환해, 각자 우선순위가 매겨진
구체적·재현가능한 결함 목록(파일:줄, 깨뜨리는 입력)을 받았습니다. 제작자(메인 루프)가 모든
material 결함을 고치고 pytest+스모크테스트를 재실행한 뒤 다음 라운드를 시작했습니다.

검증 기준선: 모든 통계는 SciPy/numpy와 대조(정규 t/F/χ², Shapiro–Wilk, Mann–Whitney,
ANOVA/Kruskal, Fisher exact, 다변량 SMD) — 초기 구현부터 ≤1e-9 수준 일치 확인.

(`table1/trend.py`: 모수 행은 ANOVA **선형대비**, 순위 행은 **Jonckheere–Terpstra**(동점 보정),
이진 범주형은 **Cochran–Armitage**). (2) `--group-order` — 군(열) 표시 순서 고정 및 용량축 정의.
(3) `--format latex` — booktabs 표 출력. (4) `--encoding` — cp949 등 CSV 인코딩 지정.
검증은 외부 패키지가 아니라 **완전열거 순열 분산**(JT의 동점 보정 분산이 소표본 순열 분산과
기계정밀도 일치)과 **대수적 항등식**(k=2에서 선형대비≡Student t, JT≡연속성 보정 없는 MWU,
CA≡Pearson χ², CA z²≡N·r²)으로 고정했습니다.

**패널 4인(정확성·엣지케이스·문서정직성·테스트/PII) 병렬 1라운드. 수정한 실질 결함:**
- **`--group-order` 오타 시 용량축이 조용히 파일 순서로**: 하나도 안 맞으면(또는 일부만 맞아
  나머지가 파일 순서로 붙으면) `--trend` 와 함께 쓸 때 **하드 오류**로 변경. 이전에는 경고만 나고
  `--trend-scores` 가 엉뚱한 열에 붙었습니다(p=8.7e-05 vs 정답 8.4e-13).
- **빈 군이 용량축을 조용히 줄임**: 특정 군에서 변수가 전부 결측이면 그 군이 축에서 빠지는데
  범례는 전체 점수를 그대로 표시했습니다 → **행 주석에 실제 사용한 군·점수**를 적도록 수정.
- **한 군이 전부 결측이면 나머지 군의 omnibus 검정까지 사라짐**(기존 결함, 게다가 주석 문구가
  사실과 달랐음) → 빈 군만 제외하고 **나머지 군끼리 검정**, 제외한 군을 주석에 명시(scipy 대조 일치).
- **`_tie_sizes` NaN 무한루프**: 비유한 입력에 JT가 멈추지 않고 도는 문제 → `ValueError`.
- **완전한 단조 관계에서 경향성 열이 공란**: 군내 분산 0(가장 강한 경향)일 때 예외로 빠졌음 →
  `one_way_anova` 와 같이 `t=±inf, p=0` 보고.
- **CSV/TSV 출력이 다범주형의 p값·SMD를 통째로 누락**(기존 결함) → md/html/latex/json 과 동일하게 기록.
- **극단값 하나가 표 전체를 중단**(1e300 셀 1개 → rc=2, 출력 없음) → 그 변수만 건너뛰고 경고.
- **LaTeX**: `<`·`>`·`|` 미이스케이프(OT1에서 다른 글자로 조판 — 검열값 `>100` 이 깨짐) → 추가.
- **마크다운 범례가 유일하게 이스케이프를 건너뜀** → 군 라벨·가중치 열 이름 등 **자료 유래 문자열만**
  이스케이프(범례 자체의 `**굵게**`·`|SMD|>0.1` 은 보존). 자유텍스트 셀의 HTML 주입 경로 차단.
- **문서 정직성**: 경향성 검정은 *표기(`--display`)* 가 아니라 **보고된 검정 계열**을 따라간다는 점을
  README·사용법·양 언어 범례에서 정정(이전 문구대로면 `--display median` 사용자가 JT를 보고했다고
  오해). 2군 경고의 "동일" 주장도 Mann–Whitney(연속성 보정)·Welch·Fisher 예외를 명시하도록 수정.
  README 코드펜스 미닫힘(기존)으로 두 개 절이 통째로 코드블록에 삼켜지던 문제도 수정.
- **`--trend-scores`** 빈 문자열 무시·전부 동일값을 "자료 부적합"으로 오인하던 문제, 1e100 점수의
  101자리 전개, 1e160 점수에서의 오버플로(대비 계수 정규화로 해결) 수정.
- **헤더보다 열이 많은 행**이 조용히 잘리던 문제(따옴표 없는 쉼표) → 오류로 중단.
- 메시지 카탈로그 전체에서 리터럴 `<`·`>` 제거(md에서 `&lt;` 로 새던 문제) + 회귀 테스트로 고정.
