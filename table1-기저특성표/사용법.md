# table1 빠른 사용법 (한글)

임상 CSV → **출판용 "표 1"(기저 특성표)** 을 자동으로 만들어 줍니다.
평균/중앙값·정규성 검정·카이제곱/Fisher·표준화 평균차(SMD)·결측을 한 번에 정리합니다.

## 1) 가장 쉬운 방법 — 더블클릭

폴더 안의 **`실행.command` 를 더블클릭**하세요. 예제 데이터(SERENE 합성 기저표)로
표가 어떻게 나오는지 바로 볼 수 있습니다.

## 2) 내 데이터로 실행

CSV에 **군(group)을 나타내는 열**(예: `arm`, `treatment`, `그룹`)이 하나 있으면 됩니다. (군 열이 없으면 `--group` 을 빼고 실행 → 전체 코호트 기술통계표.)

```bash
cd ~/Downloads/02_프로젝트/깃헙/table1-기저특성표

# 설치(최초 1회) — 안 해도 아래 python3 -m 방식으로 실행 가능
python3 -m pip install -e .

# ① 모든 변수 자동 판별
table1 내데이터.csv --group arm
#   (설치 안 했다면)  python3 -m table1.cli 내데이터.csv --group arm

# ② 원하는 변수만, 코드형(0/1) 열은 범주형으로 강제
table1 내데이터.csv --group arm --vars age,sex,isi,bmi --categorical sex

# ③ 원고에 붙일 CSV 파일로 저장
table1 내데이터.csv --group arm --format csv -o 표1.csv

# ④ 영문 저널 제출용: 영어 라벨 + 변수 이름/단위 + (CONSORT) p값 숨김
table1 내데이터.csv --group arm --lang en --no-pvalue \
  --labels rmssd_ms="RMSSD (ms)" ahi="AHI (events/h)"

# ⑤ 비교(관찰) 연구용: 군간 차이(95% CI) + 다중비교 보정 p값, HTML로 저장
table1 내데이터.csv --group arm --effect --padjust holm --format html -o 표1.html

# ⑥ 군(group) 없이 — 전체 코호트 기술통계표(단일군 시험·코호트 기술)
table1 내데이터.csv --vars age,sex,bmi
```

## 3) 결과 읽는 법

- **연속형** 행: 정규분포로 판단되면 `평균 (표준편차)`, 아니면 `중앙값 [Q1, Q3]` 로 나옵니다.
  행 이름 옆에 `— 평균(SD)` / `— 중앙값[IQR]` 로 어떤 요약인지 표시됩니다.
- **범주형** 행: 수준별로 `n (%)`. %는 기본적으로 **그룹 안에서의 비율**입니다.
- **p값**: 두 군이 유의하게 다른지. 어떤 검정을 썼는지는 맨 오른쪽 `검정` 열에 있습니다.
- **SMD**: 두 군 간 표준화 평균차. **0.1보다 크면** 두 군이 그 변수에서 불균형함을 시사합니다
  (무작위배정·매칭 후 균형 점검에 유용).
- **· 결측 n**: 그 변수에서 빠진 값의 개수.
- 표 아래 **주석/경고**에 정규성·등분산·기대빈도 등 주의사항과, 제외된 ID 열 안내가 나옵니다.

## 자주 쓰는 옵션

- `--display median` : 연속형을 항상 중앙값[IQR]로
- `--test-cont welch` : 연속형 검정을 항상 Welch t로(분산 사전검정 없음 — 권장). `student`/`nonparam`도 가능
- `--binary-single` : 이진(2수준) 변수를 한 줄로(예: `sex = M — n(%)`). `--ref sex=F` 로 표시할 수준 선택
- `--pct row` : 범주형 %를 "수준 내 비율"로
- `--pct-decimals 0` : 범주형 %를 정수로(예: `46%`)
- `--fisher` : 2×2 표에 항상 Fisher 정확검정
- `--no-overall` : '전체' 열 숨기기
- `--no-pvalue` : p값 열 빼기(무작위배정 시험은 SMD로 균형 보고 — CONSORT 권고)
- `--range` : 연속형에 `(최소–최대)` 범위 추가
- `--effect` : 군간 **차이(95% CI)** 열 추가(연속형 평균차/Hodges–Lehmann, 이진형 위험차 %p). **두 군 비교 전용**, 방향은 첫 군 − 둘째 군
- `--padjust holm` : 변수별 p값에 **다중비교 보정**(`bonferroni`/`holm`/`bh`/`by`). 무작위배정 시험 기저표엔 비권장(비교/관찰 연구용)
- `--lang en` : 영어 라벨(영문 저널 제출용) / `--labels 열=이름` : 변수 표시 이름·단위
- `--format json` : 프로그램에서 쓰기 좋은 JSON으로 / `--format html` : **Word·저널 제출 시스템에 붙여넣을 HTML 표**

## 팁

- 첫 행은 **열 이름(헤더)** 이어야 합니다. 결측은 빈칸/`NA`/`.` 등으로 두면 알아서 처리합니다.
- 파일 경로 대신 `-` 를 주면 **표준입력(stdin)** 에서 읽습니다(예: `cut -d, -f2- 내데이터.csv | python3 -m table1.cli - --group arm`).
- 엑셀에서 저장할 때 **`CSV UTF-8`** 로 저장하면 한글 열 이름도 깨지지 않습니다.
- 환자 ID처럼 값이 전부 다른 열은 자동으로 빠집니다(표에 넣고 싶으면 `--categorical 열이름`).
