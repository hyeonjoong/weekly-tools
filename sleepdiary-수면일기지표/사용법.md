## 1. 내 파일 준비하기

엑셀에서 **한 행 = 한 밤**이 되도록 정리하고 `CSV`로 저장합니다.

| 열 | 필수? | 예시 값 |
|---|---|---|
| 대상자 ID | 권장 | `S01`, `환자03` |
| 시기 | 선택 | `baseline`, `followup` |
| 날짜 | 선택 | `2026-03-04` (ISO 권장) |
| 취침 시각 | 소등이 없으면 필수 | `22:50`, `오후 10시 50분` |
| 소등 시각 | **필수** (없으면 취침 시각으로 대체) | `23:00`, `11:00 PM` |
| 입면잠복기 | 선택 | `20`, `20분`, `1:05` |
| 중도각성 시간(WASO) | 선택 | `30` |
| 각성 횟수 | 선택 | `2` |
| 최종기상 시각 | **필수** | `07:00` |
| 침대에서 나온 시각 | 권장 (없으면 최종기상으로 대체 — SE가 높아짐) | `07:15` |

> 엑셀에서 시각 셀이 `1900-01-01 23:00:00`처럼 보여도 괜찮습니다 — 날짜
> 부분은 무시하고 시:분만 읽습니다.

파일이 CP949(한글 엑셀 기본)든 UTF-8이든 그대로 두어도 됩니다.

## 2. 열이 제대로 인식되는지 먼저 보기

```bash
python3 -m sleepdiary.cli 내일기.csv --list-columns
```

```
자동인식 결과:
  subject       → subject_id
  lights_off    → lights_off
  sol           → sleep_latency_min
  ...
```

`—`로 나오는 필수 항목이 있으면 직접 지정합니다:

```bash
python3 -m sleepdiary.cli 내일기.csv \
    --lights-off "소등" --final-awake "기상시각" --out-of-bed "침대밖"
```

같은 항목의 후보 열이 둘 이상이면 **오류가 납니다.** 이 도구는 헷갈릴 때
추측하지 않습니다 — 위처럼 직접 지정해 주세요. 이름이 똑같은 열이 둘 있는
파일도 (앞엣것의 값이 조용히 사라지므로) 거부합니다.

## 3. 기본 분석

```bash
python3 -m sleepdiary.cli 내일기.csv
```

보고서는 위에서부터 이렇게 읽으면 됩니다.

1. **열 매핑** — 내가 의도한 열이 맞는지 확인.
2. **자료 품질** — 몇 박을 제외했고 왜 제외했는지. **여기를 반드시 보세요.**
   - "제외된 밤"은 계산이 불가능한 행입니다(시각 오기입, 음수 등).
   - "경고"는 이상하지만 가능한 값이며 **집계에 포함**되어 있습니다.
     원자료를 확인한 뒤 필요하면 직접 지우세요.
3. **대상자별 요약** — 사람마다 몇 박을 썼는지, 평균 TST/SE/SOL/WASO,
   수면중앙시각, 규칙성.
4. **집단 요약** — 여기의 `n`은 **밤 수가 아니라 사람 수**입니다.
5. **시기 비교** (옵션) / **논문용 문장 초안**.

---

## 4. 전후 비교 (가장 흔한 용도)

시기 열에 `baseline`, `followup` 같은 값이 있으면:

```bash
python3 -m sleepdiary.cli 내일기.csv --compare-periods baseline followup
```

- 차이 = **나중 − 먼저**. SOL이 줄었으면 음수로 나옵니다.
- 두 시기를 **모두 기록한 대상자만** 짝으로 씁니다(짝 n이 보고서에 찍힙니다).
- 대응표본 t검정(평균차·95% CI·Cohen's dz)과 Wilcoxon 부호순위검정을
  나란히 보여줍니다. 표본이 작거나 분포가 치우쳤으면 Wilcoxon을 함께 보고하세요.
- **다중비교 보정은 하지 않습니다.** 12개 지표를 다 검정하므로, 주 지표를
  미리 정해두는 것이 맞습니다.

## 5. 순응도가 낮은 대상자 걸러내기

임상시험 프로토콜은 보통 "유효한 일기 5~7박 이상"을 요구합니다.

```bash
python3 -m sleepdiary.cli 내일기.csv --min-nights 5
```

걸러진 대상자는 보고서 끝에 이름과 밤 수가 찍힙니다. **논문에 몇 명을 왜
제외했는지 적어야 합니다.**

## 6. 결과 저장하기

```bash
python3 -m sleepdiary.cli 내일기.csv \
    --compare-periods baseline followup \
    --per-night-csv 밤별.csv \
    --per-subject-csv 대상자별.csv \
    --json 결과.json \
    --markdown
```

- `밤별.csv` — 모든 밤의 계산 결과. 제외된 밤은 `valid=False`와 사유가
  같이 들어갑니다. **원자료 검토용으로 가장 유용합니다.**
- `대상자별.csv` — 사람(×시기)별 평균. SPSS/R로 넘겨 추가 분석하기 좋습니다.
- `결과.json` — 전부 담긴 기계판독용 파일.
- `--markdown` — 논문·슬라이드에 붙일 표.

## 7. 자주 겪는 문제

| 증상 | 원인과 해결 |
|---|---|
| `필수 열을 찾지 못했습니다` | 열 이름이 특이합니다. `--lights-off` 등으로 직접 지정. |
| `후보 열이 여러 개입니다` | 비슷한 이름의 열이 둘 이상. 쓸 열을 직접 지정. |
| 제외된 밤이 많다 | 시각 표기가 섞여 있을 가능성. `--per-night-csv`로 사유를 보세요. |
| SE가 이상하게 높다 | SOL/WASO 열이 인식되지 않아 0으로 처리됐을 수 있습니다. `--list-columns`로 확인. |
| 수면중앙시각이 정오 근처 | 야간형과 주간형이 한 사람 안에 섞여 원형평균이 애매해진 경우. 밤별 값을 확인하세요. |
| 한글이 깨져 보인다 | 보고서 머리의 `인코딩:` 줄을 먼저 보세요. `latin-1`이면 인코딩을 잘못 판별한 것이니 엑셀에서 'CSV UTF-8'로 다시 저장하세요. 그렇지 않다면 터미널 표시 문제입니다. |
| `열 이름이 중복됩니다` | 같은 이름의 열이 둘입니다. 뒤엣것만 읽히고 앞엣것의 값이 사라지므로 거부합니다. 엑셀에서 이름을 다르게 고치세요. |
| 군(group)이 "시기"로 잡힌다 | `group`/`arm`/`군` 열은 시기로 자동인식됩니다. 병렬군 시험이면 `--ignore-period`를 쓰세요. |
| `--compare-periods`가 거부됨 | 시기 열이 없거나 값 철자가 다릅니다. 오류 메시지에 실제 값이 나옵니다. |

## 8. 결과를 보고할 때

보고서의 "논문용 문장 초안"은 **초안일 뿐**입니다. 최소한 다음을 함께 적으세요.

- 분석 단위가 **대상자**이고, 대상자마다 밤별 값을 평균했다는 것.
- 몇 박을 왜 제외했는지, `--min-nights`로 몇 명을 걸렀는지.
- 수면일기가 **자기보고**이며 PSG/액티그래피와 다를 수 있다는 것.
- SOL/WASO 결측을 0으로 처리한 밤이 몇 박인지 (보고서 "자료 품질"에 나옵니다).
- 낮잠은 포함되지 않았다는 것.
- 두 시기를 모두 기록한 대상자만 비교한 완전자료 분석이라는 것(ITT 아님).
- 다중비교 보정 여부.
