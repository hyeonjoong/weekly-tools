# powerplan — 임상연구 표본수·검정력 설계기

프로토콜/IRB/연구계획서에 그대로 붙일 수 있는 **표본수 계산**을 명령 한 줄로. 평균·ANOVA 계열은 비중심 t/F 분포로 정확히 계산하고, 탈락·군집설계·다중비교·기저값 보정(ANCOVA)·**중간분석(군차별설계)** 까지 반영하며, 사전연구 CSV에서 효과크기를 직접 뽑아 **한국어·영어 프로토콜 문장**까지 만들어 줍니다. 생존분석·반복측정(MMRM)·이분형 비열등성·McNemar·kappa 설계도 지원합니다. 외부 의존성 0.

## 목적 / Why this exists

연구를 시작할 때마다 "몇 명이 필요한가"에 답해야 합니다. IRB, 임상시험 프로토콜, 연구비 신청서에는 예외 없이 표본수 근거가 들어가고, 심사자는 α·검정력·효과크기·탈락률이 어디서 왔는지 묻습니다. 그런데 G*Power는 GUI라 재현 기록이 남지 않고, 온라인 계산기는 근거가 불투명하며, R 패키지는 설치·문법 부담이 있고 "분석 대상 n"과 "모집 n"을 나눠 보여주는 경우가 드뭅니다. 결과적으로 매번 손으로 다시 계산하고, 프로토콜 문장은 또 따로 씁니다. `powerplan`은 그 한 사이클(계산 → 검증 → 문장)을 한 번에 끝내고, 명령어 자체가 재현 가능한 기록이 되도록 만든 도구입니다. 특히 **기저값이 있으면 ANCOVA 보정으로 실제 필요한 표본수**를 계산하고(추적값만 비교하는 것보다 흔히 절반), 사전연구 데이터를 넣으면 **관측 효과크기의 신뢰구간 하한**으로 보수적 표본수를 기본값으로 제시합니다 — 소규모 파일럿의 효과크기를 그대로 믿어 본연구가 미검출로 끝나는 흔한 실패를 막기 위해서입니다.

Every study starts with "how many participants?", and every IRB submission, trial protocol and grant application must justify it. G*Power is a GUI that leaves no reproducible record, online calculators hide their assumptions, and sample-size packages rarely distinguish the **number to analyse** from the **number to enrol**. `powerplan` closes that loop in one command: it computes power exactly from the noncentral t/F distributions for means and ANOVA, applies the ANCOVA/change-score design factor when a baseline measurement exists, inflates for attrition, clustering and multiplicity, and emits ready-to-paste Korean and English protocol sentences. Given pilot data it plans on the **lower confidence bound** of the observed effect size by default — the conservative choice that prevents an underpowered main study. It is aimed at clinical/pharma researchers running insomnia-device and hearing-rehabilitation trials who need defensible numbers fast, offline, and reproducible from the command line itself.

## 지원하는 설계

| 하위 명령 | 언제 쓰나 | 계산 방식 |
|---|---|---|
| `ttest2` | 두 독립군 평균 비교 (device vs sham) | **정확** 비중심 t · `--analysis ancova/change` 지원 |
| `paired` | 같은 사람 전후 비교 (baseline → 8주) | **정확** 비중심 t |
| `onesample` | 기준값·규준 대비 | **정확** 비중심 t |
| `prop2` | 두 군 반응률(반응자 비율) 비교 | 정규근사 z (Yates 연속성 보정 옵션) |
| `anova` | 3군 이상 평균 비교 | **정확** 비중심 F |
| `corr` | 두 변수 상관 (HRV × 수면지표) | Fisher z 근사 |
| `noninf` | "더 나쁘지 않다" (비열등성) | **정확** 비중심 t, 단측 |
| `equiv` | "같다" (동등성, TOST) | **정확** 두 단측검정 동시확률 |
| `repeated` | 같은 지표를 여러 번 측정 (ISI 4·8·12주) | **정확** 비중심 t + Frison–Pocock 분산배율 (`--estimand last/average`) |
| `survival` | 사건까지의 시간 (재발·사망) | Schoenfeld 로그순위 + 지수 생존모형 |
| `mcnemar` | 같은 사람의 두 이분형 판정 | Connor 1987 정규근사 (+ 정확검정 검정력 표시) |
| `prop1` | 단일군 반응률 vs **성능목표치**(OPC) | **정확** 이항검정 (기각 임계값까지 제시) |
| `crossover` | 2×2 교차설계 (같은 사람이 두 처치를 다 받음) | **정확** 비중심 t (개인 내 SD 기준) |
| `icc` | 신뢰도 연구 (ICC 신뢰구간 폭) | Bonett 2002 근사 (정밀도 기준) |
| `loa` | Bland–Altman 일치한계 정밀도 | Bland & Altman 1999 근사 |
| `kappa` | 범주형 판정 일치도 (센서 vs 판독) | Fleiss 1969 분산 (정밀도 기준) |
| `diag` | 민감도·특이도 추정 (유병률 반영) | Buderer 1996 (정밀도 기준) |
| `pilot` | 사전연구 CSV → 효과크기 → 표본수 | 위 계산 + d의 정확 신뢰구간 |

`noninf`·`equiv`는 결과가 **연속형이면 `--sd`**, **이분형이면 `--p1/--p2`** 를 받아 각각 비중심 t와 위험차 z 검정으로 계산합니다.

**옵션이 설계마다 다릅니다:**

**옵션이 설계마다 다릅니다. 의미가 없는 옵션은 아예 등록되지 않으므로, 정확한 목록은 언제나 `powerplan <설계> --help`입니다.**

- 검정력 기반 설계 공통: `--alpha` `--power`(→표본수) `--n`/`--n-total`(→검정력) `--dropout` `--comparisons/--alpha-method` `--sensitivity`
- **`--sides` 없음**: `anova` `noninf` `equiv` (검정 방향이 설계로 고정됩니다)
- **`--ratio` 있음**(두 군 배분비): `ttest2` `prop2` `noninf` `equiv` `repeated` `survival`
- **`--cluster-size/--cluster-icc` 있음**: `ttest2` `prop2` `corr` `anova` `noninf` `equiv` `repeated` `survival` `pilot`. 없는 설계 — `paired` `onesample` `mcnemar` `prop1` `crossover` (군집을 *군에 배정*하는 구조가 아닙니다)
- **`--interim/--spending/--timing/--futility` 있음**: `ttest2` `paired` `onesample` `prop2` `corr` `noninf` `repeated` `survival` `mcnemar` `pilot`. 없는 설계 — `anova`(전방향 F 검정) `equiv`(TOST) `prop1`(정확 이항검정) `crossover`(시기·이월효과)
- `icc` `loa` `kappa` `diag` → 정밀도 기준이라 `--alpha`와 `--n`만 받습니다. `--n`을 주면 "이 인원으로 얻는 정밀도"를 거꾸로 계산합니다 (`--power`/`--dropout`/`--cluster-*`/`--comparisons`/`--interim` **없음** — 탈락은 직접 나눠서 보정하세요)
- 설계별 추가 옵션: `--ratio`(두 군 설계 전부), `--analysis`/`--baseline-r`(ttest2), `--post`/`--baseline-n`/`--rho`/`--analysis`/`--estimand`(repeated), `--hr`/`--median1`/`--accrual`/`--followup`/`--event-rate`/`--method`/`--time-unit`(survival), `--p01`/`--p10`(mcnemar), `--continuity`(prop2), `--bias-correct`(corr), `--lower-is-better`/`--diff`(noninf), `--diff`(equiv), `--means`(anova), `--prevalence`(kappa/diag), `--raters`(icc), `--p1`/`--p0`(prop1), `--diff`/`--sd-within`(crossover), `--sens`/`--spec`/`--half-width`(diag), `--groups`/`--filter`/`--baseline`/`--plan-on`/`--conf`/`--skip-invalid`(pilot)
- 모든 설계 공통: `--format text|md|json` `-o 파일` `--force`

전체 목록은 `powerplan <설계> --help`.

### 2) 기저값이 있으면 ANCOVA로 — 표본수가 절반으로

사전-사후 측정이 있는 연구(거의 전부)에서 추적값만 비교하는 것은 검정력을 버리는 일입니다. 기저값을 공변량으로 넣으면 분산이 (1 − r²)배로 줄어듭니다:

```bash
$ powerplan ttest2 --d 0.309 --power 0.8 --analysis ancova --baseline-r 0.711
```
```
 검정         : 공분산분석 ANCOVA (기저값을 공변량으로 보정)
 효과크기     : Cohen's d = 0.309 (작음/small · 설계배율 0.494 → 실질 d 0.439)

▶ 필요한 분석 표본수 : 군당 83명 (1군 83 + 2군 83) = 총 166명
```
같은 가정에서 추적값만 비교하면 군당 166명(총 332명)입니다 — **정확히 2배**. r은 사전연구에서 추정할 수 있습니다(아래 3번). `--analysis change`(변화량 분석)도 있으며, 배율 2(1−r)이라 **r > 0.5일 때만** 유리합니다.


### 5) 중간분석이 있으면 — 군차별설계(group-sequential)

안전성·윤리 때문에 중간분석을 하는데 같은 α를 그대로 쓰면 1종오류가 부풉니다(2회면 0.05 → 0.083). `--interim`을 주면 α 소비함수로 각 시점의 임계값을 나누고, 그 대가인 **표본수 팽창계수**까지 반영합니다.

```bash
$ powerplan ttest2 --d 0.5 --power 0.9 --interim 1 --spending pocock
```
```
▶ 필요한 분석 표본수 : 군당 95명 (1군 95 + 2군 95) = 총 190명

■ 중간분석 경계 (Pocock 형 (Lan–DeMets) α 소비함수, 총 2회 분석)
  시점        정보비율    누적 N    Z 경계      명목 p    누적 α  중단확률
  ------------------------------------------------------------------------
  중간 1         0.500        95    2.1570     0.03101    0.0310     60.2%
  최종           1.000       190    2.2010     0.02774    0.0500     29.8%
  (중단확률 = 대립가설이 참일 때 그 시점에서 유의성에 도달할 확률)
  기대 표본수: 효과가 있으면 133명, 없으면 187명 (최대 190명)
  고정설계(중간분석 없음)라면 172명 → 팽창계수 ×1.1110
```

`--spending obf`(기본, 초반을 아껴 최대 표본수가 거의 안 늘어남) · `pocock`(초반에 넉넉히 써 조기중단 확률이 높음) · `linear`. 중간분석 시점은 `--timing 0.4,0.7`처럼 정보비율로 지정합니다(기본은 균등 배치). 분석 사이 간격은 최소 1%(정보량)여야 하며, 더 촘촘하면 거절합니다 — 그보다 붙은 중간분석은 실제로 의미가 없고 수치적으로도 믿을 수 없습니다. 프로토콜 문장에도 경계값과 팽창계수가 함께 들어갑니다.

#### 무익성(futility) 중단 경계 — `--futility`

실제 DSMB 헌장에는 "효과가 없어 보이면 그만둔다"는 규칙이 거의 항상 들어갑니다. `--futility`를 주면 **β 소비함수**로 그 경계를 잡습니다 — α 소비함수의 거울상으로, "대립가설이 참인데도 시점 t까지 무익성으로 멈출 누적확률"을 β\*(t)로 맞춥니다.

```bash
$ powerplan ttest2 --d 0.5 --power 0.9 --interim 1 --spending pocock --futility obf
```
```
▶ 필요한 분석 표본수 : 군당 97명 (1군 97 + 2군 97) = 총 194명

■ 중간분석 경계 (Pocock 형 (Lan–DeMets) α 소비함수, 총 2회 분석, 무익성 O'Brien–Fleming 형)
  시점       정보비율        누적 N   Z 경계     명목 p   누적 α 중단확률  무익성 Z 무익중단
  ------------------------------------------------------------------------------------------
  중간 1        0.500            97   2.1570    0.03101   0.0310    63.1%    0.3849    65.0%
  최종          1.000           194   2.2010    0.02774   0.0500    36.9%    2.2010    32.6%
  (중단확률 = 대립가설이 참일 때 그 시점에서 **어떤 이유로든** 멈출 확률 = 효능 + 무익성)
  (무익중단 = 효과가 **없을** 때 그 시점에서 무익성으로 멈출 확률. 최종 시점의 무익성 경계는 효능 경계와 같습니다)
  무익성으로 멈출 누적확률: 효과 없으면 65.0%, 효과 있는데 잘못 멈추면 2.0% (= 소비한 2종오류 β*)
  실제 검정력 손실: 90.0% → 89.5% (0.5%p) — 같은 표본수에 무익성 규칙만 얹었을 때. 이만큼을 되찾도록 표본수를 늘렸습니다
  무익성 경계에서의 조건부 검정력 — 중간 1: 39% (추세대로면 1%). = 그 시점에 경계값을 봤을 때 최종분석에서 유의해질 확률(가정한 효과가 맞다면 / 관측 추세가 이어진다면)
  비구속적(non-binding): 무익성 경계를 무시하고 계속해도 전체 α는 0.0500 이하로 유지됩니다. 경계를 지키면 **효능 방향** α가 0.0250 → 0.0246으로 내려갑니다 (양측 α 0.05가 아니라 그 절반과 비교한 값입니다).
  기대 표본수: 효과가 있으면 133명, 없으면 129명 (최대 194명)
  고정설계(중간분석 없음)라면 172명 → 팽창계수 ×1.1317
```

읽는 법 네 가지:

1. **무익성 Z 0.3849** — 중간분석에서 Z가 이 값 아래면 "효과 없음"으로 중단을 권고합니다. 관측된 Z가 0.38이라면 **추세가 그대로 이어진다는 전제에서는** 최종에 유의해질 확률이 1% 수준입니다(가정한 효과가 실제로 맞다면 39% — 아래 3번). 양측설계에서는 이 경계가 해(harm) 방향 효능 경계(−2.157)까지 덮으므로, DSMB에는 '무익'과 '해'를 구분해 보고하도록 헌장에 적으세요.
2. **비구속적(non-binding)** — 효능 경계를 무익성과 **무관하게** 정했기 때문에, DSMB가 무익성 경계를 넘고도 "계속 간다"고 결정해도 전체 1종오류율은 0.05를 넘지 않습니다. FDA 적응적 설계 가이던스(2019)는 구속적 경계가 "규칙을 실제로 지킬 때만" α를 통제한다는 점을 지적하는데, 이 툴은 그 위험을 피해 구속적(binding) 경계를 **지원하지 않습니다**. 대신 경계를 지키면 **효능 방향** α가 0.0250 → 0.0246으로 내려갑니다. 비교 대상은 양측 0.05가 아니라 그 절반(0.025)입니다 — 무익성 경계를 지키면 해(harm) 방향으로 기각할 길이 사실상 막히므로 단측 설계처럼 굴러가기 때문입니다.
3. **조건부 검정력** — 경계 Z 값만으로는 감이 안 옵니다. 그래서 "그 시점에 경계값을 봤을 때 최종분석에서 유의해질 확률"을 함께 찍습니다: `중간 1: 39% (추세대로면 1%)`. 앞은 가정한 효과가 실제로 맞다는 전제, 뒤는 관측된 추세가 그대로 이어진다는 전제입니다. DSMB 회의에서 실제로 오가는 숫자가 이쪽입니다.
4. **팽창계수 1.1110 → 1.1317** — 무익성 규칙을 얹으면 검정력이 90.0% → 89.5%(0.5%p)로 내려가므로, 이를 되찾도록 표본수를 늘립니다. 여기서 헷갈리기 쉬운 것: "효과가 있는데 잘못 멈출 확률 2.0%"는 **소비한 2종오류 β\***이지 검정력 손실이 아닙니다 — 그렇게 멈춘 시험 대부분은 어차피 최종에서도 실패했을 것이기 때문입니다. 대신 효과가 없을 때 기대 표본수가 187명 → 129명으로 줄어듭니다 — 무익성 경계를 넣는 진짜 이유입니다.

`--futility obf`(초기엔 거의 멈추지 않음, 보수적) · `pocock`(초기부터 적극적으로 멈춤) · `linear`. `--interim` 없이 쓰면 오류입니다. `--n`(가진 인원으로 검정력 역산)과 함께 쓸 때는 `--power`도 함께 줘야 합니다 — 무익성 경계는 β 소비함수로 정하므로 목표 검정력이 없으면 경계 자체가 정해지지 않습니다(효능 경계와 달리 검정력에 의존합니다). **고르는 값에 따라 비용이 크게 다릅니다** — 위 설계(`--spending pocock`, 검정력 90%)에서 `obf`는 표본수를 1.9%만 더 요구하지만(190 → 194명) `pocock`은 12.6%(190 → 214명)를 더 요구합니다. 초기 중단을 얼마나 원하는지와 표본수 여유를 함께 보고 고르세요.

DSMB 헌장에는 이렇게 적으면 됩니다 (그대로 붙여 쓰세요):

> 정보량의 50% 시점에 독립 통계자가 비맹검으로 중간분석을 수행한다. 효능 중단 경계는 Z ≥ 2.157(명목 양측 p ≤ 0.031), 무익성 중단 경계는 Z ≤ 0.385이다. 무익성 경계는 **비구속적**이므로 DSMB는 경계를 넘더라도 계속 진행을 권고할 수 있으며, 그 경우에도 전체 1종오류율은 0.05를 넘지 않는다. 두 경계 모두 실제 관측된 정보비율에 따라 소비함수로 재계산한다. DSMB의 판단은 권고이며 최종 결정은 의뢰자가 한다.

### 6) 반복측정 — ISI를 4·8·12주에 재는 설계 (MMRM/ANCOVA)

```bash
$ powerplan repeated --d 0.4 --post 3 --baseline-n 1 --rho 0.6 --power 0.8
```
```
 검정         : 마지막 방문의 반복측정 ANCOVA/MMRM (사전 평균 보정)
 효과크기     : Cohen's d (1회 측정 기준) = 0.4 (작음/small · 마지막 방문 기준, 사후 3회/사전 1회, ρ=0.6 · 설계배율 0.640 → 실질 d 0.500)

▶ 필요한 분석 표본수 : 군당 65명 (1군 65 + 2군 65) = 총 130명
  총 측정 횟수       : 520회 (1인당 4회 × 130명)
  1차 평가 시점      : 마지막 방문 1회
```

**`--estimand`가 이 설계의 핵심입니다.** 기본값 `last`는 "1차 평가변수 = 마지막 방문(12주) 시점의 군간 차이"로, 실제 프로토콜이 거의 항상 쓰는 정의입니다. 이때 중간 방문을 몇 번 하든 표본수는 줄지 않습니다 — 복합대칭·완전자료에서 마지막 시점의 분산은 σ² 그대로이기 때문입니다(중간 방문의 값어치는 탈락자의 정보를 MMRM이 회수해 주는 데 있고, 그 이득은 이 식에 넣지 않았습니다 = 그만큼 보수적입니다).

1차 평가변수를 정말 **사후 방문들의 평균**으로 정한 프로토콜이라면 `--estimand average`를 쓰세요:

```bash
$ powerplan repeated --d 0.4 --post 3 --rho 0.6 --power 0.8 --estimand average
 효과크기     : ... 사후 평균 기준 ... 설계배율 0.373 → 실질 d 0.655
▶ 필요한 분석 표본수 : 군당 39명 (1군 39 + 2군 39) = 총 78명
```

군당 65명 대 39명 — **SAP의 1차 분석이 무엇인지에 따라 40% 차이가 납니다.** 마지막 방문을 볼 계획인데 `average`로 계산하면 그대로 미검출로 끝나는 흔한 과소설계입니다. 분산 배율은 Frison & Pocock(1992)의 복합대칭 공식이고, ANCOVA에는 공변량 불균형에 따른 분산 팽창 1 + 1/(N−3)까지 반영했습니다.

참고로 사후 1회만 재고 기저값 보정도 하지 않으면(`--post 1 --baseline-n 0 --analysis post --rho 0`) 군당 100명입니다 — 기저값 하나를 공변량으로 넣는 것만으로 65명입니다.

### 7) 생존분석 — 사건 수가 표본수를 결정한다

```bash
$ powerplan survival --hr 0.7 --median1 12 --accrual 18 --followup 12 --power 0.8
```
```
▶ 필요한 분석 표본수 : 군당 198명 (1군 198 + 2군 198) = 총 396명
  기대 사건 수       : 247.9건 (대조 136.4 + 중재 111.4) ← 검정력은 사건 수가 결정합니다
  사건 발생 확률     : 대조 68.9% · 중재 56.3% (등록 18 + 추적 12개월, 지수 생존모형)
```
Schoenfeld 공식으로 필요 **사건 수**를 먼저 구하고, 지수 생존모형(중앙생존 `--median1`, 등록기간 `--accrual`, 추가 추적 `--followup`)으로 등록 인원을 역산합니다. 사건 수만 알고 싶으면 `--event-rate 1`을 주면 총 N이 곧 사건 수입니다. 추적을 늘리는 쪽이 등록을 늘리는 쪽보다 싼 경우가 많으니 `--followup`을 바꿔 가며 비교해 보세요.

### 8) 이분형 결과의 비열등성·동등성, 그리고 대응 비율(McNemar)

```bash
powerplan noninf --margin 0.10 --p1 0.70 --p2 0.70 --power 0.8      # 반응률 비열등성: 군당 330명
powerplan equiv  --margin 0.10 --p1 0.60 --p2 0.62 --power 0.8      # 반응률 동등성(TOST)
powerplan mcnemar --p01 0.05 --p10 0.15 --power 0.8                 # 같은 사람의 두 판정: 155명
```
`noninf`/`equiv`는 `--sd`(연속형) 대신 `--p1/--p2`(이분형)를 주면 위험차 기준으로 계산합니다. `mcnemar`의 `--p01`/`--p10`은 **전체 대상자 중** 판정이 엇갈린 쌍의 비율이며, 검정력은 그 불일치 쌍에서만 나옵니다.

```bash
$ powerplan prop1 --p1 0.60 --p0 0.45 --power 0.8
```
```
 검정         : 정확 이항검정 (단일군, 성능목표치 대비)
 유의수준     : α = 0.025 (단측)

▶ 필요한 분석 표본수 : 95명
```

### 10) 2×2 교차설계 — 같은 사람이 두 처치를 다 받는다

```bash
$ powerplan crossover --diff 3 --sd-within 6 --power 0.8 --dropout 0.15
▶ 필요한 분석 표본수 : 순서당 33명 (AB 33 + BA 33) = 총 66명
▶ 모집 표본수        : 순서당 39명 (AB 39 + BA 39) = 총 78명  (탈락 15%)
```

`--sd-within`은 **개인 내** 표준편차입니다(사람들 사이의 SD가 아닙니다). 사전연구에서 같은 사람을 두 번 잰 차이의 SD가 σ_diff라면 σ_w = σ_diff/√2 입니다. 이월효과가 없다는 가정이므로 휴약기간 근거를 프로토콜에 적어야 합니다.

### 11) 진단정확도 — 유병률까지 반영해야 맞는 숫자가 나온다

```bash
$ powerplan diag --sens 0.9 --spec 0.85 --prevalence 0.2 --half-width 0.05
▶ 필요한 대상자 수   : 995명
  질환자 / 비질환자  : 약 199명 / 796명  (제약이 되는 쪽: 민감도)
  예상 반폭          : 민감도 ±0.04955 · 특이도 ±0.02648
  사례-대조 설계라면 : 질환자 199명 + 비질환자 250명이면 충분합니다
```

민감도는 **질환이 있는 사람에서만** 추정되므로, 필요한 것은 "전체 n"이 아니라 "질환자 n"입니다. 유병률 20%면 질환자 199명을 채우려고 995명을 등록해야 합니다 — 이 나눗셈을 빼먹는 것이 이 설계에서 가장 흔한 실수입니다.

기본값은 **Wilson(score) 구간**입니다. 흔히 인용되는 Buderer 공식은 Wald 구간 기준이라 같은 조건에서 695명이면 된다고 하지만, 민감도가 0.9를 넘으면 Wald 구간은 실제로 논문에 보고되는 Wilson·Clopper–Pearson 구간보다 **좁게** 나와 목표 정밀도를 달성하지 못합니다(위 예에서 실제 반폭 ±0.061). 문헌값과 맞춰야 하면 `--method wald`.

### 12) 범주형 판정의 일치도 — kappa

```bash
$ powerplan kappa --kappa 0.7 --width 0.2 --prevalence 0.3
```
연속형 지표(호흡수·심박)는 `icc`/`loa`, **범주형 판정**(이상소견 유무, 수면단계 하나를 골라 이분화)은 `kappa`입니다. 유병률이 극단적일수록 필요한 표본수가 급증하므로 `--prevalence`를 실제값으로 넣으세요.

### 13) 그 밖의 설계

```bash
powerplan prop2 --p1 0.30 --p2 0.50 --power 0.8            # 반응률 30%→50%: 군당 93명
powerplan anova --k 3 --means 8,6,5 --sd 6 --power 0.8     # 3군 비교
powerplan corr --r 0.35 --power 0.8                        # 상관 r=0.35: 62명
powerplan noninf --margin 3 --sd 8 --power 0.8 --lower-is-better   # 비열등성(ISI)
powerplan equiv --margin 5 --sd 8 --power 0.8              # 동등성(TOST)
powerplan icc --icc 0.8 --width 0.15 --raters 2            # 신뢰도 연구: 90명
powerplan loa --sd-diff 2.0 --half-width 0.5               # LoA 정밀도: 183명
powerplan ttest2 --d 0.5 --n-total 100                     # 총 N으로 검정력 확인
powerplan icc --icc 0.8 --width 0.15 --n 40                # 40명이면 폭이 얼마나 되나(역방향)
powerplan ttest2 --d 0.4 --power 0.8 --cluster-size 10 --cluster-icc 0.05 --dropout 0.1
powerplan ttest2 --d 0.5 --power 0.8 --comparisons 3        # 다중비교 α 보정
powerplan ttest2 --d 0.5 --power 0.8 --format md -o 표본수.md
```

군집 무작위배정에서는 세 숫자를 구분해 보여줍니다:

```
$ powerplan ttest2 --d 0.4 --power 0.8 --cluster-size 10 --cluster-icc 0.05 --dropout 0.1

  유효 표본수(개인배정 기준) : 군당 100명 (1군 100 + 2군 100) = 총 200명
▶ 필요한 분석 표본수 : 군당 145명 (1군 145 + 2군 145) = 총 290명   ← × 설계효과 1.450
  목표 검정력        : 80.0%  →  실제 달성 80.4%
▶ 모집 표본수        : 군당 170명 (1군 170 + 2군 170) = 총 340명  (탈락 10%, 군집 단위 올림)
  군집 수            : 1군 17개, 2군 17개 (군집당 10명 — 위 모집 인원은 군집 단위로 올린 값)
```

## 계산의 정확도 — 무엇과 대조했나

- **비중심 t / 비중심 F를 직접 구현**했습니다(정규근사 아님). 비중심 t는 χ 분포에 대한 조건부 기대값을 Gauss–Legendre 복합구적으로, 비중심 F는 Poisson 가중 불완전베타 급수로 계산합니다. mpmath 40자리 기준값과 **상대오차 1e-11 이하**로 일치합니다(기준값을 테스트에 하드코딩 — scipy 없이도 검증됩니다).
- **G*Power 3.1 값과 일치**: d=0.5→군당 64명, d=0.8→26명, d=0.2→394명, 검정력 90%→86명, 대응표본 dz=0.5→34명, ANOVA k=3 f=0.25→군당 53명(총 159), 비율 .30 vs .50→군당 93명 등 16개 사례를 테스트로 고정.
- **몬테카를로 교차검증**: 비중심 t와 TOST 검정력을 6만 회 시뮬레이션 기각률과 4 표준오차 이내로 대조(고정 시드, 오프라인).
- **검정의 크기(1종오류율) 확인**: 효과크기를 0에 가깝게(1e-9) 두면 5개 설계(양측)·4개 설계(단측)에서 기각률이 α와 2e-3 이내로 일치합니다. `mcnemar`와 이분형 `noninf`는 이 툴이 쓰는 **검정력 함수가 한쪽 꼬리만 보므로** 귀무가설에서의 값이 α/2로 수렴하며, 그 값도 따로 고정해 두었습니다(실제 McNemar 검정 자체는 양측으로 α를 지킵니다).
- **ANCOVA 설계배율**은 Frison & Pocock(1992) / Borm et al.(2007)의 (1−r²) 공식과 ±2명 이내로 일치. 반복측정(`repeated`)의 분산 배율은 복합대칭 자료를 직접 생성해 잰 경험분산과 2% 이내로 일치.
- **ANCOVA 분산 팽창**(공변량 불균형에 따른 1+1/(N−3))을 반영했고, 반영 전/후를 모의실험(6만 회 ANCOVA 적합)과 대조해 확인했습니다 — 빼먹으면 검정력이 0.5~1.5%p 과대평가됩니다.
- **군차별설계 경계를 교과서 상수와 대조**: Pocock(1977) 상수 경계 2.178/2.289/2.361/2.413(K=2~5, 양측 0.05)과 O'Brien–Fleming(1979) 첫 경계 2.797/3.471/4.049/4.562를 재귀적분으로 재현(오차 < 1e-3), 표본수 팽창계수 1.110/1.166/1.202/1.229(검정력 0.80)도 일치. **이는 재귀적분 엔진 자체의 검증이며, `--spending`이 만드는 Lan–DeMets 소비함수 경계는 이 고전 상수와 값이 조금 다릅니다**(예: `--spending pocock --interim 1`은 2.157/2.201). 소비함수 설계의 귀무가설 이탈확률이 정확히 α임을 확인하고, 20만 회 몬테카를로와도 대조.
- **kappa 분산**은 Fleiss·Cohen·Everitt(1969)의 일반 델타법 공식을 2×2에 직접 대입한 값과 1e-12 이내로 일치.
- **McNemar**: Connor(1987) 공식을 손계산과 대조하고, 정확 조건부 이항검정의 검정력을 4만 회 모의실험과 대조(0.7617 vs 0.7632). 두 값을 함께 출력합니다.
- **문서 정직성을 테스트로 강제**: README·사용법.md·실행.command 안의 모든 명령을 실제로 실행하고, 문서가 약속한 숫자(군당 64명, 설계배율 0.640, Z 경계 2.1570 …)가 진짜로 출력에 나오는지 확인합니다(`tests/test_docs_examples.py`). 문서와 코드가 어긋나면 테스트가 깨집니다.
- **생존분석**의 지수 생존모형 사건확률을 20만 구간 사다리꼴 적분과 1e-8 이내로 대조, Schoenfeld 필요 사건 수(HR 0.7·검정력 0.8 → 247건)를 손계산과 대조.

## Notes / 한계 (정직하게)

- **"정확"이라고 쓴 것은 (1) 평균·ANOVA·반복측정·교차설계의 t·F 검정과 (2) `prop1`의 이항검정뿐입니다.** `prop2`는 정규근사 z, `corr`는 Fisher z, `survival`은 Schoenfeld/Freedman 정규근사, `mcnemar`는 Connor 정규근사, `icc`·`loa`·`kappa`·`diag`는 근사식입니다. 중간분석 경계도 Z 정규근사입니다.
- `corr`의 Fisher z 근사는 **정확법보다 0~1명 크게** 나옵니다(계획 단계에서는 보수적이라 안전). 심사자의 G*Power 값과 맞추려면 `--bias-correct`를 쓰세요.
- `prop2`는 정규근사 z 검정 기준입니다. **Fisher 정확검정**을 쓸 계획이면 5~15% 여유를 두세요. 기대 사건수(n·p)가 군당 5 미만이면 정규근사가 깨집니다. `--continuity`는 검정통계량에 Yates 보정을 적용한 것이며, 표본수를 직접 부풀리는 Casagrande–Pike–Smith 공식과는 몇 명 차이가 날 수 있습니다.
- `ttest2`는 **등분산**을 가정합니다(Welch를 쓸 계획이면 약 5% 여유). 비모수 검정(Mann–Whitney)을 쓸 계획이면 10% 정도 여유를 두세요.
- `anova`의 표본수는 **전체 F 검정** 기준입니다. 특정 두 군 사후비교를 확실히 검출하려면 보정된 α로 `ttest2`를 따로 계산하세요.
- ANCOVA 배율은 **기저값 공변량 1개**를 가정합니다(자유도 1 차감). r을 낙관적으로 잡으면 표본수가 과소해집니다.
- 군집설계는 설계효과(DE = 1 + (m−1)·ICC) 보정 방식입니다. 군집 수가 적으면(군당 10개 미만) 혼합효과모형 기반 계산이 더 적절합니다.
- `icc`(Bonett)·`loa`(Bland–Altman)는 **검정력이 아니라 정밀도(신뢰구간 폭) 기준**이며, 근사식이라 정확법과 몇 명 정도 차이가 날 수 있습니다.
- `survival`은 **Schoenfeld 정규근사 + 비례위험 + 지수 생존**을 가정합니다. 생존곡선이 교차하거나(면역치료) 효과가 늦게 나타나면 맞지 않으며, 그때는 RMST 기반 설계가 필요합니다. `--dropout`은 중도절단을 단순 인원 비율로만 보정합니다.
- `repeated`의 분산 배율은 **복합대칭**(모든 측정 쌍의 상관이 같음)을 가정합니다. 실제로는 시간 간격이 멀수록 상관이 낮아지므로(AR(1)) 약간 낙관적입니다 — 가장 먼 두 시점의 상관을 `--rho`에 넣으면 보수적입니다.
- `mcnemar`(Connor)·이분형 `noninf`/`equiv`는 **정규근사**입니다. 기대 불일치 쌍이 20 미만이거나 기대 사건수가 군당 5 미만이면 정확법을 쓰고 여유를 두세요.
- `kappa`는 **평가자 2명·이분형 판정·두 평가자의 유병률이 같다**는 가정의 대표본 분산식입니다. **3범주 이상(예: 수면단계 W/N1/N2/N3/R)이나 가중 κ는 이 식으로 계산할 수 없습니다** — 관심 범주를 하나 골라 이분화하거나 시뮬레이션 기반 계산이 필요합니다.
- 중간분석(`--interim`)의 경계·팽창계수는 **Z 통계량(정규근사)** 기반입니다(gsDesign·EAST와 같은 방식). 무익성 경계는 `--futility`로 함께 계획할 수 있으나 **비구속적(non-binding)만** 지원합니다 — 구속적 경계는 DSMB가 계속 진행하기로 하면 α가 새기 때문입니다. `anova`·`equiv`에는 적용되지 않습니다.
- `prop1`은 **대조군이 없는** 설계입니다. 표본수보다 성능목표치 p₀의 근거가 심사에서 더 많이 지적됩니다.
- `crossover`는 **이월효과가 없다**고 가정합니다(휴약기간 근거 필요). 생물학적동등성(로그변환 TOST·CV 기반)은 다루지 않습니다.
- `diag`는 관측이 **서로 독립**이고 참조표준이 **완전하다**고 가정합니다. 수면단계 판독처럼 한 사람에게서 수백 개의 epoch가 나오는 자료에서는 "질환자 199명"이 사람이 아니라 **독립 관측 199개**라는 뜻이 되며, 실제로는 개인 내 상관 때문에 훨씬 더 필요합니다 — 이 툴은 그 보정을 제공하지 않습니다. AUC 비교, 두 검사의 상관을 반영한 짝지은 비교는 다루지 않습니다.
- **아직 없는 설계** (자주 필요한 순): 공동 1차 평가변수(둘 다 성공해야 하는 설계 — α를 나누는 `--comparisons`는 이 경우 **틀린 보정**입니다), 구속적(binding) 무익성 경계, 교차설계의 비열등성·동등성, **반복 관측이 있는 진단정확도**(수면단계처럼 1인당 수백 epoch — `diag`는 관측이 서로 독립이라고 가정합니다), 평균·평균차의 정밀도(신뢰구간 폭) 기준 표본수, 발생률(Poisson·음이항) 비교, k군 비율 비교(χ²), Simon 2단계 설계, 적응적 표본수 재계산, 생물학적동등성, 생존분석 비열등성(HR 마진), 오즈비·상대위험 마진 기반 이분형 비열등성, AUC 비교·짝지은 진단검사 비교, 다범주·가중 kappa, 군집-교차설계·계단쐐기(stepped-wedge), Welch(부등분산) t 검정, 회귀 다중예측자, 계층화 로그순위, RMST, 순서형·비모수(Mann–Whitney) 정확계산.
- 마진(비열등성·동등성)과 "임상적으로 의미있는 차이"는 통계가 아니라 **임상적 판단**입니다. 이 툴은 계산만 해 줍니다. 3상 확증시험이라면 검정력 0.80보다 0.90을 권합니다.
- 사전연구 기반 계획의 하한은 `--conf`로 조절합니다. **`--conf`는 양측 신뢰수준**이므로 `--conf 0.95`의 하한은 한쪽 꼬리 2.5% 지점입니다(단측 97.5% 하한). "사전연구는 불확실하니 상한/하한으로 보수적으로 잡으라"는 제안 자체는 Browne(1995)과 Kieser & Wassmer(1996)에서 왔지만, 그 두 논문은 **분산(SD)의 상측 신뢰한계**를 다루며 효과크기 하한을 다루지 않습니다 — 여기서 쓰는 방식은 같은 취지의 응용입니다. 기본 0.95는 가장 보수적이며, 너무 커서 계획이 불가능하면 `--conf 0.8`처럼 낮춰 보세요.
- `mcnemar`는 Connor 정규근사로 표본수를 잡고, **정확 조건부 이항검정의 검정력을 함께 표시**합니다. 정확검정은 이산분포라 보수적이므로(실제 크기 0.05 → 0.032) 그쪽으로 분석할 계획이면 표본수를 더 잡아야 합니다.
- 중간분석의 **정보량**은 설계마다 다릅니다. `survival`은 사건 수 기준으로 경계표를 만들고(정보비율 50% = 목표 사건 수의 절반), 나머지 설계는 1차 결과변수를 완료한 인원 기준입니다 — 등록 인원이 아닙니다.
- 저장물(`-o`)과 모든 출력 아래에는 **재현 정보**(도구 버전·명령·시각)가 붙습니다. 단 경로는 파일 이름만 남깁니다(폴더 이름에 연구·대상자 정보가 들어가는 일이 흔하므로). `pilot`의 오류 메시지는 기본적으로 **원본 셀 값을 보여 주지 않고** 행·열 위치만 표시하며, 값이 필요하면 `--show-values`, 출력물을 공유해야 하면 `--redact`를 쓰세요.
- 수치 신뢰 범위: α ≥ 1e-9, 검정력 ≤ 1−1e-10, 자유도 ≤ 1e12. 그 밖(예: `--power 0.99999999999999`)에서는 표본수가 1~3명 흔들릴 수 있습니다. 자유도 2 이하 + 극단적 임계값 조합에서는 비중심 t의 절대오차가 최대 ~1e-3까지 커질 수 있습니다(표본수 결과는 바뀌지 않음).
- **CSV/데이터 취급**: 네트워크 접속이 전혀 없습니다(코드에 소켓/HTTP 계열 import가 없음). CSV는 앞 64KB만 읽어 인코딩·구분자를 판별한 뒤 **스트리밍으로 한 줄씩** 처리하므로 파일이 커도 메모리는 수십 MB 수준입니다(100만 행·15MB 파일을 2.6초에 읽으며 메모리 증가는 3MB 미만). 인코딩은 utf-8·한국어 엑셀(cp949)을 자동 인식하며, 그 밖의 인코딩(예: Shift-JIS)은 오류 없이 깨진 글자로 읽힐 수 있으니 열 이름이 이상하면 UTF-8로 다시 저장하세요. 결과 저장은 `-o`로 지정한 파일에만 쓰고, 권한 0600·심볼릭 링크 미추적·기존 파일은 `--force` 없이 덮어쓰지 않습니다. 저장물에는 군 라벨·요약통계·관측 범위가 들어가며, 숫자가 아닌 원본 값은 남기지 않습니다.
- 번들 예제(`examples/*.csv`)는 **합성 데이터**입니다 — 실제 환자 자료가 아닙니다([examples/README.md](examples/README.md)).
