# 사용법 (한글 빠른 안내)

## 30초 요약

**투고 봉투 안의 파일이, 작업 폴더의 최신본과 같은 세대인지** 확인합니다.
낡은 파일만 찍어 줍니다. **고치지는 않습니다.**

## 1) 일단 눌러 보기

`실행.command` 를 **더블클릭**하세요. 합성 예제로 종료코드 네 가지(0·1·3·2)를 순서대로 보여 줍니다.
실제 논문 자료는 전혀 건드리지 않습니다.

## 2) 내 논문 폴더에 쓰기 — 세 단계

### ① 무엇을 읽는지부터 본다

```bash
python3 -m stalecheck --work "/경로/내논문폴더" --inspect
```

읽은 파일 수, 확장자 분포, **대상 확장자 밖이라 보지 않은 파일 수**, 봉투로 인식한 폴더와 그 근거,
제외한 아카이브 폴더를 인쇄하고 **판정하지 않고** 끝냅니다. 여기서 "잘못 읽었다"를 1초 안에 알 수
있습니다. 판정하지 않으므로 **종료코드는 항상 2**입니다(`--inspect && 제출` 이 통과하지 않게 하려는 것).

### ② 봉투를 지정한다

`--package` 를 안 주면 후보만 인쇄하고 **거절합니다**(종료코드 2).
추론해서 바로 판정하지 않습니다 — 이 트리에는 `submission/`, `01_제출용_SUBMISSION/`,
`제출패키지` 처럼 명명 규약이 여러 개 섞여 있어서, 추론이 틀리면 전부 헛짚기 때문입니다.

```bash
python3 -m stalecheck --work "/경로/내논문폴더"
# → 봉투 후보를 인쇄하고, 그대로 복사해 쓸 수 있는 실행 줄을 알려 줍니다
```

### ③ 판정한다

```bash
python3 -m stalecheck \
    --work    "/경로/내논문폴더" \
    --package "/경로/내논문폴더/submission" \
    --out-dir ~/Desktop/세대점검_20260918
```

봉투가 여러 벌이면 `--package` 를 여러 번 주면 됩니다.

```bash
python3 -m stalecheck --work "/경로/BELL_Paper3" \
    --package "/경로/BELL_Paper3/SUBMISSION_BRM" \
    --package "/경로/BELL_Paper3/SUBMISSION_JPBA"
```

## 3) 결과 읽는 법

```
짝지음 41쌍 · 일치 20쌍 · 그중 메타데이터만 달랐던 것 0쌍
```
→ 이름으로 짝지은 41쌍 중 20쌍이 같습니다. "메타데이터만 달랐던 것"은 **다시 렌더했을 뿐**
내용은 같은 파일 수입니다(이게 0이 아니면, 정규화가 오탐을 막아 준 겁니다).

| 표시 | 뜻 | 해야 할 일 |
|---|---|---|
| `[치명] 봉투가 구세대` | 내용이 다르고, **작업본이 나중에 수정됨** | 작업본을 봉투로 다시 복사할지 판단 |
| `[경고] 봉투가 더 최신` | 내용이 다르고, **봉투가 나중에 수정됨** | 봉투에서 손으로 고친 것입니다. **그 수정이 작업 폴더에 없습니다** — 덮어쓰기 전에 꼭 확인 |
| `[판정불가]` | 내용은 다른데 수정시각으로 방향을 못 정함 | 두 파일을 직접 비교 |
| `[경고] 빌드 누락` | `.md` 가 `.docx` 보다 최신 | 다시 굽기 |
| `[경고] 그림 형제 세대 불일치` | 같은 그림의 `.png` 와 `.pdf` 가 다른 세대 | 두 포맷을 같이 다시 내보내기 |

콘솔에는 **치명 최대 5건**만 펼쳐집니다. 전체는 `--out-dir` 의 `세대불일치.csv` 에 있습니다.

**마지막 `[커버리지 자백]` 을 꼭 읽으세요.** 이 툴은 "봉투가 최신"이라고 보증하지 않습니다.
짝지은 쌍에 대해서만 말하고, 못 읽은 파일·건너뛴 파일·짝을 못 지은 파일을 전부 적어 둡니다.

## 4) 종료코드 (스크립트에서 쓸 때)

| 코드 | 의미 |
|---|---|
| 0 | 치명 0건 · 판정불가 0건 |
| 1 | 봉투가 구세대인 쌍이 있음 |
| 2 | 판정 없이 거절 — 봉투 미특정 · 경로 문제 · 인자 값 오류 · `--inspect` |
| 3 | 판정 불가 — 읽지 못한 파일/폴더 · 비교한 쌍 0 · **이름이 겹쳐 판정 못 한 파일 있음** · `[판정불가]` 쌍 있음 · 커버리지 미달. **3이 1보다 우선** |

`[판정불가]`(내용은 다른데 수정시각으로 방향을 못 정함)가 하나라도 있으면 **3**입니다.
`cp -p`·Dropbox·rsync 는 수정시각을 그대로 복사하므로, 그 상황에서 `0`(깨끗함)이 나가면 안 됩니다.

## 5) 자주 묻는 것

- **왜 고쳐 주지 않나요?** 어느 쪽이 옳은지는 사람만 압니다. 봉투에서 직접 고친 경우가 실제로
  있고(`[경고] 봉투가 더 최신`), 자동 복사는 그 수정을 되돌릴 수 없게 덮어씁니다.
- **PDF 가 매번 다르다고 나오지 않나요?** 생성시각·문서ID를 지우고 비교하므로, 다시 렌더만 한
  파일은 조용합니다. 실제 논문 트리에서 불일치 49건 중 11건이 이 방식으로 걸러졌습니다.
- **`_이전/`·`_superseded/` 는요?** 폴더 이름에 `_이전`·`이전버전`·`superseded`·`archive`·`backup`·`백업`
  이 **들어 있으면**(대소문자 무시) 작업 폴더로 치지 않습니다 — `03_archive`·`Data_Archive`·`백업본_그림`
  도 해당합니다. 작업 폴더와 봉투 **양쪽 모두**에 적용되고, 제외한 목록은 자백에 인쇄됩니다.
  포함하려면 `--include-archives` (권하지 않습니다 — 같은 이름이 둘이 되어 판정이 사라집니다).
- **`.tif`·`.eps`·`.xlsx` 그림/표는요?** 기본 스캔 대상이 아닙니다. 대신 **몇 개를 안 봤는지 자백**하고,
  비교한 쌍이 하나도 없으면 `0`(깨끗함)이 아니라 **`3`(판정 불가)** 로 끝냅니다.
  포함하려면 `--ext tif --ext xlsx` 처럼 지정하세요.
- **60MB 넘는 파일은요?** 건너뛰고 **자백합니다**. 기준은 `--max-bytes` 로 바꿀 수 있습니다.
- **리포트를 논문 폴더 안에 쓰고 싶어요.** 거절합니다(종료코드 2). 입력 트리에 아무것도 쓰지 않는
  것이 이 툴의 약속입니다.
