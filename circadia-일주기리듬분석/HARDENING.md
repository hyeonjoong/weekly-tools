# HARDENING log — circadia (일주기리듬 분석)

Adversarial review of this tool. Each round: an independent panel of reviewer
subagents attacks the tool from first principles; every material finding is
fixed, regression tests are added, and `python3 -m pytest` is re-run to green
before the round closes.

## 라운드 0 — 빌드 시점 자체 점검 (2026-08-27)

빌드 세션이 패널 투입 전에 스스로 잡은 것들과, 설계로 원천 차단한 함정,
그리고 패널이 파고들 만한 알려진 한계를 기록한다.

### 빌드 중 잡은 버그 (패널 전에 수정 완료)

- **일별 지표 CSV 렌더링이 첫 행에서 크래시.** `for key, (val, unit) in
  d.items():` 는 언패킹이 `continue` 가드보다 먼저 실행되므로 `날짜` 문자열
  값에서 `ValueError` 가 났다. `--out-dir` 경로 전체가 죽는 버그. 언패킹을
  루프 본문으로 옮겨 수정, `tests/test_cli.py::test_out_dir_writes_three_artifacts`
  가 회귀를 막는다. (`report.py`)
- **CSV 수식 인젝션 가드가 음수를 오염.** `-` 로 시작하는 셀을 전부 `'` 로
  이스케이프하면 SRI −100, 음수 Δ 같은 정당한 숫자가 문자열이 되어
  statwise 투입이 깨진다. 순수 숫자로 파싱되는 셀은 가드에서 제외.
  (`report.py`, `tests/test_report.py::test_csv_guard_neutralizes_formulas_keeps_numbers`)
- **백색잡음 F 검정 테스트의 시드 함정.** 잡음 시드 5는 우연히 p=0.031 로
  유의하게 나온다(5% 위양성의 실물). 시드를 고르기 전에 5개 시드의 p 를 실측해
  p=0.58 인 시드 1을 채택하고 그 사실을 테스트 주석에 남겼다 — "잡음이면
  비유의"라는 테스트가 스스로 확률적 함정에 빠지지 않도록.
- **심박만 입력 시 활동 코사이너가 심박 적합을 중복 표기.** 활동원이 심박일 때
  같은 적합이 [심박]/[활동] 두 줄로 나오던 것을 걸음 입력이 있을 때만 활동
  코사이너를 내도록 수정. (`cli.py`)

### 설계로 원천 차단한 함정

- **acrophase 부호·시각 변환(코사이너의 고전 함정).** β=A·cosφ, γ=A·sinφ 선형화
  후 `atan2(γ, β)` 를 쓰고, t 를 '하루 중 시각'으로 두어 위상이 곧 시계 시각이
  되게 했다. 기지 위상 3개(03:00·15:00·21:30)를 심은 합성파로 시계 문자열까지
  고정. F 검정 p 는 d1=2 의 폐형식 `(d2/(d2+2f))^(d2/2)` — 근사 없음, 손계산
  리터럴로 대조.
- **짧은 데이터로 IS/SRI 를 조용히 계산하는 것.** 유효일 게이트가 값 출력을
  물리적으로 막는다(`None` + `데이터 부족(N일<5일)`). 게이트는 지표별로 다르다
  — 코사이너·액토그램은 짧아도 계산, IS/IV·SRI 는 거부, 착용률 미달은 exit 3.
- **SRI 경계 아티팩트.** 관측 구간을 자정으로 패딩하면 자정 넘김 수면 이틀이
  100 이 안 나온다(첫날 00:00–07:00 구간의 상태를 '각성'으로 지어내게 됨).
  관측 구간을 [첫 구간 시작, 마지막 구간 종료]로 정의해 동일 스케줄 → 정확히
  100, 완전 반전 → 정확히 −100 이 손계산으로 나오게 했다.
- **IV 의 비연속 차분.** 유효일이 달력에서 붙어 있지 않으면 그 사이 차분은
  '시간 전이'가 아니다 — 연속 run 안에서만 차분하고 리포트에 표기.
- **자정 wrap.** 수면 시각 통계는 '전날 정오 이후 경과시간' 프레임(Roenneberg
  관례)으로 산술 통계를 내고, L5/M10 창은 자정을 넘는 wrap 을 허용하며 둘 다
  경계 테스트가 있다.
- **진단 미끄러짐.** 모든 해석이 ①값 ②출처 있는 참고범위 ③방향 서술 구조를
  강제당하고, 테스트가 리포트·README·사용법을 진단 단정형 금지어 목록으로
  grep 한다(금지어 목록은 소스와 독립적으로 테스트에 하드코딩 — 동어반복 방지).
- **추측 금지 파싱.** 열 후보 2개 → 에러. 타임스탬프 역행·중복·미래·시간대
  혼재 → 에러. epoch 숫자 → 시간대를 추측해야 하므로 에러. 알 수 없는 수면
  단계 라벨 → 에러. 각 케이스에 이유를 설명하는 메시지와 테스트가 있다.
- **벤더 포맷 파편화.** 같은 합성 시나리오를 애플/삼성/핏빗 표기로 3벌 렌더해
  파싱 결과가 완전히 동일함을 테스트로 고정 — 별칭 사전이 아니라 파싱 등가성이
  검증 대상이다.

### 알려진 한계 (패널에 미리 자백)

1. **코사이너는 단일 성분·τ=24h 고정.** 다성분(12h 고조파), 기간 추정, 신뢰
   타원(파라미터 CI)은 없다. zero-amplitude 검정의 잔차 정규성·독립성 가정은
   자기상관 있는 생체 시계열에서 낙관적일 수 있다(README 한계 절).
2. **IS/IV 는 완전한 날만 사용** — 보간을 거부한 대가로, 갭 많은 데이터에서는
   유효일이 급감하고 다른 구현(결측 빈을 프로파일 평균으로 메우는 pyActigraphy
   류)과 값이 다를 수 있다. 방침은 문서화돼 있으나 수치 비교 검증은 안 했다.
3. **SRI 는 기기 수면 판정에 종속** — 기기가 못 잡은 낮잠·조각 수면은 각성으로
   계산된다. 1분 해상도 반올림으로 비정렬 초 단위 구간에서 ±1분 오차 가능.
4. **사회적 시차는 원식 |MSF−MSW|** — MSFsc(수면부채 보정) 아님, '금·토 밤 =
   주말밤' 은 표준 근무 주간 가정. 교대근무·자유직에는 라벨 자체가 틀린다.
5. **야간 심박 강하 참고범위는 ABPM 관례의 준용** — 심박 고유 근거 아님(리포트
   에도 같은 문장이 붙지만, 참고범위를 아예 빼는 게 옳다는 반론이 가능하다).
6. **착용률은 '시간 빈에 표본 1개 이상' 기준** — 한 시간에 1표본만 있어도 그
   시간은 커버된 것으로 친다. 성긴 표본(예: 30분 간격 심박)에서는 실제 착용보다
   후하게 나올 수 있다.
7. **걸음수 기반 IS/IV/RA 는 가속도계 count 문헌과 분포가 다르다** — IV 캐비앗은
   리포트에 넣었지만 정량 보정은 없다.
8. **액토그램 활동 3분위 임계는 기록 전체 기준** — 극단적으로 활동적인 하루가
   있으면 다른 날이 전부 `-` 로 눌린다. 표시 문제일 뿐 지표에는 영향 없음.
9. **기상 전 상승의 +2 bpm 임계는 자체 규칙** — 문헌 확립 기준이 아니라
   결정론을 위한 명시적 선택(코드 주석·리포트에 기준 표기).
10. **성능**: SRI 분 단위 루프와 액토그램 슬롯 스캔은 O(일수×1440) — 42일
    상한에서 문제없지만 수년치 입력이면 느려질 수 있다(v1 은 1~6주 상정).
