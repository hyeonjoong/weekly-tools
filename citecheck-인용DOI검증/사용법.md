# citecheck 사용법 (한글 빠른 안내)

> 원고의 인용/DOI를 Crossref에 대조해 **깨진 DOI · 제목/연도/저자/저널 불일치 · 철회된 논문 · 우려표명(Expression of Concern)/게재철회·삭제/정정 · 이미 정식 출판된 프리프린트 · 중복 DOI/PMID**를 잡아냅니다.
>
> 입력은 **BibTeX(.bib) · RIS(EndNote·Zotero·Mendeley) · CSL-JSON(Zotero·pandoc) · CSV/TSV 표(엑셀·구글시트·Covidence) · 일반 텍스트**를 자동 인식합니다.
> 결과는 화면 텍스트 외에 **JSON · CSV(엑셀) · Markdown(공동저자 공유용)** 으로도 뽑을 수 있습니다.
>
> ⚠️ **인터넷 연결이 필요합니다** (Crossref `api.crossref.org`, DOI 해석기 `doi.org`에 접속).
> 오프라인이면 각 항목이 "Lookup failed" 경고로 표시되고 종료코드는 **3(검증 불가)** 이 됩니다 — 네트워크 장애가 "정상 통과(0)"로 오인되지 않습니다.

## 가장 쉬운 방법
이 폴더의 **`실행.command` 파일을 더블클릭** → 동봉된 예시(`examples/sample.bib`)로 바로 실행되고 사용법이 화면에 뜹니다. (첫 실행 시 Crossref 조회로 몇 초 걸릴 수 있습니다.)

## 터미널에서
`python3 -m citecheck` 형태가 어디서나 동작합니다. (`citecheck`라는 짧은 명령은 파이썬 스크립트 경로가 PATH에 있을 때만 됩니다.)
```bash
# 내 논문 참고문헌 검사 (아래 경로는 예시 — 본인 파일 경로로 바꾸세요)
python3 -m citecheck ~/path/to/references.bib

# EndNote/Zotero의 RIS, Zotero/pandoc의 CSL-JSON도 자동 인식
python3 -m citecheck references.ris
python3 -m citecheck references.json

# 엑셀·구글시트·Covidence로 관리하는 문헌 표(CSV/TSV)도 그대로 검사
#  (열 이름으로 인식 — DOI / PMID / Title / Authors / Year / Journal 등, 순서·대소문자 무관)
python3 -m citecheck included_studies.csv

# 텍스트 참고문헌 목록도 가능
python3 -m citecheck refs.txt --format text

# DOI가 없는 항목을 Crossref에서 찾아 "이 DOI인 것 같다"고 알려줌
python3 -m citecheck refs.bib --suggest-doi

# 조회 결과를 캐시 → 수정하며 반복 실행할 때 즉시 끝남 (기본 7일 후 만료)
python3 -m citecheck refs.bib --cache

# 공동저자에게 공유할 표 만들기 (CSV는 엑셀, Markdown은 PR/노트)
python3 -m citecheck refs.bib --report csv > citations.csv
python3 -m citecheck refs.bib --report markdown

# PMID까지 PubMed로 교차검증 (Crossref가 놓친 철회 + PMID↔DOI 불일치)
python3 -m citecheck refs.bib --pubmed

# 정상 항목까지 모두 보기
python3 -m citecheck refs.bib --verbose

# 경고도 실패로 처리 (제출 전 엄격 점검)
python3 -m citecheck refs.bib --strict

# 신경 쓰지 않기로 한 검사는 코드로 끄기 (--strict를 실제로 쓸 수 있게 해줌)
python3 -m citecheck refs.bib --strict --ignore no-doi,correction
python3 -m citecheck --list-checks   # 끌 수 있는 검사 코드 전체 보기
```

## 결과 읽는 법
- `✓` 정상 — Crossref 기록과 일치
- `!` 경고 — 제목/연도/저자 불일치, DOI 없음, 중복 DOI, **정정(correction/erratum)이 나온 논문**, **이미 정식 출판된 프리프린트**, 또는 Crossref엔 없지만 해석은 되는 DOI (확인 권장)
- `✗` 오류 — DOI가 어디서도 안 열림, 또는 Crossref가 **철회(retraction) · 우려표명(expression of concern) · 게재철회(withdrawal) · 삭제(removal)** 로 표시한 논문

### 새로 추가된 검사 (임상/약리 연구자에게 특히 중요)
- **우려표명·게재철회·정정**: Crossref의 Crossmark 정보를 읽어, 인용한 논문에 우려표명이 붙었는지(오류), 정정/erratum이 나왔는지(경고)를 알려줍니다. 임상시험 논문의 수치가 정정된 줄 모르고 인용하는 사고를 막습니다.
- **프리프린트 → 정식 출판본**: medRxiv/bioRxiv 프리프린트를 인용했는데 이미 학술지에 게재됐다면 그 DOI를 알려줍니다 (심사 과정에서 수치가 바뀌는 경우가 많아 중요).
- **`--suggest-doi`**: DOI가 없는 항목을 제목·저자·연도로 Crossref에서 검색해 **확실한 경우에만** DOI를 제안합니다. 제목 92% 이상 일치가 기본 조건이고, 여기에 **세 가지 배제 조건**이 있습니다 — ① 연도가 서로 다르면 제외(같은 제목의 다른 연도 논문이 흔함), ② 제1저자 성이 다르면 제외, ③ 제목이 4단어 미만이면 제외(`title={Editorial}` 같은 제목은 100% 일치해도 논문을 구별하지 못함). 양쪽 다 값이 있을 때 **서로 어긋나는 경우만** 배제하며, 한쪽이 비어 있다고 배제하지는 않습니다. 틀린 DOI를 자신 있게 알려주는 것이 더 나쁘므로 애매하면 아예 침묵합니다 — **제안된 DOI는 붙여넣기 전에 함께 표시되는 논문 정보를 꼭 눈으로 확인하세요.**
  또한 **찾아낸 논문이 철회된 경우에는 인용을 권하지 않고 오류로 알려줍니다.** DOI를 아예 안 쓴 참고문헌이라도 "이 논문은 철회됐다"는 사실을 잡아낼 수 있는 유일한 경로입니다.
- **`--ignore` / `--list-checks`**: 모든 검사 결과에 `retracted`, `no-doi`, `title-mismatch` 같은 **코드**가 붙습니다(JSON 출력과 CSV의 `codes` 열에도 나오므로 CI에서 문장 대신 코드로 판단할 수 있습니다). `--strict`는 원래 실무에서 쓰기 어려웠습니다 — 실제 논문은 DOI가 없는 단행본·진료지침·제품설명서를 반드시 인용하므로 항상 실패했기 때문입니다. 이제 `--ignore no-doi,correction`처럼 끌 검사를 지정하면 제출 전 게이트로 실제로 쓸 수 있습니다. `--ignore`는 **보고만** 숨길 뿐 조회를 건너뛰지 않으며, 오타 난 코드는 조용히 무시하지 않고 사용법 오류(종료코드 2)로 알려줍니다. 단 **`lookup-failed`는 끌 수 없습니다** — 이는 인용이 틀렸다는 뜻이 아니라 **조회 자체가 안 됐다**는 뜻이라서, 숨기면 오프라인 실행이 "정상 통과"로 보고되기 때문입니다(이 도구가 절대 하지 않겠다고 약속한 바로 그것). 출력은 **오류 → 경고 → 정상** 순으로 정렬되어, 참고문헌 200개에서도 철회 논문이 "DOI 없음" 경고 60줄에 묻히지 않습니다.
- **`--cache`**: 조회 결과를 `~/.cache/citecheck/lookups.json`에 저장해 재실행이 즉시 끝납니다. **기본 7일 후 만료**되는데(`--cache-ttl`로 조정), 이는 의도적입니다 — 새로 철회된 논문을 놓치면 안 되기 때문입니다. 캐시는 속도만 바꿀 뿐 판정을 바꾸지 않으며, 캐시 파일이 깨졌거나 못 써도 그냥 캐시 없이 정상 동작합니다.

종료코드: `0` 정상 · `1` 오류(또는 `--strict`에서 경고) · `2` 입력 문제(파일 없음/참고문헌 없음) · `3` 조회 실패로 검증이 불완전(오프라인 등 — 일부 항목은 검증됐을 수 있음).
오류(`✗`)가 하나라도 있으면 종료코드 1 → 제출 전 점검 스크립트로도 쓸 수 있습니다.
(철회 탐지는 기본적으로 Crossref가 표시한 경우만 잡히며, Crossref의 철회 수록이 완전하지 않습니다. `--pubmed`를 붙이면 PMID가 있는 항목을 PubMed로도 조회해 Crossref가 놓친 철회("Retracted Publication")와 PMID↔DOI 불일치를 추가로 잡습니다(인터넷 필요, 조회 실패 시 종료코드 3).
저널 불일치 검사는 ISO-4 약어("N Engl J Med")와 대문자 약칭("NEJM", "JAMA", "BMJ", "PNAS")과 관사("The")를 모두 감안하므로 흔한 표기는 오탐하지 않습니다.
텍스트/일반목록 모드에서는 저자·연도 추정이 부정확해 저자·연도·저널 비교를 생략하고, DOI 해석·철회·"인용문이 실제 논문 제목을 언급하는지"(=DOI 뒤바뀜 탐지)만 검사합니다. 정밀한 제목/연도/저자/저널 대조가 필요하면 BibTeX·RIS·CSL-JSON 같은 구조화된 파일을 쓰세요.)
