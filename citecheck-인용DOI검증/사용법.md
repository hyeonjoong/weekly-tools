# citecheck 사용법 (한글 빠른 안내)

> 원고의 인용/DOI를 Crossref에 대조해 **깨진 DOI · 제목/연도/저자/저널 불일치 · 철회된 논문 · 중복 DOI/PMID**를 잡아냅니다.
>
> 입력은 **BibTeX(.bib) · RIS(EndNote·Zotero·Mendeley) · CSL-JSON(Zotero·pandoc) · 일반 텍스트**를 자동 인식합니다.
> 결과는 화면 텍스트 외에 **JSON · CSV(엑셀) · Markdown(공동저자 공유용)** 으로도 뽑을 수 있습니다.
>
> ⚠️ **인터넷 연결이 필요합니다** (Crossref `api.crossref.org`, DOI 해석기 `doi.org`에 접속).
> 오프라인이면 각 항목이 "Lookup failed" 경고로 표시되고 종료코드는 **3(검증 불가)** 이 됩니다 — 네트워크 장애가 "정상 통과(0)"로 오인되지 않습니다.

## 가장 쉬운 방법
이 폴더의 **`실행.command` 파일을 더블클릭** → 동봉된 예시(`examples/sample.bib`)로 바로 실행되고 사용법이 화면에 뜹니다. (첫 실행 시 Crossref 조회로 몇 초 걸릴 수 있습니다.)

## 터미널에서
`python3 -m citecheck` 형태가 어디서나 동작합니다. (`citecheck`라는 짧은 명령은 파이썬 스크립트 경로가 PATH에 있을 때만 됩니다.)
```bash
# 내 논문 참고문헌 검사 (아래 경로는 예시 — 본인 파일 경로로 바꾸세요)
python3 -m citecheck ~/path/to/references.bib

# EndNote/Zotero의 RIS, Zotero/pandoc의 CSL-JSON도 자동 인식
python3 -m citecheck references.ris
python3 -m citecheck references.json

# 텍스트 참고문헌 목록도 가능
python3 -m citecheck refs.txt --format text

# 공동저자에게 공유할 표 만들기 (CSV는 엑셀, Markdown은 PR/노트)
python3 -m citecheck refs.bib --report csv > citations.csv
python3 -m citecheck refs.bib --report markdown

# PMID까지 PubMed로 교차검증 (Crossref가 놓친 철회 + PMID↔DOI 불일치)
python3 -m citecheck refs.bib --pubmed

# 정상 항목까지 모두 보기
python3 -m citecheck refs.bib --verbose

# 경고도 실패로 처리 (제출 전 엄격 점검)
python3 -m citecheck refs.bib --strict
```

## 결과 읽는 법
- `✓` 정상 — Crossref 기록과 일치
- `!` 경고 — 제목/연도/저자 불일치, DOI 없음, 중복 DOI, 또는 Crossref엔 없지만 해석은 되는 DOI (확인 권장)
- `✗` 오류 — DOI가 어디서도 안 열림, 또는 Crossref가 **철회**로 표시한 논문

종료코드: `0` 정상 · `1` 오류(또는 `--strict`에서 경고) · `2` 입력 문제(파일 없음/참고문헌 없음) · `3` 조회 실패로 검증이 불완전(오프라인 등 — 일부 항목은 검증됐을 수 있음).
오류(`✗`)가 하나라도 있으면 종료코드 1 → 제출 전 점검 스크립트로도 쓸 수 있습니다.
(철회 탐지는 기본적으로 Crossref가 표시한 경우만 잡히며, Crossref의 철회 수록이 완전하지 않습니다. `--pubmed`를 붙이면 PMID가 있는 항목을 PubMed로도 조회해 Crossref가 놓친 철회("Retracted Publication")와 PMID↔DOI 불일치를 추가로 잡습니다(인터넷 필요, 조회 실패 시 종료코드 3).
저널 불일치 검사는 ISO-4 약어("N Engl J Med" = "The New England Journal of Medicine")와 관사("The")를 감안하므로 흔한 약어 표기는 오탐하지 않습니다.
텍스트/일반목록 모드에서는 저자·연도 추정이 부정확해 저자·연도·저널 비교를 생략하고, DOI 해석·철회·"인용문이 실제 논문 제목을 언급하는지"(=DOI 뒤바뀜 탐지)만 검사합니다. 정밀한 제목/연도/저자/저널 대조가 필요하면 BibTeX·RIS·CSL-JSON 같은 구조화된 파일을 쓰세요.)
