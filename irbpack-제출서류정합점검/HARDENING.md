**기획서 표와 실측이 다른 점(정직하게 남긴다).** 기획서는 연구계획서가 `2회 방문`이라고
적었지만, 실제 문장은 `단계별 1~2회 방문 (소아 검사의 경우 다회기 허용)` 이었다. 그래서
보호자용 설명문의 `1회 또는 다회기 방문` 은 계획서가 허용한 범위 **안**이고, 범위 밖으로
나가는 것은 **CRF 의 Visit 1~6 회기 폼**이다. 툴은 방문·회기 항목을 여전히 **치명**으로
올리되, 값을 말한 문서 5곳을 전부 나란히 인쇄해 사람이 3-way 그림을 보게 한다.
(기획서 숫자를 그대로 하드코딩하지 않고 실제 문서를 다시 읽어 확인한 결과다.)

### 빌드 중 스스로 잡은 오탐 3건 (합성 예제가 잡아냈다)

1. `1회 방문 소요시간은 90분` 의 **'1회'를 방문 횟수로** 세고 있었다 → `_PER_VISIT_TAIL` 로 배제.
2. CRF 의 `Visit 1·2·3` 을 `회기폼 1-3회` 라는 **다른 단위**로 만들어 계획서 `3회` 와 충돌시켰다
   → 같은 단위(`3회`)로 정규화하고, 방문 횟수에만 **범위 포괄**(`1~2회` 안의 `2회`)을 적용.
3. 소요시간에도 범위 포괄을 적용했더니 실제 패킷에서 `총 약 1~3시간` 이 `60~90분 vs 90~180분`
   불일치를 **통째로 삼켰다** → 범위 포괄은 방문 횟수 하나로 축소. 연령·소요시간은 적힌 그대로 대조.

| **P2-1** | 절 단위 게이트를 넣으면서 **`검사 소요시간: 약 60분`·`개인정보 보관기간: 3년` 형태가 통째로 사라졌다** — 게이트 단어는 앞 절에, 숫자는 뒤 절에 남았다. 값을 말하는 문서를 오히려 "대응 값이 없습니다"로 인쇄했다(침묵보다 나쁘다) | 자기 값이 없는 게이트 절은 **다음 절까지 게이트를 넘긴다**(레이블→값). 이미 값을 가진 절은 넘기지 않는다(옆 문장의 숫자를 끌어오지 않도록) |

### 나머지 (전부 고침)

- **P2-3** 서술형 연령(`스무 살에서 예순네 살`)이 주제 접촉에도 안 걸려 조용히 넘어갔다 — README 는 "못 읽었다고 말한다"고 약속하고 있었다. → 한글 수사 연령 패턴을 주제 판정에 추가(값으로 읽지는 못하되 **자백은 한다**).
- **P2-4** `채취한 검체는 냉장고에 보관한다` 가 개인정보 보관기간 주제로 잡혀 경고가 나갔다. → 보관 주제를 `개인정보·기록·자료·문서 … 보관/폐기` 문맥으로 좁히고, 보상 주제에서 맨 '지급' 을 뺐다.
- **P2-5** 개정 축에서 짝을 못 찾은 부속문서가 **아무 말 없이** 빠졌다. → "짝을 찾지 못해 보지 못한 문서" 를 자백에 인쇄.
- **P2-6** 접기 계산이 행 단위라, 이미 펼쳐 보여 준 문서가 접힌 목록에도 이름이 올랐다. → 문서 단위로 접는다.
- **P2-7** 4분할된 버전 대조단위는 문서당 값이 하나라 부속문서 규칙이 닿지 않는다(무해한 방어적 설정 — 주석으로 남김). 요약 줄 길이는 부속문서 규칙 정리로 짧아졌다.
